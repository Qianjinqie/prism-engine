## Что это

Prism Engine — это медиа-движок, написанный на Rust без единой сторонней кодовой зависимости и охватывающий модули изображений, аудио, геометрии, физики, рендеринга, DSL и другие. Все 103 зависимости — это `path`-зависимости внутри данного репозитория: ни зависимости от сети, ни пакетного менеджера, ни рисков цепочки поставок.

Используется **распространение исходников одним файлом**: весь движок (481 файл, 26 crate) объединён в один UTF-8 текстовый файл `prism-engine-v1.0-source.txt`. Имея этот файл, вы можете локально восстановить дерево каталогов, в точности совпадающее с репозиторием.

## Почему распространение одним файлом

- **Аудируемость**: один текстовый файл — читается глазами, поддерживает `diff` и проверку хэша; опубликованная версия заморожена.
- **Воспроизводимость**: упаковка детерминирована — SHA-256 двух упаковок при одинаковом входе полностью совпадает.
- **Портативность**: не нужно клонировать огромный репозиторий; один файл передаётся по почте или в чате, а сборку можно восстановить даже офлайн.
- **Компромисс**: распространение одним файлом жертвует удобством «просмотра кода прямо на GitHub» в обмен на детерминированность «весь код в одном файле и проверяется побайтово». После распаковки вы получаете обычный Cargo workspace, ничем не отличающийся от рядового Rust-проекта.

## Быстрый старт

Предварительные требования: установите [Rust](https://www.rust-lang.org/) (с `cargo`) и [Node.js](https://nodejs.org/) 18+.

```bash
# 1. Скачайте файл prism-engine-v1.0-source.txt из репозитория и сохраните его локально
# 2. Откройте его в текстовом редакторе и сохраните скрипт Node.js, расположенный
#    между "UNPACK SCRIPT BEGIN" и "UNPACK SCRIPT END", в отдельный файл unpack.cjs в том же каталоге
# 3. Запустите распаковку (несколько секунд, восстанавливает 481 файл)
node unpack.cjs
# 4. Перейдите в восстановленное исходное дерево и запустите полный прогон тестов
cd src/..
cargo test --workspace --release
# Ожидаемый результат: 3271 passed / 0 failed
```

После распаковки вы получаете стандартный Cargo workspace (26 crate в `src/`); дальнейшие команды `cargo` такие же, как в обычном Rust-проекте.

> Цепочка проверки wasm на мобильных устройствах: `rustup target add wasm32-unknown-unknown`, затем `cargo build -p prism-core --target wasm32-unknown-unknown`.

| Путь | Описание |

## Сборка и тестирование

```bash
# Дымовой прогон всего репозитория (release, рекомендуется)
cargo test --workspace --release
# Эквивалентный псевдоним
cargo xtest
# Быстрая проверка одного crate
cargo test -p prism-core --release
```

- Полный прогон тестов: **3271 passed / 0 failed** (проверено фактическим запуском на свежераспакованном дереве).
- Гейты: 14, включая защиту от фантомной записи (G1~G4), сканирование гигиены open source (0 внутренних следов), самопроверку соответствия (9/9), обратную самопроверку соответствия (8/8, при нарушении всегда красный), цепочку сборки wasm32.

Запуск гейтов локально (требуется Node 18+):

```bash
node tools/ghost_guard.mjs --check        # Защита от фантомной записи: G1 дубликаты определений / G2 строгое надмножество / G3 документация с начала строки / G4 компиляция
node tools/hygiene_scan.mjs               # Гигиена open source: должно сообщить «чисто (0 внутренних следов)»
node tools/compliance_check.mjs           # Самопроверка соответствия: должно пройти 9/9
node tools/compliance_check.mjs --self-test   # Обратная самопроверка: должно дать красный результат, доказывая разрешающую способность критериев
```

## Соответствие

Движок гарантирует **нулевую зависимость от стороннего кода**, и это подтверждено самопроверкой:

- **C1 нулевая зависимость от стороннего кода**: все 103 зависимости — `path`-зависимости данного репозитория; нет `build.rs`, нет инструкций нативной линковки, `Cargo.lock` фиксирует 26 пакетов этого репозитория.
- **C2 полнота реестра активов**: у 5 записей основной таблицы активов заполнены все поля, статусы самостоятельной разработки заданы контролируемым словарём; полный текст шрифтовой лицензии OFL 1.1 находится вместе со шрифтом в `src/prism-text/font_data/LICENSE`.
- **C3 заявление о принадлежности сторонних компонентов**: `Compliance/THIRD-PARTY-NOTICES.md` присутствует и чётко разграничивает «активы-данные ≠ кодовые зависимости».

> Примечание: в составе репозитория распространяются **исходники**. Шрифтовые активы (подмножество Prism Sans SC) лицензируются по SIL OFL 1.1, **полный текст лицензии лежит вместе со шрифтом в** `src/prism-text/font_data/LICENSE`; источники активов и лицензионный реестр см. в `Compliance/assets/资产登记.md`.
