## 4. GPU 四后端真实状态（订正旧账本的「web 骨架」印象派）

| 后端 | 行数 | 弄到哪了 |
|---|---|---|
| CPU 参考后端 | — | ✅ **唯一真能出图**（软件光追，全平台兜底） |
| Vulkan | 4,383 | 探测链（手写 FFI 零依赖）+ **自研 SPIR-V 发射器**（发射/校验/反汇编/对拍）就绪；**缺渲染管线** |
| Metal | 764 | 探测链（仅 macOS）+ MSL 双份源约定 + 1 个样例；**缺管线与其余 kernel** |
| WebGPU | 7,655 | 浏览器绑定厚实，wasm/移动测试链在用 |

三个 GPU 后端全部刻意 `is_available() = false`——「探测到设备 ≠ 能出图」的诚实纪律。
**最短路径：Vulkan 先通（现成件最多）→ Metal 按双份源跟上 → WebGPU 收尾（分发面）。**

## 6. 派工规则（五条）

1. **每波 3–5 个 agent 同时干**，各管一摊，文件互不打架（谁的文件谁写）。
2. **每个 agent 发完整任务书**：干什么、改哪些文件、验收标准、自跑测试——不靠猜上下文。
3. **QA 不每波过堂**：攒 1–2 波批量审一次，0.5–1 小时全审完（作者工作习惯）。
4. **深水区先文档后码**：环推进必须先出数学配置文档再写实现，禁止跳步。
5. **硬门槛一道**：全绿回归（约 6 分钟）+ 两遍渲染 md5 一致——不过不交付。
