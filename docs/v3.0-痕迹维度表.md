# V3.0 W3 痕迹维度表（§3.4 定桩冻结）

> 本表是 `docs/v3.0-路线图.md` §3.4 要求的**逐行冻结**产物，也是 §3.5
> V1–V6 判据的执行体。每一行都给「维度 | 引擎触点 | 注入点（生成源）|
> dsl 字段 | 强度范围 | analytic 值」，**不写「待核验」**。
>
> 定桩依据：§3.1 诊断（塑料感在生成逻辑太解析、太完美、无介质，不在表面装饰）、
> §3.2 双一等档、§3.3 两条治本禁令、§6 红线 1/3/4、§8 D-30/31/32。
>
> **靶子是声明一致性 + 实现合规，不是主观审美**（D-31）。`analytic` 是合法
> 交付物，不因「不够搓」被判失败；`crafted` 才允许注入痕迹。用户要
> 「只有运动带呼吸、几何绝对匀质」必须能表达 ⇒ 每族独立开关 + 强度，都能设 0。

### 2.2 信号键与独立开关（D-30）

```
w3.<族>.strength    = dim.strength / 1000            （定点换算）
w3.<族>.noise       = dim_noise(plan, 族, frame, seed, node_id) ∈ [0,1)
w3.<族>.signal      = (noise * 2 - 1) * strength      （注入量，analytic 恒 0）
w3.mode             = 1.0_f32（仅 crafted 写）
w3.frame            = frame（movie.rs 渲染前补）
```

- **关闭族不写任何键**：`enabled false` 且 `strength 0` ⇒ 该族绝对匀质，
  `WiringFrame` 里连 `signal=0` 都不出现（V1「零意外噪点」）。
- `w3_eval` 的六族凭证**仍调用该族既有 API**（digest 非空）以证明接线齐全，
  但凭证的 `param_keys` 对关闭族为空——这是正确语义，不是漏接。
- 六族既有求值器接线（`prism-app/src/w3_eval.rs`）把 `w3.<族>.signal`
  作为**实参**交给既有 crate API，把真实返回值写进 `digest`；语言层 /
  编排层不复制任何数学 / 渲染 / 质感求值（红线 1）。

### 2.3 两条治本禁令 → 静态门禁（§3.3）

| 禁令 | 门禁 | 错误码 | 与档位关系 |
|---|---|---|---|
| ① 禁止帧后贴皮（出帧后贴 grain / 滤镜 / 色调模板） | `finish::posthoc_gate`（`finish.rs:536`）全文查 `POSTHOC_BLOCK_MARKERS = ["post {", "post{", "postfx"]`；`finish` 块体内另查 `FORBIDDEN_POSTHOC_TOKENS` | `P9011` + 行号 + 三段式 | **analytic 同样判红**，不因选匀质失效 |
| ② 不规则必须种子化确定性噪声（零真随机 / 零系统时间 / 零平台 libm） | `finish::true_random_gate`（`finish.rs:517`）全文查 12 个禁用 token（`SystemTime` / `thread_rng` / `getrandom` / `rand::` / `now()` / …） | `P9012` + 行号 + 三段式 | **analytic 同样判红** |

- 两条门禁都接在 `compile_v3` 的 `codegen_v3` 之后（`lib.rs:380/381`），
  是**编译期全文检查**；实现级测试另对 `finish.rs` / `wiring.rs` / `movie.rs`
  / `w3_eval.rs` 源码做静态检出，确认注入链路不含 `eval_window` /
  `TileEffect` / 真随机 API。
- 所有不规则只走 `prism_core::eval::hash_mix` / `hash_mix_unit_f32`
  或 `prism_noise::pcg::hash2_f32`（`generators.rs:145` 同一基元）；
  **零真随机、零系统时间、零平台 libm、零线程**，两跑逐字节一致。

## 3. 错误码表（P9xxx，W3 观感档位码段，与 P1xxx–P8xxx 互不冲突）

| 码 | 含义 | 三段式建议 |
|---|---|---|
| `P9001` | `// prism-dsl 2` 漏填 `finish`（不替用户默认选档） | 显式写 `finish = analytic` 或 `finish = crafted { ... }`；旧文件按版本契约恒等 analytic |
| `P9002` | 非法档位 / 缺 `=` / `finish.mode` 非法 | 只接受 `analytic` / `crafted` |
| `P9003` | crafted 语法 / 漏族 / 未知族 / 缺 `}` / rubric 不全 | 六族逐族写 `<族> enabled true\|false strength 0..1000` |
| `P9004` | enabled 非 true/false / strength 非整数或超 `[0,1000]` / 关闭却非零 / 数值非有限 | 定点整数；关闭时 strength 必须 0；不钳制、不取默认 |
| `P9005` | `finish` / 维度 / rubric 项重复声明 | 一份文档只声明一次 |
| `P9006` | 声明 `crafted` 却六族全 0（声明与产物不符，V2 负控③） | 至少一族 `enabled true strength > 0`；要匀质请显式选 `analytic` |
| `P9007` | `analytic` 档带痕迹维度块 / rubric | 删掉块，只写 `finish = analytic` |
| `P9011` | 帧后贴皮（§3.3 禁令 1，V2 负控①） | 六族痕迹必须在渲染前链路注入 |
| `P9012` | 真随机 / 系统时间 / IO 随机源（§3.3 禁令 2，V2 负控②） | 抖动与呼吸只走 hash_mix / pcg::hash2_f32 |

全部错误由 `finish::finish_err` 统一构造：`[Pxxxx] 第 N 行：什么事\n  建议：怎么改`
（在哪 / 什么事 / 怎么改），**带行号**。错误注入集 17 例逐码断言见
`crates/prism-dsl/tests/w3_finish.rs::error_injection_set_p9001_to_p9012_all_fail_with_line_and_three_parts`。
