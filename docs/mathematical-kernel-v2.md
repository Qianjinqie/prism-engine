## 2. DSS 的形式化

### 2.1 定义

**定义 2.1（选择问题，selection problem）**。一个选择问题是一个四元组

  Q = (X, B, p, Φ)

其中 X ≠ ∅ 是候选空间，B ≠ ∅ 是参数空间（选择条件的空间），p : X → B 是满射
（商映射：把候选送到它满足的条件），Φ : X × B → ℝ 是带参数的泛函（代价）。
对 b ∈ B，记 F_b = p⁻¹(b) 为 b 的**纤维**，Φ_b(x) = Φ(x, b) 为纤维上的泛函。

*注 2.1.1*。前作 CCS/SCA 的公理化在对象层面（商对象、凸锥）展开；DSS 的公理化在
**选择规则**层面展开：同一个 (X, B, p) 配不同 Φ 给出不同选择问题。这是 DSS 能同时
装下 setup A（Φ 是在轨道上变化的 code）与 setup B（Φ 对数据重标号等变）的原因，
见 §2.4。

**定义 2.2（截面，section）**。选择问题 Q 的截面是一个映射 s : X → X，满足对一切
x ∈ X：

  (S1) p(s(x)) = p(x)   （截面值落在 x 的纤维中）；
  (S2) Φ_{p(x)}(s(x)) ≤ Φ_{p(x)}(y) 对一切 y ∈ F_{p(x)}  （截面值是纤维上的极小元）。

即 s(x) = argmin_{y ∈ F_{p(x)}} Φ_{p(x)}(y)。截面是 X 上的**自映射**（不是 B → X 的
右逆），这样 T1 的完全不变性陈述类型一致，且幂等性成为可证命题（定理 2.3(ii)）。

*注 2.1.2（与「右逆截面」的关系）*。若取 s 在 B 上的限制 s̄ = s|_{p(X)} = s（p 满），
则 p ∘ s = id_B，即通常意义的截面（右逆）。本报告采用自映射形式，两者信息等价，
但自映射形式使「s(x) = s(y) ⟺ p(x) = p(y)」（T1）类型一致、可直接陈述。

**例 2.1（三个原型实例，后文 §3 逐一展开）**。
(a) P3 图元规范序：X = 图元序列空间（排列），B = 键的多重集，p = 多重集投影，
    Φ = (Morton 码, 内容摘要) 字典序；
(b) P4 水位分配：X = ℝᵐ₊，B = (先验 θ, 预算 B₀)，p(x) = (Σxᵢ, ·)，
    Φ(x, b) = Σ Dᵢ(xᵢ; θᵢ)；
(c) P2 遍历 argmin：X = 命中候选 (t, orig, slot)，B = 查询，p = 查询索引，
    Φ = (t, orig) 字典序。

### 2.2 公理

**D1（纤维唯一极小，well-definedness）**。对每个 b ∈ B，argmin_{x ∈ F_b} Φ_b(x)
是单元素集。等价地：Φ_b 在 F_b 上不存在两个不同的极小元。

**D2（精确可复现，exact reproducibility）**。截面 s 在目标计算模型中可求值，且求值
过程位级可复现：同一输入在同一模型上重复求值得到逐位相同的输出。

**D3（一阶可证性，first-order certificate，可选公理）**。当 p 与 Φ 携带线性/凸结构
时，截面由一阶条件刻画：存在乘子 λ 使 s 是某个约束优化问题的 KKT 点，且该条件对
s 为充分。

*注 2.2.1（编号映射与 D2/D3 的地位）*。任务书的公理编号与本报告的对应：
任务书 D1（纤维唯一极小）= 本报告 **D1**；任务书 D4（可计算性/精确性）= 本报告
**D2**；任务书 D5（一阶条件/余向量）= 本报告 **D3**；任务书 D2（幂等）、D3（等变）
在本报告中**降为定理**（定理 2.3(ii) 与定理 2.4）：幂等由 D1 一步推出，等变由
D1 + 兼容性推出。把可证命题列为公理会虚增公理体系的内容、掩盖证明责任——这是
公理化的常识纪律（能证不公设）。D3 之所以保留为公理，是因为「一阶条件存在」
不能从 D1 推出（组合 argmin 无一阶条件），它是**触发式**的：仅当实例携带凸结构时
启用；此时 T3–T5 全部生效，否则 T3–T5 在该实例上**空转**而非**失效**。这一
「可选性」是 §6 中解释前作 §5.3 所观察到的「空转」现象的正确位置。

### 2.3 定理与证明

以下七条定理构成 DSS 的内核定理集。每条给出完整证明。

---

**定理 2.3（T1，完全不变性与分解等价性）**。设 Q = (X, B, p, Φ) 满足 D1，s 为截面。则

  (i)（完全不变性）对一切 x, y ∈ X：s(x) = s(y) ⟺ p(x) = p(y)；
  (ii)（幂等）s(s(x)) = s(x)；
  (iii)（分解等价性）对任意映射 F : X → Y：F 过 p 分解（即存在 F' : B → Y 使
       F = F' ∘ p）⟺ F 过 s 分解（存在 F'' : X → Y 使 F = F'' ∘ s）；
  (iv)（最紧代表元）s 是满足 (i) 的最「细」的商映射的提升：任何过 p 分解的 F
       必然过 s 分解，故「s 看到的差异」恰是「p 看到的差异」。

*证明*。
(i) ⇒：设 s(x) = s(y)。由 (S1)，p(x) = p(s(x)) = p(s(y)) = p(y)。此方向不用 D1。
    ⇐：设 p(x) = p(y)。则 F_{p(x)} = F_{p(y)}，由 (S2) 与 D1，s(x) 与 s(y) 同是
    该纤维的唯一极小元，故 s(x) = s(y)。此方向用 D1。
(ii) 由 (S1)，p(s(x)) = p(x)，故 s(x) ∈ F_{p(x)}；由 (S2) 与 D1，s(x) 是
     F_{p(x)} 的唯一极小元；而 s(s(x)) 依定义是 F_{p(s(x))} = F_{p(x)} 的唯一
     极小元。故 s(s(x)) = s(x)。
(iii) ⇒：设 F = F' ∘ p。取 F'' = F' ∘ p : X → Y，则
      F''(s(x)) = F'(p(s(x))) = F'(p(x)) = F(x)，即 F = F'' ∘ s。
      ⇐：设 F = F'' ∘ s。若 p(x) = p(y)，由 (i) 得 s(x) = s(y)，故
      F(x) = F''(s(x)) = F''(s(y)) = F(y)，即 F 在 p 的纤维上常数，从而过 p 分解
      （取 F'(b) = F(x) 对任意 x ∈ F_b，良定义）。
(iv) 由 (iii) 直接得出：过 s 分解的映射类 = 过 p 分解的映射类（(iii) 是双向的），
     而 s 比 p 细（p = p ∘ s），故 s 是不改变「可分解映射类」的最细提升。∎

*注 2.3.1*。(i) 的 ⇐ 方向是 D1 不可省的原因：若无唯一性，同一纤维可有多个极小元，
「s(x) = s(y)」不再被 p(x) = p(y) 决定。§3.1（P3）与 §5 的 NC-D2 将展示 D1 失效的
精确后果（规范形不唯一）。

**定理 2.4（T2，自然性）**。设 Q 满足 D1，s 为截面。

  (T2a，纤维内自然性) 设 Ψ : X → X 满足 (i) p ∘ Ψ = p（Ψ 保持纤维）且
      (ii) Φ(Ψx, b) = Φ(x, b) 对一切 x 与 b = p(x)（Ψ 在纤维上保持泛函）。
      则 Ψ ∘ s = s ∘ Ψ（事实上 Ψ(s(x)) = s(x) = s(Ψ(x))）。
  (T2b，跨纤维等变性) 设 T : X → X 与 τ : B → B 是双射，满足
      (i) p ∘ T = τ ∘ p（协变）且 (ii) Φ(Tx, τ(b)) = Φ(x, b)（泛函协变）。
      则 s ∘ T = T ∘ s（即对一切 x ∈ X：s(T(x)) = T(s(x))）。等价地，对提升
      s̄ : B → X（s̄(b) = s(x) 对任意 x ∈ F_b，由 T1(i) 良定义），有
      s̄(τ(b)) = T(s̄(b))——截面与数据重标号等变。

*证明*。
(T2a) 先证 Ψ(s(x)) = s(x)：由 p ∘ Ψ = p 与 (S1)，p(Ψ(s(x))) = p(s(x)) = p(x)，
      故 Ψ(s(x)) ∈ F_{p(x)}；由 (ii)，Φ(Ψ(s(x)), p(x)) = Φ(s(x), p(x))，而依
      (S2) 后者是 F_{p(x)} 上的最小值；故 Ψ(s(x)) 是 F_{p(x)} 的极小元；由 D1
      唯一性 Ψ(s(x)) = s(x)。再证 s(Ψ(x)) = s(x)：由 (i)，p(Ψ(x)) = p(x)，故
      F_{p(Ψ(x))} = F_{p(x)}；s(Ψ(x)) 与 s(x) 依定义同是该纤维的唯一极小元
      （D1），故 s(Ψ(x)) = s(x)。合起来 Ψ(s(x)) = s(x) = s(Ψ(x))，即
      Ψ ∘ s = s ∘ Ψ。
(T2b) 固定 x ∈ X，记 b = p(x)。分四步。
    第一步，T(s(x)) ∈ F_{τ(b)}：p(T(s(x))) = τ(p(s(x))) = τ(b)（协变性 + (S1)）。
    第二步，T(s(x)) 是 Φ_{τ(b)} 在 F_{τ(b)} 上的极小元：对任意 y ∈ F_{τ(b)}，
      因 T 双射且 p ∘ T = τ ∘ p，存在唯一 y' ∈ F_b 使 y = T(y')
      （p(y') = τ⁻¹(p(y)) = τ⁻¹(τ(b)) = b）；由 (ii)，
      Φ(y, τ(b)) = Φ(T(y'), τ(b)) = Φ(y', b) ≥ Φ(s(x), b) = Φ(T(s(x)), τ(b))
      （最后一步：(ii) 正向 + (S2)）。
    第三步，min_{F_{τ(b)}} Φ_{τ(b)} = min_{F_b} Φ_b：由第二步的不等式链
      （它对 F_b 中一切 y' 成立，且 T: F_b → F_{τ(b)} 是双射）直接得出。
    第四步，由 D1，F_{τ(b)} 的 Φ_{τ(b)}-极小元唯一：T(s(x)) = s̄(τ(b))。
    最后，s(T(x)) = s̄(p(T(x))) = s̄(τ(p(x))) = s̄(τ(b)) = T(s(x))。即
    s ∘ T = T ∘ s；B 形式由 s̄ 的定义转写。∎

*注 2.4.1（前作「D3 等变」字面形式的修正）*。任务书给的 D3 字面形式是
s(p(gx)) = g·s(p(x))。在 setup A（p 是轨道映射，p(gx) = p(x)）中，该式退化为
g·s(p(x)) = s(p(x))，即「g 固定每个截面值」——这对位置置换群一般为假（§3.1 将给出
P3 的反例性讨论）。正确陈述是 T2：**截面与一切保持其定义数据（p 与 Φ）的变换可交换**。
setup A 的版本是「保持键的置换固定规范形」（T2a 的实例），setup B 的版本是
「数据重标号等变」（T2b 的实例）。两者是同一自然性原理的两种读法，不是两条公理。

**定理 2.5（T3，等边际证书）**。设 Q 满足 D1 与 D3，且设：F_b 由线性约束
p(x) = b 定义（X = ℝⁿ 或其中的凸集）；Φ_b(x) = Σᵢ fᵢ(xᵢ; b) 为可分凸函数，
各 fᵢ 可微。则截面在 b 处的值 x* = s̄(b) 满足 KKT 条件：存在乘子 λ ∈ ℝᵐ 使

  ∇_x [Φ_b(x) + ⟨λ, p(x) - b⟩] = 0 在 x = x* 处，

即对每个活跃坐标 i：fᵢ'(x*ᵢ; b) = -λᵢ。特别地，所有活跃坐标的边际代价相等。

*证明*。凸可行集上的可微凸函数取极小 ⇒ 一阶条件充分（凸性）。F_b 是线性约束定义的
凸集，Φ_b 凸，故 x* 为极小元 ⟺ 0 ∈ ∂(Φ_b + δ_{F_b})(x*) ⟺ 存在 λ 使
∇Φ_b(x*) + J_p(x*)ᵀλ = 0（线性约束的 KKT，约束规范性由 p 线性保证）。可分性使
∇Φ_b = (fᵢ')ᵢ，逐坐标读出即等边际。∎

*注 2.5.1*。等边际是 P4「等畸变证书」的逐字来源（§3.3）：活跃帧的畸变对比特的
边际全部等于 -λ，故畸变全等。

**定理 2.6（T4，影子价格）**。在 T3 的条件下，设最优值函数 V(b) = Φ_b(s̄(b)) 在
b₀ 处可微，且约束规范性成立。则

  λ = -∇V(b₀)，

即乘子是「预算的影子价格」：每放松一单位约束 bᵢ，最优值改善 λᵢ。

*证明*。包络定理：V(b) = min_x {Φ(x, b) : p(x) = b}。在双利普希茨/规范约束下，
V'(b₀) = ∂Φ/∂b(s̄(b₀), b₀) - J_pᵀλ。对 P4/P6 型实例 Φ 不显含 b（b 只通过约束
进入：Φ(x, b) = Σfᵢ(xᵢ) 不含 b），∂Φ/∂b = 0，故 ∇V = -λ。∎

*注 2.6.1*。前作 OT3（P4 的 λ = -dD*/dB、P6 的 λ = -dMSE/dN）是 T4 的实例；
前作 §7.1 的数值验证（exp18：P4 相对偏差 1.3e-5、P6 含钳位仍成立）承接为本定理的
实例证据，未重跑（见 §8 第二类）。

**定理 2.7（T5，Fenchel 对偶）**。在 T3 的条件下，设 Φ_b(x) = Σᵢ fᵢ(xᵢ)（不显含
b），p 线性。则原问题 min{Φ(x) : p(x) = b} 与对偶问题

  max_{λ} [⟨λ, b⟩ - Σᵢ fᵢ*(⟨λ, aᵢ⟩)]

等价（fᵢ* 为 fᵢ 的 Fenchel 共轭，aᵢ 为 p 的第 i 行/坐标泛函），强对偶成立，
且原问题最优值 = 对偶最优值。

*证明*。标准 Fenchel–Rockafellar：凸函数 + 线性约束 + 相对内点规范 ⇒ 强对偶。
KKT 条件（T3）正是鞍点条件；沿 T3 的等边际方向消去 x 即得对偶形式。∎

*注 2.7.1*。前作 §7.1 第 3 条（P4 的 Fenchel 路线与 KKT 路线一致到 1e-15）是 T5
的实例证据（exp18，承接未重跑）。T5 同时解释了前作 NO-3/OT5 与 Fenchel 路线的
归并：两者是同一定理的两种算法读法。

**定理 2.8（T6，级联与稳定性）**。设 Q₁ = (X, B, p₁, Φ₁)、Q₂ = (X, B, p₂, Φ₂)
为两个选择问题（同一 X, B），截面分别为 s₁, s₂，串行复合 c = s₂ ∘ s₁。

  (i)（级联截面）级联问题 Q₁₂ = (X, B, p₁, Φ₁ + Φ₂) 的截面
      s₁₂(x) = argmin_{y ∈ F_{p₁(x)}} [Φ₁(y, b) + Φ₂(y, b)]（设 D1 对和成立）。
      **串行复合一般不是级联截面**：Φ₁₂(c(x)) ≥ Φ₁₂(s₁₂(x))，且等式一般不成立；
      次优性没有纯间隙界（见下面的反例 2.8.1）。
  (ii)（约束兼容 ⟹ 复合保持约束）若 p₂ ∘ s₁ = p₁（阶段间约束兼容：第一阶段的
      输出天然满足第二阶段的约束前提），则 p₁ ∘ c = p₁，即 c 仍是 p₁ 意义下
      良定义的截面（不需要重新验证 D1：c(x) ∈ F_{p₁(x)} 由链式法则保证）。
  (iii)（条件数）设 γ(x₀) = min_{y ≠ s(x₀), y ∈ F_{p(x₀)}} Φ_{p(x₀)}(y) -
      Φ_{p(x₀)}(s(x₀)) > 0 为间隙（次优与最优之差）。则选择在 x₀ 处的翻转阈值
      是 γ/2（T7），等价地：区分 s(x₀) 与任何竞争点所需的泛函分辨率是 γ/2，
      若 Φ 的动态范围为 R，则所需精度约为 log₂(2R/γ) 位。γ → 0（平局）时
      任何有限精度翻转（T7(iii)）。
  (iv)（复合误差传播）设复合泛函 V = V(σ)（P6 形式，见 §5.4 NC-D4），剖面误差
      σ̂ᵢ = σᵢ(1+δᵢ)。则 dV/V = δ̄_σ + δ̄_{1/σ} + O(δ²)，其中
      δ̄_σ = Σσᵢδᵢ/Σσᵢ（算术加权共模）、δ̄_{1/σ} = Σ(δᵢ/σᵢ)/Σ(1/σᵢ)（调和加权
      共模）；二阶残差被 C·δ² 界住（C 为与 σ 无关的常数，exp22 标定 C ≈ 1）。

*证明*。
(i) s₁₂ 是截面由定义 2.2 直接得出（Φ₁+Φ₂ 在 F_{p₁(x)} 上唯一极小）。
    c ≠ s₁₂ 与无纯间隙界由反例 2.8.1 展示。
(ii) 设 p₂ ∘ s₁ = p₁ 且 p₁ ∘ s₂ = p₁。则
     p₁(c(x)) = p₁(s₂(s₁(x))) = p₁(s₁(x))（第二式用 p₁ ∘ s₂ = p₁ 于点 s₁(x)）
     = p₁(x)（(S1)）。故 c(x) ∈ F_{p₁(x)}，即 c 是 p₁ 意义下的截面。∎
(iii) 即 T7(i) 的逐点形式：2η < γ 不翻转；η ≥ γ/2 可构造翻转（T7(iii) 的
    构造）。精度位数由 2R/γ ≥ 2ᵏ 解出。
(iv) 见 §5.4 NC-D4 的证明与 exp22 的标定（残差/δ² 在 δ ∈ [1e-3, 0.2] 上
    ≤ 0.89）。∎

**反例 2.8.1（串行复合 ≠ 级联最优，且无纯间隙界）**。取 X = ℝ²，B = {0}
（单点），p₁ = p₂ = 常值映射（唯一纤维是全部 X）。设 Φ₁(x) = ½‖x - a₁‖²、
Φ₂(x) = ½‖x - a₂‖²，a₁ = (0,0)、a₂ = (1,0)。则 s₁ = a₁、s₂ = a₂、c = s₂(s₁) = a₂。
级联 Φ₁₂ = Φ₁ + Φ₂ 的唯一极小在 x* = (a₁+a₂)/2 = (0.5, 0)，值 (a₁-a₂)²/4 = 0.25；
Φ₁₂(c) = ½·1 + ½·0 = 0.5。次优差 0.25 > 0。而两阶段各自的「间隙」在此连续
无约束情形下 γ₁ = γ₂ = 0（inf 不可达）——次优性与阶段间隙之间没有可算的依赖
关系。故「两步法 = 联合最优」不成立，「两步法的误差由阶段间隙控制」也不成立；
两步法的正确地位是 (i) 陈述中的「阶段目标各自的稳定近似」。∎

*注 2.8.1*。P6 两阶段（§3.4）是该定理的非平凡实例：p₂ ∘ s₁ = p₁ 与
p₁ ∘ s₂ = p₁ 都成立（估计量不改变预算约束），故 (ii) 适用；其复合的地位由
(iv) 的稳定性刻画（exp22），且如实陈述：**两阶段不是任何单一目标的联合最优
截面**（联合最优是角点解——逐帧 MSE 最优要求好帧多分、时域方差最优要求按
噪声分，两目标冲突时联合极值解落在可行集顶点）。

**定理 2.9（T7，近似截面）**。设 Q 满足 D1，s 为截面，x* = s(x₀)，γ = γ(x₀) > 0
为 x₀ 处的间隙。设 Φ̃ 是 Φ 的近似：|Φ̃(x, b) - Φ(x, b)| ≤ η 对一切 x ∈ F_{b₀}
（b₀ = p(x₀)）。则

  (i)（保持性）2η < γ ⇒ argmin_{F_{b₀}} Φ̃ = argmin_{F_{b₀}} Φ = x*；
  (ii)（值界）Φ(x̃*) ≤ Φ(x*) + 2η，其中 x̃* = argmin Φ̃（近似解的真值不劣于
       最优值加两倍误差）；
  (iii)（平局必然性）γ = 0 时，对任何 η > 0 存在满足 |δ| ≤ η 的扰动使
       argmin Φ̃ ≠ x*；等价地，平局在任何正精度下不稳定。

*证明*。
(i) 设 2η < γ。对任意 y ≠ x* 在 F_{b₀} 中：Φ(y) ≥ Φ(x*) + γ。于是
    Φ̃(y) ≥ Φ(y) - η ≥ Φ(x*) + γ - η > Φ(x*) + η ≥ Φ̃(x*)。故 x* 是 Φ̃ 的唯一
    极小元。
(ii) Φ(x̃*) ≤ Φ̃(x̃*) + η ≤ Φ̃(x*) + η ≤ Φ(x*) + 2η。第二步用 x̃* 是 Φ̃ 的极小元
     （故 Φ̃(x̃*) ≤ Φ̃(x*)）。
(iii) γ = 0 表示存在 y ≠ x* 同是最小值。取扰动 δ 使 Φ̃(x*) = Φ(x*) + η、
     Φ̃(y) = Φ(y) - η（在误差界内可达），则 Φ̃(y) < Φ̃(x*)，argmin 改变。∎

*注 2.9.1*。T7 的陈述对象是「候选集 + 评估」层面：算法中的 argmin 几乎总发生在
有限候选集（P2 的命中候选、P3 的键序）或已分层量化的结构上；连续情形的「间隙」由
次扰动的值差扮演，本报告不主张连续版本。P2 的 ε 剪枝预算是 T7(i) 的实例：最小安全
ε 与单侧 slab 误差的关系由 NC-D3 精确导出（§5，exp21 数值验证）。

### 2.4 两种设定：setup A 与 setup B

DSS 的实例分两种设定，区别在纤维的来历与 Φ 的对称性：

**setup A（轨道即纤维，Φ 是在轨道上变化的 code）**。群 G 作用于 X，p 是轨道映射
（纤维 = 轨道）。此时 G-不变的 Φ 会使 argmin 退化为整条轨道（纤维上每点同值，
D1 失效），故 Φ **必须**在轨道上不对称——Φ 是「在轨道上挑选代表元的 code」。
P3（图元规范序）、P1/P7 的舍入点（格上的最近点选择）属此。

**setup B（数据索引，纤维 = 水平集，Φ 对数据重标号等变）**。B 是数据/条件的空间，
纤维 F_b = {x : p(x) = b} 是约束水平集；Φ(x, b) 对数据的重标号 τ 协变
（Φ(Tx, τ(b)) = Φ(x, b)）。P4（水位）、P6（分配 + Kalman）、P2（遍历 argmin 的
查询索引）属此。

*注 2.4.2*。setup A 中「Φ 非 G-不变」不是矛盾而是结构必然：不变泛函无法区分轨道
内的点，选择问题退化为整个轨道。T2a/T2b 分别是两种设定下同一自然性原理的读法
（注 2.4.1）。这也解释了前作 §5.3 观察到的「(α)(β) 互不交互」：那不是两族分离，
而是 D3 在 setup A 上**空转**（无凸结构在场）、D1 在 setup B 上以严格凸性实现的
**同一原理的两种实例化**。

### 3.1 P3 ↦ DSS：规范形是完全不变量的截面（核心承载）

**原文中心定理**（super-algorithms.md P3 + 前作 §3.3）：排序数组是节点多重集的完全
规范不变量（任意输入顺序 ⇒ 同一排序数组；相异多重集 ⇒ 相异数组）；Morton 码 +
内容键 tie-break 给出确定性结构；规范序的 SAH 代价比 1.0000 是「保持」不是「最优」。

**DSS 读法（setup A）**。X = 图元序列空间（n 个图元的排列，允许重复代表相同几何），
B = 键多重集，p(x) = x 的键多重集（Morton 码 + 内容摘要），
Φ(x, b) = x 的字典序 code。截面 s(x) = 键字典序最小的排列 = Morton 规范形 +
内容键 tie-break 的结果。

**公理核验**（逐步）：
1. **D1（唯一极小）**：要求组合键 (Morton, 内容摘要) 在相异图元上单射。若两图元
   键全同（架构审 B2 的「同码族」），字典序在组内不区分 ⇒ 极小元不唯一 ⇒ **D1 失效**。
   这正是 QA M-2（PCG 哈希非抗碰撞）的精确数学定位：M-2 不是「工程隐患」，而是
   **D1 的概率失效模式**——键函数以可计算概率非单射。修复（B2：追加内容摘要）是
   恢复 D1；而「摘要抗碰撞」本身是概率假设（源码 signature.rs：「256 位哈希以无碰撞
   为公理」），故 P3 的 D1 是**带概率假设的 D1**，本报告如实标注：DSS 的逻辑部分
   （T1/T2a）不依赖该假设，实例的确定性依赖它。
2. **D2（精确可复现）**：排序是整数/位运算，位级可复现 ✓。
3. **D3**：无凸结构，D3–T5 在此实例上**空转**（不是失效）——见注 2.4.2。

**承载判定**：
- **T1(i)**：s(x) = s(y) ⟺ p(x) = p(y) ⟺ 两序列键多重集相同 ⟺ 原文「任意输入序
  ⇒ 同一排序数组；相异多重集 ⇒ 相异数组」的**逐字等价形式**。exp20 E1 数值验证
  （200 组置换不变 + 1000 对多重集判定，0 违例）。
- **T1(iii) 分解等价性**：渲染结果过 p 分解 ⟺ 过 s 分解 ⇒ 「任何只依赖多重集的计算
  可用规范序输入执行」——这是固定形状归约代数（graph.rs「消序用排序」）的数学形式。
- **T2a 纤维内自然性**：保持组合键的图元置换固定规范形。注意精确形式：若 π 保持
  组合键，则 sort(πx) = sort(x)（键多重集不变）；但若 π 只保持 Morton 不保持摘要
  （B2 之前的弱键），则组内 tie-break 顺序可变，规范形作为**元素序列**不唯一——
  exp20 E2 的第一级验证（弱键 ⇒ 规范序必然分歧；强键 ⇒ 一致，0 例外）。
- **SAH 代价比 1.0000**：**不是 DSS 定理**。它是「规范序相对未规范序的经验保持性」，
  与 Φ 的选择无关；DSS 不生成它，如实标注。SAH 最优性（Hilbert 曲线）是另一 Φ 的
  另一截面（NC-D5，§5.5）。

**诚实边界**。P3 的「内容键」是 DSS 中唯一带概率假设的成分；「SAH 保持性」外置为
实例证据；「SAH 最优序」不属于本实例（Φ 不同）。

### 3.2 P2 ↦ DSS：遍历 argmin 是完全不变量的截面（核心承载）

**原文中心定理**：CPU/GPU 遍历同构——argmin 置换不变（U1 规范槽位 tie-break
一举三得）；ε = 6u·t_max 剪枝安全（不漏）；MT 误差 79u·|t| 管并列判定；bit-exact
不可能的诚实声明。

**DSS 读法（setup B）**。X = 命中候选集（元素为 (t, orig, slot)），B = 查询
（射线/图元查询），p = 查询索引（把候选送到其所属查询），Φ(x, b) = (t, orig)
字典序（U1 的规范槽位 tie-break：t 相同时取 orig 小者）。截面 = 查询的最近命中。

**公理核验**（逐步）：
1. **D1**：Φ = (t, orig) 字典序是全序（t ∈ ℝ, orig ∈ ℕ 互异）⇒ 唯一极小 ✓。
   边界：t 逐位相同（B-M3：无遮挡共享边 + 精确过对角线）时 orig 仍区分 ⇒ D1 保持；
   若 t 与 orig 都相同（同一图元被重复访问），截面值相同，无分歧。
2. **D2**：见 T7 与 D2 的误差预算分析（下）。
3. **D3**：无（组合 argmin），D3–T5 空转。

**承载判定**：
- **T1(i)**：argmin 是查询的完全函数（与访问序无关）⇒ CPU 序与 GPU 序 parity。
  这正是原文「argmin 置换不变」；exp20 E1 的排序结构是其原型。
- **T2b**：查询重标号（查询集重排）等变。**验证状态如实标注**：BVH 遍历本身
  无本次数值实验；等变机制与 exp19 E3（估计阶段的观测置换不变）同构，
  此处为机制引用，非实测。P2 的实测证据来自前作 exp2/exp14（遍历同构与
  剪枝安全性，§8.2 承接）。
- **T7 近似截面**：ε 预算是 T7(i) 的实例。**本报告的新贡献（NC-D3）**：最小安全
  ε 的精确值。原文 ε = 6u·t_max 被表述为剪枝安全预算；exp21 复刻 exp14 逻辑单元
  并做最坏情形扫描，得到：单侧 slab 误差全额 δ = 3u·t_max 是「不漏」的最小保障
  （更近命中可任意贴近真实 enter，g → 0 时最小 ε → δ）；6u·t_max = 2δ 覆盖
  enter + exit **双侧**，是 2× 单侧最小的稳健选择。即：原文 6u 是正确的，
  但「6u 是最小安全值」的读法不成立——最小是 3u（单侧），6u 是双侧。本报告按
  此如实陈述（§5.3 NC-D3，exp21 E2）。
- **D2 误差预算**：MT 误差 79u·|t| 与 slab 误差 3u·t 是**两个独立误差源**
  （前作 M2 指控属实的正确表述）：前者管并列判定（ht == best_t 的相等性判断），
  后者管剪枝安全。D2 在此实例的形式是：ε 预算覆盖 slab 侧 + 并列判定用 (t, orig)
  全序吸收 MT 侧（t 的相对差小于 MT 界时 orig 决胜——这正是 U1「一举三得」的
  第三得）。

**诚实边界**。bit-exact 不可能声明由 T7(iii) 承载：γ → 0（平局）时任何正精度可翻
转；故「CPU/GPU 逐位一致」只在 γ > 2η 时有定理，平局区间靠 (t, orig) 全序把 γ
恢复到离散严格——这是 U1 的结构功能，不是运气。

### 3.3 P4 ↦ DSS：水位分配是一阶条件的截面（核心承载）

**原文中心定理**：water-filling 的 KKT 闭式；等畸变证书（活跃帧畸变全等）；
影子价格 λ = -dD*/dB；det_log2 纯 ±×÷ 的确定性实现。

**DSS 读法（setup B）**。X = ℝᵐ₊（比特分配），B = (θ, B₀)（先验 + 预算），
p(x) = (Σxᵢ, ·)（预算约束），Φ(x, b) = Σ Dᵢ(xᵢ; θᵢ)。截面 = 水位解。

**公理核验**（逐步）：
1. **D1**：Dᵢ 严格凸（指数-幂型失真）⇒ Φ_b 在预算超平面上严格凸 ⇒ 唯一极小 ✓。
   （若 Dᵢ 仅凸不严格，D1 需退化处理：如加 ℓ² 正则或钳位，见 P6。）
2. **D3**：p 线性、Φ 凸可分、可微 ⇒ D3 启用，T3/T4/T5 全部生效。
3. **D2**：det_log2（源码 det_pow.rs:24，atanh 级数，纯 ±×÷）使闭式中的 log₂
   位级可复现 ✓——这是 D2 的工程体。

**承载判定**：
- **T3 等边际** ⇒ 活跃帧畸变全等（原文「等畸变证书」的逐字形式：fᵢ'(x*ᵢ) = -λ
  ⇒ Dᵢ(x*ᵢ) 在活跃集上相等，由 fᵢ 的单调性）。
- **T4 影子价格** ⇒ λ = -dD*/dB（原文 OT3；前作 exp18 数值验证，承接未重跑）。
- **T5 Fenchel** ⇒ water-filling 有不经 KKT 的证明（原文 §7.1 第 3 条，exp18，
  承接未重跑）；前作 NO-3/OT5 与 Fenchel 路线的「归并」在 DSS 中是同一 T5 的两种
  算法读法，不再需要「归并」这一修辞。
- **T2b 等变**：通道重标号（θ 的置换）⇒ 解按同一置换重排，λ 不变。exp19 E1
  数值验证（300 次随机试验，max|n 差| = 1.8e-15，λ 相对差 1.1e-15）。

**诚实边界**。「闭式的显式反函数」（§5.4 C8 表的一条）确实是实例代数：DSS 给出
等边际条件，把 fᵢ' 反解出来是实例内容。DSS 不声称生成闭式，声称生成闭式的**证书**。

### 3.4 P6 ↦ DSS：分配律 + Kalman 是截面复合（核心承载）

**原文中心定理**：Neyman 分配 nᵢ = Nσᵢ/Σσ；C-S 界；双通道审计；GOP 探针的
窗口化（M8/U4）；Kalman 滤波的 BLUE/WLS。

**DSS 读法（setup B，两阶段）**。
- 分配阶段：X = ℝᵐ₊，B = (σ, N)，p(x) = (Σxᵢ, ·)，Φ = Σxᵢ²/σᵢ（或失真型）。
  截面 = Neyman 分配（含 max(1,·) 钳位 + 守恒投影）。
- 估计阶段：X = 状态估计量，B = 观测数据，p = 观测索引，Φ = 加权最小二乘代价
  Σ wᵢ(bᵢ - x)²。截面 = WLS 估计 = BLUE（Gauss–Markov 条件下方差极小者）。

**公理核验**（逐步）：
1. **分配阶段 D1**：Φ = Σxᵢ²/σᵢ 严格凸 ⇒ 唯一极小 ✓；钳位版 max(1,·) 后守恒投影
   仍是良好定义的截面（投影因子 Σmax(1,·) 是 σ 的对称函数，等变性保持——exp19
   E2 两版都验证：5.7e-14 级）。
2. **估计阶段 D1**：Φ = Σwᵢ(bᵢ-x)² 在 x 上严格凸（wᵢ > 0）⇒ 唯一 ✓。
3. **D3**：两阶段都线性约束 + 凸 ⇒ T3/T4/T5 生效。C-S 界是 T5 的实例
   （Σσ 型恒等式的 Fenchel/内积读法；前作 §7.1 第 2 条 λ = (Σσ)²/N² 与
   dMSE/dN 的数值，承接未重跑）。

**承载判定**：
- **T4 ⇒ λ = -dMSE/dN**（原文；含钳位例仍成立，exp18 承接）。
- **T2b ⇒ 观测/通道重标号等变**：WLS 批量估计与 Kalman 递推在观测置换下一致。
  exp19 E3 数值验证（200 次随机试验，递推-批量差 0.0——精确相等，不是近似）。
- **T6(iv) ⇒ 复合稳定性边界（本报告 NC-D4）**：剖面误差共模在一阶精确抵消
  （分配权重只依赖 δᵢ - δ̄_σ，exp22 E2：残差/δ² ≤ 1.04，O(δ²) 干净标定）；
  复合 V 的一阶敏感度 dV/V = δ̄_σ + δ̄_{1/σ}（exp22 E3：残差/δ² ≤ 0.89）；
  全局尺度误差以 (1+δ)² 进入 V（exp22 E4：与精确关系一致到 1.8e-15）。
- **Gauss–Markov 边界（本报告新增的精确陈述）**：估计问题的截面良定义性（D1）与
  最优性证书（D3/T4 的 BLUE 性）**分离**：证书要求效益权重数据独立（GM 条件）。
  通道 A（结构先验权重）满足 GM，有定理；通道 B（权重依赖观测值，如
  wᵢ = 1/(rᵢ + s·bᵢ²)）截面仍良定义（是数据的确定函数）但证书失效。exp19 E4
  数值演示：MC = 20000 下独立权重偏差 -0.00072，数据依赖权重偏差 -0.13540。
  **结论**：DSS 对 Kalman 的承载止于良定义性 + 等变性；「BLUE 最优」必须逐通道
  核对 GM 条件，不外包给架构。

**诚实边界（T6 的边界随行）**。两阶段（逐帧 MSE 最优的分配 + 时域方差最优的估计）
**不是**任何单一目标的联合最优截面——联合最优是角点解。复合的地位是「两个阶段各自
关心的目标的稳定近似」（T6(iv) 给出近似质量的量化）。如实陈述，不声称「两阶段
架构被 DSS 强制」。

### 3.5 P5 ↦ DSS：缓存键是完全不变量的提升（部分承载，解释性）

**原文中心定理**：KCT-2 充分统计量（缓存键 ⟺ 复用性）；宁过勿欠（假阴性只损性能，
假阳性出错结果）；CacheDims 五元组 + 版本入键。

**DSS 读法（混合）**。X = 渲染结果空间，B = 缓存查询空间，p = 内容到查询的映射，
Φ = **构造性**的（键函数由设计者规定，不是从候选集中 argmin 出来的）。

**公理核验（逐步，如实）**：
1. **D1**：P5 的 Φ 不是 argmin 型 ⇒ D1 不以「唯一极小」形式出现。其扮演者的是
   **键的单射性约束**：不同内容必须不同键（否则假合并）。这不是 D1 的逻辑内容，
   是实例设计约束。
2. **T1 的适用方式**：T1(i) 说「截面是 p 的完全函数」。对缓存：命中 ⟺ 键相同；
   要求「键相同 ⟺ 内容可复用」即键是复用性的**完全不变量**。这正是 KCT-2 的陈述，
   而 T1(iii) 给出它的构造性推论：**最紧缓存键构造定理（NC-D2）**——缓存键必须
   至少细分到使「不同内容不同键」；可细化的自由度为「只损失命中率」。

**承载判定**：**部分承载**。P5 的中心定理（KCT-2）不是 DSS 实例理论中的定理
（Φ 非 argmin 导出）；DSS 提供的是**解释与设计规则**：T1 把「宁过勿欠」从经验
法则提升为结构必然——假阳性 = 用非完全不变量的键做截面 = T1(i) 失效；过细键 =
细分 p 而不改变可分解映射类（T1(iv)），只损失命中率。exp20 E3 数值演示三档键
（full 无假合并 / partial 假合并 / oversized 只损命中）。

**诚实边界**。如实标注：P5 由「DSS + 实例构造」承载，不由 DSS 单独承载。若严格
执行 N2 的强读法（中心定理须是实例理论中的定理），P5 **不通过**；本报告在 §4 按
此诚实记账。

### 3.6 P1 ↦ DSS：舍入点是格上的近似截面（组合式承载）

**原文中心定理**：i128 定点 IDCT 的精确性（74.3dB，过规范 34dB）+ Σ|D| 误差界；
B1 修复（阈值常量 10× 错误）。

**DSS 读法（setup A 弱形式）**。每个舍入点 = 格 ℤᵏ 上的最近点截面（X = ℝⁿ，
B = 格点索引，p = 格投影，Φ = 到格点的距离）。

**公理核验（逐步，如实）**：
1. **D1**：最近点唯一（格 + 范数严格凸）✓。
2. **T7**：每个舍入点是近似截面：值界 |舍入误差| ≤ η（D2 的失效预算）；
   **γ = 到次近格点的距离的一半**——距格边界越近，翻转风险越大。这是「中点
   规则边界脆弱」的一般形式（B-M3 的格版本）。
3. **74.3dB 与 Σ|D| 界**：**不是 DSS 定理**。来自正交性恒等式 + 舍入分析的实例
   代数（前作 KCT-4 的实例内容）。DSS 承载的是「舍入 = 近似截面 + 预算」这一
   **结构**，不承载具体数值。

**承载判定**：**组合式承载**（D2/T7 + 实例代数），按任务书要求如实标注。
B1 修复是 D2 预算的实例修正（阈值错 10× ⇒ 预算错 10× ⇒ 界失效——T7(ii) 的值界
随预算线性劣化）。

### 3.7 P7 ↦ DSS：半群律外置，舍入/精确性由 T7/D2 承载（组合式承载）

**原文中心定理**：ln(1-t) 同构的半群律（转场复合）；u8 混合的 1 LSB 界；端点精确。

**DSS 读法**：舍入点 = 格上最近点截面（同 P1）；半群律 = 背景代数。

**承载判定**：**部分覆盖 + 外置**。舍入/误差/精确性由 T7/D2 承载（同 §3.6）；
**半群律不是截面陈述**——它是背景商结构上的实例代数（T1 的「背景」：商映射
p 的存在性使复合良定义，但半群律的证明用实例的代数性质）。如实标注：截面核心

以下六条推论在七提案文档与前作中均无。每条给出陈述、证明或证明思路、以及验证状态

### 5.1 NC-D1（重标号等变是截面的结构性质，不是实现约定）

**陈述**。设 Q = (X, B, p, Φ) 满足 D1，T, τ 为双射且 p ∘ T = τ ∘ p、
Φ(Tx, τ(b)) = Φ(x, b)（定理 2.4(T2b) 的条件）。则对一切 b ∈ B：

  s̄(τ(b)) = T(s̄(b))，且乘子按余向量变换 λ(τ(b)) = T λ(b)

（s̄ : B → X 是截面在 B 上的提升，定义见定理 2.4；单约束情形 λ 是标量，
退化为 λ(τ(b)) = λ(b)）。

*证明*。第一式即 T2b。第二式：设 D3 启用，x* = s̄(b) 满足 KKT：
∇Φ(x*, b) + J_p(x*)ᵀλ(b) = 0。对 τ(b) 写出同一式并用 T2b 的 s̄(τ(b)) = Tx*：

  ∇Φ(Tx*, τ(b)) + J_p(Tx*)ᵀλ(τ(b)) = 0。      (1)

两个 Jacobian 关系（T 为置换矩阵，T⁻¹ = Tᵀ）：对 Φ(Tx, τ(b)) = Φ(x, b) 微分得
∇Φ(Tx*, τ(b)) = T∇Φ(x*, b)；对 p(Tx) = τ(p(x)) 微分得
J_p(Tx*)·T = T·J_p(x*)（τ 线性），即 J_p(Tx*)ᵀ = T·J_p(x*)ᵀ·Tᵀ。代入 (1) 并
左乘 Tᵀ：

  ∇Φ(x*, b) + J_p(x*)ᵀ·Tᵀλ(τ(b)) = 0。        (2)

(2) 与 b 处的 KKT 相减，由 J_p(x*) 行满秩（约束规范，D3 的一部分）得
λ(b) = Tᵀλ(τ(b))，即 λ(τ(b)) = Tλ(b)。单约束时 T = 1（标量），得不变性。∎

*验证范围（如实）*：数值验证覆盖标量情形（exp19 E1/E2：λ 在通道置换下不变，
相对差 ≤ 1.1e-15）；多约束的余向量变换律由本证明给出，无数值验证（P4/P6 均为
单预算约束，无多约束实例可测）。

*引擎意义*。通道重排（GPU/CPU 布局差、通道序调整）不改变分配解与影子价格——
这不是「实现凑巧一致」，是截面的结构性质。P4 的水位、P6 的 Neyman 分配、
P6-Kalman 的 WLS 批量估计与递推（观测置换）都是实例。

*数值验证*：exp19 E1/E2/E3（12 组置换试验，max 偏差 1.8e-15 ~ 5.7e-14 级；
Kalman 递推-批量差精确 0.0）。

### 5.2 NC-D2（截面 = 完全不变量 ⟹ 最紧缓存键构造定理）

**陈述**。设 s 是 Q 的截面（D1 成立），则对任意「只依赖完全不变量的查询」
F : X → Y（即 F 过 p 分解），有 F 过 s 分解（定理 2.3(iii)）。应用于缓存：
设缓存语义为「内容 c 可复用 ⟺ R(c, c')」（复用关系），则缓存键 κ 正确的充要条件

  κ(c) = κ(c') ⟺ R(c, c')

即 **κ 必须是复用关系的完全不变量（不能粗，粗则假合并）且可按自由精度细化
（细化只损失命中率）**。两个方向的代价不对称：粗化 = 返回错误结果（正确性事故），
细化 = 少命中（性能损失）。故最优策略是「在可计算范围内取最细的完全不变量的
有限近似」——宁过勿欠是其推论，不是独立原则。

*证明*。⇒：若 κ(c) = κ(c') 但 ¬R(c, c')，则「命中」用了非完全不变量的键，
T1(i) 被违反（键相同但内容不同 ⇒ 假合并）。⇐ 方向的细化自由：若 κ 完全，
κ' = (κ, 附加字段) 仍完全（加细不破坏「相同 ⇒ 可复用」方向；只破坏「可复用 ⇒
相同」即命中率方向）。∎

*引擎意义*。P5 的键设计（KCT-2 + 宁过勿欠 + CacheDims 五元组 + 版本入键）从
三条经验法则归约为一条构造定理 + 一个代价不对称性论证。

*数值验证*：exp20 E3（三档键：full 无假合并 / partial 假合并 / oversized 只损
命中，全部按预测分化）。

### 5.3 NC-D3（近似截面的间隙形式：ε 最小性与平局必然性）

**陈述**（T7 的定量化）。(a) 设 slab 计算的 enter 值单侧误差界为 δ = 3u·t_max
（exp2b 实测界），则剪枝判定「enter_comp > best_t + ε」不漏盒内更近命中的
**最小全配置保障**是 ε = δ = 3u·t_max：更近命中可任意贴近真实 enter，故
best_t 与真实 enter 的差可任意小，所需 ε 逼近 δ 的全额；(b) 对具体配置，
最小 ε = enter_comp - best_t（如 exp14 逻辑单元中为 0.55δ = 1.65u·t_max）；
(c) γ = 0（平局）时任何 η > 0 可翻转（T7(iii)）。

*证明*。(a) 坏剪枝 = 存在真实更近命中 t' < best_t 在盒内（t' > enter_exact）
却被剪。安全性要求一切此情形下 enter_comp ≤ best_t + ε。最坏情形
best_t ↓ enter_exact（更近命中贴在盒口），此时 enter_comp - best_t ↑
enter_comp - enter_exact = δ，故 ε ≥ δ 是唯一与配置无关的保障。
(b) 具体配置直接由判定式解出。(c) 即 T7(iii)。∎

*引擎意义*。原文 P2 的 ε = 6u·t_max 是**正确的**，但其地位被精确化为：
6u·t_max = 2δ = 覆盖 enter + exit 双侧的稳健选择（2× 单侧最小）；「6u 是最小
安全值」的读法不成立（最小是 3u，单侧）。诚实修正比夸大更有工程价值：
若某平台 slab 误差界改进到 2u·t_max，最小 ε 同比例下降，预算可回收。

*数值验证*：exp21 E1（T7 四性质：2000 次 0 < η < γ/2 零翻转、500 次 η = γ
构造全翻转、平局必翻、值界零违例）；E2（exp14 逻辑单元复刻 + g → 0 最坏扫描：
最小 ε → 3u·t_max）。

### 5.4 NC-D4（复合截面的条件数：两阶段稳定边界）

**陈述**。设复合泛函 V(σ) = Σσ/(N·Σ1/σ_k)（P6 两阶段复合形式），剖面误差
σ̂ᵢ = σᵢ(1+δᵢ)。则 (a) 分配权重 ŵᵢ = σ̂ᵢ/Σσ̂ 满足
ŵᵢ = wᵢ(1+δᵢ)/(1+δ̄_σ) = wᵢ(1+δᵢ-δ̄_σ) + O(δ²)，δ̄_σ = Σσᵢδᵢ/Σσᵢ 为
σ-加权共模——剖面共模在一阶精确抵消；(b) dV/V = δ̄_σ + δ̄_{1/σ} + O(δ²)，
δ̄_{1/σ} = Σ(δᵢ/σᵢ)/Σ(1/σᵢ) 为调和加权共模；(c) 全局尺度误差
δᵢ ≡ δ 时 V((1+δ)σ) = (1+δ)²V(σ) 精确成立（一阶 2δ 是其线性化，自检一致）。

*证明*。(a) 直接展开：(1+δᵢ)/(1+δ̄_σ) = 1 + δᵢ - δ̄_σ + O(δ²)。
(b) 对数微分：log V = log Σσ - log N - log Σ(1/σ_k)，d(log Σσ) = δ̄_σ，
d(log Σ1/σ) = δ̄_{1/σ}。(c) Σ(1+δ)σ = (1+δ)Σσ，Σ1/((1+δ)σ) = (1+δ)⁻¹Σ1/σ，
相除得 (1+δ)²。∎

*引擎意义*。两阶段分配律的稳定性有了量化边界：剖面共模（如 GOP 级噪声估计的
整体偏高/偏低）在一阶不污染分配比例；真正进入复合方差的是 δᵢ 的相对偏离
（δᵢ - δ̄_σ）与两个加权共模之和。δ ≲ 10% 时一阶误差 < 1%（exp22 E3 标定）。
这解释了 P6「双通道审计」为什么应审计**偏离**而不是绝对量级。

*数值验证*：exp22 E1–E4（尺度不变性 8e-16 相对偏差；共模抵消残差/δ² ≤ 1.04；
一阶敏感度残差/δ² ≤ 0.89，跨 δ ∈ [1e-3, 0.2] 常数界；(1+δ)² 精确到 1.8e-15）。

### 5.5 NC-D5（无免费午餐：Φ 的选择就是架构的选择）

**陈述**。不存在与 Φ 无关的「规范序」。精确形式：给定 (X, B, p)，配 Φ₁ ≠ Φ₂
（各自满足 D1）的两个选择问题的截面可以不同（s₁ ≠ s₂）；特别地，
「x 是 Φ₁ 的截面（规范形）」不蕴含「x 是 Φ₂ 的截面（Φ₂-最优）」。

*证明*（反例法，反例取自文档自身）。(X, B, p) =（图元序列空间，键多重集，多重集
投影）上：Φ₁ = (Morton, 内容摘要) 字典序的截面是 Morton 规范序；Φ₂ = SAH 遍历
代价的截面是 SAH 最优序。架构审的结论「Morton 序不是 SAH 最优序——Hilbert 曲线
是合法替代」正是 s₁ ≠ s₂ 的实证；规范序的 SAH 代价比 1.0000 是「保持」不是
「最优」。故同一候选结构上，Φ₁-截面 ≠ Φ₂-截面。∎

*引擎意义*。这是对前作「事实 1」的**修订**（见 §6.1）：「K_can 实例输出非最优」
为真，但它的正确解读不是「不变性族与最优性族分离」，而是**同一 DSS 框架内不同
Φ 的截面不同**——选择 Φ 就是选择架构，没有免费的规范序。P3 因此获得一条设计
规则：若遍历性能是目标，Φ 必须包含 SAH 项（或改用别的 Φ），Morton 的确定性
由 p 保证、性能由 Φ 负责，两者不可互相顶替。

### 5.6 NC-D6（数据规范性 ⟹ 重放稳定性）

**陈述**。设 Q 满足 D1，且数据索引映射 p 对数据重标号协变（p ∘ T = τ ∘ p，
T, τ 为双射，即「数据规范化后 p 良定义」）。则截面重放稳定：
s̄(τ(b)) = T(s̄(b))（NC-D1）。反之，若 p 不协变（数据规范化步骤缺失），则截面值可随数据
的表示漂移——重放破坏。

*证明*。正向即 NC-D1/T2b。反向：p 非协变时 τ(b) 与 T(b) 落入不同纤维族，
argmin 的可行集改变，极小元可改变。P6 的实证：M8 之前 σ 探针递推使分配依赖
GOP 历史（数据表示进了解的定义域），seek 重放漂移；GOP 边界重置协议（M8/U4）
正是把 p 制成协变的修复——重置后 s 对历史重标号等变，重放稳定。∎

*引擎意义*。这是对前作「事实 2」的**修订**（见 §6.2）：「K_opt 实例输出表示依赖」
为真，但它是 **p 未规范化的病态**，不是 K_opt 的结构缺陷；修复（窗口化/重置）
在 DSS 中是一条定理（NC-D6）而不是外加的工程补丁。前作 §5.5 第 3 句「实现层单向
依赖」获得精确形式：D2（精确可复现）要求数据索引协变，即 setup B 的实例必须先把
p 规范化——这正是「K_opt 的确定性实现必须坐在 K_can 式规范结构上」的 DSS 版陈述。

## 6. 前作 §5 分离定理的处置

### 6.1 事实 1 重审：「K_can 实例输出非最优」——真陈述，重新定位为 NC-D5

前作 §5.2 事实 1：P3 的 Morton 规范序不是 SAH 最优序（Hilbert 是合法替代），
P2 的规范槽位 tie-break 与画质无关 ⇒ 存在 K_can 模型输出可证次优。

**重审**：该事实本身为真（文档内证据确凿）。但它在 §5.2–5.3 中被用作「两族分离」
的反侧构造，这一步**不成立**：在 DSS 下，同一事实的正确表述是 NC-D5——**同一
(X, B, p) 上不同 Φ 给出不同截面**。「Morton 序在 SAH 意义下次优」与「SAH 最优序
在字典序意义下非规范」是同一枚硬币的两面，都是「Φ 的选择就是架构的选择」的实例，
不构成「不变性定理族 vs 最优性定理族」的逻辑分离。分离需要的命题是「不存在同时
承载两族定理的结构类型」，事实 1 不证明这个（§6.3）。

**保留**：NC-D5 作为设计规则（遍历性能目标必须进 Φ）进入提案 P3 的修订建议。

### 6.2 事实 2 重审：「K_opt 实例输出表示依赖」——真陈述，重新定位为 NC-D6

前作 §5.2 事实 2：P4 一遍路径最优解依赖 θ 先验，P6 的 σ 探针使分配依赖 GOP 历史
（M8 前 seek 重放破坏）⇒ 存在 K_opt 实例最优解表示依赖；不变性靠外加规范化恢复。

**重审**：事实为真。重新定位：(i) 「依赖 θ 先验」不是表示依赖——θ 是数据 b 的
成分，截面本来就该依赖 b（s̄(b) 的定义）；这是把「数据依赖」误记为「表示依赖」。
真正的表示依赖是 (ii)「探针状态进入解的定义域」——即数据索引映射 p 把未规范化的
历史纳入纤维定义，p 非协变。按 NC-D6，修复（GOP 边界重置）不是「外加补丁」而是
**恢复 p 的协变性**，是一条定理的应用；且 §3.3/§3.4 的 T2b 验证表明 P4/P6 在
数据协变后精确等变（exp19）。故事实 2 也不构成两族分离的证据。

**保留**：GOP 重置协议的必要性从「工程补丁」升级为「NC-D6 的实例」；双通道审计
的审计量从「绝对量级」修订为「偏离 δᵢ - δ̄_σ」（NC-D4）。

### 6.3 分离定理的驳斥（前作 §5.3 撤回）

前作 §5.3 定理的字面陈述：「任何满足 N1–N2（对全部七提案）的结构类型 K，其公理集
必然包含两个互不交互的公理组 (α)(β)……合取不产生统一的证明技术，从而 K 无法满足
N3」。

**驳斥**。DSS 是满足 N1–N3（§4：N2 部分满足、按承载强度分级）的结构类型，其公理集
是 D1–D3（三条，不是两组互不交互的公理组），且它推出既非 K_can 型也非 K_opt 型的
新命题。按前作自己的成分矩阵（§1.2：规范化簇含 FP 误差，最优性簇含凸性/KKT 与
C–S）如实分级：
- **T1/T2 对两族实例都适用**：T1 对 P3（α 实例）给出完全不变性，对 P4（β 实例）
  给出「解是数据的完全函数」这一同样形式的陈述；
- **T7 对两族实例都适用**：对 P2（α）给出 ε 分析，其间隙结构对任何 argmin 适用；
- **NC-D1/NC-D4 是 β 族实例上的新定理**（前作 OT1–OT5 表中没有）；
- **NC-D2/NC-D3 是 α 族实例上的新定理**（前作 KCT-1..4 表中没有）；
- **NC-D6 直接把 β 族实例（P4/P6）的稳定性归约为 α 族机制**（数据规范化）——
  这是最直接的跨族命题。
综上，该定理如字面所述**为假**，DSS 是反例。

**论证链的缺陷定位**。前作的推理是：
(1) 实例成分矩阵两簇 ● 不相交（真，§1.2）；
(2) ⇒ 两族中心定理逻辑独立（事实 1+2 的真部分支持「互不蕴含」）；
(3) ⇒ 任何满足 N1–N2 的 K 必含两组互不交互的公理（**非逻辑**：从「两族定理
    互不蕴含」推不出「结构空间只有两个类型」——正如「有限阿贝尔群定理与有限非
    阿贝尔群定理互不蕴含」推不出「不存在有限群论」）；
(4) ⇒ 合取空转于 N3（**被 DSS 反驳**：DSS 的公理不是两组的合取，桥命题
    NC-D2~D6 非空转）。

步骤 (3) 是把「实例数据的聚类」当作「结构空间的上界」——这正是主理人批评的
技术核心（§9 展开）。步骤 (2) 中「互不蕴含」的弱化版本在 DSS 内部**幸存**：
T1/T2 的证明技术（排序、字典序、键构造）确实不能用于证明 T3–T5（凸对偶），
反之亦然——「证明技术不可互归」为真；但「结构不可统一」为假。

### 6.4 C8 否决表逐行重审（前作 §5.4）

前作对「万能 argmin」（C8）的五项尝试推出全部失败，结论：真描述 + 零定理生成
能力。逐行重审——问题是这些否决理由对 **C8** 成立，对 **DSS** 是否成立？

| 前作尝试推出 | 对 C8 的结论 | 对 DSS 的重审 |
|------------|------------|--------------|
| P1 的误差界 | 推不出（argmin 性不含误差信息） | **仍推不出**：74.3dB 是实例代数。但 D2/T7 给出**预算结构**（NC-D3 的格版本：中点边界脆弱性），且 B1 修复可定位为预算错误——部分生成 |
| P4 的水位闭式 | 推不出（闭式来自 fᵢ' 反函数） | **仍推不出闭式**，但 T3/T4 生成**证书**（等边际、影子价格）——证书是闭式之外的东西 |
| P6 的 C-S 下界 | 推不出（内积不等式） | **可推出**：T5（Fenchel）路线包含 C-S 型界（OT5 与 Fenchel 归并，注 2.7.1） |

**结论**：前作对 C8 的分析**完全正确且被 DSS 完整继承**——裸 argmin（无 p、无 Φ
结构、无 D1/D2/D3）确实零生成能力。DSS 的全部生成能力来自 (p, Φ, D1, D2, D3)
承载的结构，不来自「它是 argmin」这个口号。C8 与 DSS 的关系是：口号 vs 理论。
前作 §5.4 的结论「描述与理论的分别是双支柱与两内核的分界」应修订为：
**「裸 argmin 是描述，带 (p, Φ, D1–D3) 的 argmin 是理论」**。

### 6.5 弱陈述裁定：「两种求解技术不可互归」

前作 §5.5 第 3 句：两核「定理层独立、实现层单向依赖」。主理人要求的裁定：
若 DSS 成立，弱陈述「两种求解技术不可互归」是否成立？

**裁定：成立，但须按两个读法分别裁决。**

- 读法 A（**证明技术不可互归**）：**成立**。T1/T2 族（排序、字典序、键构造、
  商映射）与 T3–T5 族（凸性、KKT、Fenchel）的逻辑独立性在 DSS 内部幸存：
  T1/T2 的证明不用凸性（P3 无凸结构），T3–T5 的证明不用商结构（P4 的凸问题
  无需表示等价）。不存在把一族的证明技术用于另一族的一般转换。
- 读法 B（**不存在统一结构**）：**不成立**。DSS 给出统一结构（§2），且其桥定理
  （T6/T7/NC-D2~D6）跨族非空转。

故「两种求解技术不可互归」作为**证明论陈述**成立，作为**结构论陈述**被驳倒。
前作 §5.5 第 1 句（聚类有硬证据）作为**实例数据的描述**保留为真——它现在的位置
是「DSS 的实例空间呈两簇聚类」（§7.5 将说明这与新结构判据不矛盾：实例空间
两簇 + 一个共同母结构，恰如有限群论既有阿贝尔簇又有非阿贝尔簇）。

### 6.6 §5.6 诚实声明的核对

前作 §5.6 声明「没有证明不存在更聪明的体系可融合两族；给出的是受 N3 约束下的
否定：凡非空转融合候选必落在已评估的八类或其自然变体之中」。

**核对**：后半句被 DSS 反驳——DSS 是**第九类候选**（选择问题/截面），不在
C1–C8（规范形、充分统计量、Galois、闭包、反射子、项重写、引擎对偶、万能 argmin）

## 7. 文献定位

结论先行：**按公理体系 + 定理集判准，DSS 是新结构**；已知数学对象中最近的四族
与它的关系都是「否定关系」「特例关系」或「实例理论关系」，没有一族能认领 DSS。

### 7.1 与 reflective subcategory（反射子范畴）的关系：否定

反射子范畴 = 包含函子 i : A ↪ C 有左伴随 L : C → A；A 的对象由**泛性质**刻画
（到 A 的泛态射）。前作 C5 曾评估并否决「规范形 = 反射子」路线。

**DSS 与它的关系是否定的**：(i) DSS 的截面不是泛映射——s(x) = argmin Φ 是
**选出来的代表元**，其定义用序结构和极小性，不用泛性质；没有「到 B 的泛态射」
这一构造。(ii) 反射子的要点是「自由/余自由」的泛元素，DSS 的要点是「保持 p 的
纤维中按 Φ 挑唯一代表」。(iii) 反例可验：P4 的水位解是凸优化的 KKT 点，
不存在使它成为某反射子范畴泛对象的自然范畴结构（B 不是 C 的子范畴，
p 不是包含函子）。

故：DSS **不是** reflective subcategory 框架的应用；两者是不同的对象类别。
前作 C5 的否决理由（「无泛性质在场」）对 DSS 不适用，因为 DSS 从不声称泛性质。

### 7.2 与 canonical labeling（nauty/McKay 规范标号）的关系：setup-A 特例

nauty 处理「图在同构下的规范标号」：寻找图同构类的规范代表。这是 DSS 的一个
setup-A 实例：X = 图的标号表示，B = 同构类，p = 同构类映射，Φ = 标号的字典序
code。

**关系**：(i) **DSS 是更一般的框架**：nauty 的 Φ 是标号字典序且必须处理
Φ 在自同构下非严格的情形（自同构使多个标号同 code ⇒ 平局 ⇒ nauty 用剪枝 +
自同构群探测来恢复确定性）。DSS 把这一困难精确化为 **D1 失效模式**（§3.1：
键非单射 ⇒ 极小不唯一），并给出两条出路：强化键（P3 的内容摘要路线，恢复 D1）
或接受平局并在其上定义 tie-break（P2 的 (t, orig) 路线）。(ii) **nauty 的特有
技术（剪枝、自同构剪枝）不是 DSS 的内容**——DSS 只提供「截面何时良定义、何时
不稳定」的判据（D1、T7(iii)），不提供算法。(iii) P3 相对 nauty 的结构优势：
严格码（injective 键）使 D1 无条件成立，无需自同构剪枝——这是 exp20 E2 的
强键一致性所验证的。

**裁定**：canonical labeling 是 DSS 的 setup-A 特例（的一个分支）；DSS 超出它的
部分是 setup B（数据索引 + 等变）与 T3–T7（一阶条件、对偶、复合、近似）。

### 7.3 与 convex duality（凸对偶）的关系：setup-B 实例理论

T5 就是 Fenchel–Rockafellar 强对偶在「线性约束 + 可分凸」下的特例；T3/T4 是
KKT/包络定理。**凸对偶理论是 DSS 的 setup-B 实例理论**（当 D3 启用时），不是
DSS 本身——DSS 不假设凸性（P3 的组合 argmin 是非凸实例），凸性是 D3 的触发条件。

这与前作的定位（K_opt = SCA 装 P4/P6）**不矛盾但更精确**：前作把凸对偶立为
「内核二」，DSS 把它降为「内核在凸实例上的定理组」。这不是降级——凸对偶的全部
定理在 DSS 下一条不少（T3/T4/T5 + 注 2.7.1 的归并），且获得了两样前作给不了的
东西：良定义性的一般理论（D1/T1）与非凸实例的容身之处（setup A）。

### 7.4 与 Galois 连接的关系：实例性质，非结构
