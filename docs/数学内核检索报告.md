## 1. 公理化提取：结构成分表

对每个提案提取最小公理集：它到底用了什么**对象**、什么**运算**、什么**性质**。
中心定理按陈述形式分型：**不变性命题**（Out(x) = Out(y)，xEy）、**极端性命题**
（Out(x) ≤ Out(z)，∀z ∈ Feas）、**存在性/界命题**（存在满足界的表示；误差有界）。

### 1.3 第一份观察：承载成分的双簇聚类，且两簇不相交

上表的 ● 分布给出本文全部后续论证的经验基石：

- **簇 C（规范化）**：成分 {1, 2, 7, 8, 9, 10, 11} 的承载者是 P1、P2、P3、P5、P7；
- **簇 O（最优性）**：成分 {4, 5} 的承载者是 P4、P6；
- **两簇的 ● 承载集不相交**：没有任何一个结构成分同时是两个簇中某提案的中心定理承载者。
  ○ 层的接触点只有两处，且都在**实现层**不在定理层：P4/P6 的确定化实现需要
  ℤ 格/FP 误差分析（成分 9/10 的 ○），P6-Kalman 带有充分统计量气味（成分 8 的 ○）。
- P8 的 ● 是成分 12，它机械化的是簇 C 的成分 8——即 P8 属于簇 C 的工程延伸，
  不是第三簇。

这就是 QA「双支柱 5+2」的严格形式：不是「两类看起来相似的东西」，而是
**中心定理的承载数学成分形成两个不相交的簇**。问题只剩：这两个簇是某个更深
结构的两个而人不知的侧面（有核），还是本质上不可通约（无核）？§2 检索，§5 论证。

## 2. 内核检索：八个候选逐一评估（含否决理由留痕）

评估标准（预先钉死，防止事后放水）：一个候选要成为**七提案的单一核**，必须
(N1) 是一个数学结构类型（公理体系 + 实例）；(N2) 每个提案的**中心定理**是该
结构理论中的定理（内核提供承载证明，不只是描述）；(N3) 能推出至少一条文档中
没有的新命题（新推论检验）。三条缺一即否决，否决理由留痕。

### C1 规范形 = 商对象代表元（泛性质/余等化子）

- **内容**：X/E 的商泛性质（E-不变函数唯一分解过商映射）；规范形 = 代表元选取
  r: X → R（常类、幂等、保表示）；输出 = G∘r。
- **覆盖**：P2（argmin = 命中全集的极小代表元）、P3（sort = 置换轨道的代表元）、
  P5（键 = ker F 类的摘要代表元）完全承载；P1/P7 的舍入点（round = 到 ℤ 格的
  投影代表元）；P8 是代表元构造的机械化。
- **证明力**：对不变性定理完全承载——「良定义性」恰是商泛性质 + r 常类性。
- **裁决**：**采纳为 K_can 的骨架；作为七提案单一核否决。** 否决理由：P4/P6
  没有商结构——它们的困难不是「同一语义对象的多种表示互相扰动」，而是「多个
  可行解中哪一个最优」。把最优解叫做「规范形」不承载任何证明：KKT 的证明用的是
  凸性与对偶，不是商泛性质；§0-A 原文对 P4/P6 的牵强覆盖（架构师 m6）在此获得
  精确的数学表述——**牵强点在于把一个序性质（最优）说成了一个商性质（规范）**。
- **留痕**：Bourbaki 式的 eponymous structure；P3 证 3 的归纳法正是该泛性质在
  排序上的算法形态（§3.3 给出对应）。

### C2 充分统计量（信息论）

- **内容**：π 是 F 的充分统计量 ⟺ π(x)=π(y) ⇒ F(x)=F(y) ⟺ ker π 细于 ker F。
- **覆盖**：P5（本体）；P3（内容键排序数组是 build 的充分统计量）；P2（argmin
  是命中集合的充分统计量）；P6-Kalman（(Σx_k/σ_k², Σ1/σ_k²) 是 θ 的充分统计量）。
- **否决理由**：P1/P7 **无压缩**——它们是精确性提案不是压缩提案（把实数计算
  搬进 ℤ 不减少任何信息，充分统计量语言无对象可挂）；P4/P6-分配无压缩（分配是
  θ/σ 剖面自身的函数）。
- **裁决**：**采纳为 K_can 的子结构（内核定理 KCT-2）；不作为全核。**

### C3 Galois 连接 / 伴随

- **覆盖**：P4/P6 的对偶（水位 ↔ 预算、√λ ↔ N 是单调双射）；P5 的核-商分解。
- **否决理由**：**在覆盖处空转**——任何单调双射都是 Galois 连接，该框架对
  water-filling 不增加任何证明力（KKT/Fenchel 才是承载证明）；P1/P2/P3/P7 的
  中心定理无 Galois 形式（round 不单调；min 的伴随构造牵强且不承载「最小元
  唯一」这一实际证明）。
- **裁决**：**否决**（留痕：它是 K_opt 的语言装饰，不是内核。N2 不满足）。

### C4 闭包算子 / 格论

- **覆盖**：sort、round、min 都是幂等投影（核算子意义上的闭包）；P7 的半群
  在整数格上精确。
- **否决理由**：(a) P4/P6 无自然闭包结构——最优解不是可行集的闭包（闭包算子
  的定理「不动点成格」推不出 KKT）；(b) 「最优 = 闭包」是隐喻，违反 N2；
  (c) P5 的哈希不是格运算。
- **裁决**：**否决为主**；「幂等投影」作为 K_can 公理 A2(c) 的一条被收编。

### C5 范畴论：反射子（reflective subcategory）

- **覆盖**：同 C1——sort 是到「已排序序列」全子范畴的反射、round 是到整数
  子格的反射、digest 是到「规范键」的反射，反射子的泛性质给出良定义性。
- **否决理由**：P4/P6 无自然反射子——「最优解子范畴」不是反射子：不存在从任意
  可行解到最优解的、满足泛性质的函子；最优性是**序性质**（比较所有可行解），
  反射是**子对象性质**（万有提升），两者范畴层级不同。
- **裁决**：**采纳为 K_can 的范畴语言（KCT-1 的优雅表述）；作为全核否决。**

### C6 项重写 / 合流性（Church–Rosser）

- **内容**：确定性 = 合流（任何两条执行路径到达同一规范形）；修复合流的两条
  机制：把运算换成 AC-精确的（整数/min/哈希），或把策略规范化（固定形状归约）。
- **覆盖**：全部七提案的**确定性主张**（见 §3.2 KCT-3 与 §6.3）。
- **否决理由**：推不出 P4/P6 的**最优性主张**——water-filling 解不是任何自然
  重写系统的规范形，它是凸对偶的产物；水位二分是**搜索**不是**归约**。
- **裁决**：**部分采纳**——合流性语言进入 K_can 的精确性公理动机（A3）与
  KCT-3；作为七提案全核否决（N2 对 P4/P6 不满足）。

### C7 引擎自有对偶分类（开发者指南 §3.5.3 的 DualityPair 五对偶）

- 把七提案往引擎注册元数据上映射：P4/P6 → `PrimalMultiplier`（原问题↔乘子）；
  P3/P5 → `ContentDigest`（内容↔摘要）；P1 → `TimeFrequency`（DCT）；
  **P2/P7 不落入任何一对偶**（argmin 与凸组合半群都不是对偶）；P6 的分配与
  Kalman 分居两类。
- **裁决**：这不是候选核而是**独立佐证数据点**——引擎自身的注册分类就把七提案
  分裂了，说明双簇聚类是自然断层线，不是 QA 的牵强归类。

### C8（任务候选之外）「万能 argmin」元原则

- **内容**：每提案的选择步骤确实都是某候选集在某序下的唯一极值元：P2 的
  argmin_≺；P3 的排序（= 置换集按内容键字典序的 argmin）；P4/P6 的 argmin_目标；
  P5 的最紧键（= 细化格上的 argmax）；P1/P7 的 round（= 格上按距离的 argmin）。
- **评估**：描述为真。但**非承载**：每提案的中心定理（P1 的正交性用法与误差界、
  P4 的 KKT 闭式、P6 的 C-S 下界、P3 的归纳法）都不从「它是 argmin」推出；
  且推不出任何新推论（§5.4 给出检验过程）。
- **裁决**：**否决为核；保留为设计启发式的正确数学表述**——它正是 §0-A 三问
  清单（「输出的规范形/最优解是什么」）的数学化，其价值在方法论而非定理。

## 3. 内核一：K_can（规范化内核）

### 3.1 公理体系：规范计算结构（Canonical Computation Structure, CCS）

一个 CCS 是六元组 **(X, E, R, r, Ω, G)**：

- **X**：表示空间（input representations——同一语义对象的全部表示：加载序、
  遍历序、并列枚举、浮点历程、参数子集……）；
- **E ⊆ X×X**：表示等价关系（「表示同一语义对象」）；
- **R**：代表元空间，承载运算族 Ω；
- **r: X → R**：**规范代表映射**，满足三条公理：
  - **A2(a) 常类性（E-不变）**：xEy ⇒ r(x) = r(y)。（规范形必须是语义对象的
    函数，不是表示的函数——B2 的失败正是违反此条。）
  - **A2(b) 代表性**：r(x) 与 x 表示同一语义对象（携带 F 所需的全部语义内容；
    允许有界近似，其误差界是实例内容）。
  - **A2(c) 幂等性（投影性）**：r(r(x)) = r(x)。（sort/round/min/digest 皆满足；
    B1 的失败与此相关：安全阈值常量必须是安全集的精确边界函数，而非近似估计。）
- **A3 精确性**：Ω 中每个运算是 R 上的**确定性函数**——相同输入位型必得相同
  输出位型，计算不读取未提及的输入（无 RNG、无时钟、无指针身份、无执行序
  依赖、无 libm/fma 收缩语义）。工程形态：ℤ^k 算术、定点、全序比较、确定性
  哈希、IEEE 规定的基本 FP 运算（仅当执行序列被 R 唯一确定时）。
- **A4 因子分解**：输出 Out = G∘r，G 是 Ω 上的程序。

> **设计立场声明**：A1（商泛性质）不是 CCS 的「成分」而是背景数学——见 KCT-1。
> A2(a)+A3 承载**确定性**内容，A2(b) 承载**质量**内容（保真/紧致/端点精确），
> 这个切分是 K_can 最重要的内部结构：确定性定理只依赖前两条。

### 3.2 内核定理

**KCT-1（良定义性与位级确定性）**。设 (X,E,R,r,Ω,G) 满足 A1–A4。则：
(i) Out 是 X/E 上良定义的函数（xEy ⇒ Out(x)=Out(y)）；
(ii) 若 A3 成立，则 Out 逐位可复现：同一输入表示在两跑/两平台/两执行序下给出
    逐字节相同的输出。

*证明*。(i) xEy ⇒ r(x)=r(y)（A2(a)）⇒ G(r(x))=G(r(y))。(ii) Out(x) 的值由
r(x)（函数，A2(a) 保证良定义）与 G（Ω-程序）决定；A3 保证 Ω-程序的每一步是
位型层面的函数且不读环境量，故整条程序是位型的函数；由归纳于程序长度得位级
可复现。∎

> 注：(i) 就是商对象的泛性质（coequalizer 的 universal property）在 CCS 上的
> 特例：任何 E-不变的 F: X→O 唯一分解为 X → X/E → O。原文各提案的「纯函数」
> 论述全部是 (i) 的手写版本。

**KCT-2（可靠性/充分性准则）**。设 F: X→O 确定性，π: X→K 是键映射。则

```
π 对 F 可靠（π(x)=π(y) ⇒ F(x)=F(y)）  ⟺  ker π ⊆ ker F  ⟺  π 过商 X/ker F 分解。
```

且键族中的**最紧**可靠键实现 ker π = ker F（= 输出类的摘要）。

*证明*。⟹：π(x)=π(y) ⇒ (x,y)∈ker π ⇒ F(x)=F(y) ⇒ (x,y)∈ker F。⟸：平凡。
分解：π̄([x])=π(x) 由 ker π ⊆ ker F 良定义。最紧性：若 ker π ⊊ ker F，则存在
x≠̃y（F 同值）而键不同，浪费缓存条目；ker π = ker F 时键恰是输出类的完全
不变量（模哈希碰撞）。∎

**KCT-3（AC 折合三分律）**。设 ⊕ 是集合 S 上的二元运算，折合（fold）一个
有限多重集。则：
(i) ⊕ 为半格（结合+交换+幂等）⇒ 折合值与结合序、枚举序无关；
(ii) ⊕ 为 AC 且**精确**（在被表示结构上是真函数，如整数加法）⇒ 同上；
(iii) ⊕ 非精确（FP 加减：在位型上交换但不在被表值上结合）⇒ 折合值序相关；
    此时只有三条出路：**定形**（固定结合序，如 prism-core 的固定形状归约）、
    **排序**（先规范化枚举再折合，`reduce_sorted_by_key`）、**预算**（给序相关
    性一个解析误差界，如 P2 的 u(⌈log₂n⌉+1)Σ|x|）。

*证明*。(i)(ii)：AC 运算下降到自由交换幺半群，多重集的折合等于该幺半群中的
和，唯一。(iii) 的标准前向误差分析（Higham 风格）给出 P2 所用界；三条出路
分别对应：把策略变成规范形（定形/排序）或把分歧关进界里（预算）。∎

**KCT-4（舍入链误差复合）**。设管线由若干舍入点（第 j 点格距 g_j）与其间的
精确线性/仿射运算组成，第 j 个舍入点对输出的 ℓ¹ 敏感度为 s_j。则

```
|误差| ≤ Σ_j s_j·(g_j/2) + g_final/2 。
```

*证明*。每个舍入点扰动 ≤ g_j/2（round-to-nearest 的最优性：最近格点），经
线性管线放大 s_j 倍；末位舍入 ≤ g_final/2；三角不等式合并。∎
（P1 是三舍入点 + 末位移位的实例，P7 是一舍入点 + 末位舍入的实例，见 §3.5。）

### 3.3 五提案到 K_can 的映射证明

以下逐提案给出**完整**映射：实例化 CCS 六元组、逐条验证公理、引出该提案中心
定理为 KCT 的推论。不准许「显然」。

#### P3 ↦ K_can（原文证 1–3 的内核形式）

- **实例化**：X = 图元序列空间（同资产的全部加载/合并/三角化输出序）；
  E = 置换等价（同多重集）；R = 内容键排序后的数组；r = 按内容键
  (morton, 质心位型, 内容摘要) 排序；Ω = {键比较, SAH 切分（min/max 累加 +
  整数计数 + f32 累加 +  winding 聚合）, 确定性哈希}；G = build。
- **A2(a) 验证**：内容键是严格全序（前两项整数比较，第三项摘要比较，摘要
  抗碰撞假设如文档 M-2 所钉）⇒ 同一多重集的任意两个输入序列排序到**同一
  数组**。这正是原文证 3 归纳法的结论——归纳法（首分歧位 full key 必等 ⇒
  位相同 ⇒ 可交换）就是 A2(a) 在排序上的构造性证明。**B2 的旧键 (code,index)
  违反 A2(a)**：index 是表示量（加载序）不是语义量，同码族内排序结果随表示
  漂移——交叉审的伪定理指控在内核语言中是一条公理违反。
- **A2(b) 验证**：排序数组是原序列的置换（保多重集）；build 只读数组值
  （证 1：无 RNG/时钟/指针身份）⇒ 语义保持。
- **A2(c) 验证**：对已排序数组再排序不变。
- **A3 验证**：比较与哈希精确；f32 累加的 A3 合格性是**间接的**——R 的元素
  （排序数组）唯一确定了全部 FP 运算的执行序列（按下标序），而 f32 基本运算
  是 IEEE 逐位规定的 ⇒ 在此唯一序列下每个 FP 运算是位型的函数 ⇒ A3 合取
  成立。这就是原文证 2「规范化后无条件逐位相同（不是至多噪声）」的公理根据：
  **不是 f32 变精确了，而是规范代表元把执行序列钉死了**。
- **结论**：KCT-1 ⇒ BVH（结构 + 叶内序 + winding 聚合）是多重集的纯函数且
  逐位可复现。∎（= 原文证 1+2+3 的合并与加强）

#### P2 ↦ K_can（语义级 parity 是结构性的，字节级不可能也是结构性的）

- **实例化**：X = 命中记录的枚举序列；E = 置换；R = 有限链 (H, ≺)，≺ =
  (t, 规范槽位) 字典序；r = argmin_≺；Ω = {比较, min}；G = 槽位→图元查表。
- **A2(a)**：有限链上最小元唯一 ⇒ argmin 是多重集的函数。**A2(b)**：最小元
  ∈ H。**A2(c)**：min 幂等。
- **剪枝安全性的内核位置**：A2(b) 要求 argmin 的定义域是**真实命中全集**的
  函数；遍历会剪枝 ⇒ 需保证「被剪子树不含更近命中」（不漏）。ε=6u·t_max 松弛
  证的就是定义域完整性——即 P2 证 1b 是 A2(b) 的加强版（安全性 + argmin 不变
  的合取 = 定义域完整 + 代表元唯一）。
- **A3 的分层合格性（本映射最重要的发现）**：比较与 min 在语义层精确；但
  t 是 FP 计算的（Möller–Trumbore，后向误差 ≤79u·|t|）⇒ **A3 在字节层失败**：
  `ht == best_t` 的并列真值两端可不同。KCT-1(ii) 因此只覆盖**语义层**（同一
  图元胜出），不覆盖字节层——这正是 P2「诚实声明」（bit-exact 不可能）的
  精确内核形式：不是工程遗憾，是 A3 在该实例的字节层不成立。
- **KCT-3(i) 的应用**：min 是半格 ⇒ running-min 折合无需定形、无需误差预算 ⇒
  语义级 parity 是**结构性**的；而 FP 颜色归约走 KCT-3(iii) ⇒ 需要树形定形 +
  解析预算（D-3 门禁②的 95 dB 余量）。同一提案内两条分律各得其所。
- **结论**：KCT-1(i)+KCT-3(i) ⇒ argmin 不变性（遍历序/线程调度/workgroup 无关）；
  A3 分层 ⇒ 语义级 parity 成立且字节级不可能；两者合起即 P2 全部中心结论。∎

#### P5 ↦ K_can（健全性定理 = KCT-2 的逐字实例）

- **实例化**：X = 渲染参数空间 P；E = ker F（同输出）；R = 键空间；
  r = H∘π；Ω = {规范序列化, SHA-256}；G = 缓存查表。
- **KCT-2 逐字对应**：P5 证 1「健全 ⟺ π(P₁)=π(P₂) ⇒ F(P₁)=F(P₂)」就是 KCT-2
  的左式；「π 覆盖 Dep(F)」就是 ker π ⊆ ker F；「逆否给出反例构造法」就是
  ker π ⊄ ker F 时取 (x,y)∈ker F∖ker π 造同键不同图。**fail-safe 方向**
  （宁过勿欠，证 3）的不对称也由 KCT-2 解释：欠（违反 A2(a)）⇒ 错误字节
  （健全性破坏）；过（ker π 过细）⇒ 只损失命中率（紧性损失，A2(b) 的质量面）。
- **A3**：序列化 + SHA-256 是纯整数函数（prism-core signature.rs 内置 FIPS
  实现，零依赖）⇒ 键计算本身逐位确定。
- **结论**：P5 的全部四条证明（健全性、反例、fail-safe、闭包清单补全）都是
  KCT-2 + A3 的推论。∎

#### P1 ↦ K_can（ℤ 格精确实现 ℝ 正交变换）

- **实例化**：X = 量化 DCT 系数 D∈ℤ⁶⁴（输入本就是精确的；E 的对手是**算术
  历程**——同一实数值的不同 FP 执行/舍入路径）；R = 两阶段整数管线（S1, S2 ∈
  ℤ，末位一次移位）；r = 反量化（精确）+ 表舍入 W=⌊2^16·c(u)c(v)⌉、
  C=⌊2^14·K⌉（一次性投影）；Ω = {i64/i128 乘加, 算术移位, clamp}；G = clamp。
- **A2(b) 的结构保持版（折归一化的数学作用）**：正交性恒等式
  Σc(u)²K(u,x)K(u,x') = 4δ 使归一化因子 ¼c(u)c(v) 可**同痕地**折进整数权重
  W ⇒ 整数管线计算的实值 = 精确 IDCT 的值（误差仅来自三个舍入点）⇒ 代表性
  成立且误差界为 KCT-4 的实例：|Δ| ≤ (2^-16+2^-19)Σ|D| + 0.5 LSB
  （s_W = 2^28·2^-46·Σ|D| 口径、s_C = 2^14·2^16·2^-46·Σ|D| 口径各两次，
  与原文证 2 修正后逐项一致——KCT-4 是该误差分解的一般形式）。
- **A3**：Ω 全部是精确整数运算，无 FP 舍入模式依赖、无 fma 收缩、无 libm
  ⇒ KCT-1(ii)：跨平台逐位一致（= 原文证 3）。
- **A2(c)/宽度选择**：证 1 的 i128 不是正确性装饰而是 A3 的**整数宽度选择**：
  在 i64 上 Ω 的「函数性」被回绕破坏（8-bit 最坏界 5.877e20 超 i64 64×，
  对抗块 1.30e20 超 14.1×）⇒ 宽度必须覆盖最坏定理界；快路径阈值 2^29−1 是
  A2(c) 的实例：安全/快速两子集上的 r 都必须是**安全谓词的精确函数**——
  B1 的 10× 错常量就是「r 的构造不是它声称规范的集合的纯函数」。
- **结论**：P1 四证全部为 KCT-1/KCT-4 的推论。∎

#### P7 ↦ K_can（半群 + u8 整数格）

- **实例化**：X = 实数权重 t∈[0,1]；E = 网格等价（round(256t)=round(256t')）；
  R = u8 格 W∈{0,…,256}；r = round-to-nearest；Ω = {整数乘加, 移位, clamp}；
  G = clamp。
- **A2(c)**：round 幂等（整数的最近格点是自身）⇒ 重归一化链每步误差 ≤1 LSB 有界。
- **A2(b)**：代表性 = 凸组合保真（误差 ≤1.0 LSB，证 2）+ **端点逐点精确**
  （k=0/1 ⇒ W=0/256 ⇒ 输出逐位等于源帧——Wipe 端点修复就是恢复这一条：
  smoothstep 骑跨带使端点不落在格点上，违反 A2(b) 的逐点版本）。
- **A3**：整数运算无 fma 收缩、无舍入模式 ⇒ CPU/GPU 逐位一致（证 3 =
  KCT-1(ii) 的直接实例——与 P2 的字节层失败恰成对照：**同一引擎里，语义搬进
  整数格就获得字节确定，留在 FP 就只有预算**）。
- **半群律的内核位置**：k(s)k(t) 在整数网格上精确（u32 链长 ≤3、u64 ≤4，
  n3 修正）⇒ 同目标链折叠闭式成立；t↦ln(1−t) 同构是**连续侧**的说明，整数侧
  不需要 log——即半群结构是 R 上 Ω 保持的代数结构（A2(b) 的结构保持版），
  这正是 P1 与 P7 共享的深层形态：**把连续结构的运算律无损地搬进精确格**。
- **结论**：P7 的半群律、误差界、跨端一致、端点审计全部为 KCT 推论。∎

#### P8 ↦ K_can（工程层实例：A2(a) 的构造机械化）

- P8 不引入新数学；它把 KCT-2 中「π 的构造」从人工枚举变为编译期机械枚举：
  宏展开对结构体每个字段生成入哈希代码 ⇒ 「漏字段」从每字段的人为疏失变成
  宏本身的一次性 bug。在内核语言中：**P8 是 A2(a) 的构造完备性保证**——
  键的 E-不变性（ker π ⊆ ker F）中属于 RenderParams 的部分由编译器背书，
  其余分量（种子、scene_sig、frame）仍人工但面从「每字段」缩到「每结构体」。
- QA 的 M-3（Rust 无反射 ⇒ lint 测试对将来字段静默失效）在内核语言中是一条
  精确的诊断：**A2(a) 的人工验证机制不能机械地覆盖将来表示**。P8 因此是
  K_can 的推论而非独立提案。

### 3.4 K_can 内部结构小结

- 确定性内容 = A2(a) + A3（KCT-1(ii)）：规范形是语义的函数 + 构造精确。
- 质量内容 = A2(b)（KCT-4 给误差界）：保真、紧致、端点精确。
- B1/B2 两个 B 级事故的公理诊断：B2 违反 A2(a)（键含表示量 index）；
  B1 违反 A2(c)（阈值不是安全集的精确边界函数）。**两事故同根**：
  规范形构造本身没有过 K_can 的公理检查——这正是原文 §0-A 方法论教训
  （「规范形构造本身必须是纯函数」）的公理化形式。

### 3.5 新推论（K_can 的；文档中均无）

**NC-1（统一 scene 规范形：P3×P5 融合）**。KCT-2 的最紧键 = 输出类的摘要；
对渲染输出而言，「图元多重集的内容键排序数组」是 build 与渲染共同的充分
统计量（P3 证 2 已证 build 只依赖它）。因此 **scene_sig 应定义为 P3 内容键
排序数组的确定性摘要，而不是另起一套场景哈希**。后果：(a) 「同资产多重集 ⇒

## 4. 内核二：K_opt（最优性内核）

### 4.1 公理体系：可分凸分配结构（Separable Convex Allocation, SCA）

实例为 ((f_i)_{i∈I}, (l_i)_{i∈I}, B)：I 有限；每个 f_i: [l_i,∞)→ℝ 满足
**C¹ 严格凸、f_i' 连续严格递减、f_i'(l_i) = −a_i < 0、lim_{x→∞} f_i'(x) = 0⁻**
（即 f_i' : [l_i,∞) → (−a_i, 0) 是双射）。问题：

```
min Σ_i f_i(x_i)   s.t.  Σ_i x_i = B,  x_i ≥ l_i 。
```

（P4/P6 的分配部分都是其特例；P6 的 Kalman 部分是同一内核的「加权最小二乘」
实例，见 §4.3。）

### 4.2 内核定理

**OT1（对偶闭式 + 钳位）**。设 B 可行。则解唯一存在且

```
x_i*(λ) = max( l_i, (f_i')⁻¹(−λ) ),     λ > 0 由 Σ_i x_i*(λ) = B 唯一确定；
活跃集 A(λ) = { i : a_i > λ }。
```

*证明*。目标严格凸 + 约束线性 ⇒ KKT 充分（凸对偶）。Lagrange：∃λ≥0 使
f_i'(x_i*) = −λ 当 x_i* > l_i，x_i* = l_i 否则（互补松弛：钳位发生时
f_i'(l_i) = −a_i ≤ −λ 即 a_i ≥ λ）。由双射性 x_i* = max(l_i, (f_i')⁻¹(−λ))。
唯一性：λ↦Σx_i*(λ) 连续、在至少一个活跃元上严格递减（(f_i')⁻¹ 递减，
max 保序）⇒ 至多一个 λ；可行性区间非空给定 B 可行。∎

**OT2（等边际证书）**。∀i∈A(λ)：f_i'(x_i*) = −λ。即**全部活跃单元的边际
值相等**——可断言的强证书。

**OT3（包络定理/影子价格）**。设 V*(B) 为最优值，活跃集在 B 的邻域稳定。则

```
dV*/dB = −λ 。
```

*证明*。V*(B) = Σf_i(x_i*(B))；dV*/dB = Σf_i'(x_i*)·dx_i*/dB =
Σ(−λ)dx_i*/dB = −λ·d(Σx_i*)/dB = −λ（用了 Σx_i* ≡ B 与钳位点 dx_i*=0）。∎
（数值验证见 §7：P4 与 P6 含钳位情形均成立。）

**OT4（Fenchel 证明路线）**。不经 KKT：原问题 ⇔ min_x max_{p≤0}
[Σf_i(x_i) + p(B − Σx_i)]，凸⇒可交换（minimax）⇒ 对偶问题
max_p [pB − Σf_i*(p)]，一阶条件 B − Σ(f_i*)'(p) = 0；由共轭函数性质
(f_i*)'(p) = (f_i')⁻¹(p)（p<0）得 Σ(f_i')⁻¹(p) = B，p = −λ——即 OT1 的方程。
**water-filling 因此有完全不经 KKT 的证明**（§7 数值复现）。

**OT5（a²/x 族的 Cauchy–Schwarz 下界）**。若 f_i(x) = a_i²/x（a_i>0），则

```
Σ a_i²/x_i ≥ (Σa_i)²/(Σx_i),  等号 ⟺ x_i ∝ a_i 。
```

*证明*。对 (√x_i)、(a_i/√x_i) 用 Cauchy–Schwarz。∎（P6 的 C-S 下界是
a_i=σ_i、Σx_i=N 的特例；注意 P4 的 D_i 不属此族——P4 的下界来自共轭
（OT4），两实例在同一内核内部分属不同下界机制，这正说明内核的实例有
真实的个体性，不是硬套。）

### 4.3 P4、P6 到 K_opt 的映射证明

#### P4 ↦ K_opt

- **实例化**：I = GOP 内帧；f_i(R) = θ_i·2^(−2R_i)，l_i = 0，B = 码率预算。
  假设核验：f_i'' = 4(ln2)²θ_i2^(−2R) > 0（严格凸 ✓）；f_i' = −2ln2θ_i2^(−2R)
  严格递减 ✓；f_i'(0) = −2ln2θ_i（a_i = 2ln2θ_i）✓；f_i'→0⁻ ✓。
- **OT1 ⇒ reverse water-filling**：(f_i')⁻¹(−λ) = ½log₂(2ln2θ_i/λ)；
  记 θ = λ/(2ln2) 得 R_i = max(0, ½log₂(θ_i/θ))——与原文逐字一致。λ 的唯一性
  即「ΣR_i(θ) 严格单调 ⇒ 水位唯一」。
- **OT2 ⇒ 等畸变证书**：活跃帧 D_i(R_i) = θ_i2^(−2R_i) = λ/(2ln2) = δ 常数
  （原文证 3；exp7 max/min = 1.000000 是该定理的数值形态）。
- **OT2 两单元特例 ⇒ B 帧闭式**：P、B 均活跃 ⇒ ½log₂(θ_B/θ_P) = R_B − R_P
  （原文证 4）。
- **OT3 ⇒ 影子价格**：λ = −dD*/dB = 每比特的边际畸变（新，NO-1）。
- **OT4 ⇒ Fenchel 证明**（新，NO-3）。
- **依赖加权的内核解释**：θ_i ← θ_i·d_i 是**实例参数替换**（a_i 全量缩放
  d_i 倍），SCA 结构不动 ⇒ KKT 结构与等畸变证书对加权稳健（原文自审结论
  获得内核解释：证书稳健不是巧合，是结构在参数替换下不变）。

#### P6 ↦ K_opt

**（甲）分配部分 ↦ SCA**：I = 区域；f_i(n) = σ_i²/n，l_i = 1，B = N。
假设核验：f_i' = −σ_i²/n² 在 [1,∞) 严格递减 ✓，f_i'(1) = −σ_i²（a_i = σ_i²）✓，
f_i'→0⁻ ✓。则：

- **OT1 ⇒ n_i = max(1, σ_i/√λ)**——原文的约束闭式（自审修正后的正确形式；
  无约束式 n_i ∝ σ_i 是其主动支）。λ 唯一即「Σn_i(λ) 单调」。
- **OT2 ⇒ 等边际 σ_i²/n_i² = λ**（主动支）——P4 等畸变的分配版。
- **OT5 ⇒ C-S 下界与 Neyman**：MSE ≥ (Σσ)²/N，等号 ⟺ n_i ∝ σ_i——原文证 1/2
  的最短证明；且 σ² 分配次优的比值 mΣσ²/(Σσ)² = E[σ²]/E[σ]² = 1+CV²（M7 修正后
  代数）是 OT5 与直接代入的比较，削减率 1−1/(1+CV²) 随之而来。
- **OT3 ⇒ 影子价格**：λ = −dMSE/dN（新，NO-1；§7 含钳位验证）。

**（乙）Kalman 部分 ↦ K_opt 的 WLS 实例**：单变量严格凸问题
min_θ Σ_k (x_k−θ)²/σ_k²。一阶条件 Σ(x_k−θ̂)/σ_k² = 0 ⇒ 逆方差加权均值
（BLUE）；「证书」= Var = 1/Σ(1/σ_k²)；Kalman 递推是一阶条件的增量形式
（V_n = 1/Σ_{k≤n}(1/σ_k²) 的归纳——原文证 4）；Gauss–Markov 的适用条件
（权重独立于观测）是**实例假设检查**——原文的双通道审计（通道 A 有定理 /
通道 B 仅经验）在内核语言中就是「实例假设成立/不成立」的二分，不是程度
差异。影子量 = 后验精度 1/V，加一样本（精度 w）的边际方差缩减
dV/d(Σw) = −V²（NO-1 的估计版）。

### 4.4 新推论（K_opt 的；文档中均无；数值验证见 §7）

**NO-1（影子价格包络定理：预算的边际价格）**。OT3 对两实例给出：
P4：λ = −dD*/dB = 2ln2·δ（每比特边际畸变 = 共同畸变的 2ln2 倍）；
P6：λ = −dMSE/dN（每样本边际 MSE 缩减）。**含钳位情形仍成立**（§7 验证）。
用途（新）：**预算自适应的停止规则**——P6 加样本直到 λ < 样本成本；
P4 加比特直到 λ < 比特成本。文档中 λ 只是求解中间量，从未被定价。

**NO-2（内部情形的对偶闭式）**。全部活跃时：P6：λ = (Σσ)²/N²，
MSE = (Σσ)²/N，dλ/dN = −2λ/N（影子价格按 1/N 衰减）；P4：λ = 2ln2·δ。
（§7 验证。）这把「等畸变证书」从认证件升级为**定价器**：δ 可直接换算成
每比特的畸变价格。

**NO-3（P4 的 Fenchel 证明简化）**。OT4 给出不经 KKT 的 water-filling 推导
（共轭 + 一阶条件 + 包络），且与 KKT 路线数值一致（§7）。附带消解 QA 的
m-6：log 域分段闭式就是对偶问题（一维单调方程）的离散精确解——同一路线
的两种离散化，不是两个算法。

**NO-4（共享对偶求解器的数学接口）**。OT1 给出 P4/P6 共用的求解器规格：
每单元提供 (值, 导数, 导数逆) 三元闭包 + 下界 l_i；求解器 = 对偶函数
Σx_i*(λ) 的单调求根。QA 的 P4×P6 工程收拢建议由此获得定理级 API 定义
（~30 行，两提案各传 3 行闭包；KKT 充分性由 OT1 统一背书）。

**NO-5（两单元类比：P6 的「B 帧闭式」）**。OT2 的两单元特例对 P6 给出
n_B/n_P = σ_B/σ_P（两单元的样本配比 = 标准差之比：噪声大的区域分得更多
样本）——与 P4 的 R_B − R_P = ½log₂(θ_B/θ_P) 是同一等边际证书的两面。
可用于时域累积的帧间/区间预算分配（文档未列）。

**NO-6（等分配与 σ² 分配的 MSE 等价）**。直接代入：等分配 n_i=N/m 与
σ² 分配 n_i=Nσ_i²/Σσ² 给出同一 MSE = mΣσ²/N。因此原文证 2「σ² 严格次优」
自动覆盖「等分配严格次优」（同值），「修正 σ→σ」与「修正等分→σ 律」是
同一个修正——RQ-2 的达标论证只需打一次。

## 5. 不存在性论证：不存在装下七提案的单一非空核

### 5.1 「核」的非空性标准（预先钉死）

候选 K 是七提案的核，当且仅当：
**(N1)** K 是数学结构类型（公理体系 + 实例概念）；
**(N2)** 每提案的**中心定理**是 K-实例理论中的定理——内核提供承载证明技术，
而非事后描述；
**(N3)** K 推出至少一条文档中没有的新命题（新推论检验；推不出新东西的
统一只是修辞）。

### 5.2 反侧构造：两族定理逻辑独立（事实取自文档自身）

**事实 1（不变性 ⇏ 最优性）**。K_can 的实例可以输出**非最优**的结果，
且文档自己提供了证据：P3 的内容键排序是完全规范的（A2(a) 满足），但
Morton 序不是 SAH 最优序——Hilbert 曲线是合法替代（架构师 m2 降调
「唯一自然构造」时确认），规范序的 SAH 代价 1.0000 是「保持」不是「最优」；
P2 的规范槽位 tie-break 对任意严格全序都给出 parity，与画质无关。
⇒ 存在 K_can 模型，其输出可证为次优。

**事实 2（最优性 ⇏ 不变性）**。K_opt 的实例可以输出**非不变**的结果，
文档同样自证：P4 一遍路径的最优解依赖 θ 先验（估计），P6 的 σ 探针递推
使分配依赖 GOP 历史——M8 之前的 seek 重放被破坏即「最优解随表示漂移」；
不变性是靠**外加的**规范化步骤（GOP 边界重置协议）恢复的，不是 KKT 自带的。
⇒ 存在 K_opt 实例，其最优解可证为表示依赖。

**独立性结论**。事实 1+2 表明：两族的中心定理（不变性 vs 极端性）互不
蕴含，且**反例都在文档内部**——不需要构造人造模型。

### 5.3 分离定理

**定理（候选空间内的分离）**。任何满足 N1–N2（对全部七提案）的结构类型 K，
其公理集必然包含两个互不交互的公理组：
(α) **等价/代表/精确组**——证明 P1/P2/P3/P5/P7 的不变性定理所必需
    （§1.2 矩阵：成分 1,2,7,8,9,10,11 的承载需要；抽掉任一组内成分，
    对应提案的中心定理立即不成立）；
(β) **凸序/对偶组**——证明 P4/P6 的极端性定理所必需（成分 4,5）。
且 (α)(β) 在下述意义上互不交互：对 (α) 的每个实例（如 P2 的有限链），
(β) 的公理或者不适用（无凸结构在场）或者退化（链上每点同时是极小与极大，
凸性空转）；对称地，对 (β) 的每个实例（如 P4 的连续凸问题），(α) 的公理
或者不适用（无表示等价结构——连续凸问题的「表示」问题要另行引入）或者
退化为平凡相等。因此 K 的理论 = 两个独立理论的合取 + 至多空转的桥公理；
**合取不产生统一的证明技术**，从而 K 无法满足 N3（推不出新命题）。

*论证展开*。(α)(β) 的必要性由 §1.2 矩阵保证：矩阵中两簇的 ● 承载集不相交，
且每个成分都在对应提案的证明中不可替代（例如抽掉 P2 的全序，argmin 不变性
退化为「任意选择」；抽掉 P4 的凸性，KKT 充分性失效——原文证 1 的证明第一步
就是凸性）。互不交互由反侧构造（事实 1、2）保证：若 (α) 能推出 (β) 的内容，
则事实 1 的反例不可能存在；若 (β) 能推出 (α) 的内容，则事实 2 的反例不可能
存在。桥公理空转：任何同时约束「等价类」与「凸序」的公理（如「序化的商
结构」）在至少一族实例上退化为平凡（链的商仍是链；凸问题的平凡商是单点），
不承载证明。∎（适用边界见 §5.6）

### 5.4 「万能 argmin」元原则为何不是核（N3 检验的完整执行）

对最强的统一候选——「七提案的输出都是某候选集在某序下的唯一极值元」
（C8）——执行新推论检验：试图从「它是 argmin」这一前提推出任何文档中
没有的命题。

| 尝试推出 | 结果 |
|---------|------|
| P1 的误差界 | 推不出。界来自正交性 + 舍入分析（KCT-4 的实例内容），argmin 性不含误差信息 |
| P4 的水位闭式 | 推不出。闭式来自 f_i' 的显式反函数（凸结构），argmin 性只说「存在唯一」 |
| P6 的 C-S 下界 | 推不出。下界来自内积不等式，argmin 性不说任何关于最优值的话 |
| P2 的归约预算 | 推不出。预算来自 FP 前向误差分析 |
| 任何跨提案的新设计规则 | 推不出。每个实例的「候选集 + 序」都是实例数据，元原则不含实例间的任何映射 |

结论：元原则是**真描述 + 零定理生成能力**。按 N3 否决为核。它的正确位置

教训是问第三问问出来的）。**描述与理论的这一分别，正是「双支柱」与
「两内核」的分界。**

### 5.5 比「双支柱归类」强的三句话

QA 的双支柱（规范化 5 + 最优性 2）是**归类**；本文给出的是**结构**：

1. **聚类有承载成分的硬证据**（§1.2 矩阵：两簇 ● 不相交），不是相似性印象；
2. **两簇各是一个公理体系**，各有内核定理（KCT-1..4 / OT1..5）与映射证明
   （§3.3、§4.3），且各能推出新东西（NC-1..5 / NO-1..6）——满足 N3；
3. **两核的关系被精确刻画为：定理层独立（§5.2），实现层单向依赖**：
   K_opt 的任何浮点实现要满足确定性铁律，必须把求解器本身建在 K_can 的
   精确结构上。文档内有两个现成实证：**P4 的 det_log2 接线**（M6/U3：
   water-filling 的确定性实现需要 prism-math 的位分解 + atanh 级数纯
   ±×÷ 件）与 **P6 的 GOP 重置协议**（M8/U4：σ 探针状态必须窗口化为
   规范代表，否则 seek 重放漂移）。反向依赖不存在：K_can 的全部定理
   不触及最优性。所以准确的架构陈述不是「两根支柱并肩」，而是
   **「K_can 是地基，K_opt 是上层建筑；上层建筑的确定性版本必须坐在地基上」**。

### 5.6 论证的边界与诚实声明

**本文证明了**：(a) 八个自然候选（含任务清单之外补强的「万能 argmin」）
逐一不满足 N1–N3（§2 留痕）；(b) 两族中心定理逻辑独立，反例在文档内部
（§5.2）；(c) 满足 N1–N2 的候选必须空转于 N3，结构原因是「等式型目标 vs
量化序型目标」的证明论差异（§5.3）。

**本文没有证明**：不存在某个未来发明的、更聪明的公理体系能融合两族——
这类元数学不可能性命题在完全一般性下不可达（任何两个结构都可以被并置成
一个并结构，问题只在并结构是否空转）。本文给出的是**受 N3 约束下的否定：
凡是非空转的融合候选，必落在已评估的八类之中或其自然变体之中**；八类的
否决理由（覆盖缺口 / 承载性缺失 / 空转）对自然变体同样成立，因为否决理由
全部基于各候选的**定义性特征**而非实现细节。

**对任务标准的回应**：本文没有用「已经很统一了」敷衍——正面产出是两个
能推新东西的公理体系（§3.5、§4.4 共 11 条新推论，其中 6 条有数值验证），
负面结论是有标准、有反侧、有留痕的分离论证。**单一核不存在，但这不是
研究的终点，而是研究的精确形状：七提案 = 一个规范化理论（5 实例 + 1 工程
实例）+ 一个最优性理论（2 实例）+ 一条实现层依赖。**

## 6. 内核对引擎铁律的解释力

### 6.1 确定性铁律 = KCT-1 的工程化

引擎注释原话（开发者指南 §3.5.3 LatticePlan）：「全量锚定 ℤ^k：整数运算，
**确定性是定理而非承诺**」——这正是 KCT-1(ii)：在 A3 下，位级可复现是
CCS 的定理，不是测试运气。prism-core 的两件既有设施因此获得统一解读：
**签名树**（内容↔摘要，Merkle）是 P3/P5 的商-digest 实例（KCT-2 的工程体），
**固定形状归约代数**（reduction_shape 是 n 的纯函数、reduce_sorted_by_key）
是 KCT-3(iii) 第一/第二条出路的工程体。七提案不是把外来数学搬进引擎，
而是把 L2 内核已隐含的 CCS 结构在算法层显式化——P1/P7 的格锚定、P3/P5 的
内容键、P2 的全序 argmin，分别对应「问三」（格锚了吗）、ContentDigest 对偶、
KCT-3(i) 半格折合。**架构哲学「用一个核统一各部分」在数学层的对应物：
L2 内核统一的是求值图，K_can 统一的是算法层的不变性主张。**

### 6.2 D-15/D-29：精确性公理的结构后果，不是洁癖

A3 要求 Ω 的每个运算是**可审计的纯函数**。libm 的 cos/log2 是后向函数
（P1 实测 10/64 参数差 1–2 ulp；P4 的 f64::log2 同罪）⇒ 不是位型层面的
可靠函数 ⇒ 违反 A3。不透明的第三方算术同样违反（「函数性」不可审计）。
WGSL/LLVM 的 fma 收缩自由使同一公式的位型结果依赖编译器 ⇒ 违反 A3 的
「不读取未提及输入」条款（P2 诚实声明的公理根据）。所以禁 libm、禁第三方、
警惕 fma，都是 A3 的推论；零依赖铁律的数学身份是**规范形构造的可审计性**。

### 6.3 D-3 双门禁：A3 失效处的正确仪器

GPU 路径上 A3 系统性失效（fma 收缩 + 归约序不定）⇒ KCT-1(ii) 失效 ⇒
**字节级确定不可能**——这不是妥协，是定理。此时正确的验收仪器是 D-3 的
双门禁：语义级 parity（KCT-1(i) 仍在：argmin 的全序结构不依赖 A3 的字节层，
P2 证 1/1b）+ 输出级统计门禁（KCT-3(iii) 第三分律：把非合流路径的分歧
关进解析预算 u(⌈log₂n⌉+1)Σ|x|，P2 的 95 dB 余量即预算的余量）。**双门禁
因此是「A3 成立处要字节、A3 失效处要预算」的结构正确分工**，与「GPU 不
追求逐位确定」的架构定案（负面清单 #4）互为表里。

### 6.4 CpuRef：规范代表必须在参考结构中可执行

A2(b)+A3 要求规范代表及其计算在某个参考结构（CpuRef）中完全可执行且可
审计——GPU 路径因此是「同一语义的近似执行」，语义锚点永远在 CPU 参考里。
这解释了为什么引擎要求「无 GPU-only 旁路」：旁路会使规范代表脱离参考
结构，KCT-1 的「两跑一致」失去比较基准。

## 8. 结语：本报告的净结论

1. **公理化提取**（§1）：七提案的承载数学成分形成两个不相交的簇——规范化簇
   {全序、半格、商/代表元、充分统计量、ℤ 格、FP 误差、置换作用} 与最优性簇
   {凸性/KKT、Cauchy–Schwarz}。
2. **内核检索**（§2）：八个候选逐一评估，四个被收编为两个内核的组成部分
   （C1/C5→K_can 骨架，C2→KCT-2，C6→KCT-3 与 A3 动机），四个被否决
   （C3 空转、C4 隐喻、C7 非候选、C8 非承载）。
3. **两个真内核**（§3、§4）：K_can（4 定理 + 5 映射 + 5 新推论）与
   K_opt（5 定理 + 2 映射 + 6 新推论，6 条中 3 类命题数值验证）。
4. **单一核不存在**（§5）：非空性标准 N1–N3 + 反侧构造（文档内两事实）+
   分离定理 + 元原则的 N3 检验执行。双支柱是**紧的上界**而非妥协；
   且两核关系被精确为「定理独立、实现单向依赖」。
5. **铁律解释力**（§6）：确定性是结构性的（KCT-1）；D-29 是 A3 的推论；
   D-3 是 A3 失效处的正确仪器；L2 内核与 K_can 是同一结构在软件层与
   算法层的两面。

> 留给后续的问题（不在本文范围）：K_can 的 A2(b) 质量面（保真/紧致/端点
> 精确）尚未公理化——它是一个「质量内核」的种子，值得单独立项；K_opt 从
> SCA 推广到一般凸规划（P4 的非线性约束 GOP 结构）时哪些定理幸存，亦可
> 后续展开。这两个方向都不会改变本文的分离结论，因为它们的承载成分仍
> 分别落在 §1.2 矩阵的既有簇内。
