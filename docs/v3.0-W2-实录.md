## 4. 核心项 L3 时序驱动

### 缺口原文

> 相机 / 材质 / 光源 / 几何 / 时间线 / 后处理，两帧取到不同参数值且
> 逐帧值与解析式对拍一致（沿用 `sample_binding` 逐绑定覆盖思路，做成
> 「任意参数随时序变」的统一通道）。

### 做了什么

- `wiring.rs:654` `bind_source`：把任意 `cap` 参数绑成 `PropertyChannel`
  的唯一入口。支持 `{ key 0s 0 linear key 1s 1 linear }`（走既有
  `codegen::build_channel`）与 `{ expr "t * 2 + 1" }`（走既有
  `prism_anim::Expr::parse`），不实现任何求值数学。
- `wiring.rs:617` `resolve_frame`：所有 `WiringParam::Channel` 在每帧按
  `EvalCtx::new(global_seed, node_id, frame)` 走既有
  `PropertyChannel::sample_ctx`；静态常量直接位型。
- `movie.rs:1591` `wiring_frame_values`：渲染前按帧解算，产出
  `WiringFrame`；`:1622` `render_scene_frame` 在组装
  `prism_core::Material::new` 之前用 `R-2.roughness` / `R-2.metalness`
  覆盖材质（生成源头，不是帧后贴皮）。
- `Deliverable::wiring_trace` 逐帧带 `WiringFrame::canonical_bytes()`，
  供同源对拍逐字节比对。

### 判据数字

- 六类核心项各取一行参数（相机 / 图元族 `G-1.revolutions`、材质
  `R-2.roughness`、光源 `R-1.clamp_indirect`、几何 `G-2.displacement`、
  时间线 `E-4.frame`、后处理 `R-13.n0`），声明成解析式子块。
- 两帧（frame 0 / frame 4，fps 8 → t = 0 / 0.5）：**6/6 参数值不同**，
  且逐帧值与 `prism_anim::Expr::sample(t)` 及既有
  `PropertyChannel::sample(t)` **逐位相等**（`to_bits()` 断言）。
- `wiring_frame_values(&out,0).canonical_bytes()` ≠ frame 4 的凭证。
- 统一通道对**任意**参数成立：六行只是六类核心项的取样，`build_wiring`
  不限制哪些参数可绑通道。

### 注入点行号

`wiring.rs:654`（绑定）、`:617`（解算）、`movie.rs:1591`（渲染前出口）、
`:1622`（材质消费）、`w2_wiring.rs::w2_resolve_frame_matches_property_channel_sample_bit_for_bit`、
`w2_end_to_end.rs::w2_core_l3_two_frames_differ_and_match_analytic_channel`。

## 6. 判据升级正式落档（照 V2.5 报告 §27 格式）

- **不可达性证明**：W1 `coverage_gate` 的
  `rows_cov < 100 / params_cov < 100 / tail_cov < 100` 三条断言，
  前提（W1 如实登记覆盖率不足）在 W2 达标后消失；继续保留 `< 100`
  会让 100% 反而判红，判据与交付目标直接冲突。
- **有牙新判据**：改为 `== 100`，并追加两条变异体判别力——
  ① 把任意一行的 `dsl_fields` 清空后覆盖率必须下降；
  ② `w2_delete_any_of_39_rows_is_red` / `w2_drop_any_single_field_mapping_is_red`
  遍历 39 行 / 33 行逐个注入，任一漏网即判红。
  负控集合从 W1 的 6 类扩到 **13 类**（新增 P8001…P8009 九类运行时注入
  + 删行 / 拆字段 / 平台域假 exempt / 表码漂移）。
- **性质**：`== 100` 比 `< 100` 严，负控只增不减，**收紧不是放宽**；
  未删测试、未加 `#[ignore]`、未改判据原文阈值、未把 SKIP 写成 PASS。
