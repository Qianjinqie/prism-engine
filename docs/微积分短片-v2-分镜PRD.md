## 1. 产品目标

向看过 v1 的引擎作者与所有"凭什么不用 Manim"的质疑者证明：prism-engine 的数学动画语法（坐标系、动态构造、实时数值读数、矢量公式、相机运动）加上零依赖的真路径追踪 3D，是社区版 Manim 给不了的一体化"视频即代码"管线。90 秒内完成"极限→导数→积分→基本定理→3D 切平面"的叙事闭环，每一个数学陈述经得起逐帧核对。

## 2. 用户故事

1. **作为**一位学过微积分但只记得"求导积分很抽象"的观看者，**我想**看到割线一步步收敛成切线、黎曼矩形一步步融进曲线，**从而**在 90 秒内重新建立"极限是无限逼近"的直觉。
2. **作为**一位评估引擎的工程师，**我想**看到坐标网格、矢量公式、实时滚动的斜率/面积读数、相机推拉这些"数学动画语法"原生跑出来，**从而**相信这套声明式轨道就是为数学可视化设计的。
3. **作为**Manim 的现有用户，**我想**看到片尾一支带焦散光池的路径追踪 3D 抛物面从同一支片子里长出来，**从而**意识到社区版 Manim 给不了这个（需要额外接 Blender/Three.js），而 prism-engine 一支片子全包。

## 3. 已核实引擎事实与对任务书的两处修正

> 以下全部经仓库实测（fontTools 读 cmap / 读源码），非记忆。架构师与工程师直接采信，不必再验。

### 3.1 字体事实（影响全部屏幕文案）

prism-author 渲染层使用 `prism_text::font_regular()/font_bold()` = **PrismSansSC Regular/Bold**（`crates/prism-text/font_data/`，各 6888 字形，两者覆盖一致）。注意：`assets/prism_multiscript.ttf`（175 字形）只用于 shaping 测试，**不参与成片渲染**。

| 类别 | 状态 | 结论 |
|---|---|---|
| 中文（微积分变限极限导数切线斜率面积和基本定理……） | ✅ 两者均有 | 叙述文案可用中文（v1 已验证） |
| 拉丁字母 A–Z a–z、数字 0–9 | ✅ | HUD 读数可用 |
| ASCII 标点 `/ + = < > ^ _ [ ] % * " ' ( ) , - . : ; ! ?` | ✅ | — |
| 中文标点 `，。、：；？！""''《》——……·（）` | ✅ | — |
| 数学符号 `∫ ∑ π α δ ε ∀ ∃ ⇒ → ∞ √ − ₀ ² ′ ≤ ≥ × ° ± ≈ ≠ ∈ ∂ ∇ θ λ μ` | ❌ 全部缺失 | **一律矢量绘制**（既定决策，此处给出证据） |

**修正 1**：任务书称"lim 亦无字形"。实测 l/i/m 与 `/` 均在字体中——"lim""dy/dx" 技术上可作文本渲染。按既定"矢量符号库"决策不变：S1 的三个符号位（lim、dy/dx、∫）仍走矢量（手绘衬线造型，承担标题仪式感）；S2–S7 公式采用**混合排版**——拉丁字母与数字用 PrismSansSC 字体文本，数学符号与上下标用矢量，按基线坐标拼装（符号库提供定位辅助）。

**修正 2**：v1 注释"渲染层所有文字轨道以画幅水平中心为锚（规格无 x 字段）"属实（spec.rs 中 Static/Kinetic/Typewriter 仅有 `y`）。本片轴标签、公式标签、读数 HUD 均需定位 → 需求池 E3（文字轨道增加 `center_x`，默认画幅中心，向后兼容）为 **P0，不可裁剪**。

### 3.2 引擎能力边界（影响需求池）

- `Track::Path(PathTrack)`：单条静态折线，描边/填充 + `draw_sec` 绘制进度 + `closed` + 淡入淡出。**顶点无法逐帧变化** → 切线滑动、割线连续收敛、ε/δ 带连续收缩必须靠新原语（E1 `DynPath`）。
- `render_short_concat_faded_frames`：转场**硬编码 Fade 0.5s**（`CONCAT_FADED_TRANS_SEC = 0.5`，render.rs:1147），七场景 = 6 次 Fade；Wipe 不可选（列为 P2）。
- `prism-rt::integrator::Scene` 仅含 `spheres: Vec<(Sphere, MaterialKind)>` 与 `boxes: Vec<(Aabb, MaterialKind)>`——**没有抛物面，也没有可倾斜的平面**（Aabb 轴对齐，无法表达切平面）。S7 需要新增解析二次面/平面原语（E5，最重工程项，附降级方案）。
- `prism-postfx::Warp` 存在但未接入 author 渲染管线；相机缓推的 P0 实现不依赖它（见 S2 拍 6）。
- 机器资源：32 核 / 129GB 内存——30fps 全片帧序列（2700 帧 ≈ 5.6GB 内存）与 S7 光追预渲染均无压力。
- v1 链路（复用，零改动）：`render_short_concat_faded_frames` 七场景拼接 → `prism-audio` 四声部合成 → `prism_mux::write_avi_mjpeg_audio` 双流落盘。

## 4. 分镜表（核心交付物）

### 4.0 图例与全局时间轴

**动画语法标签**（每拍必属其一或组合）：
- **【Create】** 对象从无到有（淡入/弹出/刻度依次亮起）
- **【Draw】** 沿路径生长（PathTrack `draw_sec` / 打字机逐字 / 矢量符号描画）
- **【Transform】** 已有对象逐帧变化（滑动、收缩、滚动、缩放、相机运动——依赖 E1 DynPath / E2 Counter）
- **【Fade】** 退场（淡出、鬼影化）

**屏幕文案标注**：`【文本】` = PrismSansSC 字体渲染（中文/拉丁/数字）；`【矢量】` = PathBuilder 手绘符号库渲染；`【Counter】` = 实时数值读数轨道（E2）。

**全局时间轴**（场景内时间码以各场景 t=0 为基准；全局列为压缩后成片方位，供 BGM 对齐）：

| 场景 | 内容 | 标称时长 | 全局起止 | @30fps 帧数 |
|---|---|---|---|---|
| S1 | 标题·公式符号矢量入场 | 8.0s | 0.0–8.0 | 248 |
| S2 | 坐标系亮相 + 相机缓推 | 10.0s | 8.0–18.0 | 308 |
| S3 | 极限·ε-δ 带 + 割线族收敛 | 16.0s | 18.0–34.0 | 496 |
| S4 | 导数·切线滑动 + 导函数生长 | 16.0s | 34.0–50.0 | 496 |
| S5 | 积分·Riemann 矩形累积 | 16.0s | 50.0–66.0 | 496 |
| S6 | 基本定理·双链合流 | 14.0s | 66.0–80.0 | 436 |
| S7 | 3D 光追收尾 + 落版 | 10.0s | 80.0–90.0 | 310 |
| **合计** | | **90.0s** | | Σ=2790 − 6×15 转场重叠 = **2700 = 90.000s** ✓ |

> 帧数说明：`ClipSpec::frame_count = ceil(fps·duration)`，场景时长须取帧对齐值（248/30=8.267s 等），使 Σ=93.0s 语义时长、减 6 次 Fade 0.5s（各 15 帧）后精确 2700 帧。分镜时间码为标称值，工程师按帧网格对齐（各拍漂移 ≤0.27s，不影响叙事）。
> 若主理人确认回退 15fps：帧数改为 124/154/248/248/248/218/158（Σ=1398，减 6×8=48 → 1350=90.0s），分镜时间码不变。
> 全局片头淡入 1.0s / 片尾淡出 1.5s（沿用 v1）。

**视觉系统**：背景以深蓝黑/深青黑/深紫黑渐变区分场景情绪；主曲线青 `#35D9F2`；切线与强调金 `#FFD24A`；导函数/累积链亮紫 `#B58CFF`；面积填充半透明青（alpha 0.18–0.38）；文案冷白 `#D6ECF7`；坐标网格白 alpha 0.10。

## 6. 数学准确性清单（架构师与工程师逐条核对；写错全责在 PM）

**S1**：lim（极限算子，标题艺术化符号串，非完整命题；严格写法在 S3 给出）、dy/dx（Leibniz 导数记号）、∫（积分号）——均作为符号呈现，无断言。

**S2**：y = sin x，x∈[−4,4]；振幅 ±1 在视口 y∈[−2.4,2.4] 内 ✓。

**S3**（f(x)=x²，x₀=1，L=1）：
- 割线斜率序列 m(h) = (f(1+h)−f(1))/h = ((1+h)²−1)/h = **2+h**：h=1→**3.0000**；h=0.5→**2.5000**；h=0.25→**2.2500**；h=0.125→**2.1250**；h→0→**2.0000** = f′(1) = 2x|_{x=1} = 2 ✓
- 割线第二端点：(2,4)、(1.5,2.25)、(1.25,1.5625)、(1.125,1.265625) ✓
- ε-δ：\|x²−1\| = \|x−1\|\|x+1\| < δ(2+δ)（当 \|x−1\|<δ）；取 δ 使 δ(2+δ)=ε，即 δ = √(1+ε) − 1：ε=1.00→δ=√2−1≈**0.414**（显示 0.41）；ε=0.25→δ=√1.25−1≈**0.118**（显示 0.12）✓
- 定义式（严格）：∀ε>0, ∃δ>0, 0<\|x−1\|<δ ⇒ \|x²−1\|<ε ✓（0< 排除 x=x₀ 本身）

**S4**（f(x)=x²/2，f′(x)=x）：
- 切线方程 y = ax − a²/2（过 (a, a²/2)，斜率 a）：a=−2 → y=−2x−2，m=**−2.0000**；a=−0.5 → y=−0.5x−0.125，m=**−1.0000**；a=2 → y=2x−2，m=**2.0000**；a=1 → y=x−0.5，m=**1.0000** ✓
- 导函数曲线 y=x 与切线斜率恒等；视口覆盖 f(±2.2)=2.42 ≤ 2.5 ✓

**S5**（f(x)=x² on [0,2]，右端点黎曼和）：
- Sₙ = Σ_{k=1..n}(2k/n)²·(2/n) = 4(n+1)(2n+1)/(3n²)：n=2→**5.0000**；n=4→**3.7500**；n=8→**3.1875**；n=32→**2.7930**（精确 2.79296875）；n→∞→**8/3 ≈ 2.6667** = ∫₀²x²dx = [x³/3]₀² ✓
- 右端点（递增函数）⇒ 单调递减高估，收敛方向正确 ✓
- 矩形右端高度：n=2: 1, 4；n=4: 0.25, 1, 2.25, 4；n=8: 0.0625, 0.25, 0.5625, 1, 1.5625, 2.25, 3.0625, 4 ✓

**S6**（F(x)=∫₀ˣt²dt = x³/3）：
- F′(x) = x² = f(x)；x=1.5 时 F(1.5)=3.375/3=1.125，F′(1.5)=3×1.5²/3=**2.25** = f(1.5) ✓
- B 点（F 上 x 处）切线：y = x²·(X−x) + x³/3，斜率 x² ✓
- FTC：d/dx ∫₀ˣ f(t)dt = f(x)（f 连续）✓

**S7**（曲面 z = x²+y²）：
- 切点 P=(0.8, 0.8, 1.28)：z=0.64+0.64=**1.28** ✓；r=√(0.64+0.64)≈**1.131 < 1.2**（在抛物面范围内）✓
- 切平面：∇z=(2x,2y)=(1.6,1.6) → z−1.28 = 1.6(x−0.8)+1.6(y−0.8) → **z = 1.6x + 1.6y − 1.28**（验证：代入 P 得 1.28+1.28−1.28=1.28 ✓）
- 法线 (−1.6, −1.6, 1)；两个偏导数方向（x 向 1.6、y 向 1.6）即切平面内的两条切线方向——"切平面是切线的二维推广" ✓
- 叙事闭环：抛物面 = S5 曲线 x² 绕 z 轴旋转而成（y=0 截面即 x²）✓
