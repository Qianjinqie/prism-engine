## 1. K1 三元组口径（定义来源）

命题 **K1（特性接入 = 三元组声明）**（`能力对齐的数学分层.md:388`）：一个渲染特性
接入引擎 = 声明三元组 `(核形式 K, 求逆策略 σ, 采样维度 d)`。

- **核形式 K**：积分算子 / 传输算子 / 扩散核的具体形式（共 5 种核；开发者指南
  `:737`「5 种核 + 6 种求逆策略」）。
- **求逆策略 σ ∈ 六策略**（`数学分层.md:390`；白皮书 §25）：
  `精确`（格林闭式）、`随机`（Neumann 级数 / MC）、`局部`（牛顿打窄峰）、
  `正则化`（病态+先验）、`迭代`（近端不动点）、`谱`（对角化相除）。
- **采样维度 d**：位置 / 方向 / 波长 / 时间 / 镜头。

### 两个在档参考实例（对照基准）

| 实例 | K | σ | d | 实现位置 |
|---|---|---|---|---|
| **SSS**（次表面散射） | 游走核（扩散近似）+ 表面逃逸 | 随机 | {位置, 方向, RGB} | `prism-rt/src/sss.rs` |
| **体积**（均匀介质） | 传输算子 `T(t)·σs` | 随机（delta tracking） | {位置, 方向} | `prism-rt/src/media.rs`（`HomogeneousMedium`） |

> 判完整性即以这两实例为模板：新长尾项声明三元组后，若其 K/σ/d 组合与
> 参考实例**结构同级**（同族算子 + 同族求逆），实现路径即确定。

## 2. 收敛判据（机械可判定，PRD C1 验收 3）

一项长尾算「**还清**」⟺ 同时满足：

1. **三元组完整**：K / σ / d 显式声明，且 σ 取六策略之一、d 在
   {位置,方向,波长,时间,镜头} 内闭包；
2. **实现对照参考实例结构同级**：核算子与求逆策略的组合，在 sss/media
   两实例可覆盖的形态内（即能用「随机求逆 + 传输/游走核」或等效组合实现）；
3. **通过确定性 / 对拍框架验收**：有 golden / 退化一致性 / Beer 定律类
   断言钉死，且 `cargo test` 全绿（无 `#[ignore]`、无 `TODO`）。

> 三项齐 ⇒ 该长尾可标记「还清」；缺任一项 ⇒ 仍列长尾，按缺口定级。

## 3. 名录四项（逐条声明）

### 3.1 光谱渲染（spectral rendering）

- **K1 三元组**：`K = 谱域传输算子（每波长独立传输/散射）`，
  `σ = 谱`（逐波长对角求解）+ 随机（波长重要性采样），`d ⊇ {波长}`（RGB
  三通道仅为 λ 积分的粗近似）。
- **现状**：引擎全程使用 RGB 三通道（`Vec3` 辐射），**无波长维采样**。`grep
  spectral|wavelength|波长` 命中仅 `sss.rs`（注释性「spectrum」）、
  `prism-noise/fbm`（噪声谱，非渲染）、`caustics.rs` 等——**无光谱路径追踪
  实现**。
- **缺口**：① 缺波长维度 d（采样空间无 λ 轴）；② 缺每波长独立的传输/散射
  核；③ 缺 RGB↔光谱的 CMF / 主成分（PCA）升采样。
- **K1 接入判据**：声明 `d ⊇ 波长` 即知需扩展采样器维度；核 = 波长独立传输
  算子（与体积同族，仅 σ 由「随机」升为「谱+随机」）。结构在参考实例可覆盖
  形态内（体积传输算子 + 波长轴扩展）。
- **分级**：**P2**（长尾，未实施；V2.1 不实施，仅留名）。

### 3.2 SVGF-OIDN 去噪

- **K1 三元组**：`K = 联合双边 / à-trous 滤波核`，`σ = 正则化 + 迭代`
  （à-trous 多趟 = 迭代求逆）+ 随机（时域 reprojection 的蒙特卡洛），
  `d ⊇ {时间}`（时域帧序列）。
- **现状**：`prism-postfx/src/denoise.rs` **已落地三合一脚手架**——à-trous
  空域（`AtrousSpatial`，B3 样条核 + 有理边缘停止）、**确定性时域累积**
  （递推增量均值 `acc ← acc + (cur−acc)/(n+1)`）、**variance 自适应 spp
  预算**（largest-remainder 分配）。零超越函数（D-29 有理核）。
- **缺口**：① 缺 **G-buffer 引导的时域重投影（reprojection）**——当前时域
  累积是「帧 0 起重放」的简单递推均值，非 SVGF 的 motion-vector 重投影
  （见 `denoise.rs:14`「seek 只能从帧 0 重放」）；② 缺 **OIDN 学习型滤波器**
  （用有理/样条核而非神经网络，正确但非 OIDN 口径）。
- **K1 接入判据**：核=联合双边滤波核（与去噪脚手架同族，仅补 reprojection
  维）；σ=正则化+迭代（已在档）；`d` 补「时间」的重投影对。结构在参考实例
  形态内。
- **分级**：**P2**（长尾；核心 reprojection 与学习型滤波器未实现，仅留名。
  V2.1 不实施）。

### 3.3 自适应采样（adaptive sampling）

- **K1 三元组**：`K = 方差估计算子`（逐像素 / 逐块 radiance 方差），
  `σ = 随机`（MC 方差估计）+ 迭代（收敛阈值不动点），`d ⊇ {样本, 时间}`。
- **现状**：`grep 自适应|adaptive|variance|importance` 在 `integrator.rs`、
  `gi/probes.rs`、`gi/ssgi.rs` 有方差/重要性相关词，但为**局部辅助**
  （如 probe 权重、SSGI 权重），**无逐像素方差驱动的 spp 收敛控制**。
- **缺口**：① 缺逐像素/逐块 radiance 方差的在线估计与累积；② 缺「方差超阈
  ⇒ 增样、低于阈 ⇒ 收敛」的不动点判据（σ=迭代未接）；③ 缺样本预算的
  全局再分配（与去噪的 variance-spp 可共用，但未闭环）。
- **K1 接入判据**：核=方差估计算子（与去噪 variance-spp 同族）；σ=随机+
  迭代（收敛不动点）；`d` 补样本/时间维。结构在参考实例形态内。
- **分级**：**P2**（长尾，未实施；V2.1 不实施，仅留名）。

### 3.4 异质体积（heterogeneous volume）— **C2 实施子集（本任务已结）**

- **K1 三元组**：`K = 传输算子 T(t)·σs`（`σt` 空间变化），`σ = 随机`
  （**Delta tracking 扩展**——Woodcock 多步，以场上界 majorant 步进），
  `d = {位置, 方向}`（与体积参考实例同族，仅 K 由「均匀 σt」升为「网格 σt」）。
- **现状（V2.1 流 C 实施）**：在 `prism-rt/src/media.rs` 新增
  `HeterogeneousMedium` + `Grid3`（规则三网格 σt 场，三线性采样）；
  `free_path` / `shadow_transmittance` 走 Woodcock delta tracking；
  **退化一致性已钉死**（σt 恒定场下与 `HomogeneousMedium` **逐位一致**，
  `crates/prism-rt/tests/qa_heterogeneous_volume.rs`）。
- **缺口**：无（C2 子集范围已闭环：仅异质体积，不含光谱/去噪/自适应）。
- **K1 接入判据**：与体积参考实例**结构同级**（同传输算子 + 同随机求逆，
  仅 K 参数化），收敛判据 1–3 全满足。
- **分级**：**P0（已还清）**。
