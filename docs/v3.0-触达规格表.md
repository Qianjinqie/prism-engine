> W1 交付物、W2 逐行回填，对应 `docs/v3.0-路线图.md` §2.2 / §1.2 / §7 #2 的执行体。
> 每行 `api_path:line` 与 `api_params（全集）` 均由源码实测抽取：锚点是该能力在引擎侧的
> **公开 API 定义行**，`api_params` 是该定义行的**公开参数全集**（结构体的 `pub` 字段、
> 枚举的全部变体、或函数签名的全部形参），逐个经 `crates/prism-dsl/tests/coverage_gate.rs`
> 回读源码复核。不编数字、不写「待核验」。
>
> **W2 回填（本版）**：`dsl_fields` 逐行补齐到与 `api_params` 全集一致，且**求值链真消费**：
> DSL 的 `cap "编号" { ... }` 块把每个参数显式声明成 `WiringPlan` 条目，
> `crates/prism-dsl/src/wiring.rs` 的 `CAPABILITY_ROWS` 是运行时唯一事实源，
> `prism-render::movie::wiring_frame_values` 在**渲染前**逐帧解算，
> `prism-app::w2_eval` 按行调用既有 crate 求值器。静态门禁（`coverage_gate` 的 W2 段）
> 遍历 39 行核对差集为 0，运行时同源对拍（`w2_wiring`）逐字节比对，双证齐全。
>
> **第 8 列 `wiring_ruling`** 是逐行可查的具体裁定编号（`W2-R-01 … W2-P-06`）
> + 该行既有求值器锚点，不是通配 exempt。删任意一行的映射或裁定 ⇒ 门禁判红。
>
> **`exempt_ruling` 仍只有 P-1 ~ P-6 六行**：G5 平台域「不适用（裁定）」，
> 由 `render` 命令与 D-19 双轨决定，语言层不暴露；其余 33 行一律 `∅`，
> **100% 不是靠豁免凑出来的**。

## 口径

- **参数全集**：取锚点定义行的全部 `pub` 字段 / 枚举变体 / 函数形参；不取该能力在全仓的
  所有相关结构，避免把「盘点范围」当成「可判定的差集」。锚点选择理由逐行写在备注里。
  W2 实算分母 **226**：W1 基线 225 + E-8 随 `CompileV2Output` 新增 `wiring` 字段 1 项
  （引擎 API 的真实变化，W1 门禁的「与源码不符」判别力已实测捕获并如实登记）。
- **目标级**：按 §1.1 L0–L3。核心项（相机 / 材质 / 光源 / 几何 / 时间线 / 后处理）标 `L3`，
  其余 P0 标 `L2`；平台域标 `不适用` 并挂 G5 裁定。
- **`dsl_fields` 构成**：W1 已登记的既有路径字段（如 `stage3d.material.albedo`，如实保留）
  + 该行 `api_params` 全集裸名（`cap` 块的字段名与引擎参数逐字一致）。
  因此全名口径差集 `|params(api) \ fields(dsl)| = 0`；末段口径同样 100%。
- **W2 判红集合**（在 W1 四类之上追加，全部走 `coverage_gate`）：
  ① 任一非平台域行 `api_params \ dsl_fields` 非空 ② 任一行缺具体 `wiring_ruling`
  ③ 裁定编号与 `wiring::CAPABILITY_ROWS` 不一致 ④ 运行时表与文档表漂移
  ⑤ 故意拆掉任意一行的一个字段映射 ⑥ 删任意一行 ⑦ 非平台域挂假 exempt。

## 复核锚点说明

- **渲染域**：R-1 取 `RenderParams`（路径积分的公开可调参数全集）；R-2 取 `Bsdf`；
  R-3/R-8 取 `caustics.rs` 的 `Refractor` / `CausticsSample`；R-5 取 `HairScatter`；
  R-6/R-7/R-11/G-2/G-8/G-10 取 `prism-core/src/attach.rs`（V2.5 产品路径的 DSL→引擎装配面）；
  R-10 取 `EnvStats`；R-13 取 `AdaptiveParams`。
- **几何域**：G-1 取 `prism-rt::integrator::Scene`（19 个 pub 字段）；G-3/G-4 取公开枚举的全部变体；
  G-9 取 `SubdivResult`。
- **工程化域**：E-1 取 `prism_core::eval::eval` 的五个形参；E-3 取 `FrameShard<T>` 的三个 pub 字段；
  **E-8 取 `CompileV2Output`**：W1 时 14 个 pub 字段 / 锚点 `:363`；W2 因新增 `wiring`
  装配产物变成 15 个 pub 字段 / 锚点 `:364`。这不是「改判据迁就代码」，是引擎侧公开 API
  真实扩容后的如实登记——`coverage_gate` 的「参数全集与引擎源码不符」判别力在 W2 首次
  接线时**实测判红**，据此回填，过程见 `docs/v3.0-W2-实录.md` §2。
- **平台域**：P-1/P-2/P-3/P-4/P-6 取各后端公开结构 / 枚举，P-5 取 `HwProbe`；
  六行 `api_path` 与参数全集照样真实填实，但目标级为 `不适用` 且挂 G5 正式裁定，
  不计入 L 级达标统计；`dsl_fields` 列登记的是「该行参数全集的对照名」，
  平台域**不生成 `cap` 块**（`wiring::build_wiring` 以 P8007 显式拒绝）。
