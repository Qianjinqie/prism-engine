# V3.0 能力触达规格表（39 行逐行填实）

> W1 交付物，对应 `docs/v3.0-路线图.md` §2.2 / §1.2 / §7 #2 的执行体。
> 每行 `api_path:line` 与 `api_params（全集）` 均由源码实测抽取：锚点是该能力在引擎侧的
> **公开 API 定义行**，`api_params` 是该定义行的**公开参数全集**（结构体的 `pub` 字段、
> 枚举的全部变体、或函数签名的全部形参），逐个经 `crates/prism-dsl/tests/coverage_gate.rs`
> 回读源码复核。不编数字、不写「待核验」。
>
> `dsl_fields` 按**当前真实现状**如实登记，来源是 `crates/prism-dsl/src/parser.rs` 的块分发、
> `crates/prism-dsl/src/codegen.rs` 的字段白名单与 `examples/t0_media_mesh.prism` 的产品路径样例。
> `∅` = 当前 DSL 无对应字段。W1 不要求补齐；差集即 W2 接线工作量。
>
> `exempt_ruling` **只在真有正式裁定时填**：仅 P-1 ~ P-6 属路线图 §2.1 G5 平台域
> 「不适用（裁定）」——由 `render` 命令与 D-19 双轨决定，语言层不暴露。其余行一律 `∅`。

## 口径

- **参数全集**：取锚点定义行的全部 `pub` 字段 / 枚举变体 / 函数形参；不取该能力在全仓的
  所有相关结构，避免把「盘点范围」当成「可判定的差集」。锚点选择理由逐行写在备注里。
- **目标级**：按 §1.1 L0–L3。核心项（相机 / 材质 / 光源 / 几何 / 时间线 / 后处理）标 `L3`，
  其余 P0 标 `L2`；平台域标 `不适用` 并挂 G5 裁定。W1 只要求「目标级存在」，达成在 W2/W4。
- **`dsl_fields` 不计入 W1 判红集合**：W1 判红只针对缺 `api_path`、参数全集为空、
  目标级缺失、故意删 1 行映射四类（§5.3 W1）。覆盖率支如实输出当前百分比，不设阈值。

## 复核锚点说明

- **渲染域**：R-1 取 `RenderParams`（路径积分的公开可调参数全集）；R-2 取 `Bsdf`；
  R-3/R-8 取 `caustics.rs` 的 `Refractor` / `CausticsSample`；R-5 取 `HairScatter`；
  R-6/R-7/R-11/G-2/G-8/G-10 取 `prism-core/src/attach.rs`（V2.5 产品路径的 DSL→引擎装配面，
  也是 `t0_media_mesh.prism` 五个块实际落到的结构）；R-10 取 `EnvStats`（`EnvCdf` 无 pub 字段，
  改取同文件公开统计结构，参数全集为 8 项）；R-13 取 `AdaptiveParams`。
- **几何域**：G-1 取 `prism-rt::integrator::Scene`（19 个 pub 字段，覆盖九族图元与光源 / 介质 /
  实例 / 纹理槽）；G-3/G-4 取公开枚举的全部变体；G-9 取 `SubdivResult`（`SubdivMarks` 无 pub 字段）。
- **工程化域**：E-1 取 `prism_core::eval::eval` 的五个形参；E-3 取 `FrameShard<T>` 的三个 pub 字段；
  E-8 取 `CompileV2Output` 的 14 个 pub 字段（DSL v2 完整装配产物）。
- **平台域**：P-1/P-2/P-3/P-4/P-6 取各后端公开结构 / 枚举，P-5 取 `HwProbe`；
  六行 `api_path` 与参数全集照样真实填实，但目标级为 `不适用` 且挂 G5 正式裁定，
  不计入 L 级达标统计。

## 覆盖率实录（W1 实算）

由 `cargo test -p prism-dsl --test coverage_gate -- --nocapture` 实算输出，数值如下（W1 收口实测）：

| 指标 | 实算 | 读数 |
|---|---|---|
| 结构覆盖率（39 行全有 `api_path:line` + 非空参数全集 + 目标级） | 39/39 | **100.00%** |
| DSL 字段映射行覆盖率（`dsl_fields` 非空行数 / 39） | 15/39 | **38.46%** |
| 参数级覆盖率（全名同名交集 / 参数全集） | 0/225 | **0.00%** |
| 参数级覆盖率（末段同名交集 / 参数全集） | 18/225 | **8.00%** |

- **全名口径 0.00% 的成因**：当前 DSL 字段是带块前缀的路径（`media.sigma_t`、
  `material.albedo`），引擎参数是短名（`sigma_t`、`base_color`）；两者尚未建立显式映射，
  全名交集为空是真实读数，不编映射凑数。
- **末段口径 8.00%**：把 `dsl_fields` 路径取末段后与 `api_params` 比对（`media.sigma_t` →
  `sigma_t`），反映「字段已接线但命名前缀不同」的真实触达。两个口径都低于 100%，
  差集逐行由门禁打印，即 W2 的接线工作量。
- **W1 判红集合**：缺 `api_path` 0 行、参数全集为空 0 行、目标级缺失 0 行、编号完整性 39/39；
  错误注入六类（删 1 行 / 清空 `api_path` / 清空参数全集 / 清空目标级 / 假 exempt /
  参数全集与引擎源码不符）**全部判红**；`coverage_gate` 9 条测试 0 failed / 0 ignored。

> 口径重申：结构覆盖率 100% 是 W1 的门禁骨架判据；DSL 字段映射与参数级覆盖率是**当前真实现状**
> 的如实读数，多数为空属正常，达标（100% / P0 ≥ L2 / 核心项 L3）是 §7 #2 与 W2 / W4 出口。
> 不用假映射、不用假 exempt 凑数。
