## 1. 家底勘定（先勘后论）

| 导入器 | 位置 | 规模 | 已支持块 | 材质语义 |
|---|---|---|---|---|
| USD `.usda` | `prism-io/src/usd.rs` | 4326 行 | 层头元数据；prim 树（def/over/class，类型不白名单）；属性（points / faceVertexCounts / faceVertexIndices / normals / primvars:st / xformOpOrder…）；值语法全形态（数组/元组/嵌套数组/资产路径）；关系 + 存在性校验；Xform 链烘焙 | **不求值**：只留 `material:binding` 目标路径 |
| glTF 2.0 | `prism-geometry/src/gltf.rs` | 1512 行 | 五块子集：scenes / nodes（平移缩放）/ meshes primitives（POSITION/NORMAL/TEXCOORD_0/indices）/ materials 的 pbrMetallicRoughness（+ ior/sheen/clearcoat 扩展）/ accessors（float/ushort/uint） | `PbrMaterial` ↔ B2 Disney BSDF **同构零转换** |
| MaterialX | `prism-io/src/materialx.rs` | 1959 行 | 只编译不求值 | 参数包 + 图 |
| OBJ | `prism-geometry/src/obj.rs` | 853 行 | 精简导入 | — |

USD 解析器诚实边界（`usd.rs` 模块文档自述，导出侧对称继承）：`.usdc` 结构化
拒绝（PU1001）、`timeSamples` 跳过只取默认帧、references/payloads 只记录不跨
文件、variants 不求值、非等比缩放法线记账为近似、单文件无 asset resolver。

**三条影响设计的勘定事实**：

1. **解析器不求值材质**：`build_scene` 只校验绑定目标存在（悬空 → PU1005）。
   故导出若写 `material:binding`，就**必须**同时写出目标 `Material` prim——
   否则往返第一步（再导入）即撞悬空错误。材质导出不是可选项，是绑定关系的行李。
2. **`build_scene` 把 Xform 链烘焙进顶点**，`Scene` 是扁平 f64 网格列表
   （`points`/`face_counts`/`face_indices`/`normals`/`uvs`/`material`）。
   引擎可渲染表示**本就不携带层级**——层级丢失发生在导入时，不是导出器的债。
3. **引擎材质模型 = `PbrMaterial`**（f32 字段，glTF 语义）——USD 侧
   UsdPreviewSurface 参数的现成源头，映射是字段级直射。

## 2. 最小可用子集（第一版）

**导什么**（按回流真实需求裁）：

- **mesh**：`points` / `faceVertexCounts` / `faceVertexIndices` / `normals` /
  `primvars:st`（法线与 UV 是导入器已解析项，导出零新增语义，成本近零）；
- **材质**：`Material` + `Shader`（UsdPreviewSurface）prim，参数取自
  `PbrMaterial` 直射（diffuseColor←base_color.rgb、opacity←base_color.a、
  metallic←metalness、roughness←roughness、ior、clearcoat、clearcoatRoughness、
  opacityThreshold←alphaCutoff）；
- **场景组织**：`material:binding` 关系 + 层元数据（defaultPrim / upAxis /
  metersPerUnit）；
- **polygon 保留**：`faceVertexCounts` 原样导出，导出侧不三角化（三角化是
  `RenderMesh` 的渲染侧特化，导它等于把引擎的渲染决策焊死进资产）。

**不导**（子集裁掉，理由见 §6）：动画 / timeSamples、Prim 层级树（扁平化：
root Xform + 每 mesh 一个 Mesh prim）、references/payloads/variants、
程序化配方（SDF 场 / 噪声 / 图节点参数）。

**裁减依据**：AI 社交 / 引擎自产内容回流的真实需求 = 把引擎**已生成的结果**
（几何 + 基础材质）交出去——给外部工具，或给引擎自身再消费。配方不是标准
格式的语义（DSL 文件即配方格式，回流不需要把配方译成 USD）。动画第一版不
需要：导入侧只取默认帧（PU1007 同界），导出动画无处落地。

**架构形状**（设计级，不写代码）：

```text
核心：Layer → canonical .usda 文本（规范序列化器，解析器的逆）
适配：Scene + (绑定路径 → 材质参数) 表 + 层元数据 → Layer（扁平装配）
输出：.usda 文本（String）+ 导出报告（降级 / 丢弃字段逐条记账，永不静默）
```

导入资产再导出走核心直导（未知 prim 的属性导入时已原样保留）；引擎自产内容
走适配。两个入口共用同一个序列化器，不设第二套写出门。

## 3. 目标格式：`.usda`（第一版），glTF 第二波

**选 `.usda` 的五条理由**：

1. **与解析器同 crate 同数据模型**：`Layer`/`Prim`/`Attribute`/`AttrValue` 全
   镜像，导出器是解析器的规范逆，R2 判据在同一组数据结构上闭合；
2. **文本 + canonical 序列化**：R2 可钉到字节级（§4）；
3. **零新依赖、无二进制层**：glTF writer 要手写 binary buffer + 访问器 +
   base64（零依赖铁旗下纯增代码面与错面）；`.usda` 全是已有词法 / 值语法的回写；
4. **诚实边界对称继承**：usdc 拒绝、单文件、timeSamples 跳过——导出侧不引入
   任何新格式风险（§10 诚实边界 2 的剩余量在导入侧已具名，导出同界）；
5. **互认最小面已覆盖**：`.usda` 是 USD 生态交换文本，`usdcat` 可转 `.usdz`
   进 DCC——"回流给外部工具"这半需求成立。

**glTF 为什么不是第一版**（三条具名理由，不是拖延）：① 其语义是 f32 + 三角化
（`GltfMesh` 存 `Vec3` f32、mode 限 TRIANGLES），往返判据从字节级降级到语义级；
② binary buffer 层是纯增实现面；③ 导入器在 `prism-geometry`，导出契约跨 crate
要另立（与 #9 缺口 c 的统一转换器接口捆在一起设计更省）。**触发条件：web /
社交分发需求具名**。

**诚实声明**：若下游真实消费者是 web 展示（glTF/webgpu 链），第一版 `.usda`
**不直接服务**——这是取舍不是遗漏。§10 诚实边界 2 的口径不变：风险不在格式在
互认广度；第一版把"引擎 ↔ 自身 ↔ USD 文本生态"这一圈钉死，glTF 那一圈连转换器
契约留给第二波。

## 4. R2 往返判据的工程化

**R2 原文**（§5.1）：`T: A → B` 可逆 ⟺ `T⁻¹∘T = id`；落地形式 = 签名判据——
往返后表示签名相等是充分条件（必要性是概率陈述，哈希选定后可界定）。

**判据本体 = 表示签名**（#9 缺口 a 的落地物，与 #8 `signature.rs` 同构）：
对导出 / 导入的共同中间结构（`Layer`/`Scene`）做 **canonical 序列化**（属性
顺序 = 源顺序；集合字段升序；UTF-8；LF）后取 SHA-256。导出器纪律：**只产
canonical 形式**，不重排、不美化、不插空行。

**三级判据**：

| 级 | 断言 | 语料 |
|---|---|---|
| L1 语义 | `sig(build_scene(parse(export(S)))) == sig(S)`：points / counts / indices / normals / uvs / 材质绑定路径逐项相等 | 引擎自产网格 + 既有 usda 测试夹具 |
| L2 字节 | `export(parse(export(S))) == export(S)`：对**本规范形**的再导出不动点（不承诺与手写 `.usda` 字节相同——手写源只断言 L1） | 同上 |
| L3 结构 | Prim 树同构：路径集合、父子关系、关系目标集合、属性名序相等；输入为 `Scene` 时层是扁平装配的，L3 退化为 L2 的结构侧 | 同上 |

**为什么零容差**：`.usda` 数字文本往返 f64 是**精确**的——Rust 标准库 Display
对 f32/f64 输出最短 round-trip 十进制（Grisu + 精确回退），`parse::<f64>()`
逐位还原；索引 / 计数是整数。**这一条本身要被测试钉死**（构造含 `1e-3`/`.5`/
极大极小值的夹具断言 `to_bits` 相等），不引为默认定理——宪章纪律：未经对拍的
结论是半成品。

**容差真正出现的地方**（三处，均不在第一版判据内）：

1. 未来 glTF 往返：f32 存储，断言口径 = `to_bits` 逐位（仍可零容差，但断言
   形式不同；注意 `f64→f32` 窄化本身是正确舍入，不是误差源）；
2. mesh↔SDF：R3 的 Hausdorff 界（§5），与本文无关；
3. 非等比缩放法线：导入侧已记账的**近似**（`non_uniform_normals`），导出把它
   固化——是语义近似不是数值容差；往返不叠加误差（导出的是已变换值）。

**测试形态**（继承同族先例 `usd.rs:4112 parse_is_byte_level_deterministic`、
`prism-io/src/lib.rs:485 save_png_signature_roundtrip`）：

- `export_is_byte_level_deterministic`：同场景两遍导出字节一致；
- `export_import_export_roundtrip`：L1+L2 对语料库全绿；
- `f64_text_roundtrip_is_bitwise`：浮点格式 round-trip 逐位钉死（上述）。

## 5. R3 保真度界（逐类）

**R3 原文**（§5.1）：mesh/SDF 不是对偶同构，是分辨率有界的近似对，判据是
Hausdorff 距离 ≤ f(分辨率, 梯度界)。**该界不适用于本文**——`.usda` ↔ 引擎
`Scene` 是**同一表示类内的规范重写**，不是 mesh↔SDF 的跨类转换。R3 在本文的
位置是**划界**：子集内无损；出了子集（跨表示类）必有损或有界。

| 类别 | 往返性质 | 界 / 依据 |
|---|---|---|
| 拓扑（faceVertexCounts / faceVertexIndices） | **无损** | 整数精确 |
| 顶点 / 法线 / UV 数值 | **无损** | f64 最短 round-trip（§4，测试钉死） |
| 层元数据（defaultPrim / upAxis / metersPerUnit） | **无损** | 文本 |
| material:binding 关系 | **无损** | 路径字符串；目标 prim 同文件导出（§1 事实 1） |
| 材质参数（UsdPreviewSurface 直射字段） | 属性级无损 / **语义级未接线** | 解析器不求值 Shader 输入；语义级往返待 D-1 |
| Prim 层级 / Xform 变换链 | **有损**（导入时已烘焙） | `Scene` 不携带；判据钉 Scene 级（L3 说明） |
| sheenColor / sheenRoughness | **有损（降级记账）** | UsdPreviewSurface 无对应输入；进导出报告，绝不静默（C20） |
| 程序化配方（SDF 场 / 噪声 / 图节点） | **有损（不导）** | 非标准格式语义；配方由 DSL 文件承担 |
| 源头是 SDF bake 的几何 | **有界近似** | R3 界在源头不在转换器：`d_H ≤ h/2·(1+‖∇d‖)`（h = 格距） |
| timeSamples / 动画 | **无**（默认帧） | 与导入侧同界（PU1007）；Layer 直导时 `skipped_time_samples` 无法重建，进导出报告 |
| 非等比缩放法线 | 近似**固化** | 导入侧记账项；往返不叠加 |

**逐条对上 R1 / R2 / R3**：

- **R1（同构保持）**：导出器 = `T_f`（导入器）在已支持子集上的规范逆。保持的
  具体断言：引擎侧两个表示签名相等的场景导出字节相同（canonical 序列化只吃
  规范结构）；且导出**不重排**（属性 / prim 保留引擎侧源顺序）⟹ USD 的组合
  语义（over 叠加序、属性多值序）不因导出而变。
- **R2**：§4 三级判据即工程化形式；零容差是子集内结论，容差三处已具名。
- **R3**：上表即保真度界分类；Hausdorff 界只 inherited 自 SDF 源头，不冒充
  文本往返的界。

## 6. 明确不做清单（六条）

1. **`.usdc` / `.usdz` 二进制导出**——导入侧 PU1001 结构化拒绝同族；文本互认
   已覆盖回流最小面（usdcat 可转），二进制 crate 容器是格式广度债。
2. **subLayers 跨文件导出**——导入侧只做记录不解析（会引入文件系统依赖与不可
   复现性）；单文件自洽优先。
3. **时间采样 / 动画导出**——导入侧只取默认帧，导出动画无处落地；触发条件 =
   导入侧补时间码求值器。
4. **references / payloads / variants 导出**——导入侧只记录不求值，对称不做。
5. **引擎私有节点类型 / 程序化配方的降级导出**——把配方硬降级成静态网格 =
   静默改变内容（C20）；第一版只导已烘焙结果。
6. **glTF 导出**——理由见 §3（f32/三角化判据降级 + 二进制层 + 跨 crate 契约），
   第二波连统一转换器契约一起。

## 7. 与宪章的关系

- **C13（缓存签名）**：**确认导出不进任何缓存键、不动存量签名路径**——导出是
  纯函数旁路（Scene → String），渲染 / 求值 / 缓存无一旁路。导出文本的层元数据
  带导出器 schema 版本（注释行，被导入器丢弃 ⟹ **不参与往返签名**，但交付
  manifest 可读——与 V11「引擎版本写入所有产物」同精神）。
- **C15（确定性跨版本语义）**：**确认无需 C15 登记**——纯新增能力，不碰存量
  渲染路径、不改任何既有行为（无基线重渲问题）。立规矩：浮点格式（最短
  round-trip）与 canonical 顺序**冻结**；未来若变，按行为变化清单进 changelog。
- **C17 / C18 / C20 / C24**：确定性三角件若涉旋转走 `det_cos_sin`（禁 libm，
  usd.rs 既有纪律）；错误三段式（UsdError 复用 PU 段）；导出报告记账替代静默
  （C20）；UTF-8 + LF（C24 ③）。
- **零依赖**：纯 std；宿主 crate 倾 `prism-io`（与解析器同文件族）——施工决策（D-4）。
