# 视觉计算的函子结构：八层差距的结构描述与一次性补齐

> 研究纪律：结构是发现不是设计（D-22）；不为统一而统一；凡不能承载的层如实标注。
> 本报告不依赖实验——命题以定义、定理、证明给出；数字实验只作实例旁证。
> 基础：`docs/设计/算法白皮书.md` §25（核—对偶—格）、§26（固定形状归约）。
> 实现事实：`prism-core/src/graph.rs`、`prism-render/src/tile.rs`、`prism-render/src/movie.rs`、
> `prism-mux/src/mp4.rs`。

---

## 0. 问题与判据

**目标**：引擎与成熟引擎的差距分布在八层，要求以少量代码一次性补齐。

**判据**（三条，缺一不可）：

1. **单一结构**：存在数学结构 M，使八层都是 M 的实例；
2. **证明复利**：M 的定理对每个实例自动生效，实例不重复证明；
3. **声明式接入**：每层代码量与其能力数量无关，只与其结构参数有关。

**方法**：从引擎已有的数学沉淀（§25 三问、§26 归约代数）与已有实现中**发现**
共同结构。发现失败则如实报告失败。

**主结论**（先行）：八层不是同一个结构的八个实例，而是**三类结构的分布**——
五个**算子层**（组合骨架统一）、两个**同构层**（复用骨架统一）、三个**内容层**
（各自的生成结构）。「一次性补齐」的准确含义是：**两类骨架各补一次，内容按层声明**。
把三类硬说成一类，是伪统一，本报告不做。

## 1. 起点：§25 统一了什么，没统一什么

§25 的结论：24 个算法 = 同一个算子方程 `f = g + Kf` 的六种求逆策略
（精确、随机、局部、正则化、迭代、谱），配三问（核 / 对偶 / 格）。

**统一的**：算法的**计算层**——一个任务怎么算。
**未统一的**：架构的**组合层**——多个任务怎么组织、怎么局部化、怎么复用。

算子方程回答「一个计算怎么算」，算子代数回答「多个计算怎么组合」。
八层差距的主体在后者：不是算不出，是组合不起来。

## 2. 视觉空间与层

### 2.1 底空间

**定义 2.1（视觉底空间）**。视觉底空间是有限偏序集

```
S = (T × P, ≤)
```

`T` 为帧格，`P` 为参数格（像素格、采样格、控制点格）。取有限偏序是数学选择：
计算总是离散的，有限偏序上的层范畴等价于预层范畴，一切 Kan 扩展是有限枚举（定理 3.5）。

### 2.2 视觉层

**定义 2.2（视觉层）**。`S` 上的视觉层是函子

```
F : S^op → V
```

`V` 是视觉值范畴：对象为视觉贡献（颜色、几何、位移、遮罩），态射保结构。
对开集 `U ⊆ S`，`F(U)` 的元素称为 `U` 上的**截面**。

**公理 L（粘合）**。若 `{U_i}` 覆盖 `U`，截面族 `{σ_i}` 在一切重叠上限制相等，
则存在唯一 `σ ∈ F(U)` 使 `σ|_{U_i} = σ_i`。

**注 2.1**。有限偏序上的预层自动满足 L（重叠有限，逐点拼接）。L 的价值在于可检查：
tile 协议的逐字节一致性就是它的实现判据（定理 5.2）。

**注 2.2（关键）**。层不拥有底空间，层作用于底空间。同一部片子的不同层是同一个
底空间上的不同函子；它们的区别在值域与截面，不在底空间。这是三类结构能够共存的
原因：**底空间只有一个，值域有很多个**。

### 2.3 为什么是层而不是函数

函数 `f: S → V` 缺少两样东西：

1. **局部定义域**：层可只在 `U ⊂ S` 有定义（粒子只在某时段存在）。函数的定义域是
   全空间；层的定义域是开集。裁剪因此成为结构运算，而非特例。
2. **粘合**：多个局部层可拼成全局层，且拼接唯一。函数的语言里，「分块渲染」
   「分布式渲染」「增量渲染」是三个技巧；层的语言里是同一个公理的三次应用。

## 3. 四个基本算子

### 3.1 拉回 f*：重参数化

**定义 3.1**。`f : S' → S` 为偏序映射。`(f*F)(U') = F(f(U'))`。

**定理 3.1（函子性）**。`(g∘f)* = f*∘g*`，`id* = id`。

*证明*。逐点：`((g∘f)*F)(U) = F(g(f(U))) = (f*(g*F))(U)`。∎

**实例**：关键帧、缓动、音频驱动、相机轨道、时间缩放——全是 `f*`，区别只在 `f` 的形状。
**动画不是能力，是底空间之间的映射。**

### 3.2 推前 f*：渲染

**定义 3.2**。`f* ⊣ f*`，`f*` 是右 Kan 扩展：

```
(f*F)(U) = lim_{f(U') ⊆ U} F(U')
```

**定理 3.2（伴随性）**。`f* ⊣ f*` 成立。

*证明*。有限偏序上的 Kan 扩展伴随是标准结果（Mac Lane, *CWM*, X.3）。∎

**实例**：渲染 = 场景层到像素层的推前。伴随性保证「先渲染再裁剪」与「先裁剪再渲染」
在交换图意义下一致——tile 协议正确性的来源（定理 5.2）。

### 3.3 张量 ⊗：叠加

**定义 3.3**。`(F ⊗ G)(U) = F(U) ⊗_V G(U)`，`⊗_V` 是值域合成算子（over/add/multiply/…）。

**定理 3.3（闭合性）**。若 `V` 闭合 monoidal，则 `Sh(S)` 在 Day 卷积下闭合 monoidal，
且 `⊗ ⊣ Hom`。

*证明*。Day 卷积保持闭合性（Day 1970；Kelly, *Basic Concepts of Enriched Category
Theory*, §6）：`Hom(F⊗G,H) ≅ Hom(F,Hom(G,H))`。离散底空间上逐点定义是 Day 卷积特例。∎

**实例**：层叠加、效果链、多轨混音。混合算子的代数性质（结合律、单位元）由 `V` 决定，
不由 `Sh(S)` 决定——**换混合模式不改编排代码的数学根据**。

### 3.4 内 Hom：依赖

**定义 3.4**。`Hom(G,H)` 由定理 3.3 的伴随给出。

**实例**：音频驱动视觉、参数绑定、条件效果（遮罩控强度）。依赖不是新机制，是闭合性的另一面。

### 3.5 紧支撑推前 f!

`f!` 只对纤维中落在给定支撑内的部分求和。**实例**：tile 裁剪、遮罩、局部求值。
`f! ⊣ f!` 给出「局部求值 + 粘合」的伴随对。

### 3.6 可计算性

**定理 3.5（有限性）**。有限偏序上，`f*`、`f*`、`f!`、`⊗`、`Hom` 均为有限枚举，
可在 `O(|S|^2)` 内计算。

*证明*。有限偏序的每一层只有有限个元素；Kan 扩展是有限极限/余极限，即有限枚举；
逐点张量与内 Hom 是值域上的有限运算。∎

## 4. 八层的三类结构

这是本报告的核心发现：**八层不是同质的**。按「数学位置」分类，得到三类。

### 4.1 第一类：算子层（五个）——组合骨架由四算子统一

| 层 | 底空间 | 值域 | 使用的算子 | 实现对应 |
|---|---|---|---|---|
| 编排 | 时间 × 场景参数 | 视觉贡献 | `⊗` + `Hom` + `f*` | `graph.rs`、`movie.rs` |
| 渲染核心 | 场景 × 像素 | 辐照度 | `f*` + `⊗` | `prism-rt`、`tile.rs` |
| 后期/调色 | 像素格 | 像素值 | `⊗`（卷积）+ `Hom`（遮罩）+ `f!` | `postfx`、`aesthetic` |
| 音频（处理侧） | 采样格 | 波形/频谱 | `f*` + `⊗` + `Hom` | `prism-audio`（FFT/混音/反应） |
| 性能/GPU | tile 格 | 局部结果 | `f!` + `⊗`（固定形状归约） | `tile.rs`、`reduction_shape` |

**这五层的组合需求由四算子生成**。定理 5.1 对它们全部生效：任意组合仍是层，
自动获得确定性、粘合性、参数化能力。

### 4.2 第二类：同构层（两个）——复用骨架由「层的同构类」统一

| 层 | 数学位置 | 判据 | 实现对应 |
|---|---|---|---|
| 资产/场景 | 层的**表示等价** | 两个表示同构 ⟺ 语义相同 | `geometry`（mesh↔SDF）、`io`（USD/MaterialX） |
| 生态/缓存 | 层的**同构类** | 签名相等 ⟺ 同构 ⟹ 计算可复用 | `signature`、`incremental` |

**关键**：这两层不是四算子的实例。它们的数学位置是**同构类**（isomorphism class）：

- 资产：`mesh` 与 `SDF` 是同构的两种表示。表示转换是 §25 的**对偶切换**（边界↔体），
  不是拉回。资产管线的正确性 = 表示转换保持层同构。
- 缓存：签名函数 `K` 把层映到签名格；缓存正确性 = `K(F) = K(G) ⟹ F ≅ G`（定理 5.4）。
  这是层的**同构类**的判定，不是内 Hom。

**这两层的统一结构是「同构类」**，与四算子并列，不重叠。

### 4.3 第三类：内容层（三个）——各自生成结构，不由骨架统一

| 层 | 生成结构 | 数学位置 |
|---|---|---|
| 视觉品类（生成算法） | 流场、L-system、Voronoi、细胞自动机、分形 | **自由层**（生成元 + 关系自由生成） |
| 物理（XPBD/SPH） | 微分方程的时间演化 | **层上的流**（flow，需要微分结构） |
| 最优分配（率控、降噪采样） | 凸优化 | `V` 上的**凸结构**（§25 的最优性侧） |

**这三层的内部不由四算子生成**。它们的确定性来自各自的纯函数性，不来自层结构。
把它们硬套进层论，就是伪统一。

### 4.4 三类的关系

```
        ┌─────────────────────────────────────┐
        │  骨架（一次性补齐的部分）              │
        │  ┌───────────────┐  ┌─────────────┐  │
        │  │ 算子层（5）     │  │ 同构层（2）   │  │
        │  │ 四算子 + 粘合   │  │ 同构类判定    │  │
        │  └───────────────┘  └─────────────┘  │
        └─────────────────────────────────────┘
                        ↕ 声明接入
        ┌─────────────────────────────────────┐
        │  内容（各自实现，不由骨架统一）         │
        │  视觉品类生成 / 物理演化 / 最优分配     │
        └─────────────────────────────────────┘
```

**「一次性补齐」的准确含义**：骨架补一次（算子层 + 同构层），内容按层声明接入。
不是「八层一套代码」，是「两类骨架 + 八层声明」。

### 4.5 表示层：DSL / Author 的位置

DSL 与作者 API 不属于上述三类——它们不是「视觉层」，而是**层表达式的语法**：

- 一个 DSL 文档 = 一个层表达式（四算子 + 内容层的组合）的语法表示；
- 编译器 = 从语法到层表达式的翻译；
- `ClipSpec` / 组合子 = 常用层表达式的宏。

这解释了为什么「补 DSL 节点」永远不解决表达力问题：节点是语法，表达力来自
**语法能翻译到的层表达式有多丰富**。语法可以无限增长；骨架不立，翻译目标就永远是吸管。
**先立骨架，语法自然有落点。**

## 5. 核心定理与新推论

### 5.1 闭合性

**定理 5.1**。设 `F_1,…,F_n` 是 `S` 上的层，`op_1,…,op_{n−1} ∈ {f*,f*,⊗,Hom,f!}`。
若源与目标底空间匹配，则复合表达式定义 `S` 上的层。

*证明*。每个算子是层范畴之间的函子（§3），函子复合是函子。∎

**推论 5.1（新层自动归位）**。新增视觉能力只需声明底空间与截面，用四算子与已有层
组合，自动获得确定性、粘合性、可缓存性。

### 5.2 局部性

**定理 5.2**。设 `{U_i}` 是 `S_pixel` 的 tile 覆盖，`F ∈ Sh(S_pixel)`。若局部求值
`F|_{U_i}` 在重叠上一致（halo 协议保证），则 `glue({F|_{U_i}}) = F` 在整幅上逐字节一致。

*证明*。公理 L 给出唯一全局截面；`F` 本身是全局截面，故 `glue` 结果等于 `F`。
逐字节一致来自 `V` 的离散性（像素值域有限，相等即逐字节相等）。∎

**推论 5.2（halo 半径的数学位置）**。halo 不足 ⟺ 重叠不一致 ⟺ 粘合失败。
tile 边缘伪影是粘合公理失效的直接表现，不是工程误差。

**推论 5.3（并行性判据）**。一个效果可 tile 并行，当且仅当它是 `f!` 的实例
（只依赖有限邻域）。依赖全局数据的效果（如需要全图直方图的自动曝光）不是 `f!`，
必须走全局重算——这是结构判据，不是经验规则。

### 5.3 重参数化

**定理 5.3**。`φ : T' → T` 为时间重映射，则 `φ*` 是函子，`(ψ∘φ)* = φ*∘ψ*`。

*证明*。定理 3.1。∎

**推论 5.4（驱动源的组合性）**。多个驱动源（关键帧 + 音频 + 表达式）的组合 =
多个 `f*` 的复合，与顺序无关。这解释了「参数绑定可任意嵌套」而不产生歧义。

### 5.4 内容寻址

**定理 5.4（条件性）**。`K` 为签名函数。若 `K(F) = K(G) ⟹ F ≅ G`，则缓存命中
`K(F)` 可复用 `F` 的计算结果。

*证明*。层同构保持一切截面值；计算结果只依赖截面值。∎

**注 5.4.1**。这是**条件性**定理：它把缓存正确性归约为「签名是否完全刻画层的同构类」。
§25 的 Merkle 保证书给的是哈希碰撞概率，不是同构刻画。后者需要签名覆盖层的全部依赖
（依赖闭包）。本报告不声称该问题已解决，只指出它的正确位置：**层的同构类**。

### 5.5 新推论（结构推出、文档中无）

**推论 5.5（混合算子的合法性判据）**。一个值域算子 `⊕_V` 可作为层混合使用，
当且仅当 `(V, ⊕_V)` 是 monoid（单位元 + 结合律）。若不满足，层的组合顺序会影响结果，
`⊗` 不再是结构运算。

*意义*：这给出「新增混合模式」的判定标准——先验证 monoid 律，再接层。

**推论 5.6（参数化的封闭性）**。`Hom` 的闭合性保证「参数化任意深度」不增加新结构：
`Hom(F, Hom(G, H)) ≅ Hom(F⊗G, H)`。嵌套驱动（音频 → 粒子 → 材质）在结构上是平的。

**推论 5.7（同构层的判据形式）**。资产层与生态层的复用共享同一**判据形式**：
`F ≅ G`（层同构），但作用于不同的层——资产层判「几何语义的两种表示是否等价」，
生态层判「两次计算是否等价」。因此两者可共用同一套签名基础设施（哈希 + 依赖闭包），
但不能互相替代。**同源的是判据形式，不是判据对象**。

**推论 5.8（内容层的接入边界）**。内容层（生成算法/物理/最优分配）接入骨架时，
只需满足两条：① 截面是纯函数；② 定义域是开集。它们不参与四算子的组合律证明，
但自动获得粘合与缓存——**这是「内容层不必重写确定性逻辑」的根据**。

## 6. 诚实边界

1. **不声称单一结构**：八层是三类结构的分布（§4），不是同一结构的八个实例。
   「一次性」= 两类骨架各一次，不是「一个定理装下全部」。
2. **不声称覆盖生成算法内部**：自由层、流、凸优化是内容层的数学位置，不由层论生成。
3. **不声称表示定理**：本报告不证明「任何视觉计算都可由四算子生成」——那需要先
   公理化「视觉计算」的全部语义，本报告不做此断言。声称范围限于八层的**组合需求**。
4. **定理 5.4 是条件性的**：签名完备性（依赖闭包）未解决。
5. **Kan 扩展的实现代价**：定理 3.5 给出 `O(|S|²)`，但实际常数取决于底空间大小；
   大场景需要分层（层次化底空间），本报告未展开。
6. **数学不解决审美**。本报告解决「组合骨架」，不解决「什么好看」。审美 = 值域的
   选择 + 参数的选择 + 节奏的判断，属于设计判断，不在数学里。骨架让引擎能组合任意
   效果；「组合哪个效果」仍是审美决策。**这是「打不过 HTML」问题的一半答案**：
   数学补齐另一半（组合成本），审美那一半要靠设计纪律与作品迭代，不能靠定理。

## 7. 代码量论证

| 部件 | 内容 | 估计行数 |
|---|---|---|
| 层核心 | 底空间、层 trait（`domain`/`section`）、粘合 | 150–200 |
| 四算子 | `pullback`/`pushforward`/`tensor`/`hom`/`compact_pushforward` | 250–350 |
| 同构核 | 签名接口 + 同构类判定（与 `signature` 复用） | 80–120 |
| 编排 | 层列表 + 算子表达式求值 | 100–150 |
| 每层声明 | 底空间 + 截面 + 算子选择 | 30–50 × 8 = 240–400 |
| 合计 | | **820–1220** |

对比：八层各写一遍组合逻辑至少数千行，且确定性/粘合/参数化要重复实现。
**骨架一次，内容声明**——这是「少量代码」的准确来源。

## 8. 实施规格

每层接入需声明四件事：

1. **底空间**：`S` 的格结构（时间格、参数格、tile 格）
2. **值域**：`V` 的对象与混合算子（须满足推论 5.5 的 monoid 律）
3. **截面**：`section(t, p) → V` 的纯函数
4. **算子选择**：使用的四算子（拉回/推前/张量/内 Hom/紧支撑推前）

八层的声明表见 §4.1 / §4.2；内容层按推论 5.8 接入。

## 9. 与 §25 的关系

§25 三问（核/对偶/格）回答「一个计算怎么算」；本报告四算子回答「多个计算怎么组合」。
两者是同一结构的两层：

- 核 = 层在值域上的作用（`⊗` 的具体形式）
- 对偶 = 算子的选择（在哪一侧算）
- 格 = 底空间的离散化（有限偏序）
- 求逆策略 = 截面的构造算法（六种，§25 已给）

**§25 统一了 24 个算法，本报告统一了 8 个架构层的两类骨架。** 二者合起来构成
「计算层 + 组合层」的完整描述；单靠任何一个都不够。
