> 状态：**压缩终点（第 5 轮）**。活文档。

## §0 自检：这不是命名法

命名法的特征：给既有零件起数学名，推不出任何新结论。三条检验：

1. **自存性**：没有引擎，对象也存在——抽象机的「步进 + 停机」（计算理论）、
   格上的 Kleene 链、动力系统的离散化、拓扑排序的遍历，全是它的实例。
   引擎不特殊。
2. **新结论**：它推出引擎里现在没有的结论——(a) 物理每帧容差停机可直接移植到
   任意环（同一停机器）；(b) 音频群作用 ⟹ 样本流可免费重算（seek 成本 O(1)，
   与物理快照分叉但同源，F5 的成本律）；(c) DAG/环/时间/音频共用同一个调度循环
   ⟹ 现在三套独立代码（拓扑序 / 快照私有协议 / session 循环）并成一套。
3. **简洁的来源**：不是「发明了更少的代码」，是**消灭重复**——三套并一套，
   省下的是两份实现 + 两份 bug 面。

三条全过。往下立数学。

## §1 数学对象（自存定义）

**定义 1.1（推进-停机框架）**。四元组 `(X, ⊑, P, H)`：

- `X`：状态空间（引擎侧 = 全图值向量；数学侧 = 任意集合）；
- `⊑`：`X` 上的预序（信息/计算进度序；可为平凡序）；
- `P : X → X`：推进函数（一步：展开一个节点 / 迭代一轮 Neumann / 推进一帧 / 推进一步相位）；
- `H : X → Bool`：停机判据。

**求值语义**：从初态 `x₀` 出发，序列 `x_{k+1} = P(x_k)`，求最小的 `n` 使 `H(x_n)`
成立，输出 `x_n`。记作 `AH(x₀) = x_n`。

**这就是「计算」的最裸形式**：步进 + 终止判据。不需要格、不需要算子、不需要
范畴——那些都是特例的附加结构。

**定义 1.2（单调推进）**。若 `x ⊑ y ⟹ P(x) ⊑ P(y)`，称 P 为单调推进。
单调推进在完全格上有 Kleene 链 `x₀ ⊑ P(x₀) ⊑ P²(x₀) ⊑ …`。

## §2 四实例定理：引擎的四个动态性是同一框架的四个配置

### 命题 2.1（DAG = 推进-停机的特例）【定理】

取 `X` = 全图值向量（未计算 = ⊥），`P` = 「按拓扑序展开全部就绪节点一步」，
`H` = 「所有节点有值」。则 `AH(x₀)` = 引擎现有 `eval` 的输出，且停机步数 = `D+1`
（D = 图深度）。

*证明*。即《求值台的数学》命题 3.1：同步 Kleene 第 `D+1` 步 = 单遍拓扑序求值。
「按拓扑序展开」与「同步展开」在 DAG 上等价（就绪集只增不减）。∎

### 命题 2.2（环/不动点 = 推进-停机的三配置）【定理】

取 `X` = 完全格 `L^V`，`P` = 同步算子 `G`（`G(x)_v = f_v(x|_{dep(v)})`）。
停机判据三选一，即三模式：

| 模式 | H | 数学 | 停机保证 |
|---|---|---|---|
| M1 | `x` 已触顶（`P(x) = x`） | Kleene | 有限高格 ⟹ 必达（命题 3.9） |
| M2 | `‖P(x) − x‖ < ε` | Banach 压缩 | `ρ(G) < 1` ⟹ 必达 |
| M3 | 计数器 = n | 截断 Neumann | 必达（定数），无收敛承诺 |

**新结论（推进-停机视角独有）**：三模式不是三个子系统，是**同一个 H 的三个实例**——
换停机判据即换模式，推进器、状态、依赖、签名全部不变。引擎现状 XPBD = M3
是「只实现了 H 的一个实例」，补 M1/M2 是加两个 H，不是加两个调度器。

### 命题 2.3（时间 = 沿帧格的推进）【定理】

取 `X` = 帧状态，`⊑` = 帧号序（`ℤ` 的自然序），`P = Φ_f`（帧间算子），
`H` = 「当前帧 = 目标帧」。则 `AH` = 顺序求值到目标帧；快照 = 已求值状态的
检查点；**seek = 从检查点或从 x₀ 重放**（粒子 `seek_with` 正是此构型的显式重放实例，
《解结构》命题 P1）。

**新结论**：时间维度不是求值台的「私有协议」（现状：ConstraintFlow 特例），
是推进-停机的一个标准配置。任何能力声明「我的状态在帧间演化」即获得时间实例，
无需复制快照读写代码。

### 命题 2.4（音频 = 群作用推进）【定理】

取 `X` = 相空间 `S¹ = ℝ/ℤ`，`P(i) = (φ₀ + ωi) mod 1`（`ℤ` 在 `S¹` 上的旋转），
`H` = 「样本缓冲区末尾」。则 `AH` = 振荡器逐样本求值（《解结构》命题 F1）。

**新结论（群作用免费重算）**：群作用 `P(i+j) = P(i) ∘ P(j)` ⟹ `x(i)` 是 i 的
纯函数 ⟹ **任意 seek 成本 O(1)**（重算单个样本即可，无需重放）。物理快照与
音频重算的分叉（F5）在框架内统一：**分叉的是 H 与成本，不是 P 的数学**。

### 2.5 四实例的配置表（一张表看完统一）

| 动态性 | X | ⊑ | P | H | 现状代码 |
|---|---|---|---|---|---|
| DAG | 值向量 | 深度序 | 拓扑展开 | 全有值 | `eval.rs` 单遍 |
| 环 | `L^V` | 信息序 | 同步 G | 触顶/残差/定数 | 缺（禁环） |
| 时间 | 帧状态 | 帧号序 | Φ_f | 目标帧 | ConstraintFlow 私有协议 |
| 音频 | 相空间 | 采样序 | 群作用 | 缓冲末尾 | `sample_osc` 纯函数 |

**四行是同一个框架的四行配置。统一完成——且不是命名，每行都有定理（2.1-2.4）。**

## §3 统一定理（承重墙）

### 命题 3.1（有限性）【定理】

若 `(L, ⊑)` 无无穷升链且 P 单调，则 `AH` 必达停机（M1），步数 ≤ `|V|·(|L|−1)`
（《求值台的数学》命题 3.9）。**离散引擎域（f32 点值）不满足 ⟹ M1 无保证，
必须 M2（残差）或 M3（截断）**——这是「模式必须显式」的数学根据。

### 命题 3.2（群作用免费重算）【定理】

若 `P` 是群 `G` 在 `X` 上的作用且 `x(i) = w(P(i)(x₀))`，则对任意 `i`，
`x(i)` 可由 `x₀` 直接求值（不依赖历史），seek 成本 = 单样本成本。
**音频、发射（粒子）、确定性采样（S4）全部适用**——引擎的「无全局 RNG」
纪律即此定理的工程表述。

### 命题 3.3（检查点-重放等价）【定理】

若 P 确定（同输入同输出逐位）且状态转移满足马尔可夫性（跨度 1），则
「从检查点继续」与「从 x₀ 重放到检查点」逐位一致（《求值台的数学》命题 4.3）。
**seek 语义的统一根据**：检查点（快照）合法 ⟺ 该式成立；不成立时报错，不静默
（P3012 修复的数学身份）。

## §6 诚实边界

1. **核心是识别不是发明**：推进-停机是计算理论的裸模型，本报告的贡献是
   (a) 证明引擎四动态性是它的四配置（每配置一条定理）；(b) 有限精度生死判定
   （3.1：为什么 M1 无保证——这条是真新东西，教科书没有，因为数学默认实数）。
2. **追不上的部分说清楚**：#10（渲染特性广度）、格式广度、GPU 后端完整度是
   **内容量**，核心只改变接入方式（注册 vs 造子系统），不减少内容本身。
   「1000 行追上 Cycles」是假话；「1000 行拿到编排层的统一入场券，内容逐个注册」
   是真话。
3. **未证**：签名闭包的完备性（配置哈希碰撞 ⟹ 行为差异）仍是猜想；
   分层语言（配置层 vs 内容层）未决。两者都不阻塞内核先行——内核先用
   「Rust 注册 API 当配置层」，DSL 投影随后。
