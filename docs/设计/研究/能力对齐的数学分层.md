## §1 为什么是层不是十二条

十二条差距各自踩在一个自存的数学分支上，且分支之间有依赖：

```
验证层（确定性）        ← 兜住全部：一切输出逐位可复现
  ↑
并行层（可分解性）      ← 核跑得快：r-局部 + halo
  ↑
表示层（同构类）        ← 接得进：格式/表示的等价判定
  ↑
核层（算子方程）        ← 算得出：渲染方程家族实例化
  ↑
求值层（推进-停机）      ← 调度得动：四实例一套循环（已立核心）
  ↑
值域层（格/非结合代数）  ← 算得对：预乘、色彩格同构
```

**依赖方向自下而上**：值域层错了，上面全错（over 非结合让图层树不可扁平化 =
求值层的缓存依据崩塌）；求值层错了，核接不上图。**所以偿还顺序 = 层序自下而上**，
这不是偏好，是依赖。

### §2.1 色彩链代数（第 7 轮证明）

**设定**。白点集 W；`B = BRADFORD`（可逆 3×3）；`Adapt(w₁,w₂) := B⁻¹·D₁₂·B`，
`D₁₂ = diag((B·x₁)/(B·x₂))`（引擎实现 `bradford_adaptation` 字面形式，
`src==dst` 短路恒等）。色彩空间 def 给出 `M_f = rgb_to_xyz(f)`（可逆）。

**命题 C1（Bradford 转移律）**。对任意 `w₁,w₂,w₃ ∈ W`：
`Adapt(w₂,w₃) · Adapt(w₁,w₂) = Adapt(w₁,w₃)`。

*证明*。记 `b_i = B·x_i`（锥体响应向量）。则
`Adapt(w_i,w_j) = B⁻¹·diag(b_j/b_i)·B`（逐分量比）。于是
左边 `= B⁻¹·diag(b₃/b₂)·B·B⁻¹·diag(b₂/b₁)·B = B⁻¹·diag(b₃/b₂)·diag(b₂/b₁)·B`
（`B·B⁻¹ = I`）`= B⁻¹·diag(b₃/b₁)·B = Adapt(w₁,w₃)`。∎

**命题 C2（线性链 = 群元素）**。设 `f, g` 两空间传输函数均为 `Linear`。
则 `convert(g,f) : v ↦ M_g⁻¹·Adapt(w_f,w_g)·M_f·v`，是 `GL(3,ℝ)` 元素。
任意链 `c₁→c₂→…→cₙ`（全 Linear）的复合 `= M_{cₙ}⁻¹·Adapt(w₁,wₙ)·M_{c₁}`，
与分组无关；`w₁ = wₙ` 时 Bradford 项为 `I`，零额外运算。

*证明*。由 C1：`Adapt(w₂,w₃)·Adapt(w₁,w₂) = Adapt(w₁,w₃)`，相邻 Bradford
项沿链逐步塌缩；矩阵乘法结合律处理括号。∎

*工程含义*。管线「场景线性 → 工作空间 → 显示线性」当前逐步各转一次
（每步一次 Bradford 舍入）；C2 允许预复合为单矩阵， Bradford 次数
`n−1 → 1`。同白点链路（引擎内部 sRGB↔ACEScg 全 D65 接入段）本来短路，
不受影响——**预复合是纯增益，无兼容性代价**。

**命题 C3（非线性障碍 / 分流判据）**。设链中某空间传输函数 `t ≠ Linear`。
则该链不能表为单个线性算子；且两段传输函数 `t₁ ≠ t₂` 时不可交换
（除通道独立的幂函数同指数退化情形）。

*证明*。线性段保线性组合，非线性段不保（幂函数 `x^e` 对 `e ≠ 1` 不满足
`(αx+βy)^e = αx^e + βy^e`）；Lab 含分段立方根同理。故任何含非线性段的
真因子分解不可交换。∎

*纪律*（与 #3 合流）：链静态分为**矩阵段**（可预复合、可重排、可括号化）
与**传输段**（锁序、锁括号）；两类不可混布重排。这正是混合算子层
「覆盖类可扁平化 / 着色类锁序」的同一结构——**值域层的内部统一**。

**命题 C4（两轨同构判据）**。旧 `ColorSpace` 变体 `e` 与新
`ColorSpaceDef` 定义 `d` 表示同一色彩空间，当且仅当三元组
`(primaries, white_point, transfer)` 逐项相等（浮点容差内）。

*已核对*：`LinearSrgb ↔ srgblinear`（D65, sRGB 原色, Linear）、
`AcesCg ↔ acescg`（D60, AP1, Linear）、`Aces2065 ↔ aces2065`（D60, AP0,
Linear）、`SrgbDisplay ↔ srgb`（D65, sRGB 原色, Srgb）——4/6 对上；
`PqDisplay` 在新轨 20 空间中**无对应**（BT.2020 TF 是 HLG 家族，PQ 编码
空间未注册）——**PQ 是两轨合并时唯一真缺口**，且可指名（补一个 def 即可）。

**命题 C5（定义域 = 正锥）**。`PureGamma{e}` 拒绝负输入：`(−x)^e`（`e`
非整数）在 ℝ 中无定义。`Lab` 拒绝负 XYZ：`f(t)` 线性段
`κt/27 + 4/29` 对 `t < 0` 的外推值会越过断点与幂段重叠或反序，破坏双射。

*结论*：引擎「色彩域恒非负」的成文纪律（`validate_primaries`/
`non_finite` 系列）不是工程便利，是**数学定义域**——值域层的格纪律在
色彩域的实例。

**命题 C6（有限精度断链）**。C1 在 f64 下近似成立，偏差
`‖Adapt(w₂,w₃)·Adapt(w₁,w₂) − Adapt(w₁,w₃)‖ = O(ε·cond(D₁₂D₂₃)·‖B‖·‖B⁻¹‖)`；
预复合使 Bradford 作用次数从 `n−1` 降至 1，**总舍入误差单调下降**。

*证明*。逐项为 f64 乘加，每步引入相对 `ε` 的扰动；`cond(D)` 为对角条件数
（= 分量比极值比）；`‖B‖·‖B⁻¹‖` 为 Bradford 常数（固定）。矩阵乘积的
扰动传播由范数乘性给出。∎

*这是有限精度算子理论的又一实例*：实数上精确的转移律，离散上以条件数为
模近似；且「更少作用次数」严格占优——**预复合不是优化，是误差纪律**。

**成熟引擎对标**：Cycles 的预乘 + OCIO；AE 的 32bit 线性合成。引擎差在
#3 的一个 bug 级修复 + #12 的库完整度。

### §3.1 求值层承重缝：M2 误差界（第 7 轮证成）

上一轮留缝：「Banach 界在 Gauss–Seidel 上的形式没证」。证完了，而且比预期
有价值——它把 M2/M3 的选择从设计偏好变成**有数学根据的判定**，并指出引擎
需要一个而原先没有的机制（发散检测，本轮施工已补，见 §3.1.1）。

**设定**。迭代函数 `Φ: X → X`（X = 状态空间，装备范数 ‖·‖），GS 形式
`x_{k+1} = Φ(x_k)`，不动点 `x*`。M2（容差停机）= `‖x_{k+1} − x_k‖ ≤ ε` 时停。

**命题 E1（M2 误差界：压缩情形）**。若 `Φ` 是 L-压缩（`L < 1`），则
(i) 残差衰减 `‖x_k − x*‖ ≤ L^k‖x_0 − x*‖`；(ii) 容差停机时
`‖x_K − x*‖ ≤ ε/(1−L)`——**停机判据用连续差，误差界用余项**，这是标准结果。

*证明*。(i) `‖x_{k+1} − x*‖ = ‖Φ(x_k) − Φ(x*)‖ ≤ L‖x_k − x*‖`，归纳。
(ii) `‖x_k − x*‖ ≤ ‖x_{k+1} − x_k‖ + ‖x_{k+1} − x*‖ ≤ ε + L‖x_k − x*‖`，
解出 `‖x_k − x*‖ ≤ ε/(1−L)`。∎

**命题 E2（非扩张情形：不发散但无先验界）**。若 `Φ` 只非扩张（`L = 1`），
则迭代不发散（`‖x_k − x*‖` 不增，若不动点存在），但 Banach 定理**不给出
衰减率**——M2 此时**没有先验误差界**，停机只能记录残差事实（M3+残差），
或另证谱条件。

*证明*。`L = 1` 时 E1 的归纳给出 `≤ ‖x_0 − x*‖`（常数），且 E1(ii) 的
`ε/(1−L)` 除零——界不存在，非证明疏漏。∎

**这正是 XPBD 的真实位置**：约束投影是**非扩张**的（到凸集的投影收缩
距离：`‖P_C(a) − P_C(b)‖ ≤ ‖a − b‖`），所以引擎注释里的「残差 O(q^iters)
衰减，q<1」不是 Banach 假设——q<1 来自约束雅可比的**结构性质**（每步投影
把违反量乘以与约束条件数相关的因子），是逐类约束可证的命题，不是泛泛的
压缩性。**数学定位**：XPBD = 非扩张框架 + 结构性衰减率；M2 对它有
「事后残差」无「先验界」。

**命题 E3（复合 Lipschitz 的分解与发散判定）**。设 `Φ = P_n ∘ … ∘ P_1`
（顺序投影复合）。则 `Lip(Φ) ≤ Π_i Lip(P_i)`；凸集投影 `Lip = 1`，
非凸/折叠约束投影可 `> 1`。

*推论*：(a) 全凸约束 ⟹ 非扩张 ⟹ 不发散（E2 安全）；(b) 存在 `Lip > 1`
分量 ⟹ 有发散风险；(c) **有限精度下 `Lip = 1` 的边界情形**
（`1 + O(ε)`）在长迭代中显现为残差缓慢上升——发散检测阈值必须带 ε 余量，
即「连续若干步残差不降」而非「单步不降」。

*工程对应*：E3(c) 的「阈值必须带 ε 余量、连续若干步而非单步」原先在引擎
里**没有任何实现**（施工方 grep 证实：原有 smoke 只查流体速度散度、hair
只做速度钳制，皆非迭代残差发散检测）——本轮施工按此推论新落
`DivergenceDetector`（`prism-physics/src/xpbd.rs`：连续 ≥3 步残差上升
且超 ε 余量判定发散）。**这是推论先行、工程后补的实例，不是「工程已有、
数学追认」——账必须记对。**

#### §3.1.1 发散检测的工程落点（第 8 轮施工补录）

E3(c) 原话：「连续若干步残差不降」而非「单步不降」，「阈值必须带 ε 余量」。
本轮施工（施工方 C，宿主注册路）把它落成 `prism-physics/src/xpbd.rs`：

| 数学条件 | 工程形态 |
|---|---|
| 连续 ≥ k 步（数学未定 k，工程取 3） | `DivergenceDetector` 连续上升步数计数 |
| 残差超过 ε 余量 | `SolveModeMeta::residual_eps` 配置 + 余量比较 |
| 可判定 | `SolveMode{M3, substeps, iterations, residual_eps}` 随帧元数据进签名 |

同时修正了 xpbd 模块文档里 Banach 错误归属（q<1 是结构性质不是泛泛压缩性，
E2 的订正条款）。**这是六层差距偿还中「数学推论直接变成一行新增机制」的
最小完整案例——1000 行内核里没有它，它单独 ~30 行。**

**三定理的净结果**（推进-停机核心的最后一块数学）：

| 情形 | 数学 | 模式选择 |
|---|---|---|
| Φ 可证 L-压缩 | E1：有先验界 `ε/(1−L)` | **M2 正规** |
| Φ 非扩张（凸投影） | E2：安全但无先验界 | **M3 + 残差记录** |
| Φ 含 Lipschitz > 1 分量 | E3：可判定、可检测 | **M3 + 发散检测** |

模式声明从「节点作者选一个」变成「按 Lipschitz 结构查表」——**这是求值层
最后一个未数学化的缝**。至此推进-停机四元组（X, ⊑, P, H）每一件都有
定理级依据：兼容性（3.1）、刚性（3.2）、时间轨道（3.3）、有限性（3.9）、
三模式（3.10/3.11）、seek 等式（4.3）、误差界（E1–E3）。

### §3.2 #8 缓存签名闭包：从「条件性」到「条件明确」（第 8 轮证成）

**勘定**：`prism-core/src/signature.rs`（1005 行：canonical 序列化 + 自底向上
子树哈希 + 通道定义哈希 + 缓存键五元组 + 内置 SHA-256）+ `prism-render/src/
incremental.rs`（1299 行：三维复用 + `ReuseVerdict` 逐字节一致 + 五类通道
`ChannelKind`{Const/Track/Expr/Spring/AudioReactive} 的恒定区间）。
家底比文档原来标的「条件性成立，未验完」完整得多——条件可以逐条钉死。

**命题 S1（静态闭包充分性）**。设无状态节点输出 `y = F(θ, u₁..u_k)`，
`F` 纯函数（宪章），签名 `sig(n) = H(θ, sig(uᵢ), Composition, NodeId)`
（NodeId/Composition 按公理补全——`signature.rs:25-29` 自述的偏差声明）。
缓存键 `= (schema, engine, sig, 分辨率, spp, tile)`。则：**键其余分量固定时
`sig` 相等 ⟹ 输出相同**。

*证明*。签名树是 Merkle 树：自底向上哈希，改叶子只动自身到根的祖先锥
（`signature.rs:16` 自述，标准性质——子树哈希由子签名决定，故
`sig(a) = sig(b) ⟹` 两棵子树逐节点同构同参（哈希无碰撞公理）⟹ 同图同参数
⟹ `F` 纯函数 ⟹ 同输出）。∎

*条件明示*：(a) `F` 纯函数（宪章）；(b) 求值上下文 `c` 的每个影响输出的
分量都在键的其余分量里（分辨率/spp/tile = 采样面）；(c) **节点输出与 frame
无关**——无状态节点这是定义性质；有状态节点见 S3。

**命题 S2（三维覆盖完全性）**。输出的影响因素分三类：静态配置（θ, 图结构）、
时间（frame 上的参数变化）、采样（pixel/spp）。签名维覆盖静态（S1）、
帧区间维覆盖时间（恒定区间 ⟹ 参数恒定 ⟹ 输出恒定，由五类通道的界保证）、
tile 维覆盖采样。**三类互斥且穷尽 ⟹ 三维复用模型覆盖全部影响因素。**

*这是复用正确性的完全性论证*：任何输出差异必来自三类之一，故必被某一维
的缓存键/区间判定捕获——不存在「漏网」的影响因素。（反证：若有第四类
因素 f 不在三维内，则存在同键同区间不同输出的可能——与 `ReuseVerdict`
的逐字节一致关卡矛盾。）

**命题 S3（动态层的键扩充条件——#8 的核心答案）**：

| 动态类型 | 输出依赖 | sig 闭包？ | 键必须含 | 依据 |
|---|---|---|---|---|
| 无状态节点 | (θ, u) | ✅ | — | S1 |
| **流节点**（ConstraintFlow） | 帧历史 `x(f−1)` | ❌（sig 是静态哈希） | **frame** | D-28 快照键 `(sig, frame)`；续算等价 = seek 等式 4.3 |
| **迭代节点**（M2/M3） | `(ε, n)` 模式参数 | ❌（sig 不含模式） | **ε, n** | 模式元数据进签名（§3.1 查表的设计依据） |
| 音频反应（CH4） | 烘焙表区间 | ✅（区间内） | 区间 | `incremental.rs` CH4 |

*这条命题就是 #8 的数学完形*：签名对**静态层**完全闭包；对**动态层**，
缓存键必须按类型补帧/补模式参数——**补的方式两条都已证**（4.3 seek 等式 +
模式元数据）。原文档「未验完」的条件性，现在是一条分类表。

**命题 S4（LRU 逐出中性）**。缓存逐出只影响「是否重算」，不影响「算出什么」：
命中 = 取回字节，未命中 = 重算，两者输出相同（S1+S2）。故 seek 等价成立
（D-28 自述，本命题给出依据）。

**#8 结论**：**数学完毕**。条件全部钉死：静态层 sig 闭包；流层键含 frame；
迭代层键含 (ε, n)；时间维靠五类通道恒定区间。无一悬空。

## §6 并行层：可分解性 → #11

**自存数学**：平移不变算子的有限支撑分解（tile 化判据已证：r-局部 + halo ≥ r）。

**#11 勘定（第 7 轮）**：三后端（compute/metal/vulkan/web）目录齐全；

**命题 P1（可分解 = 并行正确的充要条件）**。算子 `A` 平移不变且支撑半径 r：
`A(x)[p]` 只依赖 `x[p−r, p+r]`。则输出可分解为 tile 拼接，
tile 大小任意——**halo ≥ r ⟹ tile 结果与全局逐位相同；halo < r ⟹
差 ≤ 截断核尾部质量**（可解析估计）。

*证明*。平移不变 + 有限支撑 ⟹ `A = Σ_k A_k`（核的有限分解），每 `A_k`
只读窗口；halo ≥ r 时窗口完备，`A_k` 在 tile 内精确求值；halo < r 时
缺的是支撑尾部的 `A_k`，其质量 = 尾部概率和。∎

*这是并行层唯一需要的数学*：它同时是 #11 的偿还判据和 #4 的验收接口
（GPU vs CPU 逐位相同 ⟺ halo ≥ r）。

**数学核心（第 7 轮，三条）**：

**命题 R1（转换器 = 保持结构的态射）**。资产格式范畴 C（对象 = 格式文件，
态射 = 保真转换），引擎表示 E。导入器 `T_f: C_f → E` 的正确性 =
`T_f` 保持同构类：`a ≡_C a'` ⟹ `T_f(a) ≡_E T_f(a')`。

*这是「同构保持」的可操作化*：不是「转过来看起来对」，是格式内声明的等价
（同名引用、实例化 prim、组合层级）在引擎侧仍等价。

**命题 R2（往返 = 同构的工程判据）**。`T: A → B` 可逆（在同构类上）
⟺ `T⁻¹∘T = id`。**落地形式**：签名判据——往返后表示签名相等是充分条件；
不成立 ⟹ 必有信息损失（可定位到丢失的字段）。签名碰撞使必要性仅为概率
（哈希函数选定后可界定）。

*这是 #8 缓存与 #9 资产的合流点*：签名既是缓存键又是往返判据——一台机器
两个用途，和之前「语法写得出配置、签名判得清等价」同一个判断。

**命题 R3（mesh/SDF 不是对偶同构，是分辨率有界的近似对）**。
`bake_mesh` 把连续表面离散到砖格（`pack_brick` 3×2²⁶ 键），信息有损；
反向提取同样有损（零等值面的拓扑近似）。**两者都不是同构**，正确性判据
不是「往返相等」而是「Hausdorff 距离 ≤ f(分辨率, 梯度界)」。

*证明要点*。bake 的每点误差 ≤ 半格边长 × 局部 Lipschitz（距离函数 1-Lipschitz
于原曲面——SDF 定义性质），故 `d_H(SDF⁻¹(0), mesh) ≤ h/2 · (1+‖∇d‖)`，
其中 h 为格距；反向（如 marching cubes）误差由等值面插值方案给出同类界。∎

*这条修正的价值*：它把 #9 的验收从「肉眼比对」变成**可证的保真度上界**——
UE/USD 资产管线的真正卖点就是这个，而引擎的 `mesh_sdf` 结构已支持（梯度
可解析，brick 分辨率已知）。

**#9 偿还量级（修正后）**：签名判据 ~150 行（与 #8 共享）+ 反向转换器
（零等值面提取，几百行）+ 统一转换器契约（接口级）。**USD/glTF/obj 解析器
已是资产，不重写。**

是逐位或有界——判据只有这两档。

**命题 V3（集成验收 = 帧轨道签名）**。一部片子的确定性 = 每帧输出哈希组成
的轨道签名 `H = (h_0, h_1, …, h_F)`；seek 等式（命题 4.3：写入正确性 +
马尔可夫性 + 无断档）保证跳帧求值与顺序求值的轨道相同——**时间线上的
任意存取不改变输出**。

*三条合起来就是「对齐」的验收协议*：每层能力接入后，V1 保证单帧可复现，
V2 保证并行不破坏，V3 保证时间线完整。成熟引擎的「参考图/回归测试矩阵」
就是这个协议的工程化。

### §11.1 GPU 后端真实状态（第 8 轮后勘定，订正 §8 印象派）

第 8 轮账本把 #11 记成「web 骨架」是印象派。`prism-gpu`（19,518 行）实际是
**四个后端、三个半成品**：

| 后端 | 行数 | 状态 |
|---|---|---|
| CpuRefBackend | — | ✅ 唯一可出图（软件光追，全平台兜底） |
| Vulkan | 4,383 | 探测链（dlopen/dlsym FFI 零依赖）+ **自研 SPIR-V 发射器**（发射/校验/反汇编/CPU 对拍）就绪；**缺渲染管线** |
| Metal | 764 | 探测链（仅 macOS）+ MSL 双份源约定 + 1 个真实样例；**缺渲染管线与其余 kernel** |
| WebGPU | 7,655 | 浏览器绑定厚实，wasm/移动测试链在用 |

三者 `is_available()` 恒 `false`（「探测到设备 ≠ 能出图」的宪章式诚实）。
**结论：#11 不是从零铺量，是在半成品上接通渲染管线——最短路径 Vulkan
（探测链 + SPIR-V 现成），Metal 按 MSL 双份源跟上，WebGPU 收尾（分发面）。
双份源维护成本（每 kernel 两份源）记为已具名债。**
