## 0-A. 统一框架：确定性双支柱（任务 2 的核心答案）

七个提案表面解决七个不相干的问题（JPEG 解码、GPU 遍历、BVH 构建、率控、
缓存键、降噪分配、转场混合），自审第 2 问「是否存在统一数学框架」的答案是
**是**：全部同源于两大支柱——**规范化**（canonicalization）与**最优性**
（optimality）——

> **支柱一（规范化）：确定性 ≡ 计算是规范形（canonical form）的纯函数。**
> 凡输出可被非规范输入（加载序、线程调度、平局、估计误差）扰动的系统，
> 解法都是把输入映射到规范形，再对规范形做纯函数计算。
>
> **支柱二（最优性）：最优解本身消解启发式任意性。** 凡目标函数与约束
> 可写，凸性/KKT/BLUE 给出的闭式解即规范——「调参」被「解方程」取代。

【交叉审修正：原文七提案「全部同源于规范化原理」对 P4/P6 牵强——水位 θ
与闭式 `n_i` 是最优性结果（KKT/BLUE），被消解的是建模错误而非穿透到输出的
非规范输入。如实改为双支柱：**P1/P2/P3/P5/P7 归规范化（5 项），P4/P6 归
最优性（2 项）**。三问清单本身是好工具，保留。】

逐提案对照：

| 提案 | 支柱 | 规范形 / 最优解 | 被消解的扰动源 / 建模错误 |
|------|------|----------------|------------------------|
| P3 | 规范化 | 内容键排序后的图元表（`(code, 质心位型, 内容摘要)` 全序） | 资产加载序 / 三角化序 / 合并序 |

**框架的方法论价值**（可直接用于后续提案的自检）：给定一个新系统，问三个
问题——① 输出的规范形（或最优解）是什么？② 当前计算路径上有哪些非规范
输入能穿透到输出？③ 能否把规范形构造本身也做成纯函数（排序键、水位、
闭包哈希都是）？三个都答了，确定性就是定理而不是测试运气。这也解释了
为什么「规范化」总是以小杠杆（一次预排序、一个 tie-break、一次开方）
消解大风险（R6/R1/RQ-2）。

**框架自身被交叉审验证的实例**：本轮 B1/B2 两个 B 级问题的共同教训是
**规范形构造本身必须是纯函数**——问一遍三问清单的第③问（「这个键/常量/
排序的构造本身，是不是它声称规范的那个集合的纯函数？」）即可同时抓住
两题：B1 的阈值常量不是安全条件（i64 不溢出集合）的纯函数、B2 的
`(code, index)` 排序键不是图元多重集的纯函数（index 即加载序）。

**检索结论（任务 2 逐项）**：P1 考虑过 Arai/AAN 快速 DCT（每 1D 5 乘）——
因破坏表共享与证明简洁性而否决，记为未来性能项（见 P1 ⑧）；P4/P6/P7 的
更强替代即 ⑧ 节给出的依赖加权 / 约束闭式 / u8 整数设计（已并入）；P2、
P3、P5 经检索在本引擎约束（零依赖/确定性/表共享）下**无更优已知构造**
【交叉审降调：「全序 argmin 与 Morton 规范化是唯一自然构造」表述过强——
Hilbert 曲线是质心排序键的合法替代（局部性更优，否决理由成立但不支撑
「唯一」；全序 argmin 的「唯一」仅指「与 CPU 现行规则一致」这个工程约束。
缓存键的充分统计量表述仍是信息论下的最紧形式】。

## 1. P1 — JPEG 定点 IDCT（V1.5-A / P0-2 / ADR-19）

### ① 问题现状

- 编码器已是全整数：`crates/prism-mux/src/jpeg.rs:86` 的 `DCT_COS` 是标度
  2^14 的整数余弦表，`jpeg.rs:100` `fdct_8x8` 全程 i64 累加。
- 但**基线 JPEG 解码器尚不存在**（`prism-io/src/` 仅有 DNG 无损 JPEG 路径
  `raw_lossless_jpeg.rs`；基线解码是路线图 V1.5-P0-2 的绿地项），若新写
  解码器时沿用浮点，即重犯既有错误。
- **D-29 活违规**：`crates/prism-mux/src/video.rs:821` `idct_8x8` 用 f64
  浮点 IDCT；其余弦表 `video.rs:628-642` `cos_table()` 以
  `std::f64::consts::PI` + `f64::cos()` 懒初始化。`f64::cos` 是 libm 后向
  函数而非 IEEE-754 正确舍入——实测 64 个参数中 **10 个与正确舍入差 1–2
  ulp**（exp1-C）⇒ 现行 PRMV 解码路径跨平台非位精确。架构文档 ADR-19 对
  「浮点 IDCT 的 IEEE 逐位性」的担忧事实上不成立：IEEE-754 根本不管 `cos`。

### ② 数学结构

JPEG 基线的二维 DCT（T.81 A.3.3）：

```
f[x][y] = ¼·Σ_{u,v} c(u)c(v)·F[u][v]·K(u,x)·K(v,y),   K(a,b)=cos((2b+1)aπ/16)
```

**正交性**（离散余弦变换是正交变换）：

```
Σ_u c(u)²·K(u,x)·K(u,x') = 4·δ(x,x')
```

**折归一化**：把归一化因子 c(u)c(v) 折进系数权重。定义

```
W[u][v] = 2^16·c(u)c(v) ∈ {2^16, 46341, 32768}   （对应 c(u)c(v) = 1, 1/√2, ½）
C[a][b] = ⌊2^14·K(a,b)⌉ ∈ ℤ                     （编码器 DCT_COS 同表，可复用）
```

则精确 IDCT 可写为两阶段整数累加：

```
S1[u][y] = Σ_v D[u][v]·W[u][v]·C[v][y]
S2[y][x] = Σ_u S1[u][y]·C[u][x]
f[x][y]   = S2[y][x]·2^-46        （D = F·Q 为反量化系数）
```

标度核对：精确值 = ¼·2^-28·Σ c(u)c(v)·D·C·C = Σ D·C·C·W·(¼·2^-28·2^-16)
= Σ D·C·C·W·2^-46。✓

### ③ 算法设计

1. 反量化：`D[u][v] = F[u][v]·Q[u][v]`（i64；ZigZag 序直接乘，与
   `video.rs:804` 既有约定一致）。
2. 列阶段：`S1[u][y] = Σ_v D[u][v]·W[u][v]·C[v][y]`（8×8 双重循环，i64）。
3. 行阶段：`S2[y][x] = Σ_u S1[u][y]·C[u][x]`（i64）。
4. 末位统一标度：`s = (S2 + 2^45) >> 46`（round-half-up），clamp 到
   [0,255]（8-bit）或保持 i32（高位深路径）。
5. 全程无浮点、无超越函数、无 libm：D-29 从根上消除。

### ④ 数学证明

**证 1（正确性/无溢出）**【自审修正：原文「i64 余量 ≥ 256×」为伪定理界——
那是对真实块观测值的经验描述伪装成界；exp8 重算的最坏情况定理界如下】。
基线 JPEG 约束：|F[u][v]| ≤ 2047（DC）/1023（AC），8-bit 量化表 Q ≤ 255，

## 2. P2 — GPU↔CPU 遍历同构 + tie-break 修正 + 归约误差界（V2.0-G / D-3）

### ① 问题现状

### ② 数学结构

**全序 argmin 置换不变定理**：设 H 为有限命中记录集，≺ 为 H 上的严格
全序（此处 `(t, slot) ≺ (t', slot') ⟺ t<t' ∨ (t=t' ∧ slot<slot')`，
slot 为规范槽位——P3 规范化后的图元下标，U1；CPU 现行代码
`bvh.rs:466` 用的是 orig，修正后与 GPU 统一到 slot）。
则 `argmin_{≺}(H)` 与 H 的任何枚举序无关——遍历过程中的 running-min
每步比较在 ≺ 下精确，有限集在全序下的最小元唯一。**推论**：只要 CPU 与
GPU 使用**同一个**全序，图像就是遍历序的纯函数（parity 的结构基础）。

**树形归约前向误差界**：n 项 f32 求和，pairwise（树形）归约

```
|fl(S) − S| ≤ u·(⌈log₂ n⌉ + 1)·Σ|x_i|,    u = 2^-24
```

（每层一次舍入共 ⌈log₂n⌉ 层 + 最终一次）。对比顺序归约的
`(n−1)·u·Σ|x|`，树形在 n=1024 时紧 93×（实测）。

**剪枝安全性引理**【自审补充：原文只证了「命中集合内 argmin 与枚举序
无关」，漏了遍历本身会**剪枝**——被跳过的子树本可含更近命中，则
「同一全序」不足以保证 parity，还须剪枝不漏真实命中。交叉审 M1 修正：
原文「任何访问序下被剪的子树集合相同」是**假陈述**——剪枝判据依赖当前
最优值 `best_t`，而 `best_t` 的演化依赖**已访问集合**（CPU 深度优先
递归与 GPU wavefront 队列序访问同一节点时 best_t 可以不同）⇒ 被剪集合
确实随访问序不同。正确论证是**安全性 + argmin 不变性的合取**】。
设遍历按 AABB 的入射区间 `[t_lo, t_hi]` 剪枝
（`prism-geometry/src/bvh.rs:452-456`：`t_lo > best_t` 才跳过）。
f32 slab 测试的区间有舍入误差 `|δ| ≤ 3u·|t|`（证 2）。取统一松弛
`ε = 6u·t_max`（见下）后：

```
剪枝判据改为 t_lo > best_t + ε：
①（不漏）设子树内有一真实命中参数 t。若该子树被剪
   （t_lo 计算值 > best_t + ε），则 t_lo 精确值 >
   best_t + ε − 3u·t_lo ≥ best_t + 3u·t_max > best_t
   （ε = 6u·t_max 覆盖 enter 侧保守舍入 3u，另 3u 覆盖 exit 侧）；
   而真实命中须 t ≥ t_lo 精确值 > best_t ⇒ 被剪子树内不存在
   「更近但被剪」的命中（漏命中的安全性）；
②（argmin 不变）在**已访问集合**上，≺ 下的 argmin 与访问序无关（证 1）；
③ 合取：不漏 + 已访问集 argmin 不变 ⇒ 最终命中与访问序无关。
```

即：**同一个 ε 同时干两件事**——「不漏真实命中」（安全性）与「给 argmin
不变性提供不漏的前提」（parity 结构）。这是 tie-break 修正能推广到 GPU
的载重部件：GPU 每线程独立维护 best_t 与剪枝，只要不漏，两端的「先剪谁
后剪谁」差异就不穿透到最终命中。

**ε 的基准（每射线上界）**【交叉审 M2：原文 `ε = 6u·|t|` 的 `|t|` 未
定义——射线参数在遍历中变化（是 best_t？当前 AABB 的 t_hi？命中点？
不指定则「1e-7 仅在 |t| ≤ 0.28 时充分」的换算缺锚点）】。改为每射线
一次计算的尺度上界：

```
ε = 6u·t_max,   t_max = 根 AABB 对射线的出射参数（或场景远平面距离）
一次算出、全遍历复用（近命中处略保守，只损性能不漏命中）
```

exp14-T1 实测：79 条随机射线，`6u·|t|/(6u·t_max) ≤ 0.996`——逐点取
`|t|` 至多比统一 `t_max` 紧 0.4%，保守代价可忽略；而锚点唯一、可证。

**MT 后向误差界（并列判定的误差源）**【交叉审 M2：三角形侧 Möller–
Trumbore 交点 `t` 的舍入误差从未界定，而 tie-break 的 `ht == best_t`
恰是两个 MT-`t` 的比较——slab 的 3u 界管不到它；两个误差源须分开
表述】。MT 是低深度有理式（少量乘加 + 一次除法），标准后向误差分析给

```
|δt| ≤ c·u·|t|,    c = 79（exp14-T3 标定，与 slab 的 3u 相互独立）
```

含义：`ht == best_t` 的并列判定在两端各带 ≤79u·|t| 的数值不确定度——
这正是「数值级 bit-exact 不可能」（诚实声明）的定量来源；而语义级
parity 不受影响（同一图元胜出由全序 argmin 结构保证，fma 造成的
t 微扰只会让并列在两端**有时**判平、有时判不平，不改变「更近者胜」
的方向性）。

### ③ 算法设计

1. **WGSL/CPU tie-break 对齐（全序 = `(t, 规范槽位)`）**【交叉审 U1
   采纳 + M4 修正】：叶更新改为 `ht >= 0.0 && (ht < best_t ||
   (ht == best_t && slot < best_slot))`，其中 tie-break 键是图元在
   **P3 规范化后数组中的下标（规范槽位）**，不是加载序 orig——规范槽位
   是图元多重集的纯函数（P3 内容键排序结果唯一），CPU/GPU 两端一致、
   跨加载序不变（「同资产多重集 ⇒ 同 MD5」闭合成单一机制）。**GPU 实现
   是寄存器级两级比较，不用任何原子**：`rt_bvh.wgsl:89-92` 现行即每线程
   私有 best_t/best_tri 的寄存器比较（hit 记录线程私有，归约发生在颜色
   值上而非 hit 记录上，不存在跨线程归约 hit 的场景）。【M4：自审轮
   推荐的 packed-u64 atomicMin 在 WGSL **不可行**——WGSL/WebGPU 原子
   操作只有 32 位（`atomicMin` 仅 `atomic<u32>/<i32>`），按原文实现
   无法编译；且如上无必要。若未来真出现共享 hit 槽，32 位原子也无法
   表达 64 位键的字典序，届时再议。】
2. **slab padding 相对化**：`ε = 6u·t_max`（t_max = 根 AABB 出射参数，
   每射线一次；覆盖 enter/exit 两侧各 3u），替代绝对 1e-7；剪枝判据
   同步改为 `t_lo > best_t + ε`（安全性引理见 ②）。
3. **归约误差预算写进门禁**：D-3 门禁①的「均值/方差有界」从经验阈值
   升级为定理预算：两归约序差的均值 ≈ 0、方差 ≤
   `2·u²·(log₂n+1)²·(Σ|x|)²/n²`（可解析给出，不靠试）。
4. 遍历结构同构：桶数、切分规则、叶容量与 CPU 逐项相同（切分确定性
   由 P3 保证），使 GPU/CPU 遍历同一棵树。

### ④ 数学证明

**证 1（parity 结构）**。CPU/GPU 采用同一全序 ≺（此处
`(t, slot) ≺ (t', slot') ⟺ t<t' ∨ (t=t' ∧ slot<slot')`，slot 为规范
槽位——U1）后，由 argmin 置换不变定理，最终命中与遍历序、与线程调度、
与 workgroup 大小均无关；剩余差异仅来自归约舍入（证 3）——这正是 D-3
「kernel 语义级 parity + 浮点末位统计判定」想要拆开的两层，现在有了
精确分界。【交叉审 U1 加强】规范槽位是图元多重集的纯函数（P3 内容键
排序结果唯一）⇒ 键 `(t, slot)` 同时是**加载序与遍历序**双重的纯函数
⇒ argmin 不变性从「遍历序无关」加强为「**加载序 + 遍历序双重无关**」——
「同资产多重集 ⇒ 同 MD5」由此闭合成单一机制（若仍按 orig tie-break，
加载序会从 tie-break 漏回输出，P3 白做）。

**证 1b（剪枝安全性，自审补充 + 交叉审 M1 修正）**。剪枝判据
`t_lo > best_t + ε`：① 被剪子树内不存在「更近但被剪」的命中（不漏——
推导见 ② 引理的 ①）；② 已访问集合上的 argmin 在 ≺ 下与访问序无关
（证 1）。合取两者 ⇒ 最终命中与访问序无关。【M1：自审轮原文写的是
「任何访问序下被剪的子树集合相同 ⇒ 遍历覆盖的命中集合相同」——第一环
为假（best_t 依赖已访问集合，CPU 递归序与 GPU 波前序访问同一节点时
best_t 可不同，被剪集合确实不同）。现删除该陈述，代之以「不漏 +
argmin 不变」的合取——结论（parity 结构）完全幸存，论证不再依赖假
前提。】

**诚实声明（自审新增，重要）**：tie-break 对齐**不能**推出 CPU/GPU
bit-exact。WGSL 不排除 fma 收缩：同一公式 `a·b+c` 在 GPU 可能编译为
fma（单次舍入）、在 CPU 为两条指令（两次舍入）⇒ slab 测试的 t 与
MT 交点的 t 两端可差 ≤1 ulp / ≤79u·|t|（证 2/② MT 界）⇒
`ht == best_t` 的并列判定本身可在两端给出不同真值。因此：
① 语义级 parity（同一图元胜出）由证 1/1b 保证，是结构性的；② 数值级
bit-exact **不可能**由任何 tie-break 规则保证，D-3 的统计门禁（证 3 的
解析预算）是**必需仪器**而非可选装饰。文档此前「消除 parity 分歧」的
表述应理解为「消除 tie-break **规则**分歧这一类」，不是「消除全部
字节差异」。

**证 2（padding 充分性 + MT 界）**【交叉审 M2 重写：原文 `ε = 6u·|t|`
的 |t| 未定义；且 slab 界与 MT 界两个误差源被混作一处】。分两个独立
误差源表述：
```
源一（slab，管剪枝安全）：f32 slab 测试中 inv_d 与乘积各有一次舍入，
  Δenter、Δexit 各 ≤ 3u·|t|（实测 1.7u，界 3u）。取 ε = 6u·t_max
  （t_max = 根 AABB 出射参数，每射线一次）时：舍入不可能把真实命中
  推出 AABB（保守侧）也不可能把真实未命中拉入（激进侧误差同界覆盖）。
  1e-7 仅在 |t| ≤ 1e-7/(6u) ≈ 0.28 时满足该条件——绝对 padding 在
  大场景下不充分的定量刻度。
源二（MT，管并列判定）：Möller–Trumbore 交点 t 的后向误差
  |δt| ≤ c·u·|t|，c = 79（exp14-T3 标定，低深度有理式的标准后向
  分析）——tie-break 的 ht == best_t 两端各带此不确定度。
```
两源互不相干：slab 界保证不漏（安全性），MT 界量化并列判定的数值
不确定度（诚实声明的定量来源）；语义级 parity 两者都不破坏
（更近者胜的方向性由全序结构保证）。

**证 3（归约界与门禁余量）**。由树形归约界（②），两归约序之差
|Δ| ≤ 2u(log₂n+1)Σ|x|/n。实测（exp3，n=512/像素，2000 像素）：
两序输出 MSE = 3.03e-14 ⇒ PSNR = 135.2 dB；D-3 门禁②要求 ≥ 40 dB
（MSE ≤ 1e-4），余量 95 dB。差的均值 −6.5e-9（≈0）、方差 3.0e-14，
低于信号方差 1.1e-5 约 8.6 个量级 ⇒ 门禁①统计判定有巨大安全余量。
【交叉审 n5：原文「10 个量级」算错——`1.1e-5/3.0e-14 = 3.7e8 ≈ 10^8.6`，
改数不影响结论。】树形归约界本身 400 组（含降序同号最坏形）全部满足，
界利用率 max 0.419。

### ⑤ 工作量杠杆

V2.0-G 是路线图最大单项，R1（GPU 管线工作量黑洞）是最高风险。parity
失败的代价在于「GPU 已经能跑之后才发现的深层分歧」——本提案把其中
一整类（tie-break 规则分歧，无条件可达率 ≈12%、并列事件内 40.6% 逐位
同 t）在 3 行 WGSL + 1 个常量内前置消解，
并把 D-3 门禁的两条统计判据变成有解析预算的验收公式。parity 测试网
已存在（`integrator.rs:22-26`、`wavefront.rs:825-943`），无需新建。

### ⑥ 效果提升

- 消除一类可达的 tie-break 规则分歧：并列事件中 40.64%（480/1181）为
  逐位同 t，无条件率 ≈12%（480/4000）——端到端阳性实例（共享边 +
  逐位同 t + 两端选不同图元，修正前 diff=255 LSB、规范槽位后 diff=0）
  见 ⑨-3 / exp14-T4。
- slab 修正使大尺度场景（|t| > 0.28）不漏真实命中——这是画质正确性，
  不是精度微调。
- 归约误差预算化：引擎 CPU 路径本就用固定形状树归约
  （`accum.rs` → prism-core reduce），本提案给这条既有路径与任何
  GPU 树形归约一个统一的解析预算（`u·(log₂n+1)·Σ|x|`），替掉 D-3
  门禁里的经验阈值；顺带确认 GPU 若退化为顺序归约（n=1024）界松
  93×、余量（95 dB）仍够——不构成阻塞。

### ⑧ 自审结论

**自审发现**：

1. **【修正过度声称】原文「消除 40.6% 可达的 parity 分歧」被理解为
   bit-exact 保证——不成立**。WGSL fma 收缩使两端 t 可差 ≤1 ulp，
   `ht == best_t` 的并列真值本身可不同 ⇒ 数值级 bit-exact 不可能。
   本提案保证的是**语义级 parity**（同一图元在全序下胜出，与遍历序
   无关），D-3 统计门禁是必需仪器。已在 ④ 补「诚实声明」。
2. **【补充缺失引理】原文只证 argmin 不变性，漏了剪枝决策的序无关性**——
   被跳过的子树本可含更近命中，则「同一全序」不足。已补证 1b 与 ② 的
   剪枝安全性引理：统一松弛 `ε = 6u·t_max`（交叉审 M2：原文
   `ε = 6u·|t|` 的 |t| 未定义，改为每射线上界）保证「不漏真实命中」，
   与 argmin 不变性合构成 parity 的载重部件。【交叉审 M1：原文的中间
   陈述「被剪子树集合相同」为假（best_t 依赖已访问集合），已改为
   「不漏 + argmin 不变」合取。】
3. **【实现修正】GPU 全序 argmin 用寄存器级两级比较**
   `(ht < best_t) || (ht == best_t && slot < best_slot)`，不用原子。
   【交叉审 M4：自审轮推荐的 packed-u64 atomicMin 在 WGSL **不可行**——
   原子只有 32 位，按原文实现无法编译；且 hit 记录线程私有
   （`rt_bvh.wgsl:89-92` 现行即寄存器比较），不存在跨线程归约 hit
   的场景，无必要。tie-break 键同时改用规范槽位（U1）。】
4. 未发现问题：归约误差界（400 组全满足、利用率 max 0.419）、slab
   3u 界（实测 1.7u）、并列触发率（1181/4000、480/1181）均通过重核。

**更优算法检索**：**已检索，在本引擎约束下无更优已知构造**。
① 全序 `(t, 规范槽位)` 是 tie-break 不变性的自然构造（任何 tie-break
都是全序的选取，问题只在与 CPU 一致；「唯一」仅指与 CPU 现行规则
一致这个工程约束——交叉审 m2 降调）；② GPU 端该全序的最优实现是
**寄存器级两级比较**（单线程私有状态，无原子可用也无原子必要——
WGSL 仅 32 位原子；交叉审 M4）；③ 剪枝松弛除 ε-slack 外，「保守
AABB 扩张」方案等价但费一次盒变换，无增益。替代方案「GPU 侧禁止
fma」不可行（编译器自由），「双跑取交」费一倍算力且仍不
bit-exact——均否决。

**测试方案**：

- **A1 大规模 parity**：100k+ 射线打共享边构型族（exp2b 构造：两三角
  共享边、微角度错开），CPU/GPU 双跑；tie-break 修正后分歧数断言 = 0
  （修正前 480/1181 = 40.64% 作阳性对照保留）。**A1-E 端到端阳性实例**
  【交叉审 M3 补】：确定性构造「共享边 + 逐位同 t」——两三角形共享边、
  微角度错开、无第三遮挡，射线命中使两端 f32 计算给逐位相同的 t：
  CPU（tie-break 规则）选 TA、GPU（slot 序）选 TB ⇒ 端到端输出
  diff > 0（exp14-T4 实测 diff = 255 LSB）；改用规范槽位 tie-break 后
  diff = 0。该实例钉死「规则分歧可穿透到输出」，不是概率论证。
- **A2 极端参数**：远距射线 |t| ∈ [1e3, 1e7]（相对 padding 验证）——
  构造远平面场景断言命中不遗漏（绝对 1e-7 padding 下漏）；t=0 起点
  射线（除零防御：inv_d = inf 的 slab 行为须两端一致）。
- **A3 边界**：擦边命中（enter−exit < 6u·t_max）⇒ 断言保守侧不漏
  （漏真实命中是安全性违例，多算一次是性能问题）。
- **A4 归约压力**：n=1024 顺序 vs 树形 10^6 像素对拍，MSE ≤ 解析预算
  `2u²(log₂n+1)²(Σ|x|)²/n²`；D-3 门禁② PSNR ≥40 dB 余量报告。
- **B 变异体**：

## 3. P3 — BVH 确定性结构定理 + Morton 规范化（V2.0-H / R6）

### ① 问题现状

  SAH-BVH（`bvh.rs:618` `best_sah_split`），但**输入图元序未规范化**。
  【交叉审 M5：原文档路径 `prism-rt/src/bvh.rs` 错——BVH 实际在

- 风险登记册 R6：「BVH 构建非确定（切分规则/排序未钉死）击穿确定性
  铁律」——USD mesh 加载序、图元合并序都可能变化，同场景两跑 MD5
  可能不同。
- 无现有反证表明已确定：**winding 聚合与叶内排列依赖输入序**
  【交叉审 m7：原文「切分选择依赖 f32 累加序（桶质心/边界在输入序上
  累加）」瞄准偏移——源码核验：`Aabb::grow/grow_point` 是 min/max
  （精确、序无关），桶**边界**本就序无关，桶直方图与切分选择在实测中
  置换不变（exp2-D2 的 10/10 是必然不是运气）。真正的序敏感在
  `bvh.rs:313-324` 的 winding 聚合（`area_sum/n_sum/ac_sum` 按输入
  下标序累加）与叶内排列】。

### ② 数学结构

**集合函数定理**：12 桶 SAH 切分的代价是桶直方图（每桶质心、边界、
计数）的函数，而直方图是图元**集合**的求和——与枚举序无关（至多
f32 累加舍入噪声）。故切分**选择**是集合的函数；差别仅在**叶内排列**
与 **winding 聚合**（① 的 m7 修正）。

**Morton 规范化**：图元质心 (x,y,z) → **21-bit/轴** Morton code
（整数交错，3 轴共 63 bit 适配 u64 键）。【交叉审 m1：原文「30-bit
每轴」在 u64 下不可能（3×30 = 90 bit > 64），且与 exp2 脚本实际
实现的 21-bit/轴脱节；f32 尾数 24 bit 也意味着 >21-bit/轴的码宽需
双字键。共码阈值随之重述：场景 extent > **2^21** 单位时远距图元共码
（比 2^30 早 9 个量级到来，对大场景是更紧的约束）——这个问题真实
存在，须测试覆盖（⑧-A2）。】归一化 `(c−min)/(max−min)` 用 f32 基本
运算（IEEE-754 对加减乘除、min/max、比较全部逐位规定 ⇒ 跨平台确定；
见 ⑦），码计算本身是纯整数【n1：② 原「prism-core 无浮点即可算」
与 ⑦ 的修正自相矛盾，现统一为「归一化可用 f32 基本运算、码计算纯
整数」】。

**内容键（tie-break 键）**【交叉审 B2 必修：原文 `(morton_code,
orig_index)` 中的 `orig_index` 是图元在**输入数组**中的位置——它
**就是加载序本身**。同码族（质心精确重合/共码）内按 index 排序 ≡
稳定排序 ≡ 保留加载序 ⇒ 排序后数组**不是**图元多重集的规范函数
（反例见 ⑨-1）。tie-break 键改为**内容键**】：

```
排序键 = (morton_code, 质心精确位型, 图元内容摘要)
  质心位型：质心 f32 的 IEEE-754 位型（f32::to_bits，跨加载序不变）
  内容摘要：图元自身数据的确定性整数 hash（prism-noise 既有件，
            兜底「位型也相同」的真重复——位相同的图元可互换，
            换序不改变任何下游值）
```

按内容键预排序后，构建输入成为图元**多重集**的规范函数（归纳法
证明见证 3）：Morton 码与质心位型是图元自身数据的纯函数，内容摘要
兜底真重复 ⇒ 排序结果唯一。于是整棵 BVH（结构 + 叶内序 + winding
聚合）是多重集的纯函数。

### ③ 算法设计

1. `Bvh::build` 入口：按内容键 `(morton, 质心位型, 内容摘要)`
   预排序（前两项整数比较、第三项 hash 比较，无 FP 语义依赖）。
   【B2：原 `(morton, index)` 的 index 即加载序，同码族下排序结果
   随加载序漂移——见 ⑨-1 反例。】
2. 结构签名测试：随机置换输入 10 次，断言结构签名（节点数/叶位/
   切分面序列 + **winding 字段**的哈希）恒等。【m7：原签名未覆盖
   solid_*/winding 字段，而 winding 恰是序敏感输出之一——补上后
   签名与「序敏感点清单」对齐。】
3. 切分 tie-break：桶代价并列时取**桶索引最小**（固定规则，与输入序
   无关；桶直方图本身已序无关）。
4. 保留 SAH 不变：只改输入序，不改切分目标函数。

### ④ 数学证明

**证 1（纯函数性）**。构建无 RNG、无时钟、无指针身份依赖 ⇒ 同输入
两遍逐位同树（exp2-D1 实测两遍字节相同）。

**证 2（切分序无关）**【自审加强：原文是概率性论证（「代价差 > 噪声底
时 argmin 不变」），只在输入未规范化时可用；规范化后应给无条件版本】。
桶直方图 H = Σ_{p∈S} h(p) 是集合求和；SAH 代价 C(H) 是 H 的代数式。
**关键观察**：`prism-geometry/src/bvh.rs:313-324` 的桶累加
（`area_sum += a`、`n_sum`、`ac_sum`）与稳定划分都是按**图元在数组中
的下标序**依次累加——规范化后数组序是多重集的规范代表（内容键排序
结果唯一，证 3）⇒ 每个 FP 累加的执行序列逐位置相同 ⇒ f32 加法是
IEEE 规定逐位确定的 ⇒ 所有累加结果**逐位相同**（不是「至多噪声」）。
于是 SAH 代价、argmin 切分选择、winding 聚合、叶内排列全部逐位复现。
**不需要**「切分间隙 > 噪声底」这类条件——概率性论证是未规范化时代
的遗产，规范化后切分选择是无条件确定的。
实测（exp2-D2）10/10 置换下节点结构一致（作为回归证据保留）。

**证 3（完全置换不变 + 内容键归纳法证明）**【交叉审 B2 必修重写：
原文「Morton 规范化后输入序列 = sort(多重集)，是规范代表 ⇒ 输出字节
相同」在同码族下不成立——`(code, index)` 排序键的 index 是加载序，
同码族内按 index 排 ≡ 稳定排序 ≡ 保留加载序 ⇒ 排序结果随加载序
变化（反例见 ⑨-1），原文是一句未证命题。内容键下重证如下】。

**归纳法证明**：设同一多重集 M 的两个输入序 π₁、π₂ 经内容键排序
得到数组 A₁、A₂（各含 M 的全部图元）。设 B = build（纯函数：无
RNG、无时钟、无指针身份依赖——证 1）。对首个分歧位 i 归纳：

```
① A₁[0..i−1] = A₂[0..i−1]（归纳假设：前缀已逐位相同）
② 在首位 i 上，A₁[i] 与 A₂[i] 的 full key 必相等——否则键的全序
   已确定先后，两者到 i 为止都取了可比较的最小剩余元，矛盾
③ key 相等 ⇒ morton 码等 + 质心位型等 + 内容摘要等 ⇒（摘要抗碰撞）
   两位是位相同的图元
④ 构建全过程是数组值的确定函数（每个 FP 运算按固定下标序执行）
   ⇒ 交换 A₁ 中两位不改变任何中间量与输出
⑤ 归纳：A₁、A₂ 诱导完全相同的构建 ⇒ B(A₁) = B(A₂) 逐字节相同 ∎
```

【实测（exp13-T1）】旧键 `(code, index)`：10 个同码族置换 → **10 个
不同结构签名**（缺陷复现）；新键 `(code, 位型, 摘要)`：同 10 个置换
→ **1 个签名**（修复确认）。

【自审加强（保留）】上述逐位相同论证同时给出比「输出字节相同」更强
的结论：**构建内所有 FP 运算的结果逐位相同**——包括那些不进入最终
结构签名的中间量。这把「10 个置换 → 1 签名」的实证从抽样证据升级
为结构必然。【B2 修正后的限定】该结论的前提是「输入数组是多重集的
规范代表」——内容键排序结果唯一（归纳法）使之成立；原文的前提
（`(code, index)` 规范）在同码族下为假，是 B2 的核心。

**证 4（代价无损）**。SAH 只依赖集合 ⇒ 预排序不改变任何候选切分的
代价。实测（exp2-D4）汤场景/聚类场景 SAH 总代价比 = 1.0000。
内容键的额外成本：每图元一次小记录哈希，构建期 O(n)，相对 SAH
建树可忽略（exp13-T6）。

### ⑤ 工作量杠杆

R6 是已登记风险，标准对策是「稳定排序+固定切分规则+专门测试」——本
提案把它压缩成：一次整数预排序 + 一个结构签名测试。不需要新建基础
设施（SAH、叶构建、遍历都已实装）。

### ⑥ 效果提升

- 资产管线顺序变化（USD 加载序、mesh 合并序、并行三角化输出序）
  不再影响渲染 MD5——确定性铁律从「同二进制同输入」加强到「同资产
  多重集」。
- 结构签名测试成为 V2.0-H 的验收件，parity 对拍（V2.0-G）也因此获得
  稳定基准（P2 的 tie-break 用规范槽位 = 本规范化后的数组下标，

### ⑦ 风险反证

- **Morton 精度上限**【自审修正：原文担心「FP 归一化会引入平台差异」
  并给出过度保守的对策——该担心过强，精确结论如下】：
  **21-bit 每轴**（m1）⇒ 场景 extent > 2^21 单位时远距图元共码
  （**这个问题真实存在**，且比 2^30 早 9 个量级到来——对大场景是
  更紧的约束，须测试覆盖）；但归一化的平台性问题**不存在**：场景
  AABB 的 min/max 是精确比较（IEEE min/max 无舍入、序无关），归一化
  `(c−min)/(max−min)` 只含 f32 减/除——IEEE-754 对加减乘除与
  min/max/比较全部规定逐位确定，跨平台一致（这与 exp2b 实测 slab
  相对误差 1.7u 在各次重跑中稳定复现是同一现象）。真正的分歧源
  只有两个：libm 超越函数（D-29 已禁）与 fma 收缩（WGSL/LLVM
  自由）——Morton 构造不碰这两类 ⇒ **f32 基本运算做 Morton 构造是
  跨平台安全的，不必须退化为纯整数**。设计纪律（保留）：Morton
  计算禁用超越函数与近似除法；共码平局由**内容键**（质心位型 +
  内容摘要）打破 ⇒ 内容键全序的规范性只依赖 code 的**确定性**（上述）
  与内容键的**纯函数性**（证 3 归纳法），不依赖 code 的区分度。
  extent 超限时的退化行为（远距图元共码 → 质心位型/摘要序）须写入
  测试（见 ⑧-A2）。
- 预排序增加 O(n log n) 整数比较，相对 SAH 建树的 O(n log n) FP
  运算可忽略；实测无代价劣化（证 4）。

### ⑧ 自审结论

**自审发现**：

1. **【加强】证 2 的概率性论证（「切分间隙 > 噪声底时不变」）在规范化
   后应升级为无条件定理**：规范化使输入数组序成为规范代表，桶累加/
   稳定划分的全部 FP 运算按固定下标序执行，而 f32 加减是 IEEE 逐位
   确定的 ⇒ 所有中间量与最终结构**逐位相同**（非「至多噪声」）。原
   概率版是未规范化时代的遗产，保留为回归证据（10/10 置换）。
   【交叉审注意：该加强的成立以「输入数组是规范代表」为前提——内容键
   排序（证 3 归纳法）使之成立；原 `(code, index)` 键在同码族下
   不成立（B2）。】
2. **【修正】⑦ 对「FP 归一化引入平台差异」的担心过强**：IEEE-754 对
   f32 加减乘除、min/max、比较全部逐位规定；分歧源只有 libm 超越
   函数与 fma 收缩，Morton 构造不碰。故归一化算 Morton 码是跨平台
   安全的，不必须纯整数化——但纪律保留（禁超越函数/近似除法），
   extent > 2^21 的共码退化是真实限制，须测试覆盖。【交叉审 m1：
   共码阈值按 21-bit/轴重述（原 2^30 与 30-bit 表述一并退役）。】
3. 未发现问题：SAH 代价无损（1.0000）、两遍同树、结构签名测试的
   充分性均通过重核。【交叉审 m7：签名须补 winding 字段哈希——
   原签名（节点数/叶位/切分面）未覆盖序敏感的 winding 聚合，已补。】

**更优算法检索**：**已检索，在本引擎约束（零依赖/确定性/表共享）
下无更优已知构造**。【交叉审 m2 降调：原文「唯一自然构造」过强——
① Morton 码是「质心 → 整数排序键」的标准构造，Hilbert 曲线是合法
替代（局部性更优），否决理由（21-bit 下增益不确定/计算更贵/递归
定义多实现分歧面）成立但不支撑「唯一」；② 内容键字典序是全序
规范形的自然构造（code 定序、位型与摘要破平局，三者都是纯函数）；
③ 「先按 index 排序再构建」（最朴素的规范化）同样确定——但丢弃
空间局部性，SAH 代价劣化；Morton 是「确定性」与「SAH 代价无损」
同时成立的已知最廉价构造（exp2-D4 1.0000）。④ 并行化构建（TBVH
等）在确定性铁律下须以确定性划分规则实现，属实现细节非算法替代。】

**测试方案**：

- **A1 大规模置换不变**：100k+ 图元（含 10% 重合质心同码族），
  随机置换 10 次，结构签名（节点数 + 叶位序列 + 切分面序列 +
  **winding 字段**的哈希）恒等；SAH 总代价比 ≤ 1.0000·(1+1e-6)。
  【B2 修正后本测试才可运行：原 `(code, index)` 键在同码族下签名
  随加载序漂移（⑨-1 反例），内容键下 10 置换 → 1 签名（exp13-T1
  实测）。】
- **A2 极端参数**：全图元同点（Morton 全同码 ⇒ 纯内容键平局）；

## 4. P4 — 率控 water-filling + B 帧闭式权重（V1.5-E）

### ① 问题现状

- `crates/prism-mux/src/video.rs:37`：`VideoConfig.quality` 单一质量
  参数；`video.rs:98` I 帧 JPEG 直接用 `config.quality`；
  `video.rs:108` 残差质量 = `quality−17` clamp [50,80]——**启发式**，
  无率畸最优性，对 GOP 内帧复杂度差异盲目。
- V1.5-E 明确要求「档位率控/B 帧」，当前无数学框架支撑调参。

### ② 数学结构

**率畸模型（高率近似）**：帧 i 在速率 R_i 下的畸变

```
D_i(R_i) = θ_i·2^(−2R_i),    θ_i = 帧复杂度（预测残差能量）
D''(R) = 4(ln2)²·θ·2^(−2R) > 0  ⇒ RD 曲线严格凸
```

**Lagrangian 松弛**：`min ΣD_i s.t. ΣR_i = B, R_i ≥ 0`。凸性 ⇒ KKT
充分。一阶条件 `−2ln2·θ_i·2^(−2R_i) + λ = 0` 给出：

**reverse water-filling 解**：`R_i = max(0, ½·log₂(θ_i/θ))`，θ 为水位
（对偶变量），由 `ΣR_i = B` 定（单调，二分可解）。

**文献锚点（可行性外部验证最强的提案）**【交叉审补充】：reverse
water-filling + 复杂度加权就是 **x264 两趟 ABR 的核心分配器**——水填充
进码控是 2005 年以来的工业实践（Lurker/x264 mbtree 一脉），x264 mbtree
沿运动轨迹传播复杂度正对应本提案的依赖加权 d_i。同族算法在每天数十亿
帧的规模上运行 ⇒ 本提案的算法族有最强的外部可行性验证（其余六提案
无此量级的外部背书）。

**等畸变证书**：所有活跃帧（R_i > 0）满足 `θ_i·2^(−2R_i) = λ/2ln2 =
常数` ⇒ **最优解处各活跃帧畸变全相等**。这是可在 CI 中断言的强证书。

**B 帧闭式权重**：GOP 中 B 帧复杂度 θ_B < θ_P ⇒

```
R_B − R_P = ½·log₂(θ_B/θ_P)     （P/B 均活跃时精确成立）
```

θ_B = θ_P/4（层级 B 帧典型增益）⇒ R_B = R_P − 1 bit/符号。

**依赖加权（误差传播修正）**【自审新增，exp10-T2】：上述模型把各帧
独立，忽略 P 链误差传播——被后续帧参考的帧，其编码畸变会进入后续帧
的预测基准。一阶近似下，端到端输出畸变为

```
J(R) = Σ_i d_i · θ_i · 2^(−2R_i),    d_i = 后续以 i 为参考的帧数 + 1
```

即 GOP=12（I+11P 链）时 d = [12,11,…,1]。加权只是换了一组 θ
（`θ_i ← θ_i·d_i`），**算法、KKT 结构、等畸变证书全部不变**（证书对
加权稳健，exp10-T3：活跃帧加权畸变 max/min = 1.000000）。加权后
water-filling 自动把比特压向 I/P 链前端——与 H.264/HEVC 码控「I/P 帧
QP 差」的工业实践定性一致。**诚实的口径声明**：这不是「免费加强」
——加权 WF 是 J 的 KKT 最优解（端到端口径严格优于未加权，改善中位
17.4%），但在帧独立目标 J₀ = Σθ_i2^(−2R_i) 下恒劣于未加权 WF
（畸变中位 +21.7%，折算到对等速率 baseline 的降幅为 61.1% vs 68.9%，
让出 ~8 个百分点）。是**口径换修**：关心端到端输出质量 ⇒ 加权；
只盯逐帧独立畸变之和 ⇒ 不加权。真实视频编码关心端到端，故推荐加权。
且 d_i 线性加权是一阶近似（运动补偿会部分抵消/放大传播误差），属
模型内结论。

### ③ 算法设计

1. GOP 头（I 帧）用固定较高质量（场景锚点，模型外特判）。
2. 每帧复杂度 θ_i：两遍编码时取头遍实测（rate, distortion）拟合
   `θ_i = D·2^(2R)`；一遍编码时用前一 GOP 同位置帧的先验 + 有界漂移。
3. 水位 θ 二分（≤ 200 步双精度足够），闭式分配 R_i。
   **det_log2 是前置基础设施**【交叉审 M6 必修：原文「纯 FP 无 libm」
   是**假陈述**——二分水位每步要求值 `ΣR_i(θ)`，而
   `R_i = ½·log₂(θ_i/θ)`，**绕不开 log2**；std 的 `f64::log2` 是 libm
   后向函数（与 P1 已实测的 `cos` 同罪：跨平台非位精确），按文档字面
   实现即违 D-29 与确定性铁律。且这不是可选优化：对 `L = log₂θ` 二分
   仍需 log、对共同畸变 δ 二分也需 log——绕不开，只能建。
   **部分申诉 + 修正形态**：架构师「引擎无 log2 基础设施、须自建」
   的核验不实——`prism-math/src/det_pow.rs:24` **已有
   `pub fn det_log2(x: f64)`**（IEEE 精确指数提取 + 尾数 atanh 级数，
   纯 ±×÷、无 libm、自带 <1e-10 测试与 bitwise 确定性测试，与本件
   det_ln/det_exp/det_pow 同纪律）。架构师核验的
   `prism-geometry/src/det_math.rs` 那 5 个 f32 件确实无 log——但
   **prism-mux 不依赖 prism-math**（其 Cargo.toml 仅 prism-io/
   prism-audio）⇒ 正确形态不是「自建 40 行」而是「**接线既有件**」：
   prism-mux 的 Cargo.toml 加一行 prism-math 依赖 + 调用方改用
   det_log2（f64 口径）+ 水位层容差验证。`log₂θ_i` 每帧预算一次
   减半调用量。】实测（exp15）：python 逐 op 复刻 det_log2 vs libm
   ≤ 2.4e-11；对 P4 水位（θ 跨 6 个数量级）的水位差 3.7e-14、
   |ΣR−B| 1.1e-13——相对 A1 的 1e-9 容差有 2^11 余量。
4. R_i → 量化档：查该帧 RD **下凸包**上的最近档（凸性保证内点被支配，
   只需 hull 上的点；搜索空间从 O(阶梯²) 降到 O(hull)）。
5. 编码后断言等畸变证书（活跃帧 D_i 相对偏差 < 容差）——不满足即
   说明 θ 估计失真，回退到凸包贪心并记录诊断。

### ④ 数学证明

**证 1（凸性/KKT 充分）**。D''(R) > 0（②）⇒ 目标严格凸、约束线性
⇒ KKT 点为全局最优；R_i ≥ 0 的活跃集由水位 θ 自动确定。

**证 2（最优性数值对照）**。θ = [1.0, 0.5, 0.3, 0.2, 0.1]、预算 6.0：
water-filling 解 ΣD = 0.296430 vs 20 万次单纯形随机搜索最优 0.296713
（WF 不劣于搜索，比 0.9990）。

**证 3（等畸变证书）**。上例 WF 解的各帧畸变 = [0.0593]×5，
max/min = 1.000000——活跃帧畸变严格相等，与 KKT 一阶条件一致。

**证 4（B 帧闭式）**。GOP = I+2P+9B，ρ = θ_B/θ_P ∈ {1, ½, ¼, ⅛}：
数值 WF 的 R_B 与闭式 `R_P + ½log₂ρ` 差 ≤ 1.1e-16（f64 累加噪声）。

**证 5（收益）**【自审修正：原「63.0–73.6%（3 次试验）」是点估计，
统计证据不足；exp10-T1 以 200 试验重测】。12 帧 GOP（首帧场景切换
尖峰 θ≈8–16，其余对数正态 σ=0.4）：等速率分配 vs WF，等总比特下
总畸变降幅 **中位 68.9%，IQR [63.8%, 74.4%]，min 53.8%，max 81.4%**
（200 试验，GOP=12，预算 12 bit/符号）。收益依赖 GOP 内复杂度离散度
（I 帧尖峰倍率 + P 帧对数正态 σ）——尖峰弱、P 帧复杂度接近时收益
下降，这是模型内的诚实边界。原三点估计的区间恰好落在 IQR 内，结论
方向不变、数字改统计量。

### ⑤ 工作量杠杆

V1.5-E 的「档位率控/B 帧」从「启发式调参 + 主观验收」变为「闭式算法
+ 可断言证书」：水位二分 ~20 行、凸包查表 ~30 行、证书断言 ~10 行，
且调参空间从「质量档怎么设」塌缩到「θ 怎么估」。等畸变证书同时是
回归门禁（任何破坏最优性的改动立刻红）。

### ⑥ 效果提升

等比特总畸变降 63–74%（等价 PSNR +4~5 dB 于同码率）；B 帧按闭式
权重省比特（ρ=¼ 时每 B 帧 −1 bit/符号）；切换帧不再被平均质量饿死
（实测 WF 把 3.3–3.6 bit/符号 分给尖峰帧，其余帧 0.4–1.3）。

### ⑦ 风险反证

- **模型风险**：真实 RD 曲线不是精确指数形。若 θ 估计偏差大，WF 在
  错误模型上最优——但仍在**凸族**内，且等畸变证书会检测到不一致
  （证书失败 ⇒ 回退路径），不会静默劣化。诚实的结论：收益上界
  63.8–74.4%（IQR）依赖模型保真，下界由证书回退保证。
- **两遍成本**：头遍编码 + 拟合增加一遍运算。对策：一遍路径用前一
  GOP 先验（GOP 间复杂度相关性高），证书监控漂移。
- 离散质量阶梯的量化把连续解投影到 ladder，损失 ≤ hull 弦 slack
  （凸性保证可界）；非凸 real-RD 时该 slack 无界——已归入模型风险
  的证书回退路径。
- **依赖加权是一阶近似（自审新增）**：d_i 线性累积忽略运动补偿对
  传播误差的抵消/放大；若实测传播系数与 d_i 偏离大，加权收益
  （端到端 17.4% 中位）会缩水——建议以端到端 PSNR 对拍做上线前
  验证（两遍路径下成本可接受），并把 d_i 系数的标定列为 V1.5-E
  的调参项（调 1 个标量，不是调一套启发式）。

### ⑧ 自审结论

**自审发现**：

1. **【修正弱证据】证 5 的「63.0–73.6%（3 次试验）」是点估计**——
   200 试验重测（exp10-T1）：中位 68.9%、IQR [63.8%, 74.4%]、
   min 53.8%。原区间恰落在 IQR 内 ⇒ 方向不变、数字改统计量；
   诚实边界：收益依赖 GOP 内复杂度离散度，尖峰弱时降幅收窄。
2. **【修正「免费加强」表述 + 新增结构】依赖加权不是免费的**：
   原模型帧独立，低估「早期帧被多帧参考应多分比特」。加权后
   （exp10-T2）：端到端口径 J 的改善中位 17.4%（IQR 16.2–18.1%，
   这是加权 WF 的 KKT 最优性所致、恒非负）；但帧独立口径 J₀ 下
   恒劣于未加权（+21.7% 畸变、对等速率降幅让出 ~8 个百分点）。
   定级为**口径换修**：端到端（真实视频关心的口径）严格更优，
   帧独立口径让出部分收益。证书对加权稳健（exp10-T3）。
3. 未发现问题：KKT 充分性、等畸变证书（max/min = 1.000000）、
   B 帧闭式（差 ≤1.1e-16）、20 万次搜索对照（0.9990）均通过重核。

**更优算法检索**：**已检索，并列提出 1 项更强变体（依赖加权，已
并入 ②）**。其他候选：① 「λ-域搜索替代水位二分」——等价（同一
KKT 对偶变量），无增益；② 逐帧 RDO（率畸优化，实际编码率控
主流）——比 WF 更贴近真实编码器（考虑 CABAC 上下文码率），但
需要实际编码器在线支持，超出本引擎 MJPEG/PRMV 自研路径的能力，
记为外部依赖项不提案；③ 依赖加权的传播模型若要做强，可引入
「传播系数矩阵」取代标量 d_i——GOP 内帧间参考图是已知的，系数
可精确构造（不再是一阶近似），但增益上限受运动补偿精度限制，
列为 V1.5-E 后续增强，本提案先用标量 d_i（调 1 个参数）。

**测试方案**：

- **A1 大规模**：GOP=1000 帧、θ 跨 6 个数量级；水位二分 ≤200 步
  收敛断言（|ΣR−B| ≤ 1e-9）；等畸变证书 max/min = 1（1e-9 容差）。
- **A2 极端参数**：G=1（单帧）；θ 全等（退化为等分配，证书仍
  成立）；预算=0（全零速率）；预算远超需求（水位低于 min θ，全
  活跃）；θ 含 0（无复杂度帧 ⇒ R=0）；θ 跨 2^30 倍（I 帧尖峰极端）。
- **A3 边界**：负预算/NaN 输入防御（明确拒绝或钳位，不 panic 于
  生产路径）；依赖加权 d_i 全 1（≡ 未加权，逐位同式断言）。
- **A4 最优性对照**：100 组随机 θ 剖面，WF 解 vs 20 万次随机
  搜索：ΣD_WF ≤ 1.001·ΣD_search。
- **B 变异体**：
  - B-M1 水位二分方向写反（lo/hi 反向更新）⇒ 预算残差
    |ΣR−B| > 1e-6 或畸变爆炸（exp9 曾踩此坑：Σn 爆贵）。
  - B-M2 R_i 投影量化档用 floor 而非最近档 ⇒ 等比特总畸变比
    闭式高 >5%。
  - B-M3 B 帧闭式退化为 R_B = R_P（去权重）⇒ ρ=¼ 时总畸变
    +10% 以上。
  - B-M4 活跃帧判据用 R_i > 0.5（错阈值）⇒ 证书在钳位帧上
    max/min > 1.01（钳位帧被误列活跃）。
  - B-M5 依赖加权乘错方向（θ_i/d_i）⇒ 端到端口径劣于未加权
    （阳性对照：加权方向可证伪）。
  - B-M6 水位二分用 `f64::log2`（libm）⇒ 跨平台 MD5 分歧

## 5. P5 — 缓存键完备性定理 + 依赖闭包哈希（V1.5-P1-4 / V2.0-I）

### ① 问题现状

- `crates/prism-core/src/signature.rs:452-468` `CacheDims` =
  `{width, height, spp_tier, tile, engine_version, frame}`；
  `signature.rs:473-486` `cache_key` 哈希这些维度 + 子图签名。
- 但渲染输出还依赖 `crates/prism-rt/src/integrator.rs:768`
  `RenderParams{spp, max_bounces, clamp_indirect, nee_only}`——四项
  **均不在键内**；且 `spp` 只以「档位」进键，精确值丢失。
- `crates/prism-render/src/incremental.rs` 的三维复用模型把「键相等
  ⇒ 逐字节一致」当公理式断言——**当前键不支撑该断言**。
- 【自审补充】闭包还漏两项：`crates/prism-rt/src/sampler.rs:206-208`
  `EvalCtx.global_seed`（采样种子**不在** `RenderParams` 内，是独立
  字段——同参数不同种子 ⇒ 不同噪声实现 ⇒ 不同图）；以及 **scene 数据
  本身**（`integrator.rs:243` `Scene` 是纯数据结构：spheres/boxes/
  paraboloids/planes/lights/medium——「同子图签名但场景内容不同」
  的资产切换同样产生陈旧命中）。原 ③ 的键设计已含 `scene_sig`，
  此处把闭包清单补全为：**RenderParams 全字段 + sampler 种子 +
  scene 内容签名 + 子图签名 + frame**。
- 【自审更正】`CacheDims` 当前**未接生产路径**（`spp_tier` 仅测试
  消费：`incremental.rs:945`、`signature.rs:948/959`）——这是零成本
  修复窗口：现在补字段只需改签名一处 + 测试；等缓存系统上线后再修，
  成本是 schema 迁移 + 陈旧缓存清洗。

### ② 数学结构

**缓存健全性定理**。设输出 `O = F(P)`，P 为全部渲染参数（确定性的
F）。缓存键 `k = H(π(P))`。则

```
健全 ⟺ π(P₁) = π(P₂) ⇒ F(P₁) = F(P₂)
```

即 π 必须是 F 的**充分统计量**：等价地，F 的依赖闭包
`Dep(F) = {P 中被 F 读取的分量}` 必须被 π 覆盖。逆否命题给出反例
构造法：任何 `Dep(F) \ π` 中的分量都能造出「同键不同图」——
**陈旧命中**，且返回的是似是而非的字节（最坏的失败模式：不崩溃、
只是错）。

### ③ 算法设计

1. **键结构**：`cache_key = hash(tag, schema_version, engine_version,
   subgraph_sig, dims, RenderParams_bytes, sampler_state,
   scene_sig, frame)`，其中 `RenderParams_bytes` 由
   `RenderParams::to_hash_bytes()` 产生（字段名+值逐个入哈希的显式
   实现，禁 derive 黑盒）。
2. **闭包 lint 测试**（防回归）：对 `RenderParams` 每个字段构造
   「仅该字段不同」的参数对，断言键不同；新增字段忘记入哈希时该
   测试红。同理覆盖 scene/sampler 维。
3. schema 版本随键结构 bump：旧缓存静默失效重建（宪章 C13/D-28 既有
   语义），不误复用。
4. 与 P7 联动：转场链的精确有理权重向量也入键（转场是渲染输入的
   一部分）。

### ④ 数学证明

**证 1（健全性）**。若 π 覆盖 Dep(F)，则 π(P₁)=π(P₂) ⇒ P₁ 与 P₂ 在
Dep(F) 上逐分量相同（哈希碰撞概率按 SHA-256 计，业务上忽略）⇒
F 确定性 ⇒ F(P₁)=F(P₂) ⇒ 缓存命中返回正确字节。✓

**证 2（现行键的反例）**。取同子图、同 dims、同帧，两RenderParams
仅 `max_bounces` 不同（3 vs 6）：`trace_one` 的弹射次数上界读该字段
⇒ 图像不同（间接光样本数不同）；而现行 `CacheDims` 无该字段 ⇒
`cache_key` 相同 ⇒ 第二次渲染命中第一次的字节——**陈旧命中的具体
构造**。同法适用于 `clamp_indirect`、`nee_only`、精确 `spp`
（同档不同值）。

**证 3（fail-safe 方向）**。过度入键（哈希不影响输出的量）只减少
命中、不产生错误字节；入键不足才产生错误字节。故设计规则是
「宁过勿欠」——与宪章「旧缓存静默失效」语义一致。

### ⑤ 工作量杠杆

V1.5-P1-4 与 V2.0-I 都建在这个键上；现在修，成本是几个字段 + 一个
闭包 lint 测试【n2 修正：原「反射式测试」术语误导——Rust 无运行期

### ⑥ 效果提升

incremental「键相等⇒逐字节一致」从假设升级为定理；V2.0-I 的

## 6. P6 — 降噪分配律修正（σ 非 σ²）+ Kalman 时域（V2.0-RQ-2 / D-2）

### ① 问题现状

- `crates/prism-postfx/src/denoise.rs:171` `allocate_spp` 按权重
  largest-remainder 分配（实现正确、确定性已测），但**文档语义是
  「variance 自适应」**——若调用方传方差 σ² 作权重，则分配
  `n_i ∝ σ_i²`，**不是** MSE 最优。
- `denoise.rs:130` `TemporalAccumulator::accumulate` 用均匀递推均值
  `acc + (cur − acc)/(n+1)`——只在各帧方差相等时最优。
- RQ-2 验收线：「同等画质采样数下降 ≥50%」。

### ② 数学结构

**分配律（Lagrange）**【自审修正：原表述 `n_i ∝ σ_i` 只在无约束
（n_i > 0 自动满足）时成立；工程实现有 `n_i ≥ 1` 约束，正确闭式
须分主动/钳位两支】：`min Σσ_i²/n_i s.t. Σn_i = N, n_i ≥ 1`。拉格朗日
`−σ_i²/n_i² + λ = 0` ⇒ 主动支 `n_i = σ_i/√λ`（**标准差**，不是方差）；
`n_i ≥ 1` 的 KKT 互补松弛给出钳位支 `n_i = 1`（当 σ_i < √λ）。合并：

```
n_i = max(1, σ_i/√λ),    √λ 由 Σn_i = N 确定（单调，二分可解）
```

（exp9-T1/T2：400 组随机剖面上，约束闭式 vs 无约束比例式——更优
61 / 持平 324 / 更差 15；「更差」的 15 例全部是 σ_i 极度悬殊时
无约束式把某区域压到 n_i = 0 的非法解，正见约束的必要性。）

**Cauchy–Schwarz 最优性下界**：
`(Σσ_i)² = (Σ√n_i·σ_i/√n_i)² ≤ (Σn_i)(Σσ_i²/n_i) = N·MSE`
⇒ `MSE ≥ (Σσ)²/N`，等号成立 ⟺ `n_i ∝ σ_i`。σ² 分配达到等号仅当
所有 σ 相等。

**Neyman 分配正名**【交叉审补充文献锚点】：`n_i ∝ σ_i` 就是
**Neyman（1934）分层抽样分配**——90 年历史的最优分配律。本提案以
「修正」framing 呈现，正名「回归 Neyman 分配」文献站位更稳，也更强
论证「σ² 是误用」（Neyman 分配在抽样文献里从未是 σ²）。

**削减率定理**：等分配 `MSE_eq = m²·E[σ²]/N`，最优
`MSE_opt = m²E[σ]²/N` ⇒

```
MSE_eq/MSE_opt = E[σ²]/E[σ]² = 1 + CV²
采样削减率 = 1 − 1/(1+CV²)
```

CV=1（区域噪声差一倍，典型）时恰为 **50%**——正是 RQ-2 的验收线。

**Gauss–Markov / Kalman**：帧观测 `x_k = θ + ε_k`（ε_k 零均值、方差
σ_k²、互不相关）时，逆方差加权 `x̂ = Σ(x_k/σ_k²)/Σ(1/σ_k²)` 是
MMSE 最优线性估计，`Var = 1/Σ(1/σ_k²)`。递推形式：

```
K_n = V_{n−1}/(V_{n−1}+σ_n²),  x̂_n = x̂_{n−1}+K_n(x_n−x̂_{n−1}),
V_n = (1−K_n)V_{n−1} = 1/Σ_{k≤n}(1/σ_k²)
```

**方差来源的双通道审计**【自审新增，exp9-T4】：Gauss–Markov 定理
要求权重 `1/σ_k²` 中的方差是**已知常数**。本引擎有两种来源，保证
等级不同——

```
通道 A（已知方差）：σ_k² 由 spp 数与全局噪声模型闭式给出（spp 是
  渲染预算的已知函数，不依赖被估数据）⇒ 权重独立于观测 ⇒ Gauss–
  Markov 适用 ⇒ 逆方差加权是 MMSE 最优线性估计（有定理）。
  实测（exp9-T4，300 剖面×400 实现）：改善 69.2%。
通道 B（插件方差）：σ_k² 用当帧像素数据在线估计 ⇒ 权重依赖被估
  数据本身 ⇒ Gauss–Markov 前提破坏 ⇒ 仅有经验最优性。
  实测：改善 69.4%（与通道 A 数值接近，但【无保证】）。
```

设计规则：时域累积器的 σ_k² **默认走通道 A**（spp 推导）；若用
通道 B，须在文档与测试中标注「经验值」，且不得把 BLUE 最优性
写进证书。等方差剖面时两通道都退化为 `K_n = 1/n`，与现行递推
**逐位同式** ⇒ 零回退（证 4 保持）。

### ③ 算法设计

1. **分配律修正**：`allocate_spp` 权重语义改为「区域噪声**标准差**」；
   调用方传 `sqrt(方差)`（或让 allocate_spp 内部对输入开平方——二选
   一，但必须写进文档与测试，防再次误用）。largest-remainder 分配器
   本身不动（确定性已证）。
2. **Kalman 时域**：`TemporalAccumulator` 状态 `(acc, samples)` →
   `(acc, V, samples)`；σ_k² 由当帧 spp 与像素方差先验闭式给出
   （spp 来自 P6-1 的自适应预算——两个改动天然耦合）。
3. 全程 f32 乘除固定式 ⇒ 逐位确定；seek 重放语义不变（状态仍显式）。

### ④ 数学证明

**证 1（分配最优性）**。目标在各 n_i 上严格凸（`2σ_i²/n_i³ > 0`）、
约束线性 ⇒ KKT 全局最优；C-S 不等式给分布无关的最优值下界，
`n_i ∝ σ_i` 达到它——即 Neyman（1934）分配（② 的正名）。

**证 2（σ² 严格次优）**【交叉审 M7 必修重写：原文代数有错——σ² 分配
`n_i = Nσ_i²/Σσ²` 的 MSE = `Σ_i σ_i²/n_i = Σ_i (Σσ²/N) = m·Σσ²/N`
（**每项同为 Σσ²/N，共 m 项**），原文写 `(Σσ²)²/N`（漏了求和的外括、
多平方一次）。由此「与最优 `(Σσ)²/N` 之比 = `(Σσ²)²/(Σσ)²`」不成立——
反例：所有 σ_i = 0.5 时该比 = 0.25 < 1，而等 σ 时两种分配本应给出
相同结果（exp16-T2 复现该反例）。正确推导】：

```
σ² 分配 MSE = Σ_i σ_i²/(Nσ_i²/Σσ²) = m·Σσ²/N
最优 MSE     = (Σσ)²/N
比值         = m·Σσ²/(Σσ)² = E[σ²]/E[σ]² = 1 + CV² ≥ 1   （C-S）
```

结论方向不变：σ² 分配严格次优（等号仅当所有 σ 相等，即 CV = 0）。
实测（exp4，m=8，CV=1/2）：σ² 分配 MSE 比最优高 **+22% ~ +172%**——
与修正后的 `1+CV²` 自洽（对应 CV ∈ [0.47, 1.31]，exp16-T3 验证
2000 组）。

**证 3（削减率与 RQ-2 可达性）**【自审修正：原「−79.3%」是单次
重尾抽样值，exp9-T3 以 20 抽统计重测】。等分配 → σ 律的采样削减率
= `1 − 1/(1+CV²)`（②）。CV=1 时：**中位 55.5%，IQR [48.6%,
65.1%]**（20 抽，m=32 区域）；单抽可达 79.3%（重尾）也可见 48.6%
下沿——RQ-2 的 ≥50% 线**中位过线但贴边**，依赖区域噪声离散度，
须以统计门禁（多场景中位 + IQR 下沿报告）验收而非单点。
对照：σ² 律仅 −19.6%（同口径）⇒ **σ² 权重下 RQ-2 线不可达**——
这是本提案最硬的杠杆：不是「更好」，是「达标与不达标」的差别
（该结论方向不受统计化影响：两个分布无重叠）。

**证 4（Gauss–Markov）**。BLUE 标准定理；递推=批量的等价性由对
`V_n = 1/Σ_{k≤n}(1/σ_k²)` 的归纳给出（实测差 3.3e-16，f64 噪声）。
等方差剖面时 `K_n = 1/n`，与现行递推**逐位同式** ⇒ 无回退。

**证 5（实证）**。300 个随机 σ 剖面 × 400 实现：Kalman 经验 MSE
300/300 严格低于现行均匀均值（持平集恰为恒定 σ 剖面）；变剖面场景
（噪声递减/递增/随机）改善 55.0–80.5%。

### ⑤ 工作量杠杆

两处改动都是小手术：权重开方（1 行）+ 累积器状态加一维 f32（~10 行）。
但没有它们，RQ-2 的 P0 验收线在完整实现之后才会失败——那是路线图
上最贵的失败时序。D-2 阶段一（时域累积）已落地，本提案是其最优性
补全，不是新阶段。

### ⑥ 效果提升

同等画质采样数 −55.5%（中位，CV=1，IQR 48.6–65.1%；单抽重尾可见
79.3%）；时域估计 MSE −55~80%（变噪声剖面，通道 A 有定理 / 通道 B
为经验值）；恒定噪声零回退；降噪后端（SVGF 阶段二）的 spp 预算
语义由此确定。

### ⑦ 风险反证

- **σ_i 估计成本与 seek 重放协议（交叉审 M8 必修）**：需要区域方差
  先验。低成本方案：低 spp 探针帧（预算的 1/8）估计 + 帧间递推；
  诚实声明估计误差会稀释理论收益（削减率从 55.5% 中位向估计精度
  收敛），但 C-S 下界保证不会劣于等分配太多。**递推 σ 状态使第 k 帧
  的分配依赖 0..k−1 的历史，直接跳帧（seek）重放会得到不同 σ ⇒
  不同分配 ⇒ 违反 seek 重放语义**（P5 刚把「seek 重放无损」当卖点）。
  钉死的协议【U4 采纳】：**σ 状态只在一个 GOP 内递推、GOP 边界重置**
  ——重放成本 = 1 GOP，有界；探针自身的确定性由引擎确定性保证
  （探针输出是帧的确定函数），无需额外论证，但须声明。替代路线
  （σ 状态显式序列化进渲染状态、seek 时恢复）留作实现选项；
  exp17 验证 GOP 内递推 + 边界重置下 seek 到 GOP 中段重放与顺序
  播放逐位相同（跨 GOP 不重置的对照实现则漂移——阳性证据）。
- **RQ-2 验收线的统计形态（自审新增）**：CV=1 时削减率中位 55.5%
  但 IQR 下沿 48.6% < 50% ⇒ 单场景验收有不过线风险。建议验收
  协议改为「≥5 个测试场景的中位数 ≥50% 且逐场景报告 IQR」——
  把点验收升级为统计验收，与 D-3 门禁②的精神一致。
- Kalman 需要逐像素方差缓冲：累积状态从 2 个 f16 缓冲增至 3 个
  （+50% 时域内存）；可代存 `1/σ²` 于 f16（动态范围够：spp ≤ 2^24
  ⇒ 1/σ² ≤ 2^24，f16  max 65504——不够！须 f32 或对数存储。记录
  为工程约束：V 缓冲用 f32）。
- 若帧间方差实际独立同分布（静态场景），Kalman ≡ 现行（证 4），
  收益为零但无损耗——升级是免费的期权。
- **通道 B 的保证缺口（自审新增）**：若 σ_k² 走插件估计（当帧数据），
  权重依赖被估数据，BLUE 最优性不成立（② 双通道审计）——此时
  「MSE −55~80%」是经验区间不是定理区间，测试断言须用统计界
  （如「不劣于现行」）而非「达到理论最优」。

### ⑧ 自审结论

**自审发现**：

1. **【修正】分配闭式漏约束**：原 `n_i ∝ σ_i` 无约束形式在
   `n_i ≥ 1` 下可给出非法解（某区域 n_i = 0）。正确闭式
   `n_i = max(1, σ_i/√λ)`（KKT 互补松弛：主动支 σ_i/√λ + 钳位支 1）。
   exp9-T1/T2：400 组随机剖面上约束式 vs 无约束式更优 61/持平 324/
   更差 15，「更差」例全为无约束式的 n_i=0 非法解。
2. **【降级】「采样削减 79.3%」是单抽重尾值**：exp9-T3 以 20 抽
   重测——CV=1 中位 55.5%、IQR [48.6%, 65.1%]。RQ-2 的 50% 线
   **中位过线但贴边**（IQR 下沿 48.6% < 50%），须统计形态验收
   （多场景中位 + IQR 报告）。σ² 律 19.6% 不可达的结论不变
   （两分布无重叠）。
3. **【补充保证缺口】Kalman 的 Gauss–Markov 适用性分双通道**：
   已知方差（spp 推导，权重独立于观测）⇒ MMSE 最优有定理
   （69.2%）；插件方差（当帧估计，权重依赖被估数据）⇒ 仅经验值
   （69.4%，无保证）。默认走通道 A；通道 B 的测试断言用「不劣于
   现行」统计界。
4. 未发现问题：C-S 下界、σ² 严格次优（+22~172%）、递推=批量
   （3.3e-16）、等方差零回退（逐位同式）均通过重核。

**更优算法检索**：**已检索，并列提出 1 项更强变体（约束闭式，
已并入 ②）**。其他候选：① 「权重 ∝ σ_i^α、α 由数据标定」——
   把 σ/σ² 之争变成连续旋钮；但 α=1 是 MSE 最优的唯一定点
   （拉格朗日一阶条件刚性），标定只会引入估计误差，否决；
   ② 时域用完整 Kalman 滤波（状态 = 真值 + 方差，含过程噪声 Q）——
   若帧间真值有随机游走（场景动态），Q>0 的卡尔曼滤波严格优于
   定权重递推；但 Q 的标定是新参数且静态场景 Q=0 退化，
   列为后续增强（先落通道 A 的零回退版本）；③ 「按区域 CV 自适应
   切换 σ/σ² 律」——CV 信息已隐含在闭式里（√λ 自动处理），
   冗余，否决。

**测试方案**：

- **A1 大规模三方对拍**：10^6 像素 × 100 区域（σ 跨 4 个数量级），
  σ 律 vs σ² 律 vs 等分配：σ 律 MSE ≤ 理论下界 (Σσ)²/N ×1.001；
  削减率统计报告（≥20 抽的中位 + IQR）。
- **A2 极端参数**：m=1（单区域）；σ 全等（≡ 现行逐位同式断言）；
  σ 跨 2^20 倍；N < m（预算不足 ⇒ 钳位路径，Σn > N 须显式声明
  而非静默超支）；σ=0 区域（n_i=1 钳位）。
- **A3 边界**：CV=0（无差异，削减率 0）；CV→∞；N 恰等于 m
  （全钳位）。
- **A4 Kalman 长时间**：10^4 帧递推 vs 批量对拍（≤1e-3）；V 缓冲
  若用 f16 必须被拒（spp ≤ 2^24 ⇒ 1/σ² > f16 max）——断言 f32。
- **B 变异体**：
  - B-M1 调用方传 σ² 忘开方 ⇒ 削减率 <50%（RQ-2 线红）+ MSE
    +22~172%。
  - B-M2 去 min-1 钳位（纯比例）⇒ 小 σ 区域 n_i = 0 ⇒ 除零/空
    采样（断言存在区域 n_i ≥ 1）。
  - B-M3 Kalman 退化为 K_n = 1/n（忽略 σ 差异）⇒ 变剖面 MSE
    劣化 >10%。
  - B-M4 V_n 更新漏乘 (1−K) ⇒ V 不收敛到 1/Σ1/σ²，批量对拍
    差 >1e-3。
  - B-M5 σ_k² 用当帧插件估计却按通道 A 写证书 ⇒ 证书型测试在
    权重依赖数据的构型上失败（阳性：保证等级不可混标）。
  - B-M6 σ 状态跨 GOP 递推（不重置）⇒ seek 到 GOP 中段重放与顺序
    播放 diff > 0（阳性：M8 的必要性——重置协议是 seek 重放语义
    的前提）。

## 7. P7 — 转场半群 + 定点权重（V1.5-C / ADR-18）

### ① 问题现状

- `crates/prism-author/src/render.rs:1335` `mix_frame` 作用于 **u8 RGBA**
  （`Vec<u8>`，每像素 4 字节）；Fade/Wipe 分支用 f32 `lerp` +
  `.clamp(0.0,255.0) as u8`——`as u8` 是 toward-zero **截断**，
  有系统性 −0.5 LSB 暗偏（exp11-T1 全网格实测 mean −0.4883 LSB、
  负偏置占比 97.7%）；`render.rs:1465` `concat_with_transition`
  链式拼接。
- Transition 枚举是 **Fade/Wipe/Dissolve/Push**（`render.rs` 转场
  doc 注释：Up/Down/Dissolve{seed}/Push{dir}）——原文档写的
  「Slide」不存在的，已正名（自审修正：以源码为准）。
- V1.5-C 将把这些类型下沉 `prism-core`（ADR-18）——**下沉时顺手
  换成有代数结构的实现，成本最低**；否则 f32 lerp + 截断语义被
  固化成 core 公约，日后难改。

### ② 数学结构

**保留分数乘法半群**【自审修正数学错误：原文「经 logit 变换同构于
(ℝ,+)」是错的——logit(s+t−st) ≠ logit(s)+logit(t)（反例 s=t=½：
logit(¾)=ln3 ≠ 0=logit(½)+logit(½)）。正确的同构是保留分数的
对数】：淡混合 `F_t(A,B) = (1−t)A + tB`。定义保留分数
`k(t) = 1−t`，复合 `F_s∘F_t`（**同一目标帧 B**）的保留分数 =
`k(s)k(t)` ⇒ 复合参数闭式 `u = s+t−st`。乘法可结合 ⇒ `{F_t}` 关于
复合构成**半群**（单位元 t=0）；保留分数集 (0,1] 的乘法半群经
`t ↦ ln(1−t)` 映到 (−∞,0] 加法半群 ⇒ **t ↦ ln(1−t) 是同构**
（exp11-T3：2000 组随机 (s,t)，固定种子 20261017 下
|ln(1−u)−ln(1−s)−ln(1−t)| ≤ 1.34e-12——【交叉审 m5：原文 8.9e-13
是未钉种子的历史输出，钉死后重跑为 1.34e-12；量级与结论不变】）。
转场参数复合是精确闭式，链式不漂移。

**u8 域定点表示**【自审替换：原 2^-24/f32 网格是为浮点帧缓冲设计的，
与 `mix_frame` 的 u8 域错位】。输出是 8-bit ⇒ 权重直接取 **256
分母网格**：`W = round(256·t) ∈ {0,…,256}`，混合

```
out = (W·b + (256−W)·a + 128) >> 8        （round-to-nearest）
```

误差 = 权数量化（`|W−256t| ≤ ½` ⇒ 权重误差 ≤ 0.5/256）+ 输出舍入
（≤½）⇒ 合计 ≤ 1.0 LSB，且 **round-to-nearest 无系统偏置**
（exp11-T1/T1b：网格 t mean +0.0078、连续 t mean +0.0068，
对比现行截断 mean −0.4883）。这正是「规范化原理」在值域上的形态：
把混合钉在整数格上，f32 舍入模式/fma 收缩/截断偏置一并消解。

**凸权重半群（四转场统一框架）**【自审新增，exp11-T4】：四种转场
共享同一套权重代数——混合输出 = 源帧的凸组合：

```
Fade：逐像素权重 w = t（全局）
Wipe：逐像素权重 w = smoothstep((x−edge+band)/2band)（位置函数）
Dissolve：逐像素权重 w ∈ {0,1}（hash < k 的 0/1 选择——凸集极值点）
Push：权重为分段 0/1（覆盖判据 x < c）——凸集极值点 + 整数平移
```

保留分数相乘的半群律对**任何**权重生成方式成立（凸组合的复合仍是
凸组合）⇒ 四种转场可链式复合、可统一做端点审计、可统一入缓存键
（P5）。逐像素选择规则（smoothstep/hash/覆盖判据）是权重向量的
**装饰**，权重代数才是结构。**端点精确性审计**（exp11-T2）：
Fade（k=0/1 时 lerp 端点精确）、Dissolve（hash∈[0,1) 的 0/1 判据）、
Push（c=0/W 的纯拷贝 + 边界 repeat）端点**逐位精确**；**Wipe 不
精确**——smoothstep 带骑跨分界线 edge=(1−k)·w，k=0 时带左半落入
右缘 1 列、k=1 时带落入左缘 2 列（污染权重 0.156/0.5/0.84）。修复：
分界行程扩展 `edge(k) = (1−k)·(w+2·band) − band`，使两端混合带
完全出画（修复后实测污染列 = 0）。

### ③ 算法设计

1. `core::sceneseq`（V1.5-C 新建）内置 **u8 域整数混合器**：
   `out = (W·b + (256−W)·a + 128) >> 8`，`W = round(256·t)`
   （t 为凸权重，含 Wipe 带内连续权重——round 一次，无系统偏置）。
2. 转场链状态 = **凸权重向量**（每源帧一个 u16 权重 + 公共分母
   256；链长 ≤ **3** 时可用 u32 保持完全精确，≤4 用 u64，更长链
   每步重归一化，误差 ≤ 1/256 LSB/次，有界）。【交叉审 n3：原文
   「≤4 用 u32」差一个单位——4 个 ≤256 的权重乘积最大
   `256^4 = 2^32 = u32::MAX + 1`，全 1 边界溢出一个单位；u32 对应
   ≤3（`256^3 = 2^24`）。】**注意**：折叠为「单 fade」只对
   **同一目标帧**的链成立（半群律）；不同目标的两段转场保持
   权重向量形态（见 ⑥ 的修正）。
3. 权重向量入缓存键（与 P5 联动）⇒ 转场链的中间态可缓存、seek
   重放无损。
4. Wipe 分界行程扩展（`edge(k) = (1−k)(w+2·band) − band`）+
   Dissolve 的阈值抖动继续走 `prism-noise` 整数 hash
   （确定性不依赖 FP）；Push 的整数采样 round + 边界 repeat 不变。

### ④ 数学证明

**证 1（半群律，含同构修正）**。`k(s+t−st) = (1−s)(1−t)`（展开即得）

是到 (−∞,0] 加法半群的同构（2000 组 max 1.34e-12，固定种子
20261017）；**logit 不是**（s=t=½ 反例）。【自审新增：原文档 ⑥ 的
DSL 等式
`fade(fade(x,a,t₁),b,t₂) = fade(x,b,t₁+t₂−t₁t₂)` **不成立**——
第二段 b 侧是不同帧 b≠a，复合律前提破裂；两段链的轨迹是 x→a→b
折线，与 x→b 直线一般不同（exp11-T3 实测残差 max 0.7598，即 ~194
LSB 量级——【交叉审 m5：原文 0.816 是未钉种子的历史输出，钉死后
重跑为 0.7598；量级与结论不变】）。正确表述：两段链 = 三源凸权重向量
`[(1−t₁)(1−t₂), t₁(1−t₂), t₂]`，折叠为单 fade 仅当 a=b（同目标）。】

**证 2（u8 域误差界）**【自审替换：原 2^-24 界随网格设计一并退役】。
单次混合误差 = 权重量化（`|W−256t| ≤ ½` ⇒ 对混合值的影响
≤ 0.5/256·|b−a| ≤ 0.5 LSB）+ 输出舍入（≤ 0.5 LSB）⇒
**worst-case ≤ 1.0 LSB**，且 round-to-nearest ⇒ **无系统偏置**
（实测：网格 t mean +0.0078 / max 0.5；连续 t mean +0.0068 /
max 0.9521；对照现行截断 mean −0.4883 / min −0.9961）。
整数域无 fma 收缩、无舍入模式依赖 ⇒ 链式 worst-case 与链长无关
（权重向量重归一化每步另加 ≤1 LSB/次，有界）。

**证 3（跨端一致性）**。WGSL 允许 fma 收缩：`fma(1−t, a, t·b)` 与
分离乘加 `(1−t)·a + t·b` 实测差 ≤ 1 ulp（max 5.96e-8，中位 0）——
即同一 transition 在 CPU 与 GPU 下**逐位不同**。整数混合无收缩语义
⇒ 两端逐位一致。这对「转场也要进 GPU 合成路径」的未来是刚需。

**证 4（端点精确性审计）**【自审新增，exp11-T2/T4】。四转场逐位
端点（k=0 全 a、k=1 全 b）：Fade（整数端点精确）、Dissolve
（hash∈[0,1) 的 0/1 判据）、Push（纯拷贝 + 边界 repeat）**成立**；
**Wipe 现行实现不成立**（k=0 右缘 1 列、k=1 左缘 2 列被部分混合，
污染权重 0.156/0.5/0.84）——smoothstep 带骑跨分界线所致。修复
`edge(k) = (1−k)(w+2·band) − band` 后实测两端污染列 = 0（带完全
出画；代价是 k 的有效行程多 2·band/w 的死区，<1px 推进量）。
凸一致性（任意 k 输出 ∈ [min(a,b), max(a,b)]）四转场全成立
（整数混合保序 + 直拷保序）。

**证 5（诚实的效果边界）**。实测 f32 链式漂移停留在 u 量级（凸组合
的舍入不相干累积，n=48 时 ~8e-9）——**精度不是本提案的主要卖点**；
卖点是 ① worst-case 界 O(1)（可证明、可写门禁）；② GPU fma 下的
跨端 bit-exactness；③ 精确权重向量可哈希、可缓存、可重放；
④ 【自审新增】消除现行 `as u8` 截断的 **−0.5 LSB 系统性暗偏**
（转场中段每通道每像素确定性偏暗，大面积均匀亮度偏移人眼可见）——
这是画质修正而非精度微调，且 ④ 是零数学风险的纯增益。

### ⑤ 工作量杠杆

V1.5-C 是绿地（类型下沉 + 新建 sceneseq），实现即用新语义，无迁移
成本；约 50 行。若等 author 层固化后再改，要动 `mix_frame` 全部
调用方 + 黄金基线。

### ⑥ 效果提升

u8 域 worst-case ≤1 LSB 无系统偏置（消现行 −0.5 LSB 系统暗偏）；
同目标转场链折叠闭式；CPU/GPU 转场逐位一致；转场链中间态可入
缓存（P5 键体系直接受益）；作者 DSL 获得转场代数——
**同目标链** `fade(fade(x, a, t₁), a, t₂)` = `fade(x, a, t₁+t₂−t₁t₂)`
（渲染器可折叠，半群律保证）；**不同目标链**保持三源凸权重向量
`[(1−t₁)(1−t₂), t₁(1−t₂), t₂]`（一般不可折叠为单 fade，见证 1
的自审修正）。

### ⑦ 风险反证

- 收益的主体仍是结构性的而非大幅精度提升（证 5 已诚实量化）——
  若团队只认「可测量的画质提升」，本提案应排最后。它排在 P7
  正是因为如此。【自审更新】证 5 新增的「−0.5 LSB 系统暗偏消除」
  是可测量的画质项，但幅度小（0.2% 亮度级）——排序结论不变。
- **u8 域即 LDR 域**：转场当前全部用例为 u8 RGBA（LDR），256
  分母网格无精度问题；HDR（>1 值域/f16 帧缓冲）路径须按曝光
  缩放或加指数位——记为 HDR 路径的待办（原 2^-24 网格的担心
  随设计替换一并退役）。
- 链式精确态（权重向量）增加实现复杂度；可降级为「每步重归一化
  + 有界误差」方案（仍满足证 2 的界）。
- 【自审新增】Wipe 修复（edge 行程扩展）改变 k∈(0,1) 的带位置
  刻度（k 与推进量不再严格线性）——若 DSL 把 k 当「推进比例」
  暴露给作者，须文档说明死区语义（<1px，实际不可见）；黄金
  基线须重截（诚实声明：这是端点正确性修复，不是语义微调）。

### ⑧ 自审结论

**自审发现（exp11，全部数值实证）**：

1. **【修正事实】源码是 Push 非 Slide；mix_frame 是 u8 域非 f32
   帧缓冲**。原文档按 f32/2^-24 网格设计定点混合，与实现域错位——
   已替换为 u8 域 256 分母整数混合（`(W·b+(256−W)·a+128)>>8`）。
2. **【修正数学错误 1】「logit 同构于 (ℝ,+)」错误**：反例
   s=t=½ ⇒ logit(s)+logit(t)=0 ≠ logit(¾)=ln3。正确同构是
   保留分数对数 `t ↦ ln(1−t)`（2000 组 max 1.34e-12，固定种子
   20261017——交叉审 m5 同步）。
3. **【修正数学错误 2】⑥ 的 DSL 折叠等式错误**：
   `fade(fade(x,a,t₁),b,t₂) = fade(x,b,u)` 不成立（第二段 b 侧
   是不同帧，半群复合前提破裂；残差 max 0.7598 ≈ 194 LSB——交叉审
   m5 同步：原文 0.816/208 LSB 是未钉种子输出）。
   正确结构 = 三源凸权重向量；折叠仅同目标时成立。
4. **【新发现 + 修复】Wipe 端点不精确**：smoothstep 带骑跨分界线，
   k=0 右缘 1 列 / k=1 左缘 2 列被部分混合（0.156/0.5/0.84）⇒
   「端点逐位精确」证书对 Wipe 不成立。修复 `edge(k)=(1−k)(w+2·band)−band`
   实测两端污染列 = 0。
5. **【新发现】现行 `as u8` 截断有 −0.5 LSB 系统暗偏**
   （全网格 16.8M 次实测 mean −0.4883、负偏置 97.7%）⇒ u8 整数
   round-to-nearest 是纯增益修正（mean +0.0078、max err 0.95）。
6. 未发现问题：半群律/结合律/F_0=id、凸一致性（四转场输出恒在
   [min,max]）、Dissolve/Push 端点精确、fma 跨端 1-ulp 差均确认。

**更优算法检索**：**已检索，提出 1 项更强统一框架（凸权重半群，
已并入 ②）**——它把四种转场的权重生成统一为「凸权重向量的不同
参数化」，使半群律、端点审计、缓存键、跨端一致性四件事从
「Fade 性质」升级为「全族性质」。其他候选：① 「u16 中间累加」
（混合用 u16）——**否决，但理由修正为「无必要」**【交叉审 n4：
原文以防「256·255 溢出」否决不实——u16 恰好够（max
`256·255 = 65280` 于累加、`255·256 = 65280`，实测 u16 max 65408
≤ 65535），结论（取 u32）不变，理由是「已有 u32 无需更窄类型」
而非「会溢出」】；② 「误差反馈抖动（dithering）」消 round 偏置——
round-to-nearest 已无系统偏置，dither 会引入噪声纹理且破坏
seek 重放确定性，否决；③ 「LUT 化权重 × 输入」（256×256 查表）——
快但 64KB 表且破坏链式闭包语义，否决。

**测试方案**：

- **A1 大规模全帧对拍**：1920×1080 × 四转场 × 256 个 k 档 vs
  f64 精确参考：max |diff| ≤ 1 LSB 且 |mean bias| ≤ 0.1 LSB
  （现行实现阳性对照 mean ≈ −0.488）。
- **A2 极端参数**：k=0/k=1 端点**逐位**断言（四转场全精确——
  含修复后的 Wipe）；a=b（任意 k 输出恒 = a）；a=0,b=255（最大
  动态）；1×1 帧；w=1,2,3（带 > 画面宽的极端窄画面）。
- **A3 边界**：连续 k 扫描（非 1/256 网格）无漂移；负 k/>1 k
  的 clamp 行为两端一致。
- **A4 链式与稳定性**：同目标 4 段链 vs 折叠闭式差 ≤ 2 LSB；
  100k 像素长时间混合无累积漂移。
- **B 变异体**：
  - B-M1 回退截断（去 `+128 >>8`）⇒ mean bias ≈ −0.488 断言红
    （判据 mean < −0.4）。
  - B-M2 Wipe edge 不扩展行程（旧 (1−k)w）⇒ k=0/k=1 端点逐位
    断言红（污染列 > 0）。
  - B-M3 同构按 logit 实现（文档原错误）⇒ 折叠等式数值反例
    （s=t=½ 残差 >1e-6）。
  - B-M4 折叠按不同目标等式实现（文档 ⑥ 原错误）⇒ 三段链折叠
    残差 >0.1（~194 LSB 量级）。
  - B-M5 Dissolve hash 换 f32 rand ⇒ 跨端 MD5 分歧（阳性：
    证明整数 hash 纪律的必要性）。
  - B-M6 链式精确态用 u32 存 4 段链（256⁴ = 2³² 溢出一个单位）⇒
    全 1 边界断言红（阳性：n3 修正的必要性——u32 只保 ≤3 段）。

## 9. 负面清单（诚实的「不做」）

1. **QMC mesh 面采样（Sobol/Owen 上车三角形采样）——不提案。**
   现有 `sampler.rs` 的 Joe–Kuo 64 维 Sobol + XOR 打散已是
   (t,m,s)-net 级；对光滑被积函数 ANOVA/Koksma 分解下 QMC 的边际
   增益落在估计噪声内。真正的方差杠杆在 P6 的分配律（CV=1 时
   中位 −55.5%，IQR 48.6–65.1%），不在采样序列升级。
   **工作量应花在 P6。**
2. **公式排版 max-plus 格化（tropical 代数优化字形布局）——不提案。**
   结构优雅，但当前 SDF/光栅路径已过门禁；无可测画质或确定性增益，
   净杠杆为零。
3. **Morph 接入、PH-1 物理入管线、V1.5-B 字体装载、V1.5-F 预览壳、
   ffmpeg 协作探测链——不提案。** 纯工程整合，本桌（算法）无数学
   杠杆；应由工程波次按路线图推进。
4. **「让 GPU 也逐位确定」——不提案，且反对。** D-3 已正确定案：
   GPU 浮点归约序非确定是物理性质，双门禁（语义级 parity + 输出级
   PSNR/统计）是正确框架。本报告的 P2 是**强化**该框架（给统计判据
   解析预算），不是推翻它。
5. **BVH 质量再调优（HBVH/宽 BVH/更细 SAH）——不提案。** 实测 SAH
   代价相对预排序输入无损（1.0000），构建质量已在位；进一步调优
   是 trace 时间与构建时间的权衡，与确定性目标无关，留给性能波次
   用数据决策。
6. **自研 H.264/AV1 编码器——重申不做**（D-10 已禁）。P4 的率控
   只作用于自研 MJPEG/PRMV 容器路径与「档位」决策，不越界。
