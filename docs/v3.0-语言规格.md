## 1. 版本头方案（D-24，双解析器共存）

| 版本头 | 前端 | 入口 | 语义 |
|---|---|---|---|
| 无版本头 | v1 块语法 | `prism_dsl::compile` | 零损失，逐字节同帧（`examples/spin_red_ball.prism`） |
| `// prism-dsl 1` | v2 全块语法 | `prism_dsl::compile_v2` | 零损失，逐字节同帧（`t0_media_mesh.prism` / `w2d_showcase.prism`） |
| `// prism-dsl 2` | v3 LL(1)+Pratt 前端 | `prism_dsl::compile_v3` | 本规格；编译产物降级为 v2 块文本后走 `compile_v2` |
| 其它版本 | — | `P1023` / `P1024` | 硬错，三段式，带行号 |

**零损失契约**：`detect_version_head` 的既有行为与既有测试**一行不改**（含 `// prism-dsl 2` 在旧入口触发
`P1023` 的断言）。v3 由新入口 `detect_version_head_v3` 单独识别，两条版本判定路径物理隔离。
`compile_auto` 只做分派，对「无头 / 版本 1」与旧 `compile_v2` 完全等价。

**块语法降级为语法糖**：v3 的 `emit` 语句把计算结果插值为 **v2 块文本**（首行 `// prism-dsl 1`），
再交给既有 `compile_v2` 装配成 `CompileV2Output`。语言层不重建节点图、不重实现任何数学或渲染
（§6 红线 1）。旧文件永久可解析、永久逐字节同帧。

**观感定桩边界**：`finish` 双档按 D-30 属 W3 独立波；本规格**不引入** `finish` 字段，
也不预留任何帧后贴皮入口 —— v3 的唯一产物出口是 `emit` 展开后的 v2 声明文本，
W3 必须在 W2 的求值链生成源头注入，不在本层埋伏笔。

## 2. 语法特性清单（§4 A1，逐条正例 + 负控）

八类特性，每类给出**正例形态、负控形态、错误码、判据**。正例与负控均由
`crates/prism-dsl/tests/v3_language.rs` 逐条断言。

| # | 特性 | 正例 | 负控（必 FAIL 且带行号 + 三段式） | 错误码 |
|---|---|---|---|---|
| A1-1 | 缩进块 | `def f(x):` + 4 空格缩进体 | 缩进不成 4 的倍数 / tab 与空格混用 / 该缩进没缩进 | P3001 / P3002 |
| A1-2 | 表达式（Pratt） | `a + b * 2 <= (c - 1) / 3` | 括号不闭合 / 运算符连写 / 缺右操作数 | P3003 / P3004 |
| A1-3 | 变量 | `r = 1.5` | 未声明即用 / 重复赋值到常量 `seed` / 赋值缺 `=` | P3101 / P3102 |
| A1-4 | `def` 函数 | `def ease(t): return t*t*(3-2*t)` | 参数重名 / 缺 `return` / 递归调用（含互递归） | P3103 / P3104 / P3105 |
| A1-5 | `for` / `if` | `for i in 0..4:`、`if x > 1: ... else: ...` | `for` 上界非常量 / 上界为负 / `elif` 后缺分支 | P3106 / P3107 / P3108 |
| A1-6 | 列表 / 字典字面量 | `[1, 2, 3]`、`{"a": 1, "b": 2}` | 尾逗号 / 重复键 / 下标越界 / 键不存在 | P3201 / P3202 / P3203 |
| A1-7 | 字符串插值 | `f"r={r}"`、多行 `f"""...{expr}..."""` | 插值式非法 / 引用未声明变量 / 花括号不闭合 | P3204 / P3205 |
| A1-8 | 行号报错 | 全部错误带 `line` 且消息含 `[Pxxxx]` + `建议：` | 任一错误缺行号 / 缺三段式 ⇒ 测试判红 | 全码段 |

**语法不许半截**（红线 2）：上表八类全部实现；不在清单内的语言构造（类、闭包、异常、模块导入、
模式匹配、`while`、IO）一律**明确拒绝**并给行号，不出现「某些情况可用」。

### 2.1 词法约定

- 缩进一律 4 空格；tab 在行首出现即 P3002。空行与注释行不产生 INDENT/DEDENT。
- 注释：`//` 与 `#` 到行尾；`// prism-dsl 2` 版本头必须由 `detect_version_head_v3` 处理。
- 标识符：`[A-Za-z_][A-Za-z0-9_]*`；数字：`[0-9]+(\.[0-9]+)?`，负数由一元 `-` 运算符承担。
- 字符串：`"..."`（普通）、`f"..."`（插值）、`f"""..."""`（多行插值，内容不转义、保留原字节）。
- 关键字：`seed def return for in if elif else and or not true false emit`。

### 2.2 顶层结构

```
// prism-dsl 2
seed = <整数字面量>                 # 一等字段，必填且只填一次
<语句>*                             # 变量 / def / for / if / emit
emit <插值字符串表达式>              # 至少一条；多条按声明序拼接
```

`emit` 之外不产生任何场景声明。`emit` 是语言与引擎之间**唯一**的声明出口，
因此「语言层成为第二事实源」在结构上不可能发生。

## 3. 确定性受限子集白名单（D-23 / §1.4）

### 3.1 允许（白名单）

| 类别 | 成员 |
|---|---|
| 字面量 | 整数、小数、布尔、字符串、列表、字典 |
| 运算符 | `+ - * / %`、`== != < <= > >=`、`and or not`、一元 `-`、下标 `[]` |
| 变量 | 顶层与 `def` 局部；`for` 绑定变量；按声明序单次赋值语义 |
| 控制 | `def`（非递归）、`for`（编译期可判定上界）、`if / elif / else` |
| 内置函数 | 仅 §6 的 `det_*` 映射表；`len`、`rand`、`int`、`str` 四个纯函数 |
| 随机 | 仅 `rand(tag)`：`hash_mix(seed, tag_bits)` → `[0,1)`，**无隐式状态** |

### 3.2 拒绝（静态拒绝，带行号 + 三段式）

| 非法语义 | 触发写法 | 错误码 |
|---|---|---|
| 系统时间 | `now()` / `time()` / `clock()` / `date()` | P3101 |
| 网络 | `http_get()` / `fetch()` / `socket()` / `url()` | P3101 |
| 文件写 / 读 | `write_file()` / `read_file()` / `open()` / `save()` | P3101 |
| 环境变量 | `env()` / `getenv()` / `environ()` | P3101 |
| 通用 IO | `print()` / `input()` / `stdin()` / `exec()` | P3101 |
| 无界递归 | 直接 / 间接 `def` 自调用、调用图中存在环 | P3105 |
| 无界循环 | `while`、上界非编译期常量的 `for` | P3106 |
| 未定义函数 / 变量 | 白名单外的任何标识符调用或引用 | P3101 / P3102 |

拒绝发生在**静态校验阶段**（`eval::validate`），先于任何求值；错误信息给出行号与
「在哪 / 什么事 / 怎么改」三段式，沿用 `movie.rs:113-149` 宪章。

### 3.3 不做图灵完备

无 `while`、无无界递归、无 IO、无隐式全局状态、无闭包捕获可变状态。所有 `for` 上界在
编译期可判定（字面量区间 `a..b` 或字面量列表），展开步数有静态上限 `MAX_EXPAND = 4096`，
超限 P3106。这保证编译必然终止、两跑逐字节一致。

## 4. 求值顺序冻结（**解析器动工前定桩**）

**冻结条款 F-1 ~ F-5，W1 内不可变更：**

- **F-1 表达式**：AST 求值严格**左 → 右深度优先**。二元运算先完整求值左子树，再完整求值右子树，
  最后应用运算符；函数调用先按声明序求值全部实参，再进入函数体；下标先求值容器再求值索引。
- **F-2 容器**：列表元素、字典条目**按声明序**迭代；字典迭代序 = 插入序，不做键排序。
  字典重复键在解析期即 P3202，不允许「后者覆盖前者」这类隐式顺序行为。
- **F-3 `for`**：`a..b` 按 `a, a+1, …, b-1` 升序展开；`for x in [..]` 按声明序展开；
  上界必须编译期可判定（F-3 与 D-23 同时约束）。
- **F-4 `if`**：条件短路只作用于分支选择，不作用于条件表达式内部 —— 条件表达式仍按 F-1 完整求值。
  未选中分支**不求值、不产生轨迹事件**。
- **F-5 轨迹**：每个求值步骤产生一条 `EvalEvent { line, tag, value_bits }`，按求值的真实时间顺序
  push 进 `trace`。`trace` 的规范字节序列进入产物哈希（§5 F-8）。
  **换序反例**：改变语句顺序、容器元素顺序或二元操作数顺序，必然改变 `trace` 顺序 ⇒ 产物哈希不同。
  这是 §7 #3「换序可检出」的执行体，不依赖任何平台浮点行为。

**为什么先冻结**：轨迹顺序是产物哈希的一部分，一旦解析器先落地再回头改求值顺序，
所有 golden 与产物哈希都要重算；W1 把顺序与种子同时钉死，W2/W3 只加能力、不动顺序。

## 5. 种子方案冻结（**解析器动工前定桩**）

- **F-6 一等字段**：`seed = <u64 整数字面量>` 是文件顶层**必填**字段，只可声明一次。
  漏填 ⇒ P3110；重复 ⇒ P3111；非整数字面量 ⇒ P3112；越界 ⇒ P3113。
  **不取默认、不静默降级**（红线 3）。
- **F-7 唯一随机源**：`rand(tag)` 走 `prism_core::eval::hash_mix`（`prism-core/src/eval.rs`
  的 splitmix64 终化函数，**实现逐字沿用、不新造随机源**）：
  ```
  h = hash_mix(seed, TAG_NAMESPACE)
  h = hash_mix(h, tag_bytes_as_u64)
  h = hash_mix(h, eval_ordinal)          // 求值序号，由 F-5 轨迹给出
  value = (h >> 40) as f64 / 16_777_216.0
  ```
  `eval_ordinal` 是**显式**的求值计数器，由固定求值顺序（F-1~F-4）导出，不是隐式全局状态。
- **F-8 种子进产物哈希**：`artifact_hash` 按以下链构造，全部为整数运算：
  ```
  h = hash_mix(seed, SCHEMA_TAG)
  h = hash_mix(h, lowered_source_len)
  for byte in lowered_source.bytes(): h = hash_mix(h, byte as u64)
  for ev in trace:
      h = hash_mix(h, ev.line as u64)
      h = hash_mix(h, ev.tag)
      h = hash_mix(h, ev.value_bits)
  artifact_hash = h
  ```
  `lowered_source` 是 `emit` 展开后的 v2 文本，`trace` 是 F-5 的求值轨迹。
  换种子、换文件、换求值顺序三者中任一变化都改变 `artifact_hash`。
- **F-9 两跑逐字节**：同一文件同一种子，两次 `compile_v3` 产出的
  `lowered_source` / `trace` / `artifact_hash` / `CompileV2Output` 全部逐字节一致。
  零线程、零系统时间、零平台 libm，CPU 侧不引入任何非确定性输入。
- **F-10 与 V2.5 零损失**：`// prism-dsl 1` 与无头文件不经过 v3 执行器，
  不读 seed、不产生 trace、不改 `artifact_hash`，渲染字节完全不变。

## 6. `det_*` 覆盖表（超覆盖面的函数先补实现再开放语法）

| 语言内置 | 引擎实现（零 libm） | 备注 |
|---|---|---|
| `abs` `min` `max` `clamp` `sign` `floor` `ceil` `trunc` `round` | `prism_math::det_scalar`（W1 新建） | 位操作 / 整数比较实现 |
| `sqrt` | `prism_math::det_scalar::det_sqrt` | 固定 6 步牛顿迭代 + 位型初值，无 `f64::sqrt` |
| `pow` | `prism_math::det_pow::det_pow` | 既有 |
| `exp` `ln` `log2` `log10` | `det_pow::{det_exp, det_ln, det_log2}` + `det_scalar::det_log10` | `det_log10 = det_ln(x)/det_ln(10)` 常量 |
| `sin` `cos` `tan` `acos` `atan2` | `prism_math::det_trig::{sin, cos, tan, acos, atan2}` + `colorspace_registry::det_atan2` | 既有 |
| `asin` `atan` | `prism_math::det_scalar::{det_asin, det_atan}` | 由 `acos` / `atan2` 恒等式导出 |
| `lerp` | `prism_math::det_scalar::det_lerp` | `a + (b-a)*t`，纯算术 |

**规则**：本表之外的函数名一律 P3101 拒绝；要开放新函数，必须**先在 `prism-math` 补零 libm
实现并加单测**，再往本表与执行器函数表登记。禁止在语言层调 `f64::sin` / `f64::sqrt` 等平台方法。

## 7. 错误码与三段式宪章（§4 A6）

| 码段 | 域 | 例子 |
|---|---|---|
| `P1xxx` | 版本头 / 防呆 | P1023 旧入口未知版本；P1024 新入口未知版本 |
| `P3xxx` | 词法 / 语法 / 静态语义 | P3001 缩进、P3003 括号、P3101 非法语义、P3105 递归、P3106 无界循环、P3110 缺 seed |
| `P32xx` | 字面量 / 插值 / 求值 | P3201 尾逗号、P3203 下标越界、P3204 插值非法 |
| `P33xx` | 降级 / 装配 | P3301 无 emit、P3302 展开文本 `compile_v2` 失败（透传原行号偏移） |

统一格式（`DslError { line, message }`）：
```
[Pxxxx] 第 N 行：<在哪 + 什么事>
  建议：<怎么改>
```
四类错误域（词法 / 语法 / 静态语义 / 求值）**全部**带行号、`[Pxxxx]` 码与 `建议：` 段。
`compile_v2` 降级失败时，P3302 用行号映射表把 v2 报错行折算回 v3 `emit` 的原始行。

## 8. 降级与同源对拍

1. `compile_v3` = `tokenize3` → LL(1)+Pratt → `validate`（白名单/递归/上界/seed）→
   `eval_program`（F-1~F-9）→ 拼接 `emit` 结果 → 首行补 `// prism-dsl 1` →
   `compile_v2` → `CompileV2Output`。
2. **同源对拍**：`compile_v3(src).base` 与「把 `lowered_source` 当作独立 `.prism` 直接
   `compile_v2`」的 `CompileV2Output` 逐字段相等；`prism-render` 侧以 `render_movie` 对同一份
   `CompileV2Output` 与语言产物出帧，逐字节一致。语言没有自己再算一遍场景。
3. **零损失**：现有 3 个 `.prism` 的 md5 与 golden 断言逐字节对账；v3 路径对它们完全不可达。
