### 1.3「权重是数据不是代码依赖」

**ML 推理为什么不违反铁律**：
一段定点前向推理（卷积/矩阵乘/GELU）**完全由本仓代码实现**，是纯函数。
权重只是**喂进去的数值**——和字体子集、方向数表是**同一类东西**。
**代码自研 ⇒ 满足零依赖铁律**；**权重有来源有许可 ⇒ 满足合规登记**。两件事，不冲突。

**重要修正**：ML/神经渲染"范式依赖"的定性**只适用于存量复刻路线**
（把 OIDN/3DGS 逐个重做 = 永远输的存量游戏）；
**ML/神经渲染本身是可做的定点前向推理工程**——推理插座已实装
⇒ **余下是纯内部工程待办，零依赖铁律不拦**。

## 4. 自检脚本

**脚本**：`tools/compliance_check.mjs`（Node 18+，**零依赖**）

| 能力 | 说明 |
|---|---|
| **核验 1** | 所有 `Cargo.toml` **无第三方 `[dependencies]`**（只允许 `path` 依赖） |
| **核验 2** | 全仓**无 `build.rs`** |
| **核验 3** | 无外部库链接（`#[link]`） |
| **核验 4** | **资产清单每项许可字段非空**（**空字段 ⇒ 判红**） |
| **核验 5** | `Cargo.lock` 无 registry 外部包 |
| **`--self-test`** | **反向自证**：故意留一个空许可字段 ⇒ **必须判红**（**不许恒过**） |

**用法**：

```bash
$ cd /workspace/media-engine
$ node tools/compliance_check.mjs
[合规] 核验 1/5：Cargo.toml 第三方依赖 ....... 通过（26 个 crate，仅 path 依赖）
...
合规检查通过：0 个问题

$ node tools/compliance_check.mjs --self-test
[自证] 注入空许可字段 → 必须判红
...
自证通过：空许可字段被成功判红
```

**CI 接线**：已挂到 `.github/workflows/ci.yml` 的 `lint` job。
**唯一判据 = 退出码**，不 grep 计数、不比对文本条数（那会写出恒真的假绿门禁）。

## 5. 本章的诚实边界

1. **`build.rs` 缺失不等于没有任何构建期工具**——字体子集化用了
   Python + fontTools，但那是**构建环境的一次性产物**，产物已落盘入仓，
   运行时零依赖；
2. **`node_modules/` 里有 `playwright`**——它是移动端验证网页的**可选**依赖，
   **不进构建链、不随源码包分发**（打包范围已排除）；
3. **资产登记的"来源"依据上游发布页**——若上游页面日后变更，
   本登记需重新核验（已实测字体 sha256 与随包记录**逐位一致**）；
4. **#4 "不受版权保护"是法律层面的判断**——本项目的做法是
   **实现公式 + 注明出处 + 不复制论文正文**，这是业界通行做法，
   但**不构成法律意见**；
5. **本章不含任何"已完全合规"的打包票**——
   四项待自研是**公开登记的待自研项**；
6. **⚠️ 一处实测发现的登记漂移（如实登记，未擅自修改）**——
   `crates/prism-text/assets/README.md` 记录 `prism_multiscript.ttf` 为
   **4,224 B / sha256 `110e2be3…c3b34`**，而**实测为 23,244 B / sha256 `0eece481…b76c7`**。
   **测试断言（`tests/multiscript_asset.rs` 的 `EXPECTED_SHA`）是对的**，
   旧 README 未同步。这正是"资产是确定性产物、字节漂移必须被看见"的机制在工作。
   **`crates/` 只读，故未擅自修改**——上报在此，由维护者决定是否同步。
   本章所有指纹均以**实测值**为准，不用过时 README 的数字；
7. **字体来源链有一处易误判处**：`font_data/README.md` 记上游为 `notofonts/noto-cjk`，
   而 `font_data/LICENSE` 首行版权是 **Adobe**（Source Han Sans）。
   二者不矛盾——Noto CJK 字形源自 Source Han Sans，OFL 要求保留上游版权声明。
   **两份文件共同构成完整来源链**，缺一不可。
