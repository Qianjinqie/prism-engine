# 合规专章（Compliance Chapter）

> **本章存在的理由**：本引擎的对外承诺是"零第三方代码依赖"，而**承诺要能被核验**。
> 文档会腐烂，判据不会——所以本章把合规判据写成可执行脚本，并把**已满足的**与
> **尚未做到的**（数据资产自研化）**分开如实登记**，两者不混成一句"已合规"。
>
> **核验入口**：`node tools/compliance_check.mjs`（须 exit 0）
> **反向自证**：`node tools/compliance_check.mjs --self-test`（**必须判红**）
> **登记日期**：2026-10-06（资产复核见 §2 与 §5.6）

## 1. 零第三方代码依赖（已满足）

### 1.1 核验方式与结果（**实测，非声明**）

| # | 核验项 | 命令 | 结果 |
|---:|---|---|:---:|
| 1 | 全仓依赖无外部 crate | 审阅根 `Cargo.toml` + 29 个 `src/*/Cargo.toml`（共 30 份 manifest） | ✅ 全部只有 `path =` 依赖 |
| 2 | 无构建期外部代码 | `find . -name build.rs -not -path './target/*'` | ✅ **输出为空** |
| 3 | 无外部 C/C++ 库链接 | `grep -rn 'extern "C"\|\#\[link' src/ --include='*.rs'` | ✅ 仅 ffi 声明，**无外部库链接** |
| 4 | 锁文件核对 | `Cargo.lock` | ✅ 仅本仓 29 个包 |
| 5 | 自动化核验 | `node tools/compliance_check.mjs` | ✅ **exit 0** |

**自验命令（可直接粘贴执行）**：

```bash
# 在解包出的 workspace 根目录执行：

# 1) 全部依赖都是本仓 path 依赖（应输出 29，无 registry 依赖）
#    注意锁文件用的是双括号段名 [[package]]，单括号写法会输出 0
$ grep -c '^\[\[package\]\]' Cargo.lock
29

# 2) 无 build.rs（应无输出）
$ find . -name build.rs -not -path './target/*' -not -path './node_modules/*'

# 3) 无外部库链接（应无输出）
$ grep -rn '#\[link' src/ --include='*.rs'

# 4) 自动化核验 + 反向自证
$ node tools/compliance_check.mjs               # 须 exit 0
$ node tools/compliance_check.mjs --self-test   # 须判红
```

> **双布局说明**：以上路径按**分发包布局**写（源码根为 `src/`）。
> 在 git 仓库里执行时，把 `src/` 换成 `crates/` 即可——两种布局的 crate
> 集合与依赖关系完全等价（演示 crate `prism-anim-demo` 不进分发包，
> 故包内 28 个、仓内 29 个 crate；详见《开发者指南》§1.7）。

### 1.2 靠什么做到

**手写清单（部分）**：

| 领域 | 自研件 | 位置 |
|---|---|---|
| 哈希 | **SHA-256**（FIPS 180-4） | `prism-io/src/sha256.rs` |
| 压缩 | **inflate**（RFC 1951）+ **zlib**（RFC 1950）+ Adler-32 | `prism-bytes/`（全引擎唯一真源） |
| 字体 | **OpenType 解析**（glyf/hmtx/name/GSUB…） | `prism-text/src/opentype.rs` |
| 图像 | PNG / JPEG / GIF / APNG / EXR / DNG / CR3 | `prism-io/` |
| 场景 | **USD `.usda` 解析** + MaterialX → 特解参数包 | `prism-io/src/usd.rs`、`materialx.rs` |
| 数学 | 超越函数自研区间逼近（**禁 libm**——不用系统数学库，避免跨平台末位差） | `prism-math/` |
| GPU | WebGPU / Vulkan / Metal **手写绑定**（架构成规：不用第三方 GPU 封装库如 wgpu） | `prism-gpu/` |
| 序列化 | 自研（**无 serde**） | `prism-io/src/distribution.rs` |
| Unicode | 手写整形状态机（**零 Unicode 依赖**） | `prism-text/src/shaping.rs` |

**代价是诚实的**：连 GPU 抽象层都自己写，意味着**自研工时显著增加**——
这是"运行期零第三方 crate"这条硬约束的直接账单，不是意外。
设计决策明确：**根本舍弃只有两笔**——
第三方生态（铁律代价）与自研工时（有限资源）。

### 1.3「权重是数据不是代码依赖」

**ML 推理为什么不违反铁律**：
一段定点前向推理（卷积/矩阵乘/GELU）**完全由本仓代码实现**，是纯函数。
权重只是**喂进去的数值**——和字体子集、方向数表是**同一类东西**。
**代码自研 ⇒ 满足零依赖铁律**；**权重有来源有许可 ⇒ 满足合规登记**。两件事，不冲突。

**重要修正**：ML/神经渲染"范式依赖"的定性**只适用于存量复刻路线**
（把 OIDN/3DGS 逐个重做 = 永远输的存量游戏）；
**ML/神经渲染本身是可做的定点前向推理工程**——推理插座已实装
⇒ **余下是纯内部工程待办，零依赖铁律不拦**。

## 4. 自检脚本

**脚本**：`tools/compliance_check.mjs`（Node 18+，**零依赖**）

| 判据 | 查什么 |
|---|---|
| **[C1.1]** | 所有 `Cargo.toml` **无第三方依赖**（只允许 `path` 依赖） |
| **[C1.2]** | 全仓**无 `build.rs`**（无构建期代码生成） |
| **[C1.3]** | 无外部库链接指令（`#[link]` / `link!`） |
| **[C1.4]** | `Cargo.lock` 无 registry 外部包（锁文件里全部是本仓 crate） |
| **[C2.0]–[C2.2]** | **资产登记表**：列齐全 / 每项字段非空 / 自研化状态落在受控词表（**空字段 ⇒ 判红**） |
| **[C3.0]–[C3.1]** | 第三方归属声明在场，且含"数据资产 ≠ 代码依赖"的关键区分句 |
| **`--self-test`** | **反向自证**：逐条注入破损 ⇒ **必须判红**；对照组 ⇒ 必须判绿（**不许恒过**） |

**用法**：

```bash
$ cd <解包出的 workspace 根目录>
$ node tools/compliance_check.mjs
仓库根：<当前目录>
判据：C1 零第三方代码依赖 / C2 资产登记完备 / C3 归属声明
== C1 · 零第三方代码依赖 ==
  ok    [C1.1] 全部 130 条依赖均为本仓 path 依赖  29 个 crate，零第三方
  ...（C1.2–C3.1 略）
合规自检通过：9 项判据全部通过

$ node tools/compliance_check.mjs --self-test
...
self-test: 8/8 通过
SELF-TEST OK: 违规必红、良好必绿——判据具备双向判别力
```

> 上面两段是**实测输出**（`130 条依赖` = 110 条运行期 `[dependencies]` + 20 条
> 测试用 `[dev-dependencies]`，全部是 `path` 依赖）。

**CI 接线**：已挂到 `.github/workflows/ci.yml` 的 `lint` job。
**唯一判据 = 退出码**，不 grep 计数、不比对文本条数（那会写出恒真的假绿门禁）。

## 5. 本章的诚实边界

1. **`build.rs` 缺失不等于没有任何构建期工具**——字体子集化用了
   Python + fontTools，但那是**构建环境的一次性产物**，产物已落盘入仓，
   运行时零依赖；
2. **`node_modules/` 里有 `playwright`**——它是移动端验证网页的**可选**依赖，
   **不进构建链、不随源码包分发**（打包范围已排除）；
3. **资产登记的"来源"依据上游发布页**——若上游页面日后变更，
   本登记需重新核验（已实测字体 sha256 与随包记录**逐位一致**）；
4. **#4 "不受版权保护"是法律层面的判断**——本项目的做法是
   **实现公式 + 注明出处 + 不复制论文正文**，这是业界通行做法，
   但**不构成法律意见**；
5. **本章不含任何"已完全合规"的打包票**——
   四项待自研是**公开登记的待自研项**；
6. **⚠️ 一处实测发现的登记漂移（如实登记，未擅自修改）**——
   `src/prism-text/assets/README.md` 记录 `prism_multiscript.ttf` 为
   **4,224 B / sha256 `110e2be3…c3b34`**，而**实测为 23,244 B / sha256 `0eece481…b76c7`**。
   **测试断言（`src/prism-text/tests/multiscript_asset.rs` 的 `EXPECTED_SHA`）是对的**，
   旧 README 未同步。这正是"资产是确定性产物、字节漂移必须被看见"的机制在工作。
   **`src/` 只读，故未擅自修改**——上报在此，由维护者决定是否同步。
   本章所有指纹均以**实测值**为准，不用过时 README 的数字；
7. **字体来源链有一处易误判处**：`font_data/README.md` 记上游为 `notofonts/noto-cjk`，
   而 `font_data/LICENSE` 首行版权是 **Adobe**（Source Han Sans）。
   二者不矛盾——Noto CJK 字形源自 Source Han Sans，OFL 要求保留上游版权声明。
   **两份文件共同构成完整来源链**，缺一不可。
