## 0. 先说清一件事：数据资产 ≠ 代码依赖

本项目受两条**互相独立**的规则约束，混淆这两条是本项目历史上出现过的真实错误：

| | 规则 | 现状 |
|---|---|---|
| **A** | **零第三方代码依赖** —— 零外部 crate、零 `build.rs`、零外部 C/C++ 库链接 | **已满足**（见 `README.md` 与 `THIRD-PARTY-NOTICES.md`） |
| **B** | **数据资产须登记** —— 来源 / 许可 / 合规动作**三者齐备，缺一不得入仓** | **本文件即为登记簿** |

**用户 2026-10-02 亲自收窄的口径（D-31 修订记录）**：

> 零第三方依赖约束的是**代码**；**数据资产**（字形 / 数学表 / 词典）**不是依赖**，
> 允许取自外部明确许可来源，但**来源、许可、合规动作三者齐备，缺一不得入仓**。

**本清单资产 = 明确许可下的过渡态，终态 = 自研化（D-31 / 账本 U15）。**
