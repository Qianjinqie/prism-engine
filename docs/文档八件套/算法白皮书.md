# 算法白皮书（Prism Engine · 怎么算）

> 本白皮书回答每个计算问题"**怎么算最好**"：更优算法 + 架构改良 + 超越点。三验收词：**优秀（最好超越业界常用）- 可落地（不切实际零容忍）- 不复述论文**（输出设计决策，不是文献综述）。
> 与《强大版路线图.md》的关系：路线图 = 做什么与验收；本白皮书 = 怎么算。实现对应工作流前必读对应章节。
> 架构红利缩写：**[D]** 确定性种子派生（随机性=纯函数）｜**[T]** 离线逐帧（时域信息可复用）｜**[J]** CPU/GPU 双实现判对 ｜**[S]** SDF 生态 ｜**[N]** 节点可组合。
> 工程附注（数值坑/参数）以小字标注，主体永远是算法设计。

## 1. 路径追踪积分器（B1）

**问题**：场景 + 相机 + 帧号 → 逐像素辐射估计。

**候选对比**：

| 算法思路 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| 前向光追踪（从光源） | 焦散优 | 灾难 | 大 | 差 |
| backwards PT 裸版 | 噪声大 | 中 | 小 | 优 |
| **backwards PT + NEE + 低差异采样** | 高 | 好 | 中 | 优 |
| ML 降噪/神经积分 | 高 | 需训练 | 不可 | 不可 |

**选定与设计**：
1. **采样器是灵魂**：Sobol 低差异序列 + Owen 滚动打散。哈希只负责**选点与打散**两件事：① `(种子, 像素索引)` 哈希定数字位移 c，**Sobol 索引 = 样本序号 ⊕ c**（随机数字平移：{s⊕c} 是 {0..N} 的精确平移，net 性质逐点保持）——**hash 值不得直接充当 Sobol 索引**：那是对索引空间的任意置换，等效从网格 IID 抽点，低差异性静默尽失（2026-10-02 施工实测教训，收敛退化 O(1/N)→O(1/√N) 且验收单点测不出，靠 spp 递增收敛对照才现形）；② `(种子, 像素索引, 维度)` 哈希定 Owen 打散/矩阵异或掩码；坐标 = `Sobol(i, 维度) ⊕ 打散掩码`——**禁止按维度独立取均匀随机数**（那样 (t,m,s)-net 向量性质整体消失，收敛从 O(1/N) 退化为 IID 的 O(1/√N)）。维度区分路径内用途（BSDF 方向 / 光源采样 / lobe 选择 / RR），弹射深度编码进 Sobol 维度序号；Sobol 方向数表（Joe–Kuo，公有领域常量，官方源 `new-joe-kuo-6.21201`）按 D-12 数据资产内嵌，超表维度按声明降级路径兜底。每个像素的每个样本是独立纯函数，无全局 RNG 状态。
2. **NEE（直接光采样）**：每次非镜面弹射，对每个光源发一条影子线；BSDF 采样与 NEE 用 power heuristic 做 MIS 合并，双份不重复计数。**不可被 BSDF/相位抽样命中的光源（如方向光）NEE 权重恒 1、不参与 MIS 配对**——对非几何光源做伪 MIS 配对会系统性欠估（解析对照必现）。
3. **Progressive**：算术累积缓冲（非指数滑动，保持无偏），第 k pass = 前 k-1 累积 + 新样本；验收用"累积一致性断言"。
4. **RR（俄罗斯轮盘）**：bounce ≥3 后按 throughput 概率终止；终止概率也由样本流哈希派生 `[D]`。
5. **Firefly 钳制**：仅钳间接光；阈值 = 固定常量（相对曝光基准，如中灰的 50 倍），不依赖运行时统计量——保持逐像素纯函数；偏差可控且可关闭。
6. 数据布局按 wavefront 组织（射线队列），CPU 递归实现但内存布局与 GPU 移植对齐 `[J]`。

**超越点**：业界渲染器多用全局 RNG 状态流（断点不可续、单像素不可独立重算）；我们**逐样本纯函数化 → 任意像素任意 pass 可独立重算**，分布式渲染与增量复用免费获得；Owen 打散的低差异序列同 spp 下方差显著低于纯随机。

**可落地**：integrator ~400 行 + sampler ~150 行。风险：MIS 权重细节需调优，验收断言兜底。

## 2. 焦散：MNEE 分层 + PSR（B2 后接入）

**问题**：镜面链路径（相机→镜面→光源）的焦散低方差估计。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| 光子映射 | 收敛慢 | 需光子图 | 大 | 中（D-20 记账：光子位置全由种子派生 + 构建序固定 = 确定性烘焙资产，可进 §24 签名缓存生态；当下不选仅因工时，非数学禁区） |
| 全链 SMS（任意跳数） | 极高 | 链长指数涨 | 大 | 中 |
| **MNEE（单镜面链牛顿求解）+ PSR 兜底** | 高 | 好 | 中 | 优 |
| 仅 PSR | 中 | 极好 | 极小 | 优 |

**选定与设计**（分层策略）：
1. **k=1 镜面链 + 球面 k=2 折射链（覆盖 90% 焦散视觉：玻璃球/水面波光）用 MNEE**：把"镜面点位置"参数化为镜面切平面 2D 坐标，残差 = 反射/折射定律要求的方向与"指向光源方向"的切平面偏差（2 维）。**牛顿迭代 3 步**：平面/球镜面解析雅可比（**球面 k=2 折射链——玻璃球进出两次折射——解析雅可比同样可写，D-30 扩展**），一般曲面有限差分；步长阻尼防过冲；**多初值策略**：基点 = 链起点到光源连线段与镜面的交点（初稿曾误写"相机点"，v1.3 已修正——见版本史脚注），再在切平面按 Sobol 2D 流撒 k 个偏移初值 `[D]`——不同光源/曲率的吸引域不同，单初值会漏估部分焦散区域；多解收敛时按残差最小 tie-break。连线无交或牛顿不收敛自动退化为普通 NEE（永不比基线差）。
2. **k≥2 其余链用 PSR 兜底**：镜面 roughness 注入种子派生微抖动 ε `[D]`，让普通路径"挤过"镜面链；ε 随 pass 数衰减（progressive 收敛到真值）。
3. 两路结果经 MIS 与主积分器合并。

**超越点**：论文级 SMS 依赖全局 RNG 做随机重启；我们**牛顿初值、jitter、重启全部由 `[D]` 哈希派生 → 焦散逐像素逐字节可复现**（论文原始实现做不到）。分层策略（单链精确解 + 多链正则化）比全 SMS 轻量一个量级。

**可落地**：MNEE ~200 行（含解析雅可比）+ PSR ~30 行。风险：极高曲率处牛顿不收敛 → 自动回退 NEE（有兜底，无失败路径）。

## 3. Disney BSDF + GGX（B2）

**问题**：材质点 + 出入方向 → 散射分布求值与采样。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| Lambert + Phong | 低 | 极好 | 小 | 优 |
| Cook-Torrance 经典 | 中 | 好 | 中 | 优 |
| **Disney 全参数 + VNDF 采样 + 多散射补偿** | 高 | 好 | 中 | 优 |
| 多层可编程材质 | 极高 | 差 | 大 | 中 |

**选定与设计**：
1. 单一 BSDF 五 lobe：diffuse（含粗糙度修正）、metal specular（GGX + Smith 遮蔽项）、transmission（IOR 驱动）、sheen（布料边缘）、clearcoat（可选次级镜面）。
2. **VNDF（可见法线分布）采样**：在"可见半球"内采样 GGX 法线而非全 NDF——同 spp 方差显著更低，且与 NEE 的 MIS 配合更干净。
3. **多散射能量补偿**：GGX 单散射在 roughness 高时能量丢失（变暗）——用解析近似补偿 lobe 按比例回填能量，不做完整多重散射模拟（过重）。
4. lobe 选择与权重比完全由样本流哈希决定 `[D]`。

**超越点**：VNDF 采样 + 多散射补偿 + 与 random walk SSS/transmission 共用"表面穿越"原语（见 §4）——一套表面框架覆盖 opaque/金属/玻璃/皮肤四种观感，参数全部对齐 glTF metallic-roughness（零转换，见 §12）。

**可落地**：~350 行。风险：无算法风险，参数默认值决定默认观感（预设调校覆盖）。

## 4. random walk SSS（B2）

**问题**：半透明材质（皮肤/蜡/玉石/牛奶）的次表面散射光传输。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| dipole BSSRDF | 中（薄几何/高曲率失真） | 好 | 中（diffusion profile 求解） | 优 |
| 路径分裂 dipole 系 | 中高 | 中 | 大 | 中 |
| **random walk（介质内随机游走）** | 高（物理正确） | 好 | 小 | 优 |

**选定与设计**：
1. 入射点按 BSDF 采样后，按 Fresnel 折射概率进入"内部模式"（方向按 IOR 折射定律偏转，全反射即留在表面）：光线穿透表面继续行进。
2. 每次行进距离按**自由程指数分布采样**——RGB 三通道各自独立的平均自由路径（radius 参数），样本由 `[D]` 哈希派生。
3. 内部碰撞点按各向同性（或 HG 反向）改变方向继续，直到**逃逸表面**（行进方向与碰撞点法线同向）；逃逸前按 Fresnel 抽样反射/逃逸——反射样本经 `[D]` 继续内部 random walk（漏掉内部 Fresnel 会超估逃逸能量，密集介质观感偏差）→ 逃逸点作为新的着色点继续正常 BSDF 路径。
4. 与体积介质共用同一个"介质内传输"原语（HG 相函数、自由程采样）——一套代码两个功能。

**超越点**：dipole 是"把三维散射拟合进二维扩散近似"——薄几何（耳朵/手指）与高曲率处误差大且参数难艺术化；random walk 是**物理本身**，参数（radius 颜色 + 各向异性）直觉化。我们因第 3 条铁律，自由程采样全函数化，无状态污染。业界现代渲染器（Cycles）也已转向此路线——我们直接出生在正确的路上，且实现量更小（复用体积代码）。

**可落地**：~120 行（media.rs 扩展）。风险：穿表面判定依赖法线方向一致 → 网格法线一致性在 glTF 导入时归一（B3 附带）。

## 5. 三合一降噪（B4）

**问题**：低 spp 路径追踪图像 → 高质量图像（无 ML 依赖）。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| OIDN 等 ML 降噪 | 极高 | 需模型 | 不可（依赖） | 不可 |
| 单层 à-trous | 中高 | 好 | 中 | 优 |
| **自适应 spp + 时域累积 + à-trous** | 高 | 好（预算更省） | 中 | 优 |

**选定与设计**（三层流水，逐层吃架构红利）：
1. **variance 自适应 spp（采样预算层）**：首遍 2spp 成对样本估方差 → 方差图指导第二遍的逐像素 spp 分配（边缘/暗部多给，平坦区少给）——同预算下 MSE 显著低于均匀采样 `[T]`。
2. **确定性时域累积（帧间层）**：预渲染序列模式下，**镜头静止**（运动相机的确定性重投影当前未设计，D-20 设计欠账，当前版本不做）→ 累积缓冲跨帧声明式复用；任意 seek 单帧模式自动退化为单帧空域。声明在 DSL（`accumulation across-frames`），不猜。
3. **à-trous 空域（像素层）**：联合双边小波孔洞迭代 5 次，稀疏核间距 2^i 递增；边缘引导特征 = 深度 + 法线 + 反照率（路径追踪 G-buffer 顺手产出）；第 1 层的方差图同时进融合权重（方差大处降低邻域混合，避免把噪声当"细节"保住）——三层不是并列而是流水衔接。

**超越点**：实时引擎的时域累积靠运动矢量估计，运动失败就 ghosting；我们**离线确定性模式可以全量时域复用、零伪影**——这是离线渲染独有的免费午餐。三层各自可独立关闭（`noise { spatial off }`）。

**可落地**：~300 行。风险：边缘引导阈值敏感 → 预设三档（草稿/标准/电影），critic 可联动调参。

## 6. BVH 构建（SAH）与遍历（B3）

**问题**：图元集合 → 加速结构，射线求交加速。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| 均匀网格 | 低（teapot in stadium） | 中 | 小 | 优 |
| equal-count BVH | 中 | 好 | 小 | 优 |
| **SAH-BVH（桶式）** | 高 | 极好 | 中 | 优 |
| LBVH/Morton（GPU） | 中高 | GPU 极好 | 大 | 中 |

**选定与设计**：
1. 构建：自顶向下 SAH——每轴 12 桶评估分割代价（SAH = 遍历成本 × 子包围面积比），代价并列时按图元索引 tie-break（**同输入永远同树** `[D]`）；叶子 4–8 图元。
2. 遍历：近子节点先入栈的有序遍历；**固定深度显式栈**（深度上界由图元总数推导：百万图元 × 叶 4–8 → 64 层必够）——不用重启式/栈裁剪技巧，遍历序天然固定；box 求交用保守判定（tmax 微量外扩）消除浮点边界漏交。附注：求交全程不用 fma 内建（或全局统一使用）——浮点融合乘加是跨平台逐位一致的隐形杀手。
3. 图元内命中：Möller–Trumbore，t 并列时按图元内索引 tie-break。

**超越点**：BVH 本身无花活（SAH 是正解，不自作聪明）；超越点在**确定性构建与遍历**——同场景跨平台同树、同遍历序、同浮点序 → md5 一致（§24 增量渲染与 golden-file 的地基）。

**可落地**：~250 行。风险：无。

## 7. mesh→SDF 烘焙（B3）

**问题**：三角网格 → 距离场（稀疏 brick 存储）。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| 精确最近点全空间查询 | 极高 | 极慢 | 小 | 优 |
| 射线奇偶判内外 | 中（射线歧义） | 中 | 小 | 中 |
| **稀疏 brick + 广义 winding number 判内** | 高 | 好 | 中 | 优 |

**选定与设计**：
1. 空间稀疏化：brick 8³ 哈希网格，仅表面附近 brick 精确化（远场用距离下界，够域算子用）。
2. 距离：brick 内对候选三角（经 brick 邻域过滤）直接最近点查询——近场精确。
3. 内外判定用**广义 winding number**（对开放网格鲁棒，射线奇偶法的歧义从这里来）；求值**直接复用 §6 BVH**（每节点增存实体角和，一树两用，O(log n) 查询）——朴素逐三角形求和 O(n)，烘焙百万面模型会慢到不可用；判定失败（病态网格）按 exterior 处理 + 警告（永不静默）。
4. `[S]` 烘焙结果注册进子图签名缓存——同模型全场景只烘焙一次；产物与程序化 SDF 同表示 → **CSG/域算子/域扭曲对现成模型立即生效**。

**超越点**：常规引擎导入 mesh 只是 mesh；我们**导入即获得无限细节（displace）、布尔组合、域变形能力**——"资产进程序化生态"。

**可落地**：~300 行。风险：非水密网格内外判定边缘情况 → winding number 天然容忍，残余退化走警告路径。

## 8. XPBD 统一求解器（B7）

**问题**：刚体/软体/布料/关节 + 接触碰撞的统一动力学求解。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| Bullet 式 impulse solver（刚体）+ PBD（柔体）双栈 | 中 | 好 | 大（两套） | 中 |
| FEM | 极高 | 慢 | 大 | 中 |
| **XPBD 统一（一套约束求解）** | 高（稳定） | 好 | 中 | 优 |

**选定与设计**：
1. **万物皆粒子 + 约束**：刚体 = 刚性粒子云 + shape matching 约束（每步求最优刚体变换对齐）；软体 = 距离/体积约束粒子云；布料 = 距离/弯曲约束网格；关节 = 两刚体粒子云间的附加约束（铰链/滑槽/限位各是一种约束梯度形式）。
2. **XPBD 核心**：每约束带 compliance α（软硬度），每子步：位置预测 → 按约束梯度修正位置，拉格朗日乘子 λ 累积——**刚度与迭代次数解耦**（PBD 的顽疾）。
3. **Substepping**：固定小步长（如 1/240s×n），"小步比多迭代稳"；步数固定 → 确定性。
4. 求解顺序按粒子/约束 id 排序（消除浮点顺序抖动，路线图工程约定）`[D]`。
5. 碰撞：粒子 vs **SDF**（B3 的 mesh→SDF / 程序化 SDF）——任意形状容器的碰撞 = 距离查询 + 梯度推出。`[S]`

**超越点**：Bullet 系需要"刚体 impulse + 柔体 PBD"两套求解器两套调参；我们**一套 XPBD 通吃四类物体**，且刚体无需四元数积分链（shape matching 替代）；碰撞吃 SDF 生态（任意 mesh 容器/地形免费获得精确碰撞）。

**可落地**：~400 行（含关节族）。风险与诚实取舍：① shape matching 最优旋转需 3×3 极分解 → 固定迭代数解析近似，确定性可控；② 粒子云刚体自由飞行存在轻微数值耗散（角动量非严格守恒）——视觉动画可接受，物理教学级精度不在引擎目标内（诚实边界）；③ 碰撞后的摩擦/弹性 = 切向速度阻尼 + 法向 restitution，同为 XPBD 约束形式——不引入第二套碰撞代码。

## 9. SPH 流体（2D 先行）（B7）

**问题**：液体表面/液滴/飞溅动画。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| 欧拉网格（Stable Fluids） | 高（烟优） | 中 | 中大 | 中 |
| 经典 SPH（力基） | 中（粘度不稳） | 好 | 中 | 中 |
| **PBF（位置基流体，并入 XPBD）** | 高 | 好 | 小（复用） | 优 |

**选定与设计**：
1. **流体 = 粒子 + 密度约束**：每个粒子带"密度=静水密度"约束，进 XPBD 统一求解——流体不是独立求解器，是约束家族新成员（与 §8 同框）。
2. 邻域：空间哈希网格（每子步重建，cell = 核半径）；2D 先行，3D 结构同构（GPU compute 移植位）`[J]`。

**超越点**：业界常见"物理域四分家"（刚体引擎/布料引擎/流体引擎/软体引擎）；我们**流体是 XPBD 的一种约束**——物理系统单一心智模型，耦合（粒子推布料、流体冲刚体）天然免费。

**可落地**：~200 行（复用 xpbd.rs + 空间哈希）。风险：粒子数与子步数的预算平衡 → 草稿/标准/电影三档预设。

## 10. Voronoi 破碎（B7）

**问题**：物体受击 → 碎片生成 + 碎片运动模拟。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| 均匀 Voronoi 预碎 | 呆板 | 好 | 小 | 优 |
| **噪声扰动 + 冲击密度自适应 Voronoi** | 高 | 好 | 中 | 优 |
| 物理裂纹扩展 | 极高 | 极慢 | 不可 | 差 |

**选定与设计**：
1. 切割：3D Voronoi 站点由种子派生 `[D]`，**先对站点加噪声偏移再做 Voronoi 切分** → 碎片边缘自然不规则（均匀 Voronoi 的"饼干感"消除）；扰动站点而非切割平面——相邻单元共享同一平分面，无缝性自动保持（逐平面独立扰动会使共享面两侧取值不一致，产生缝隙/重叠）。
2. **冲击密度自适应**：站点密度随"距冲击点距离"衰减——撞哪碎哪，远处大块。
3. 碎片运动：每个碎片 = 粒子云 + 内部约束，**入 XPBD 求解**——破碎在数据结构上就是"约束重分配"（删跨界约束，留碎片内约束，增碎片间接触约束）。与 §8/§9 同框。
4. 嵌套破碎（二次撞击再碎）= 对碎片子云重复同一算子。

**超越点**：业界常是"预碎资产 + 独立刚体模拟"两段式（破碎与模拟脱节）；我们**破碎 = XPBD 约束重分配**——同一确定性求解器，同一次冲击两次模拟结果逐字节一致。

**可落地**：~250 行。风险：3D Voronoi 切割的网格布尔运算实现量不小 → 用平面切割半空间序列实现（每碎片 = 半空间交集序列），避开通用布尔。

## 11. Spring 解析解（A2）

**问题**：阻尼谐振子初值问题的精确位置 x(t)。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| RK4 数值积分 | 高（有漂移） | seek 需 O(t/dt) 重放 | 中 | 中（累积浮点） |
| **闭式解析解** | 精确 | O(1) | 小 | 优 |

**选定与设计**：
1. 按 ζ（阻尼比）三况闭式：欠阻尼 `x(t)=e^(−ζωt)(A·cos(ωd t)+B·sin(ωd t))`，临界/过阻尼对应实根形式；A/B 由初值条件闭式解出。
2. **seek 即求值**：任意 t 直接代入——数值积分方案 seek 到 t 需从头重放积分（O(t/dt)），解析解 O(1)。这正是"确定性纯函数"对"步进状态机"的降维替代 `[D]`。
3. **目标追踪扩展**（动效常态是"目标在动"，纯初值解不够用）：把目标轨迹按关键帧分段（分段常量/分段线性），每段用对应输入的**解析响应**（阶跃响应/斜坡响应均有闭式）拼接——仍是纯函数、O(段数) 求值，seek 语义完整保留。
4. 附注：t 大时 e^(−ζωt) 下溢 → 钳为收敛态；ωd 用高精度常量。

**超越点**：业界动效库（含旧引擎 expressions.inertia）几乎全是数值步进；解析解**永不发散、seek 零成本、逐字节可复现**——三者数值积分一个都给不了。

**可落地**：~80 行。风险：无。

## 15. halation + 科学化胶片颗粒（B14）

**问题**：数字图像 → 胶片质感（高光泛红光晕 + 曝光相关颗粒）。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| 单层 bloom 变色 | 假 | 极好 | 极小 | 优 |
| **多级单向扩散 halation + 双尺度颗粒** | 高 | 好 | 小 | 优 |
| 光谱传输物理模拟 | 极高 | 慢 | 大 | 中 |

**选定与设计**：
1. **halation**：亮度阈值提取高光层 → **单向扩散链**（递归 box blur，8–12 级，每级半径倍增，逐级衰减）→ 按波长权重染色（红光穿透胶片基底更深、反射回感光层——所以是红晕不是白晕）→ 加算回主图。关键是"单向多级"（光晕向外渗）与"染色"（bloom 是白光，halation 是红光）。

## 17. 噪声族（A3）

**问题**：确定性连续随机场（一切程序化的原料）。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| sin 大数法 hash | 差（平台相关） | 好 | 极小 | **不可**（浮点三角跨平台不一致） |
| Perlin 经典 | 中 | 好 | 中 | 优 |

**超越点**：噪声是"最简单的算法"也是最容易被做坏确定性的地方——**整数 hash 路线是确定性义务而非风格选择**；fbm+域扭曲与 UV warp/SDF 域算子互通（同一噪声既画云也扭几何）。

## 19. 视频时间映射（B11）

**问题**：引擎时间轴 t → 素材内时间/帧索引（+ 音画同步）。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| 状态机播放头 | 中 | — | — | **不可**（状态不可 seek） |
| **纯函数映射 + 帧间混合** | 高 | 极好 | 小 | 优 |
| 光流插帧 | 极高 | 不可 | — | — |

**选定与设计**：
1. **三段纯函数**：标准化 `u = t/dur` → 模式映射（direct=clamp；loop=`u mod 1`；pingpong=三角折返 `1-|1-2(u mod 1)|`；变速=k 为常量时直接重映射 `u' = u·k`；k 为通道时 `τ(t) = ∫₀ᵗ k(s)ds` 取分段线性闭式积分（S9 可积），保证映射单调、seek 纯函数；Expr=用户表达式通道）→ 帧索引 = `floor(u'·fps)`，小数部分 = 帧间混合权重。
2. **变速的平滑**：前后两帧按小数权重 lerp（光流插帧明确不做——不切实际条款的执行样例）。
3. **音画同源**：音频轨道用**同一个映射函数 f(t)** 取样 → 音画天然对齐（±1 帧验收由共享 f 保证，不是事后校准）。

**超越点**：播放头状态机（旧引擎/播放器通病）seek 要重置状态；**纯函数映射 seek 零成本且音画共享同一 f**——确定性架构把"同步问题"消灭在表示层。

**可落地**：~100 行。风险：无。

## 20. FFT 与节拍/onset 检测（B6）

**问题**：PCM → 频谱 → 节拍/攻击点 → AudioReactive 通道。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| DFT 直接 | — | O(n²) 不可用 | — | — |
| **radix-2 FFT + 谱通量检测** | 高 | O(n log n) | 中 | 优 |
| ML 节拍跟踪 | 高 | 不可 | — | — |

**选定与设计**：
1. **radix-2 Cooley-Tukey**（窗长 1024/2048，Hann 窗）手写——蝴蝶运算固定顺序（确定性）。
2. **节拍检测**：频段能量 **spectral flux 正部**（本次谱 − 上次谱的正值和）→ 自适应阈值（滑动窗口均值 + 系数）→ 局部极大值拾取 → **拍间隔中值滤波**稳定 BPM。
3. **onset**：高频段 flux 提供更细的攻击点（鼓槌/拨弦级）。
4. 频段映射：bass/mid/air 三段 + 可配置 N 段 → 烘焙为 AudioReactive 通道（任意节点可读）`[N]`。
5. **状态可由 t 重建**：谱通量依赖相邻两分析窗——但窗内容完全由 t 与窗长决定，无隐藏累加器；任意 t 的节拍表可独立重算。准确说不是"无状态"，是"状态 = 纯函数(t)"。

**超越点**：检测算法本身取正解不炫技；**价值在全流程确定性**——业界音频库多用内部状态/线程，seek 重放不可复现；我们"同曲同种子同节拍表"（节拍表可缓存进签名缓存）。

**可落地**：FFT ~120 行 + 检测 ~150 行。风险：复杂音乐节拍主观性 → 阈值系数暴露为参数。

## 21. EBU R128 响度归一（C4）

**问题**：混音输出 → 目标响度（LUFS）。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| 峰值归一 | 听感错 | — | 极小 | — |
| RMS | 过时 | — | — | — |
| **ITU BS.1770 K 加权 + 门控**（=EBU R128） | 标准正确 | 好 | 中 | 优 |

**选定与设计**：
1. K 加权预滤波（高频架式 +4 dB + RLB 二阶高通，系数取 BS.1770 表格）→ 400ms 方块能量 → 双门控（绝对 −70 LUFS + 相对 −10 LUFS）→ 门内均值响度 → 增益差。
2. 方块顺序固定遍历（块划分按 BS.1770；端点补零策略按 EBU Tech 3341 测试向量校准——BS.1770 本身不定义端点处理，验收直接用 3341 向量集对拍，防短信号响度系统性偏低）`[D]`。
3. 附注：这不是"选算法"而是**实现标准**——价值在零依赖自研（业界靠 ffmpeg loudnorm），验收 ±0.5 LU 对拍 1kHz 正弦与粉噪。

**超越点**：标准无超越空间，**"引擎内建"本身是超越**（交付管线不需要外部工具就达到平台响度合规）。

**可落地**：~150 行。风险：无（滤波器系数为标准常量）。

## 22. 作曲系统（B13）

**问题**：种子 + 情绪/风格参数 → 音符序列（音符事件流）。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| 马尔可夫链（语料驱动） | 依赖语料 | 好 | 中 | 中（易跑调） |
| **和声语法状态机 + 模板织体** | 高（听感稳） | 极好 | 中 | 优 |
| 搜索式生成（评估循环） | 极高 | 慢 | 大 | 中 |

**选定与设计**（四层漏斗，全部确定性）：
1. **调式层**：种子 → 音阶（大小/五声/中古调式库）+ 根音。
2. **和声层**：**功能语法状态机**——T（主）→S（下属）→D（属）→T 的进行语法图 + 种子驱动的路径选择（每步在合法后继中按哈希加权挑选）→ 和弦序列。语法保证"永远在调上"，种子保证"不重样"。
3. **织体层**：每和弦按模板分配音符——琶音模式库（上行/下行/穿透）、柱式、bass line（根音+五音律动）、节奏 step 网格（密度参数控制休止概率）。
4. **约束过滤层**：音域钳制、声部间距、相邻小二度冲突过滤——规则链确定性过滤。
5. 情绪参数（4 情绪）映射到：速度/调式倾向/密度/音区——模板差异而非随机差异。

**超越点**：马尔可夫需要语料且长程结构弱（跑调跑出调性）；**功能语法状态机 = 少量代码锁定"听感合理"的骨架**，织体模板库提供变化——业界程序化配乐（含旧引擎 4 情绪）升级为"语法+模板"结构，情绪从"参数微调"变为"语法层差异"。

**可落地**：~400 行。风险：听感审美主观 → 4 情绪 golden 样例 + 用户听感反馈迭代（与 AI mock 流水线同构）。

## 23. 采样回放插值（B12）

**问题**：采样波形 → 任意音高的连续回放（采样器核）。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| 线性插值 | 有高频噪声 | 极好 | 极小 | 中（浮点相位漂移） |
| **Catmull-Rom + 定点相位累加器** | 高 | 好 | 小 | 优 |
| 带 sinc 重采样 | 极高 | 慢 | 大 | 中 |

**选定与设计**：
1. **Catmull-Rom 四点三次插值**（等价三次 Hermite）——音质/成本甜点：比线性少可闻混叠，比窗口 sinc 轻 10 倍。
2. **定点相位累加器**：读取位置用整数定点（如 Q32.32）累加音高比——**浮点相位长序列累加会漂移**（业界采样器的隐性不确定源），定点累加保证逐字节复现 `[D]`；音高比计算禁 pow（libm 跨平台差 1 ulp 即改变定点增量，D-29）——按 2^(k/1200) 音分格点查表（表内插值用确定性数学件）。
3. SFZ 层：文本格式解析（region/opcode 子集：key/pitch/loop/envelope）→ 循环点区间回放 + ADSR 包络复用合成器代码。
4. 附注：音色库 = CC0 精选小库（钢琴/弦乐/鼓各一）内嵌，外部 SFZ 目录加载优先。

**超越点**：**定点相位累加器**是把确定性铁律推进到音频采样层的具体设计——业界采样器几乎全是浮点相位（长演奏不可复现）；插值取甜点不攀 sinc。

**可落地**：~120 行（不含 SFZ 解析 ~80 行）。风险：音色库授权与体积（选库时记录来源与体积，内嵌数据走 D-12 同款审查）。

## 24. 增量渲染脏区间（C3）

**问题**：节点参数变化 → 需要重渲染的最小帧区间与最小子图集合。

**候选对比**：

| 算法 | 质量 | 效率 | 实现量 | 确定性友好 |
|---|---|---|---|---|
| 全量重渲 | — | 最差 | — | — |
| 场景级缓存（旧引擎） | 中 | 中 | 中 | 中 |
| **子图签名树 + 帧区间推导** | 高 | 极好 | 中 | 优 |

**选定与设计**：
1. **子树哈希自底向上**：节点签名 = hash(参数序列化 + 各子签名 + 本节点动画通道在时间轴上的"变化特征")——参数变更只影响**自身到根的祖先链**，兄弟子树签名不变 → 直接命中缓存。
2. **帧区间推导**：通道分类——Const（不变）/Track（关键帧密度给出"分段常区间"）/Expr/Spring（给出 Lipschitz 界：表达式解析出上界变化率，或保守用"逐帧变化"）/AudioReactive（烘焙表区间）。参数静态变更 → 全帧但仅该子图；动画帧变更 → 只脏受影响帧区间。
3. 缓存键 = `(子图签名, 分辨率, spp 档, tile, engine 版本, schema_version)`（宪章 R3；与架构 §4.2 五元组咬合，tile 维度与 §4.1 query 一致）。
4. **[T]** 红利：路径追踪的累积缓冲按同一签名缓存——签名不变即累积续用。

**超越点**：旧引擎场景级缓存 → 我们**子图级 × 帧区间级双维复用**：改一个 TextNode 的颜色，1080p×10s 序列只重渲该子图（reuse_ratio ≥0.5 验收）；签名树让"哪些没变"成为可证明的（哈希相等），不是启发式猜测。

**可落地**：~250 行。风险：Expr 无解析界时保守逐帧 → 如实标注保守档。

## 25. 附录：核、对偶、格——统一数学视角与红利保证书

> 2026-09-29 数学科研模式三轮探究的沉淀。**核**回答"算什么"，**对偶**回答"在哪一侧算"，**格**回答"确定性的家在哪"，**保证书**回答"红利为何成立"。拿到任何新算法先问三问——核是什么？配对哪一侧？格点锚定了吗？——三问问不出不立项（D-21 的操作化）。

### 25.1 核（Kernel）＝完全决定一个映射的最小对象

代数的核（ker φ 决定同态，第一同构定理）与分析的核（K(x,y) 决定积分算子）是同一思想的两面。核在本引擎中的五种化身，每种都是数学主干分支：

| 化身 | 数学分支 | 引擎实例 |
|------|---------|---------|
| 卷积核 k(x−y) | 调和分析 | blur / halation 渗光 / K 加权 / 插值 / à-trous（多尺度=核的尺度族） |
| 格林函数 | PDE/物理 | **Spring 闭式解=冲激响应**；热核=拉普拉斯的格林（扩散/渗光链=热核幂）；eikonal（SDF 的来源方程） |
| 转移核 | 概率论 | **路径追踪与 random walk SSS=转移核下的随机游走** |
| 协方差核 | 高斯过程 | §17 噪声族（fbm=核的谱合成，域扭曲=坐标随机场） |
| 再生核 | 逼近论/RKHS | Catmull-Rom / 样条关键帧（**自然样条=RKHS 极小范数插值，定理级事实；Catmull-Rom 为插值格式非变分极小元**）/ ACES 分段拟合 |

**§1–24 重述：24 项 = 六种核求逆策略**（解算子方程 f = g + Kf）：

| 求逆策略 | 条目 |
|---------|------|
| 精确逆（格林函数闭式） | §11 Spring、§19 时间映射 |
| 随机逆（Neumann 级数的蒙特卡洛实现） | §1 路径追踪、§4 random walk SSS |
| 局部逆（牛顿法打核的窄峰） | §2 MNEE（焦散=核的高阶窄峰） |
| 正则化逆（病态求逆加先验） | §5 降噪、§18 抠像 |
| 迭代逆（近端算子不动点） | §8–§10 XPBD（Moreau 包络本身是光滑核） |
| 谱逆（对角化后相除） | §20 FFT |

渲染与降噪由此统一：**同一个算子方程的两种数值策略**（随机求逆 vs 正则化求逆）。

### 25.2 对偶/配对：决定"在哪一侧算"

| 对偶对 | 交换公式 | 引擎选侧决策 |
|--------|---------|-------------|
| 边界↔体 | Stokes/散度定理 | mesh（编辑侧）vs SDF（组合/碰撞侧）→ §7 烘焙=对偶切换，切换后边界算子（法线/曲率）全部变场算子（∇、Δ）；**广义 winding number 的连续原型=边界实体角积分** |
| 样本↔测度 | ⟨Σδᵢ, f⟩ = ∫f dμ | 蒙特卡洛；**重要性采样=选让配对方差最小的表示侧** |
| 时域↔频域 | 傅里叶变换 | 节拍检测（频域对角化）vs 时间映射（时域精确） |
| 原问题↔乘子 | 拉格朗日对偶 | XPBD 的 λ=约束力的对偶变量 → 免费输出"约束残余"质量指标 |
| 内容↔摘要 | 哈希 | §24 签名缓存；安全性=生日界显式计算（25.4） |

**Nyquist 横贯定理**（连续↔离散转换规范，配对+核+格的合流处）：空间（像素重建滤波）、时间（**shutter 核=运动模糊**）、音频（重采样插值核）、几何（距离场渐变）四次现身——**运动模糊与像素重建是同一核族在不同轴的参数化，统一实现**；B1 的随机 shutter 采样=该核的随机求积，与后效确定性模糊是同一核的两种求积策略。

### 25.3 格（Zᵏ）：确定性的家

- 整数结构（hash、定点相位 Q32.32、帧号、样本索引、维度）生活在格 Zᵏ 上——**格是离散群，运算精确，确定性是定理而非承诺**；
- 浮点只承担格点之间的局部插值（Sobol 逆、Catmull-Rom、积分器内步进）——插值端点均为格点，漂移无累积通道；
- [D] 红利的数学表述：**把状态空间压到格上，把连续性压到核里**。

### 25.4 红利保证书：这些红利为什么成立

1. **不变性→免费（Noether 式）**：确定性 = 对执行历史的不变性（→任意像素任意 pass 独立重算）；"什么可以缓存"不是启发式——**找到不变量，缓存即定理**，§24 签名=对称性检测器。
2. **压缩映射→收敛保证（Banach）**：XPBD/投影求解=不动点迭代，压缩系数给出子步数与迭代数的选择依据；**Neumann 级数收敛条件（谱半径≤1）⇒ 多散射能量不增益（物理能量守恒的单向保证，逆命题不 claim）**——§3 多散射补偿不只是观感问题，是收敛性保障：物理正确 ⇒ 数学可收敛。
3. **内容寻址→缓存完备性（Merkle）**：§24 签名树与 git 同构；256 位哈希、10⁹ 条目下生日界碰撞概率 ~10⁻⁵⁹——缓存正确性有数字保单。
4. **逼近阶=质量定价**：质量不是玄学，是收敛阶——Sobol O(1/N) 对纯随机 O(1/√N) 的量级差给出 10 倍 spp 折扣；草稿/标准/电影三档预设 = 逼近阶的显式标价。

### 25.5 工程纪律导出

1. 新算法三问（核是什么/配对哪一侧/格锚了吗）不通过不立项；
2. 运动模糊与像素滤波共享核族实现——一套代码两个轴；
3. XPBD 求解器免费输出约束残余（λ）作质量指标；
4. 性质测试按核类做一次：对称/归一/正定/平移不变（→可 FFT），12 结构各一次覆盖全部功能；
5. 结构是发现不是设计：禁止为统一而统一造上帝对象（D-22 纪律重申）。

## 26. 确定性并行：固定形状归约代数（账四·用户指令最先偿还）

**问题**：浮点加法不结合——(a+b)+c ≠ a+(b+c)。并行归约的结合序由调度与时序决定 → 结果随执行拓扑漂移 → 确定性破产。业界常规解法是牺牲确定性换吞吐（原子浮点加），与铁律二正面冲突。**用户裁定（2026-09-30）："账四最先可以还，用一个好算法，可以保障双边"**——不是在"确定 or 快"里取舍，而是找到让两者同真的结构。

**核心构造（固定形状归约）**：规定归约树的**形状是输入规模 n 的纯函数**，与执行拓扑（核数/线程数/机器数/时序）完全解耦：

- 形状取平衡 pairwise 二叉树：每层相邻成对，奇数尾元素直接进位下一层；形状函数 `reduction_shape(n)` 全引擎唯一实现（prism-core 单点定义）；
- **双边保证**：①确定性——相同 n 必得相同树、相同浮点结合序，任意拓扑逐位一致（**并行求值结果 ≡ 串行参考结果，逐位**；"串行参考"定义为对同一 `reduction_shape(n)` 树的固定顺序求值——串行是该形状函数的退化情形，二者为同一树的两种遍历，命题才是定理）；②并行性——树深 ⌈log₂n⌉，吞吐随核数扩展；代价仅是相对原子加的固定序开销，换来 md5 级可复现。**基线注记**：既有 golden 基线在归约上树后一次性全量重基线（数值等价、逐位可能不同），走宪章 C15 渲染行为变化清单。

**工程四律**：

1. **形状唯一**：任何归约点（多采样求积、合成混合、粒子邻居求和、光子图统计）不得私定结合序，一律走唯一形状函数；
2. **安全区优先**：帧级（帧间无依赖）与 tile 级（tile 无关求值）是天然并行安全区，不涉归约；固定树形只用于帧内跨节点浮点合并；
3. **消序用排序**：无序集合（碰撞对/邻居列表）先按节点 id 排序再处理——既有确定性纪律的推广；
4. **分布式同树**：跨机分片按同一形状函数切分（任务=帧号区间，路线图 §2.6 地基），合帧 md5 校验——U8 农场的确定性免费继承。

**验收判据**：并行求值 md5 == 串行求值 md5（同种子同图逐位一致）——这是账四的还清标准，进 10/2 基座实测窗口的首个验收项。**归约层级显式声明**：当前全部归约发生在像素内（n=spp）与混音（按轨 id 序），天然安全；**禁止跨 tile 浮点归约**（确需跨 tile 合并时按同一形状函数全局重算——分片后合并的结合序与全局树可差末位，n=5 即有反例）。
**实装时序**：规格随 A1 定型（求值序语义的一部分，P0 骨架先行，D-4）；实装与压测在 10/2 验收点。
**架构红利记账**：本节是 D-21 的直接应用样例——"形状是规模的函数，不是执行环境的函数"一句同时给出两边保证；反过来说：**确定性不是并行的约束，是归约代数的免费定理**。
