### ❌ 待接线（本轮**不能**测，如实标注）

**四核心场景的手机端业务模块在本仓中不存在。** 全仓 25 个 crate 里：

- **没有任何 `wasm_bindgen` / `web_sys` / `js_sys` 引用**（全仓 grep 零命中）——
  这意味着 Rust 侧**没有**任何跨 JS 的绑定层。
- **没有** `prism-ui` / `prism-mobile` / `prism-chat` / `prism-social` 类 crate。
- `prism-app` 是 **CLI + 编辑器 wasm**（`batch`/`mcp`/`http`/`pack`/`critique` 五个命令），
  **不是**手机 App 外壳。
- `prism-ai` 提供的是 `Provider` trait + `mock` + `journal`（**native 侧的推理/文本管线**），
  **没有**对话历史、会话、角色等社交数据模型。

⇒ **AI 角色聊天 / 通讯录 / 发现页 / 个人中心 四个场景，一律标注「待接线」。**
本轮在真机上能测的是**渲染/计算正确性**，不是这四个业务场景。
把它们写成"可测"就是编造，本清单拒绝这么做。

### 事实纠正（与任务书/直觉不符，按实测为准）

1. **`[profile.wasm]` 不在 `.cargo/config.toml`**，而在**仓库根 `Cargo.toml`**
   （`inherits = "release"` + `opt-level = "s"` + `lto` + `panic = "abort"` + `strip`）。
   `.cargo/config.toml` 里只有 `[alias] xtest`。构建脚本按根 `Cargo.toml` 解析，一致。
2. `.cargo/config.toml` 里的 `target` 是 symlink → `/root/.codebuddy/artifact/prism-build-target/target`，
   wasm 走独立 `target/wasm32/`，**不污染** native target（CI 有断言复核这一点）。

## §1 开跑前检查（每次开测前跑，3 分钟）

```bash
cd /workspace/media-engine

# 1) wasm 产物能出（增量，通常 < 10 秒）
cd crates/prism-gpu/web && ./build.sh --no-test

# 2) 静态结构校验（产物存在 / 21 导出 / 14 导入）
node crates/prism-gpu/web/ci_wasm_verify.mjs crates/prism-gpu/web/prism_gpu.wasm

# 3) 源码没被幽灵写入搞坏（账七开跑前也确认一次）
node tools/ghost_guard.mjs --check --no-compile

# 4) 起本地服务（同源 http 才能用 WebGPU；file:// 多数手机浏览器会拒绝）
cd crates/prism-gpu/web && python3 -m http.server 8080
```

**手机访问**：与电脑同一 Wi-Fi，浏览器打开 `http://<电脑内网IP>:8080/index.html`。

> ⚠️ **iOS Safari 不支持 WebGPU**（截至 2026-10仍无原生支持）。iPhone 只能做
> "页面能打开、wasm 能下载、报错信息可采集" 这三项，**跑不了 GPU 用例**。
> Android Chrome / Chrome for Android 才是 WebGPU 主力目标。

**接线步骤（如实给出，不含糊）**：

1. **缺 Rust↔JS 绑定层**：全仓零 `wasm_bindgen`。需新增 `prism-web` crate，
   依赖 `wasm-bindgen` + `web-sys` + `serde-wasm-bindgen`。
   ⚠️ **与「零第三方 crate」铁律冲突** → 需主理人裁决：要么豁免这条铁律，
   要么改用 `prism-gpu` 现有的**手写 C ABI** 风格（`prism_alloc` / `prism_result_ptr`
   那套，JS 侧直接读写线性内存）。**推荐后者**：不破坏铁律，且已有先例。
2. **缺业务数据模型**：需要 `Conversation` / `Character` / `Contact` 等类型。
   本仓 `prism-ai` 只有 `ProviderRequest` / `ProviderResponse` / `Provider` trait，
   **无会话概念**，须新增。
3. **缺 UI 外壳**：`prism-app` 是 CLI，不是手机 App。需要一个能加载 wasm 的
   HTML 外壳 + 页面路由（可参考 `prism-gpu/web/index.html` 的加载方式）。
4. **接线完成后**，把 T-10~T-14 的"待接线"改为具体步骤，并**先在桌面 Chrome
   跑通再上手机**。
