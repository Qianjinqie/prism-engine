## 1. TL;DR（三个最重要的发现）

**发现一：扩散模型 = 我们 S11 扩散结构的神经特解，不需要 S13。"网络前向 = 核求逆第七种策略"经查证应精确表述为：扩散先验解逆问题在数学上已被证明等价于传统正则化优化（数据保真项 + 扩散先验项，SIAM 2025 定理级结果）——即白皮书 §25.1 六种求逆策略中"正则化逆"的数据驱动特解；同时从算子视角看，"从数据中学出求逆算子（去噪链）"替代"手工构造求逆算子（牛顿/近端不动点/MC 级数）"，构成第七种策略"学习逆"的实质。** 两者在架构上汇于同一落点：S11 新特解 + 对偶表新增"观测↔先验"一对。行业实证同步到位：OIDN 3（2026 H2）正从直接预测转向**核预测**（网络输出滤波核系数而非像素）——业界在向"网络学核、不替代核"收敛，与白皮书 §25"核 = 完全决定一个映射的最小对象"的立场不谋而合。

**发现二：定点整数推理已获"逐字节可复现"的学术定论，与白皮书 §25.3 格理论逐字同构。** 2026 年测量研究证明：INT8 量化 + 每层边界再量化（QDQ 图，H1+H2 机制——离散网格输入使卷积调度确定 + 层界回格）使推理结果跨 ARM 微架构 **500/500 逐位一致**，而 FP32 在同样条件下全部漂移（尾数损失 ~8 bit）；DCVC-RT（CVPR 2025）已把 int16 确定性整数化作为 NVC 的工程标准件（查找表处理非线性）；安全关键领域已有纯 C 定点推理先例（Q16.16，零动态分配）。**这正是"把状态空间压到格上，把连续性压到核里"在神经层的实例：权重与激活锚定在整数格上，浮点只允许出现在格点间的标定插值里。** 结论：铁律二（全链确定性）对神经前向**不构成豁免需求**，构成格锚纪律的延伸——账一吸收战的算术基础已备。

**发现三：U9 的两个吸收战武器均已成熟为独立学派，且与既有架构结构同构。** ① INR 压缩（NeRV 系）把"视频压缩"化为"模型压缩"：编码 = 拟合、解码 = 前向推理、码流 = 权重——落点是 S12 实体表示的新特解（"INR 媒体特解"），解码确定性由发现二的定点格保证，时域由 Graph(t) 纯函数（t 是网络输入坐标）原生承载；② 条件编码（DCVC 系）以"时间上下文传播 + 特征域条件"取代残差，Shannon 熵分析证明残差编码是条件编码的受限子集——其"上下文跨帧传播"与我们的签名缓存帧间增量、DCVC-FM 周期刷新与 schema_version 失效机制一一对应。**我们不必造 NVC；我们把 NVC 的数学骨架吸收为 Graph(t) 时域特解，把 3DGS/视频资产经 Dual 通道进 SDF 生态。**

### 2.2 神经渲染范式演化（NeRF → 3DGS → 后续）

- **范式时间线**（来源：radiancefields.com Timeline、NeRF 五年综述 arXiv 2210.00379、Apolo 2025 年度综述）：NeRF（2020，网络权重即场景）→ Instant-NGP（2022，多分辨率哈希编码，训练快 2–3 个量级）→ Zip-NeRF（2023，保真 SOTA）→ **3DGS（SIGGRAPH 2023，显式基元，实时化拐点）**→ 3D Gaussian Ray Tracing（NVIDIA 2024，光追处理折射/镜面/DOF）→ SVRaster（CVPR 2025，体素路线，证明"无网络无基元"也具竞争力）→ Triangle Splatting（2025，可微三角形、mesh 管线兼容）→ Radiant Foam（ICCV 2025，多面体泡沫 + 可微光追）→ 3DGUT（2025，265+ FPS，失真相机 + 次级光线）。
- **生产化信号**：Houdini 原生 splat 表示（GSOPs，2025）；4DGS 流式进 WebXR/头显（2026）；**米兰冬奥转播采用 3DGS 回放（2026）**——范式已进主流生产。
- **压缩支线**：HAC++（2025，哈希网格辅助上下文建模，100× 压缩）、FCGS（免优化压缩）——百万高斯的存储瓶颈正在被攻克。
- **范式迁移方向**：NeRF 与 3DGS 从竞争转为互补（初始化/正则化，ICCV 2025"NeRF Is a Valuable Assistant for 3DGS"）；表示层竞争焦点从"基元选型"转向"**可微渲染底座 + 表面可提取性**"。
- **与我们最相关的桥**：**GS-Pull（NeurIPS 2024）**：把 3D 高斯可微拉到神经 SDF 零水平集上联合优化（高斯离散/稀疏/离面漂移是公认痛点，SDF 是表面归宿）；**G2SDF（2024.11）**：显式高斯 + 隐式 SDF，高斯不透明度绑定到面距离。——高斯 ↔ 距离场的双向桥已有顶会级先例。

### 2.3 扩散采样与逆问题（"确定性求逆"的证据链）

- **SDE/ODE 统一**：扩散采样 = 概率流 ODE（PF-ODE）求解；DDIM 的 η 参数是随机性旋钮，**η=0 即确定性映射**；DPM-Solver/DEIS/UniPC 是专用高阶求解器（来源：扩散采样技术全景综述，innovation-cat.github.io 2025）。
- **少步化**：一致性模型（状态一致性损失：一个大步重现多个小步的复合）；轨迹蒸馏 DLMS（ICLR 2025，9K 参数设计网络，5 NFE 达到手工求解器 10–15 步质量）；OSDS（2025.12，步条件 ODE + 体积一致性正则）。
- **逆问题定位（本备忘录发现一的依据）**：预训练扩散模型作零样本先验解逆问题已成体系（DPS/Tweedie 公式/ΠGDM/SMC 分类法，arXiv 2025 综述）；**SIAM 2025（arXiv 2503.10237）证明：线性逆问题的 MAP 估计 = 传统正则化优化的解，损失 = 数据保真项 + 扩散先验项**——扩散先验在数学身份上就是"学到的正则化项"。

### 2.4 ML 降噪的算法核心结构

- **OIDN（2025 年奥斯卡科技成就奖）**：U-Net（5 级编码器 + skip 连接）+ 输入特征 = color + albedo + normal（AOV 辅助特征）+ 传输函数 + autoexposure；tile 处理（感受野 174–202 px，tile 重叠半感受野，多设备分片）；**三档质量 High/Balanced/Fast**；纯 CPU 路线（AVX-512/NEON）与 GPU 并存，跨厂商（来源：Intel 官方技术文章、DeepWiki OIDN 架构页）。
- **OIDN 3（2026 H2，HPG 2025 报告）**：架构首次大改——从**直接预测**转向**核预测**（网络输出逐像素滤波核系数），并引入**时域降噪**（实时档：前帧去噪结果 + 后向运动矢量 + 深度；终稿档：加未来帧与前向运动矢量）。
- 与 OptiX 对比：OptiX 硬件绑定，OIDN 硬件无关——"CPU 一等公民降噪"有行业先例（来源：CG Channel 2026.01 报道）。
- **结构对照**（供方向提案引用）：OIDN 的 AOV 特征 ≈ 我们 à-trous 的"边缘引导特征 = 深度 + 法线 + 反照率"（白皮书 §5）；OIDN 的 tile 重叠协议 ≈ 我们的 halo 协议（A5 已验证资产）；OIDN 三档质量 ≈ 我们草稿/标准/电影三档标价（§25.4 逼近阶定价）。

### 2.5 确定性整数推理（格锚定在神经层的实证）

- **跨平台逐位一致的充分条件已找到**：INT8 QDQ（每层边界再量化）使同一 CNN 在 Cortex-A53/A72/A76 四台设备、不同微内核（SDOT vs NEON 点积）下**每个 INT32 累加器与每个输出逐字节一致（500/500）**；机制命名 H1+H2——离散网格输入使卷积 dispatch 确定性（H1），层界 QuantizeLinear 保持网格前提（H2）；反例：x86 的 PMADDUBSW 饱和 INT16 中间值破坏不变量（来源：arXiv 2607.23227《INT8 Quantization Makes ARM Edge Inference Dispatch-Invariant》）。
- INT8 可移植性测量（七类硬件对照实验）：整数核相同时预测 1000/1000 一致；不同时 958–965/1000——**"量化一次到处部署"不安全，除非固定整数算子合同**（来源：arXiv 2609.16085）。
- 安全关键先例：certifiable-inference（纯 C99，Q16.16，零动态分配，O(1) 内存，DO-178C/ISO 26262 可认证）；Integer Intelligence（INT8 + INT32 累加 + 逐层再标定，RTL 与参考实现**零失配**，来源：MDPI Electronics 2025）。
- 结论合流：**定点格合同（位宽 + 累加位宽 + 层界回格 + 固定算子集）= 神经层的 LatticePlan**——发现二的完整表述。

## 3. 方向提案（六个，每个五要素）

> 通用前提（不逐条重复）：一切"神经"均指**推理侧**——权重是数据非代码依赖（D-20 已定性，零依赖铁律不拦）；训练/蒸馏侧留应用或服务侧（D-11 边界同款），引擎只吃定稿权重；所有并行求和走 §26 固定形状归约（卷积累加、注意力加权和均在其管辖内）。

### P1 「学习逆」：扩散去噪核链 = S11 的神经正则化特解

- **数学核心**：正则化逆的算子方程 x* = argmin ‖y − Ax‖² + λR(x)，其中 R 由扩散模型隐式承载（SIAM 2025 定理）；采样侧 = PF-ODE 确定性积分（DDIM η=0），一致性蒸馏把 N 步压成 1–4 步映射；网络学习的对象是**去噪核的参数化**（每步去掉一个频带的噪声 ≈ 热核幂的逆过程），不是核的概念本身——§25 五化身无一失效。
- **架构落点**：**S11 扩散结构新特解"神经正则化降噪"**（宿主 prism-postfx）；三问——核 = KernelKind::GreenFunction（热核族，与 à-trous 渗光链同族）；对偶 = **DualityPair 新增枚举值 ObservePrior（观测↔先验）**，本文对架构的第一个贡献：现有五对偶装不下"数据保真项↔正则化项"的配对，逆问题家族（降噪/抠像/去模糊）今后共享此对；格 = LatticePlan::LatticeAnchored（P2 定点格合同 + Sobol/哈希仅用于可选随机档）。能力面：apply = 前向去噪一步，invert = 声明不支持（正则化逆本身就是"逆的实现"），sample = 确定性档无随机（随机档经 S4）。开发者面友好名：`denoise neural`（预设档）——别名层自动接通。
- **与既有红利的关系**：确定性（P2 格锚 + η=0）→ 逐字节可复现；签名树（权重哈希 + 输入 AOV 签名 → 中间特征缓存与跨帧复用免费）；CpuRef 判对（CPU 定点实现为一等后端，OIDN 先例；GPU 实现作同层求积策略互判）；属性通道（去噪强度/步数/档位全是通道参数）；三档标价 = NFE 数（1/2/4 步 = 草稿/标准/电影）。
- **可行性评级：高。** 理由：数学身份已定理化（无理论风险）；OIDN 3 证明 U-Net 级网络 CPU 可跑且 4核8G 沙箱可承载小模型（我们目标是 ~100K–1M 参数定点小网，比 OIDN 小两个量级）；白皮书 §5 三层降噪流水线预留了"第四层替换位"——à-trous 特解保留为判对基线，神经特解作为可选升级，永不比基线差的结构兜底。
- **最小验证实验（半天，一个 agent 批次）**：手写 3 层定点 U-Net（INT16 权重 + INT32 累加，层界再量化，~50K 参数，权重由 PCG 种子固定初始化后离线最小训练集定稿——训练量控制在单 CPU 分钟级），在 1 帧 1spp 路径追踪输出上与 à-trous 对拍。通过判据：①同输入双跑 md5 一致；②PSNR ≥ à-trous 基线 +0.5dB；③1080p tile 内单帧推理 < 2s（4 核）。三条全过 = P1 升级为可立项。

### P2 定点神经核：格锚定前向 = 铁律二的神经层延伸（使能层）

- **数学核心**：把白皮书 §25.3 格理论套到神经算子上：权重/激活锚整数格（INT8/16），累加锚宽格（INT32），非线性用查找表在格点上预计算（DCVC-RT 同款），层界回格（QDQ 的 H2 = "每层边界重新锚定"），标定缩放因子是格间插值的唯一浮点生存地——**浮点只承担格点间的局部标定，漂移无累积通道**，与 §23 定点相位累加器同一纪律。
- **架构落点**：不是新结构，是 **L0 格层新增"定点格类型" + prism-math 新增定点神经原语件**（conv2d_int / matmul_int / lut_sigmoid / requant），供所有 P 系特解调用；三问——核 = 无核服务（原语件）；对偶 = 内容↔摘要（权重文件 = 模型的内容寻址资产）；格 = 本体（这就是格层自身）。
- **与既有红利的关系**：直接把"全链确定性"从解析算子延伸到学习算子；权重哈希进签名 → 权重版本管理/缓存失效走 C13 schema_version 既有钩子；INT32 累加的并行结合序由 §26 固定形状归约管（同一树形同序）；与 GPU 求积策略互判时以 CPU 定点为参考真值（比浮点判对更强：逐位）。
- **可行性评级：高（作为 P1/P3/P4 的前置使能件）。** 理由：学术与工程先例齐备（H1+H2、DCVC-RT、certifiable-inference）；算子面小（4 个原语 ~300 行）；唯一自担决策 = 整数算子合同（位宽/累加/饱和策略全引擎唯一——H1+H2 反例告诉我们合同不统一就会碎）。
- **最小验证实验（半天）**：同一 2 层 conv 网络（INT16 QDQ）分别在 CpuRef（标量实现）与 Rayon 4 线程（不同归约切分 + §26 固定形状树）上跑 100 张 64×64 输入：判据 = 逐位一致；再做 int8/int16 两档质量-速度曲线各一（为 P1/P3 选位宽提供实测数据）。

### P3 INR 媒体特解：编码 = 拟合、解码 = 前向（U9 吸收战武器一）

- **数学核心**：信号 f_θ: (x,y,t) ↦ RGB（SIREN 型周期激活抗频谱偏差）；码流 = 量化权重 + 超先验头部；解码 = 纯函数前向——**"seek 到任意 t"是网络的原生能力**（t 是输入坐标），与白皮书 §19"播放头状态机 → 纯函数映射"同构：NeRV 系天然把视频变成 Graph(t) 可调度的纯函数源。
- **架构落点**：**S12 实体表示新特解"INR 媒体"**（宿主 prism-media），与 glTF 导入（§12）、mesh→SDF bake（§7）同列资产导入特解族；三问——核 = KernelKind::ReproducingKernel（RKHS：INR = 核机器的神经实例，NTK 视角下网络在再生核空间学习，§25 再生化身直接覆盖）；对偶 = DualityPair::ContentDigest（内容↔摘要：权重 = 内容的摘要，§25.2 已有对偶对，零扩展）；格 = LatticePlan::LatticeAnchored（P2 合同 + t 锚 Q32.32 定点相位）。组合方式：Feed（进 Compose 树）+ Dual（可选：INR 表面场 ↔ SDF，远期）。
- **与既有红利的关系**：解码确定性 = P2 逐位继承；seek 零成本 = S5 时间映射红利自动适用（INR 源替换视频源后 `loop/pingpong/变速` 全部原样工作）；签名缓存管中间帧解码缓存；**零第三方依赖的解码实现 = 自研定点前向（P2 原语），这正是"窄谱方法论"在神经时代的重演**——U9 的 D-17 v3 撤销理由（"做窄不如范式创新"）在此得到正面回应：INR 特解就是范式路线的窄切口（先做"引擎内生成的 INR 资产"闭环，解码器自己写、码流自己定义，无需与行业码流互操作）。
- **可行性评级：中。** 理由：解码侧高（前向简单、学术充分）；**编码侧中**——拟合耗时（文献公认分钟级/clip），但引擎场景编码是一次性离线动作（资产导入），可接受；风险 = 同码率质量不敌 H.26x 现网（诚实标注：INR 的优势在**分辨率无关 + seek + 与图生态组合**，不在绝对压缩率，定位为"资产格式"而非"交付格式"）。
- **最小验证实验（半天）**：SIREN 2 层（~30K 参数）拟合 128×128×8 帧合成动画 → INT8 量化 → 码流 = 权重文件；解码 = P2 定点前向。判据：①解码两遍 md5 一致；②同文件体积下 PSNR 不低于 MJPEG 参考值 −2dB；③`变速 2x + seek 到 t=3.7s` 走 §19 映射原样工作（读 INR 源节点）。三条全过 = INR 特解升格为 B11 的姊妹工作流候选。

### P4 条件编码 = Graph(t) 时域增量特解（U9 吸收战武器二）

- **数学核心**：条件编码 p(x_t | c_t)，上下文 c_t = 前帧解码特征的传播——Shannon 论证条件熵 H(x_t|c_t) < H(x_t − x̂_{t−1})（残差是条件的受限子集）；DCVC-RT 证明**显式运动估计可整体删除**（隐式时域建模省 21% 码率且更快）——运动补偿从"算法必需品"降级为"可选特解"。
- **架构落点**：**S12（或 S5）新特解"时域条件源"**：帧 t 的渲染/解码以帧 t−1 的签名缓存产物（特征图）作为 EvalCtx 注入的条件输入；三问——核 = KernelKind::Convolution（特征传播 = 卷积上下文）；对偶 = DualityPair::ContentDigest（条件 = 前帧内容的摘要）；格 = P2 合同。**架构侧的真实工作量在 Graph(t) 一处**：允许节点声明"跨帧条件依赖"（与既有 SimSession"固定步长 + 快照判失效"方案同族——有状态计算已被架构预案覆盖，条件编码是它的声明式特例）。
- **与既有红利的关系**：这是方向里同构度最高的——DCVC-FM 周期刷新 ≈ schema_version 失效重建；条件上下文缓存 ≈ 签名缓存帧间命中（C3 增量渲染的 reuse_ratio ≥0.5 验收直接适用）；错误传播控制（DCVC-LCG 长程上下文）≈ 我们的"签名链任意回退重算"（确定性红利的超出部分：NVC 只能前向传播上下文，我们能**任意 seek 重建**——这是范式级差异点：我们的码流可复现，业界码流不可）。**吸收战打法的表述：不是做一个 NVC 去比 DCVC，而是把条件编码吸收为渲染增量的数学结构，反向获得 NVC 没有的任意 seek 能力。**
- **可行性评级：中高（架构改造小、性能收益依赖实验）。** 理由：Graph(t) 条件依赖声明是 A1 骨架的小扩展；收益侧不确定（渲染帧间的"条件压缩"收益取决于子图签名命中模式，需实测）；风险 = 条件依赖破坏 tile 无关性（需 halo 协议扩展到时域——设计上可行：时域 halo = 前帧重叠带）。
- **最小验证实验（半天）**：在签名缓存上实现最小"时域条件节点"：帧 t 读帧 t−1 缓存的 1/8 分辨率特征图 + 一个小 conv 特解输出残差修正。判据：①双跑 md5 一致（条件图也在签名内）；②相邻帧相似场景（相机缓动）下 reuse_ratio 相比无条件基线提升 ≥10 个百分点；③seek 到随机帧的结果与顺序渲染该帧逐位一致（确定性不因条件化破坏——这是对拍 DCVC 的关键卖点）。

### P5 距离场基元的神经渲染：3DGS 资产进 SDF 生态（账一 U1 的几何侧吸收）

- **数学核心**：3DGS 的高斯基元 = 协方差核的显式参数化（§25 协方差核化身——3DGS 在我们的语言里是"S1 核基元 + S8 体渲染积分"的组合，概念上无需新结构）；其公认缺陷（离散/稀疏/离面漂移，难以组合编辑）恰是 SDF 的强项（CSG/域算子/碰撞）；GS-Pull 已给双向桥模板。我们的原创路线 = **SDF 优先吸收**：不追 3DGS 训练与光栅化管线（那是别人的存量主场），只做"**3DGS→SDF bake**"特解——把高斯资产拉到零水平集（GS-Pull 思想的离线烘焙版），进我们的 CSG/displace/碰撞/GI 生态；同场加映"SDF + 视角相关颜色（低阶球谐）"的新视图合成特解（sphere tracing + 环境积分 = 全既有原语）。
- **架构落点**：**S12 的 Dual 切换家族新增"GS→SDF bake"特解**（宿主 prism-geometry，与 mesh→SDF §7 同框——"资产进程序化生态"承诺直接覆盖 3DGS 资产）；三问——核 = KernelKind::Covariance（输入侧高斯）→ 转移核（渲染侧积分）；对偶 = DualityPair::BoundaryVolume（**§25.2 边界↔体对偶的原生应用，零新对偶**）；格 = brick 格（§7 既有）+ 拟合迭代数格锚。 ply/spz 解析 = 新增精简解析特解（§12 glTF 精简解析同款纪律：子集 + 未支持清单永不静默）。
- **与既有红利的关系**：烘焙资产进签名缓存（同模型全场景只拟合一次，§7 先例）；拟合产物的确定性 = 构建序格锚（D-20 烘焙资产纪律：高斯读取序按资产内索引、拉取迭代固定次数）；组合能力 = CSG/域算子/XPBD 碰撞对高斯资产**立即生效**——这是对"NeRF/3DGS 引擎"的差异化：他们是渲染器，我们是**把神经捕获资产变成可组合几何**的引擎。
- **可行性评级：中。** 理由： bake 侧有顶会模板（GS-Pull）但我们的版本是"离线拟合特解"而非"可微训练管线"，简化幅度大（无梯度、固定迭代、质量由性质测试验收）；风险 = 高斯资产质量参差（稀疏视角/浮点渣高斯）→ 拟合病态；兜底 = 拟合失败按警告降级（winding number 纪律同款）。
- **最小验证实验（半天）**：合成场景（3 球 + 1 面）先程序化生成高斯点集（绕过真实捕获），写"高斯云→brick SDF"拟合特解（拉取迭代固定 10 次 + 最近核距离场混合），判据：①拟合产物与解析 SDF 的最大偏差 < 2% 场景尺度；②产物直接可被 `boolean subtract` 与 XPBD 碰撞使用；③构建序格锚（同输入重跑 brick 逐字节一致）。全过 = 真实 .ply 资产解析列入下一批。

### P6 神经缓存：签名树作为学习型算子的对称性检测器

- **数学核心**：把 §25.4 保证书第一条（不变性→免费）推广到神经算子：**"什么可以缓存"对神经特解同样是定理不是启发式**——签名 = hash(权重哈希 + 输入 AOV 签名 + 输出分辨率档 + 整数算子合同版本)；签名不变 ⇒ 输出逐字节复用（确定性是前提，P2 提供）。缓存产物家族扩展：神经中间特征图（latent）与累积缓冲/烘焙 SDF/节拍表同类。
- **架构落点**：S10 层次+签名的既有机制 + **缓存键 schema 扩展一个字段**（`neural_contract_version`）；三问——核 = 无核服务；对偶 = 内容↔摘要（签名即摘要，§25.2 原生）；格 = 哈希格（SHA-256 既有）。零新 trait——这是六个方向里架构改动最小的一个。
- **与既有红利的关系**：全部直接继承（这就是 S10 本身）；新增价值 = OIDN tile 重叠协议与 halo 协议的对拍（神经感受野 174–202 px ⇒ tile halo 尺寸 = 感受野参数化——**感受野是卷积核尺寸的函数**，与 §25.2"运动模糊与像素重建是同一核族"的参数化思想同型）；P4 的时域条件依赖正确性也由本方向保证（条件特征图进签名）。
- **可行性评级：高。** 理由：纯 S10 既有机制的字段扩展；风险仅一处——权重哈希把"同网络不同权重版本"区隔开（正确行为），但权重文件大（MB 级），哈希开销需按内容寻址文件缓存（prism-io SHA-256 已有）。
- **最小验证实验（半天）**：给 P1 的 3 层 U-Net 特解接签名缓存：参数不变 + 输入不变 ⇒ 第二次调用命中缓存（产物 md5 相等）；改一个去噪强度参数 ⇒ 仅该子图失效。判据：命中/失效行为与 §4.2 语义完全一致；权重文件哈希耗时可忽略（<50ms/MB 实测）。

## 5. 诚实边界

**有据（定理级或行业实证，可直接引用）**：扩散先验解线性逆问题 ≡ 正则化优化（SIAM 2025）；PF-ODE 确定性采样与一致性蒸馏（多源顶会）；INT8 QDQ 跨微架构逐位一致 + FP32 全漂移（500/500 对照实验，2026）；DCVC-RT int16 整数化与操作复杂度瓶颈论（CVPR 2025）；条件编码 > 残差编码（Shannon 论证，IJCAI 2025）；OIDN U-Net CPU 可跑 + tile 协议 + 三档质量（奥斯卡奖级工程实证）；高斯↔SDF 桥（NeurIPS 2024）；3DGS 进冬奥转播（生产实证）。

**是猜测（本研究推断，未经实验）**：~100K–1M 参数定点 U-Net 在 4核8G 沙箱的单帧延迟 <2s（按 OIDN 大网比例外推）；P4 的时域条件在渲染场景（而非编解码场景）的复用率收益 ≥10pp；INR 资产格式的"分辨率无关 + seek"定位足以补偿压缩率劣势（用户价值判断）；"学习逆"作为第七种策略的命名能否在白皮书 §25.1 表中稳定成立（数学实质已据，名称是表述选择——若评审认为应归并"正则化逆的神经实现"，架构落点不受影响）；SDF + 球谐新视图合成的质量上限（未做对比实验，是 P5 的远期子项而非近承诺）。

**需实验才知道（已设计成半天批次，见 §3 各方向）**：整数位宽 sweet spot（int8 vs int16 在我们原语集上的质量-速度曲线，P2 实验产出）；P1 小网对 à-trous 的实际 PSNR 增益；P3 的量化后 PSNR 与码率平衡点；P6 的权重哈希开销；P5 拟合特解对真实（非合成）高斯资产的鲁棒性——真实资产实验依赖 .ply 样本收集，列为 P5 立项后的首批验收项。

**研究局限声明**：本次调研以英文公开文献为主，未覆盖国内团队未公开工作与标准组织闭门文档；编解码标准动向（如 MPEG 神经编解码标准动作）需要季度跟踪补强 §4 信号表。

## 6. 路线选定（v2.1 转向通用引擎视角 · v2.2 确立边界：P 系内部梯队 + 排期主张，跨账目裁决移交）

> **v2.1 转向声明**：v2.0 的路线选定以"AI社交"应用场景（短视频/降噪迭代/素材交付）为核心权衡维度；v2.1 改为以**通用引擎视角**重新权衡——棱镜引擎是通用图像/视频生成引擎，路线选择的价值基准 = **引擎能力本身的完备性与通用性**，与任何具体应用解耦。权衡维度全部替换为引擎级五维；路线结论由通用视角的权衡独立决定，不追求与 v2.0 保持一致。

### 6.1 主路线

**主路线 = 三级梯队（通用视角独立重推，与 v2.0 结构一致；论证基础全面更换，显式说明见 6.2 末尾）：**

- **窗口内主链（机动位执行）：P2 → P1 → P6**——定点格原语件（使能层：确定性红利对学习算子的延伸之算术地基）→ 神经降噪特解（渲染器管线标配组件，实验→正式）→ 神经缓存键（签名缓存命中推广到学习算子）。三个半天级批次，全部落在 10/5–10/6 机动还账位内。
- **窗口后第二梯队（下一窗口，信号驱动）：P3 → P4**——INR 媒体特解（分辨率无关 + 任意 seek 的解码组件）→ Graph(t) 时域条件特解（增量渲染与任意 seek 重建）。二者均依赖窗口内产物（P2 原语件）与更重的架构评审，不进本窗口。
- **挂起监听：P5**——GS→SDF bake。技术独立、随时可做，但其输入（3DGS 资产）的可用性是**外部信号而非引擎能力问题**——通用引擎不为不存在的输入预建管线，保持 §4 信号监听即可。

**一句话表述：本窗口把引擎的"全链确定性"补上最后一块（解析算子 → 学习算子）并点亮渲染器管线的一件标配组件（降噪）——账一（范式依赖型，最大代差）从"零进展"推进到"首个可运行能力 + 全部后续方向的算术地基"；媒体侧（P3/P4）与几何侧（P5）按信号点火。**

### 6.2 选定理由（引擎级五维权衡表，逐方向显式）

**五维定义（v2.1 全部替换为引擎级维度，与任何具体应用解耦）**：

1. **渲染器标准组件覆盖度**——通用渲染/生成引擎的管线标配（降噪、媒体解码、几何导入、增量调度）中，该方向补齐哪一件；缺件即引擎残缺，与是否存在某个应用场景无关。
2. **结构通用性**——落点是否严格复用既有 12 结构 + 对偶表 + 格层，不引入引擎级特例；通用性越高的方向越不可能成为未来的架构债。
3. **引擎级属性增益**——分辨率无关 / 确定性 / 任意 seek / 签名缓存命中：引擎本体红利（白皮书 §25 保证书条款的覆盖面扩张），不依赖任何场景存在与否。
4. **依赖链与风险**（引擎内部属性，与 v2.0 相同）。
5. **机会成本**（D-25 产能观：半天批产能 vs 对既有波次的挤占）。

**选择逻辑（通用视角，显式五条）**：① **P2 排第一**——"全链确定性"是引擎身份的一部分（铁律二），定点格是该确定性对学习算子的延伸的唯一地基：没有 P2，维度③对全部神经特解失效；且零依赖/零风险/零挤占，通用视角下这是"先打地基再盖房"的必然顺序，与场景无关。② **P1 排第二**——维度①直接命中（降噪是渲染器标配组件）且是账一（最大代差）的首个能力落点；本窗口依赖全部就绪（B1/B4/B10 于 10/2 落地，机动位 10/5 开工时实验输入齐备）+ 结构化兜底使失败无代价。③ **P6 收尾**——维度③的廉价补全（一行字段把签名缓存命中推广到学习算子），且是 P3/P4 的公共前置（条件特征图进签名）。④ **P3/P4 排窗口后**——维度③增益最高的两个方向，但维度④依赖与评审成本决定其不属于本窗口：通用引擎同样受 D-25 产能约束。⑤ **P5 挂起**——维度①的缺件不归因于引擎：3DGS 资产可用性是外部信号，预建管线 = 为不存在的输入支付机会成本，违背 D-25 产能观。

**通用视角改变了什么（显式说明）**：**梯队结构（P2→P1→P6 / 窗口后 P3→P4 / 挂起 P5）经通用视角独立重推后与 v2.0 一致，但全部论证基础被替换**——P1 的排位依据从"场景高频需求（短视频草稿迭代）"改为"渲染器标准组件覆盖度"（OIDN 先例证明降噪与场景无关地属于现代渲染器管线）；P3/P4 的价值从"素材交付需求"升格为"引擎本体属性增益（维度③：分辨率无关/任意 seek/增量渲染）的直接命中"，通用视角下价值不减反升，只因维度④依赖链约束仍排窗口后；P5 的挂起理由从"场景无 3DGS 输入"改为"输入侧成熟度是外部信号而非引擎能力问题"。结论：**这是通用视角独立权衡后的结论稳健性确认，不是为一致而一致**（若重推得出不同梯队，本节会如实改序）。

**落选方向激活条件**（对应 §4 信号清单，此处只列窗口内不装的理由）：

- **P3**：不进本窗口的理由 = 编码侧（拟合）需要独立工具链批次 + "资产格式"定位需用户认可；激活信号 = INR 资产需求出现（引擎内生成 → 引擎内回放闭环，genart 输出复用）或用户令——**窗口后第一候选**。

- **P5**：不进本窗口的理由 = 输入侧未成熟（3DGS 资产可用性是外部信号，通用引擎不为不存在的输入预建管线）；激活信号 = 3DGS 资产经 DCC 成为常见输入，或"神经捕获资产参与物理/组合"的需求出现。

## 8. 风险与回退（v2.0 新增，简短）

| 步骤 | 主要风险 | 回退位（无损性说明） |
|------|---------|---------------------|
| P2 原语件 | 整数算子合同设计失误（饱和/舍入策略不一致导致跨实现失配） | 合同测试先行（V1）——失配暴露在原语件测试内，不进特解；原语件独立于主干波次，隔离零影响 |
| P1 实验 | 三判据任一不过（PSNR 增益不足 / 延迟超标 / md5 不一致） | **à-trous 基线永在**——第四层替换位"永不比基线差"是结构承诺；PSNR 不足 → 降级为草稿档专属（速度优先档）；延迟超标 → 0.5× 分辨率档；实验数据留档，方向转信号驱动 |
| P1 正式特解 | 真实渲染内容（非 Cornell-box）上泛化不足 | 特解开关默认关闭（`denoise neural` 显式启用），默认管线行为不变；效果差 → 用户不启用即零影响 |
| P6 缓存键 | 权重哈希开销超预期 | 内容寻址文件缓存（prism-io SHA-256 既有，按文件只算一次）；最坏回退 = 字段归入 engine_version（保守失效——缓存少命中，正确性不损） |
| 机动位整体 | P1 实验失败导致机动位出现空位 | P 系侧回退 = 本线停止、损失上限 = 半天批（实验数据留档转信号驱动）；**空位装什么（其他账目与否）移交施工日历与主理人** |
| P3/P4（窗口后） | 编码耗时 / 时域 halo 设计风险 | P3 限定"引擎内生成资产"闭环；P4 设计评审否决即回退（无窗口内承诺，纯信号驱动） |

**回退总原则**：主路线每一层都有"默认行为不变"的结构兜底（基线永在 / 开关默认关 / 字段默认 0 / 隔离测试目录）——**范式的成本上限 = 机动位半天批次，收益下限 = 零（不启用即无影响）**，这是把"范式依赖型账目"变成"可分期试错的期权"的排期设计。
