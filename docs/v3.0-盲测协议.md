# V3.0 W3 成对盲测协议（§3.5 V3 定桩冻结）

> **判官不是主观自评，也不是 critic 分数当胜率**（主理人裁定 / D-31 / K-9）。
> 判官是一个**确定性可计算函数**：只接收两条数值序列、不知道标签，
> 按三条可复现的「解析性 / 匀质度」指标强制二选一「哪边解析性更低（更像人搓的）」。
>
> 本协议的样本池、种子、配对顺序、判定规则、门槛、依据全部**定桩于跑测之前**
> 并落盘；不设任何可调参数（脚本没有 `--threshold` / `--seed`），
> **不许事后调门槛、不许换尺子、不许把 analytic 拉来凑数**。
> 若达不到冻结门槛，如实给数字并按 V2.5 报告 §27 格式写正式落档，
> 不写成「观感没做」或「待裁定」。
>
> 只在 `crafted` 档跑；选 `analytic` 根本不跑盲测（V4 匀质同样是能力）。

---

## 1. 判官：三条可复现「解析性」指标（确定性可计算函数）

实现：`crates/prism-app/src/w3_blind.rs::judge(first, second) -> (Verdict, bool)`。
判官**只接收两条 `&[f32]`**，不含任何标签 / 档位 / 文件名。

| 指标 | 定义 | 解析序列 | 注入痕迹序列 |
|---|---|---|---|
| ① 运动二阶差分能量 | `Σ\|x[t] − 2x[t−1] + x[t−2]\|` | 匀速 / 标准 easing 趋 0 | 惯性 / 犹豫 / 微抖 / 呼吸 ⇒ 显著非零 |
| ② 局部方差谱离散度 | 4 个等长分块方差的 `max − min` | 匀质序列谱平 | 种子化扰动使谱起伏 |
| ③ 帧间规律性 | 一阶差分同号比例 ∈ `[0,1]` | 完全规律 = 1 | 扰动破坏规律性 |

合成不规则度（三项归一化后等权相加，分母恒 > 0、纯 `+ - * /` 与位型比较）：

```
irregularity = e2/(e2+1) + spread/(spread+1) + (1 − regularity)
```

判官选 **irregularity 更大**的一边 ⇒ `Verdict::First | Second`。
两条指标逐位相同时按确定性规则选 `Second`（强制二选一，不留平局），
并置 `tie = true` 供协议记录。

- **零 libm、零真随机、零线程、零系统时间**：三条指标只用算术与位型比较。
- 观测序列来自**真实求值链**：`finish::inject_frame_values → signals_of`
  （与 `wiring.rs::resolve_frame` 同一函数），不是本模块另写一套噪声
  ⇒ 禁止两端同错。若实现退化成「帧后贴皮」或「字段没接」，生成源头序列
  不变 ⇒ 判官无区分力 ⇒ 胜率回落到随机基线，过不了冻结门槛。

## 2. 冻结项（跑测之前定桩，落盘不许改）

| 项 | 冻结值 | 依据 |
|---|---|---|
| 样本池 `BLIND_SAMPLE_COUNT` | **64 对** | 二项检验在随机猜测 `p=0.5` 下，64 次试验达到 ≥ 48 胜（0.75）单尾 `p < 1e-4`，属「显著 > 0.5」；64 为 2 的幂，配对顺序可由 `hash_mix` 位均匀打乱 |
| 每对帧数 `BLIND_FRAME_COUNT` | **24 帧** | ≥ 3 个 8 帧分块，保证局部方差谱（4 块）与二阶差分有定义 |
| 命名空间常量 `BLIND_TAG` | `0x7733_5eed_0000_0002` | 与 `W3_TAG`（`0x...0001`）/ 产物哈希链互不冲突 |
| 种子 | `hash_mix(BLIND_TAG ^ 0x5eed_5eed, index)` | 逐样本确定性派生，无外部随机源 |
| 强度档 `BLIND_STRENGTHS` | `[80, 160, 240, 320, 480, 640, 800, 1000]` | 8 档覆盖弱扰动到满强度（DSL `0..1000` 定点） |
| 活跃族掩码 | `hash_mix(BLIND_TAG, index) & 0b11_1111`，为 0 时回退 `1 << (index % 6)` | 至少一族活跃，其余族绝对匀质 ⇒ 能表达「只有运动带呼吸」 |
| 六族观测权重 `BLIND_FAMILY_GAINS` | `[0.15, 0.12, 0.14, 0.13, 0.11, 0.16]` | 判官与场景共用的确定性常量，写死在源码 |
| 配对顺序 | `b_first = (hash_mix(h, 0xA5A5_A5A5) & 1) == 1` | 独立槽位 hash 位打乱，判官不知标签 |
| **冻结门槛 `BLIND_THRESHOLD`** | **0.75**（≥ 48/64 胜） | `BLIND_THRESHOLD_BASIS`：`N=64、H0:p=0.5 的二项检验，≥48 胜（0.75）单尾 p<1e-4；门槛显著高于随机猜测 0.5，且预留 0.25 容错带，定桩于跑测之前，不事后调整` |
| critic 侧证容差 `CRITIC_REGRESSION_TOL` | **0.25**（critic 总分量纲 `0..1`） | 痕迹注入是有界微扰，允许画质总分 0.25 容错带；定桩于跑测之前。**侧证不进胜率** |

> 门槛 0.75 是**跑测之前**写在 `w3_blind.rs` 常量里的；脚本与文档、
> 协议三处同源，不接收命令行覆盖。实测结果见 §5（如实给数字）。

## 3. 固定协议（判定规则）

1. 对每个 `index ∈ 0..64`，由 `sample_params(index)` 派生 `(seed, strengths[6], b_first)`。
2. 构造观测序列：
   - `A = observation(seed, strengths, crafted=false)` —— 纯解析匀速 ramp
     （`base = 0.5 + 0.25·t/24`），六族恒 OFF；
   - `B = observation(seed, strengths, crafted=true)` —— 同 `base` +
     六族生成源头注入信号（`inject_frame_values` 逐帧解算，按 `BLIND_FAMILY_GAINS` 加权）。
3. 按 `b_first` 决定 `(first, second)`，**判官不知道哪边是 B**。
4. `judge(first, second)` 强制二选一；协议层对照真值记 `b_selected`。
5. 汇总 `b_wins / total = win_rate`；`passed = win_rate ≥ 0.75`。
6. **两跑逐字节**：`run_protocol()` 连跑两次，`BlindReport::canonical_bytes()`
   必须逐字节一致（含 64 行逐对输出的全部字段）。
7. **反假绿负控 `run_control()`**：把 B 也换成 `analytic`
   （等价「字段没接 / 痕迹挪到帧后贴皮」），判官应**失去区分力**
   （胜率显著低于门槛且出现 `tie`），证明判官不是无条件选 B。

## 4. 客观侧证：`prism-aesthetic::critic` 五维（**不是主判据**）

- 主判据 = §1 判官的确定性盲测胜率；侧证 = 既有 `critic::analyze` +
  `critic::score` 五维（exposure / contrast / color / sharpness / composition）
  与 `Score::total`，证明「`crafted` 档画质不退化」。
- **不把 critic 分数直接当盲测胜率糊弄**（§1.1 批判的维度错配）：
  `w3_end_to_end.rs::v3_critic_five_dims_are_side_evidence_only_not_the_win_rate`
  显式断言两者不相等；测试与脚本把逐维 Δ 如实打印。
- 侧证数据 = A/B 观测序列铺成 `6×4` 灰度帧，喂既有 `critic::analyze`，
  画质求值全部由既有 crate 完成（红线 1）；本模块不实现画质数学、
  不碰帧缓冲渲染管线（不是帧后贴皮）。
- 判定：`no_regression = 五维全有限 ∧ A/B 总分为正 ∧ B总分 ≥ A总分 − 0.25`。
  全池 64 对逐对输出，两跑逐字节一致。

## 5. 实测结果（如实给数字，不编、不调门槛）

运行：`sh scripts/w3_blind.sh all`（W3 收口实测）。

| 项 | 实测值 | 判定 |
|---|---|---|
| 主判据 B 胜率 | **64/64 = 1.0000** | ≥ 0.75 ⇒ **PASS** |
| 样本数 | 64 对 × 24 帧 | 与冻结值一致 |
| 两跑 `canonical_bytes()` | 逐字节一致 | PASS |
| 反假绿负控（B=A） | **28/64 = 0.4375**，平局 **64** | < 0.75 且 ties > 0 ⇒ 判官无区分力（符合预期） |

## 7. 反假绿要点（D-31 / §3.5）

- V3 盲测**只证明「`crafted` 档确实把不规则注入了生成源头」**，
  不证明也不要求所有片子都得搓；选 `analytic` 根本不跑盲测。
- 禁止「我看过觉得像搓的」当判据：判官是确定性可计算函数。
- 禁止把 critic 五维分数直接当胜率：critic 是画质指标（侧证），
  不是「像人搓的」指标。
- 负控 `run_control()` 证明判官不是无条件选 B；`w3_finish.rs` 的
  五负控（贴皮 / 真随机 / 全 0 / 漏填档位 / 字段没接）证明实现合规。
- 若协议跑出来达不到冻结门槛：**如实给数字**，不改协议、不换尺子、
  不把 `analytic` 拉来凑数；按正式落档写清（V2.5 报告 §27 格式）。
  本次实测 1.0000 ≥ 0.75，无需触发该分支。
