## 1. P1 — JPEG 定点 IDCT（V1.5-A / P0-2 / ADR-19）

### ① 问题现状

- 编码器已是全整数：`crates/prism-mux/src/jpeg.rs:86` 的 `DCT_COS` 是标度
  2^14 的整数余弦表，`jpeg.rs:100` `fdct_8x8` 全程 i64 累加。
- 但**基线 JPEG 解码器尚不存在**（`prism-io/src/` 仅有 DNG 无损 JPEG 路径
  `raw_lossless_jpeg.rs`；基线解码是路线图 V1.5-P0-2 的绿地项），若新写
  解码器时沿用浮点，即重犯既有错误。
- **D-29 活违规**：`crates/prism-mux/src/video.rs:821` `idct_8x8` 用 f64
  浮点 IDCT；其余弦表 `video.rs:628-642` `cos_table()` 以
  `std::f64::consts::PI` + `f64::cos()` 懒初始化。`f64::cos` 是 libm 后向
  函数而非 IEEE-754 正确舍入——实测 64 个参数中 **10 个与正确舍入差 1–2
  ulp**（exp1-C）⇒ 现行 PRMV 解码路径跨平台非位精确。架构文档 ADR-19 对
  「浮点 IDCT 的 IEEE 逐位性」的担忧事实上不成立：IEEE-754 根本不管 `cos`。

### ② 数学结构

JPEG 基线的二维 DCT（T.81 A.3.3）：

```
f[x][y] = ¼·Σ_{u,v} c(u)c(v)·F[u][v]·K(u,x)·K(v,y),   K(a,b)=cos((2b+1)aπ/16)
```

**正交性**（离散余弦变换是正交变换）：

```
Σ_u c(u)²·K(u,x)·K(u,x') = 4·δ(x,x')
```

**折归一化**：把归一化因子 c(u)c(v) 折进系数权重。定义

```
W[u][v] = 2^16·c(u)c(v) ∈ {2^16, 46341, 32768}   （对应 c(u)c(v) = 1, 1/√2, ½）
C[a][b] = ⌊2^14·K(a,b)⌉ ∈ ℤ                     （编码器 DCT_COS 同表，可复用）
```

则精确 IDCT 可写为两阶段整数累加：

```
S1[u][y] = Σ_v D[u][v]·W[u][v]·C[v][y]
S2[y][x] = Σ_u S1[u][y]·C[u][x]
f[x][y]   = S2[y][x]·2^-46        （D = F·Q 为反量化系数）
```

标度核对：精确值 = ¼·2^-28·Σ c(u)c(v)·D·C·C = Σ D·C·C·W·(¼·2^-28·2^-16)
= Σ D·C·C·W·2^-46。✓

### ③ 算法设计

1. 反量化：`D[u][v] = F[u][v]·Q[u][v]`（i64；ZigZag 序直接乘，与
   `video.rs:804` 既有约定一致）。
2. 列阶段：`S1[u][y] = Σ_v D[u][v]·W[u][v]·C[v][y]`（8×8 双重循环，i64）。
3. 行阶段：`S2[y][x] = Σ_u S1[u][y]·C[u][x]`（i64）。
4. 末位统一标度：`s = (S2 + 2^45) >> 46`（round-half-up），clamp 到
   [0,255]（8-bit）或保持 i32（高位深路径）。
5. 全程无浮点、无超越函数、无 libm：D-29 从根上消除。

### ④ 数学证明

**证 1（正确性/无溢出）**。基线 JPEG 约束：|F[u][v]| ≤ 2047（DC）/1023
（AC），8-bit 量化表 Q ≤ 255。则 |D·W| ≤ 2047·255·2^16 ≈ 8.6e12，
|S1| ≤ 8·8.6e12·2^14 ≈ 1.13e18 < i64::MAX ≈ 9.22e18（余量 ≥ 8×；
实测 Σ|F| 最大 5070，保守界 64·2176 = 139264，实际占用比界低 27×，
i64 余量 ≥ 256×）。16-bit 量化表（T.81 允许、罕见）时最坏项逼近 i64 上界，
须分流 i128 或分段累加——记为工程约束（见 ⑦）。

**证 2（误差界）**。定点化相对精确 IDCT 的误差来自两处：余弦表量化
（|C − 2^14·K| ≤ ½ ⇒ 相对误差 ≤ 2^-15）与 W 的舍入（46341 vs 2^16/√2
的差 ≤ 0.5/46341 ≈ 2^-15.5）。两项独立同阶，合并为

```
|Δ| ≤ (¼)·3·2^-15·Σ|F[u][v]|
```

实测（exp1-B，3000 个真实量化块）：舍入**前**定点真值与精确 IDCT 的
max|Δ| = 0.0121 个输出 LSB，界利用率 13.4%；舍入后 vs f64 参考路径
max 1 LSB、差异像素 0.24%、PSNR 74.3 dB。

**证 3（确定性）**。全程 ℤ 上精确算术 + 一次算术移位，无浮点舍入模式
依赖、无 fma 收缩语义、无平台 libm 差异 ⇒ 任意两平台逐位一致（强于
现行 f64 路径，后者已被证 3 跨平台非位精确）。

**证 4（复杂度）**。乘加次数 2·64·8 = 1024（与浮点 IDCT 相同），但消除
64 次 `cos` 调用与表初始化；每块一次 64 项 i64 扫描，缓存行为优于
浮点版的双重间接寻址。

### ⑤ 工作量杠杆

- V1.5-A/P0-2 是绿地：无遗留解码器需要重构，方案即初始实现。
- 直接消灭一个 D-29 整改项（`video.rs:628-642` 余弦表 + `video.rs:821`
  f64 IDCT 共约 60 行浮点代码连同其跨平台风险一并移除）。
- P0-8 黄金门禁（PSNR≥40dB）从「需要调参达标」变为「开箱 74.3 dB」。

### ⑥ 效果提升

3000 真实量化块：定点 vs f64 参考 max 1 LSB、PSNR 74.3 dB（门禁 40 dB，
余量 34 dB）；全幅往返两路径 PSNR 相同、逐字节相同率 99.9%+；编码器
`DCT_COS` 表经验证即正确舍入的 2^14 余弦表（0/64 不符），解码器可**复用
同一张表**，编解码共用一份资产。

### ⑦ 风险反证

- **索引约定是最大坑**（本报告作者在实验中被自己的转置 bug 咬过一次：
  定点与错误参考一致地错、与精确 IDCT 差 438 LSB）。对策：黄金测试用
  **独立参考实现**（如 python 精确 IDCT 固件）对拍，禁止用引擎自身浮点
  路径作参考（同错不报）。
- 16-bit 量化表溢出风险（证 1）：以 i128 分段或断言拒绝，写进门禁。
- 对「更高位深（12-bit）输出」路径，2^-46 标度需重核（位数线性增长，
  i64 仍足够，但要有测试）。

## 2. P2 — GPU↔CPU 遍历同构 + tie-break 修正 + 归约误差界（V2.0-G / D-3）

### ① 问题现状

- CPU 最近命中规则带 tie-break：`crates/prism-rt/src/bvh.rs:441-447`
  叶更新 `t < b.t || (t == b.t && orig < b.tri)`——在全序
  `(t, orig_index)` 下取最小。
- GPU 叶更新**只有严格小于**：`crates/prism-gpu/shaders/rt_bvh.wgsl`
  `ht >= 0.0 && ht < best_t`——并列时首个访问到的 slot 胜，等价于按
  **slot 序**而非 **orig 序**取最小。
- 实测（exp2b-T1，4000 个随机共享边构型）：1181 例两三角形同时命中，
  其中 480 例（**40.64%**）给出**逐位相同**的 t——tie 不是理论玩具，
  是高频事件；规则分歧逻辑可达。
- AABB slab 测试用 1e-7 **绝对** padding（`bvh.rs:93-110`）。实测
  （exp2b-T2）：f32 slab 舍入的相对误差 ≈1.7u（u=2^-24，≤3u 界成立），
  但 1e-7 绝对 padding 仅在 |t| ≤ 0.28 时充分——大场景/远距离射线
  可能漏真实命中。

### ② 数学结构

**全序 argmin 置换不变定理**：设 H 为有限命中记录集，≺ 为 H 上的严格
全序（此处 `(t, orig) ≺ (t', orig') ⟺ t<t' ∨ (t=t' ∧ orig<orig')`）。
则 `argmin_{≺}(H)` 与 H 的任何枚举序无关——遍历过程中的 running-min
每步比较在 ≺ 下精确，有限集在全序下的最小元唯一。**推论**：只要 CPU 与
GPU 使用**同一个**全序，图像就是遍历序的纯函数（parity 的结构基础）。

**树形归约前向误差界**：n 项 f32 求和，pairwise（树形）归约

```
|fl(S) − S| ≤ u·(⌈log₂ n⌉ + 1)·Σ|x_i|,    u = 2^-24
```

（每层一次舍入共 ⌈log₂n⌉ 层 + 最终一次）。对比顺序归约的
`(n−1)·u·Σ|x|`，树形在 n=1024 时紧 93×（实测）。

### ③ 算法设计

1. **WGSL tie-break 对齐**：叶更新改为 `ht >= 0.0 && (ht < best_t ||
   (ht == best_t && prim_orig < best_orig))`，与 CPU 同一全序
   `(t, orig)`。
2. **slab padding 相对化**：`ε = 6u·|t|`（t 取射线参数绝对值，覆盖
   enter/exit 两侧各 3u），替代绝对 1e-7。
3. **归约误差预算写进门禁**：D-3 门禁①的「均值/方差有界」从经验阈值
   升级为定理预算：两归约序差的均值 ≈ 0、方差 ≤
   `2·u²·(log₂n+1)²·(Σ|x|)²/n²`（可解析给出，不靠试）。
4. 遍历结构同构：桶数、切分规则、叶容量与 CPU 逐项相同（切分确定性
   由 P3 保证），使 GPU/CPU 遍历同一棵树。

### ④ 数学证明

**证 1（parity 结构）**。CPU/GPU 采用同一全序 ≺ 后，由 argmin 置换不变
定理，最终命中与遍历序、与线程调度、与 workgroup 大小均无关；剩余差异
仅来自归约舍入（证 3）——这正是 D-3「kernel 语义级 parity + 浮点末位
统计判定」想要拆开的两层，现在有了精确分界。

**证 2（padding 充分性）**。f32 slab 测试中 `inv_d` 与乘积各有一次舍入，
`Δenter`、`Δexit` 各 ≤ 3u·|t|（实测 1.7u，界 3u）。取 ε ≥ 6u·|t| 时，
舍入不可能把真实命中推出 AABB（保守侧）也不可能把真实未命中拉入
（激进侧误差同界覆盖）。1e-7 仅在 |t| ≤ 1e-7/(6u) ≈ 0.28 时满足该条件。

**证 3（归约界与门禁余量）**。由树形归约界（②），两归约序之差
|Δ| ≤ 2u(log₂n+1)Σ|x|/n。实测（exp3，n=512/像素，2000 像素）：
两序输出 MSE = 3.03e-14 ⇒ PSNR = 135.2 dB；D-3 门禁②要求 ≥ 40 dB
（MSE ≤ 1e-4），余量 95 dB。差的均值 −6.5e-9（≈0）、方差 3.0e-14，
低于信号方差 1.1e-5 达 10 个量级 ⇒ 门禁①统计判定有巨大安全余量。
树形归约界本身 400 组（含降序同号最坏形）全部满足，界利用率 max 0.419。

### ⑤ 工作量杠杆

V2.0-G 是路线图最大单项，R1（GPU 管线工作量黑洞）是最高风险。parity
失败的代价在于「GPU 已经能跑之后才发现的深层分歧」——本提案把其中
一整类（tie-break 分歧，40.6% 可达）在 3 行 WGSL + 1 个常量内前置消解，
并把 D-3 门禁的两条统计判据变成有解析预算的验收公式。parity 测试网
已存在（`integrator.rs:22-26`、`wavefront.rs:825-943`），无需新建。

### ⑥ 效果提升

- 消除可达率 40.64% 的逐位同 t tie 分歧（共享边异构三角形构型）。
- slab 修正使大尺度场景（|t| > 0.3）不漏真实命中——这是画质正确性，
  不是精度微调。
- 归约误差预算化：引擎 CPU 路径本就用固定形状树归约
  （`accum.rs` → prism-core reduce），本提案给这条既有路径与任何
  GPU 树形归约一个统一的解析预算（`u·(log₂n+1)·Σ|x|`），替掉 D-3
  门禁里的经验阈值；顺带确认 GPU 若退化为顺序归约（n=1024）界松
  93×、余量（95 dB）仍够——不构成阻塞。

### ⑦ 风险反证

- **padding 相对化会改变输出字节**： borderline 射线的命中判定改变，
  CPU 黄金 MD5 需重新基线。诚实声明：这是正确性修复（现行 padding 被
  证明在 |t|>0.28 时不充分），不是语义微调；须走「变更说明 + 黄金重
  基线」流程，不得静默。
- tie-break by orig 要求图元序稳定（否则 tie 结果随加载序漂移）——
  由 P3 的 Morton 规范化兜底；两提案是配套的。
- 树形归约要求 GPU shuffle 可用；不可用时退化为顺序归约，界退化为
  (n−1)u——门禁余量（95 dB）仍足够，不构成阻塞。

## 3. P3 — BVH 确定性结构定理 + Morton 规范化（V2.0-H / R6）

### ① 问题现状

- `crates/prism-rt/src/bvh.rs:262` `Bvh::build` 已实装 12 桶 SAH-BVH
  （`bvh.rs:618` `best_sah_split`），但**输入图元序未规范化**。
- 风险登记册 R6：「BVH 构建非确定（切分规则/排序未钉死）击穿确定性
  铁律」——USD mesh 加载序、图元合并序都可能变化，同场景两跑 MD5
  可能不同。
- 无现有反证表明已确定：切分选择依赖 f32 累加序（桶质心/边界在输入
  序上累加），叶内排列序显然依赖输入序。

### ② 数学结构

**集合函数定理**：12 桶 SAH 切分的代价是桶直方图（每桶质心、边界、
计数）的函数，而直方图是图元**集合**的求和——与枚举序无关（至多
f32 累加舍入噪声）。故切分**选择**是集合的函数；差别仅在**叶内排列**。

**Morton 规范化**：图元质心 (x,y,z) → 30-bit Morton code（整数交错，
`prism-core` 无浮点即可算）。按 `(morton_code, orig_index)` 字典序
预排序后，构建输入成为图元**多重集**的规范函数：Morton 码本身置换
不变，index 打破质心重合的平局。于是整棵 BVH（结构 + 叶内序）是
多重集的纯函数。

### ③ 算法设计

1. `Bvh::build` 入口：按 `(morton(centroid), index)` 稳定预排序
   （整数比较，无 FP）。
2. 结构签名测试：随机置换输入 10 次，断言结构签名（节点数/叶位/
   切分面序列的哈希）恒等。
3. 切分 tie-break：桶代价并列时取**桶索引最小**（固定规则，与输入序
   无关；桶直方图本身已序无关）。
4. 保留 SAH 不变：只改输入序，不改切分目标函数。

### ④ 数学证明

**证 1（纯函数性）**。构建无 RNG、无时钟、无指针身份依赖 ⇒ 同输入
两遍逐位同树（exp2-D1 实测两遍字节相同）。

**证 2（切分序无关）**。桶直方图 H = Σ_{p∈S} h(p) 是集合求和；SAH
代价 C(H) 是 H 的代数式。f32 累加序变化只引入噪声 δ ≤ u·Σ|h|，当
最优与次优切分的代价差 > δ 时 argmin 不变。实测（exp2-D2）10/10
置换下节点结构一致（真实场景中切分间隙远大于噪声底）。

**证 3（完全置换不变）**。Morton 规范化后，输入序列 = sort(多重集)，
是多重集的规范代表 ⇒ 输出字节相同。实测（exp2-D3）10 个置换 →
1 个结构签名。

**证 4（代价无损）**。SAH 只依赖集合 ⇒ 预排序不改变任何候选切分的
代价。实测（exp2-D4）汤场景/聚类场景 SAH 总代价比 = 1.0000。

### ⑤ 工作量杠杆

R6 是已登记风险，标准对策是「稳定排序+固定切分规则+专门测试」——本
提案把它压缩成：一次整数预排序 + 一个结构签名测试。不需要新建基础
设施（SAH、叶构建、遍历都已实装）。

### ⑥ 效果提升

- 资产管线顺序变化（USD 加载序、mesh 合并序、并行三角化输出序）
  不再影响渲染 MD5——确定性铁律从「同二进制同输入」加强到「同资产
  多重集」。
- 结构签名测试成为 V2.0-H 的验收件，parity 对拍（V2.0-G）也因此获得
  稳定基准（P2 的 tie-break 依赖图元序稳定）。

### ⑦ 风险反证

- **Morton 精度上限**：30-bit 每轴 ⇒ 场景 extent > 2^30 单位时远距
  图元共码。对策：以场景 AABB 归一化坐标算 Morton（归一化本身是
  纯 FP 但有界且只影响排序不影响输出字节——不行，FP 归一化会引入
  平台差异！更诚实的对策：用场景 AABB 的**整数**表示做归一化
  （AABB 由 FP 比较得到，边界值仍平台相关）。彻底方案：Morton 只
  用于排序平局消除，平局频繁时退化为 index 序——此时置换不变性
  只对「不同 index 的同码输入」成立，而同码同 index 不可能（index
  唯一）。故 (code, index) 全序的规范性不依赖 code 的区分度，
  只依赖其确定性：整数运算保证。记录为设计约束：Morton 计算
  必须是纯整数。
- 预排序增加 O(n log n) 整数比较，相对 SAH 建树的 O(n log n) FP
  运算可忽略；实测无代价劣化（证 4）。

## 4. P4 — 率控 water-filling + B 帧闭式权重（V1.5-E）

### ① 问题现状

- `crates/prism-mux/src/video.rs:37`：`VideoConfig.quality` 单一质量
  参数；`video.rs:98` I 帧 JPEG 直接用 `config.quality`；
  `video.rs:108` 残差质量 = `quality−17` clamp [50,80]——**启发式**，
  无率畸最优性，对 GOP 内帧复杂度差异盲目。
- V1.5-E 明确要求「档位率控/B 帧」，当前无数学框架支撑调参。

### ② 数学结构

**率畸模型（高率近似）**：帧 i 在速率 R_i 下的畸变

```
D_i(R_i) = θ_i·2^(−2R_i),    θ_i = 帧复杂度（预测残差能量）
D''(R) = 4(ln2)²·θ·2^(−2R) > 0  ⇒ RD 曲线严格凸
```

**Lagrangian 松弛**：`min ΣD_i s.t. ΣR_i = B, R_i ≥ 0`。凸性 ⇒ KKT
充分。一阶条件 `−2ln2·θ_i·2^(−2R_i) + λ = 0` 给出：

**reverse water-filling 解**：`R_i = max(0, ½·log₂(θ_i/θ))`，θ 为水位
（对偶变量），由 `ΣR_i = B` 定（单调，二分可解）。

**等畸变证书**：所有活跃帧（R_i > 0）满足 `θ_i·2^(−2R_i) = λ/2ln2 =
常数` ⇒ **最优解处各活跃帧畸变全相等**。这是可在 CI 中断言的强证书。

**B 帧闭式权重**：GOP 中 B 帧复杂度 θ_B < θ_P ⇒

```
R_B − R_P = ½·log₂(θ_B/θ_P)     （P/B 均活跃时精确成立）
```

θ_B = θ_P/4（层级 B 帧典型增益）⇒ R_B = R_P − 1 bit/符号。

### ③ 算法设计

1. GOP 头（I 帧）用固定较高质量（场景锚点，模型外特判）。
2. 每帧复杂度 θ_i：两遍编码时取头遍实测（rate, distortion）拟合
   `θ_i = D·2^(2R)`；一遍编码时用前一 GOP 同位置帧的先验 + 有界漂移。
3. 水位 θ 二分（≤ 200 步双精度足够，纯 FP 无 libm），闭式分配 R_i。
4. R_i → 量化档：查该帧 RD **下凸包**上的最近档（凸性保证内点被支配，
   只需 hull 上的点；搜索空间从 O(阶梯²) 降到 O(hull)）。
5. 编码后断言等畸变证书（活跃帧 D_i 相对偏差 < 容差）——不满足即
   说明 θ 估计失真，回退到凸包贪心并记录诊断。

### ④ 数学证明

**证 1（凸性/KKT 充分）**。D''(R) > 0（②）⇒ 目标严格凸、约束线性
⇒ KKT 点为全局最优；R_i ≥ 0 的活跃集由水位 θ 自动确定。

**证 2（最优性数值对照）**。θ = [1.0, 0.5, 0.3, 0.2, 0.1]、预算 6.0：
water-filling 解 ΣD = 0.296430 vs 20 万次单纯形随机搜索最优 0.296713
（WF 不劣于搜索，比 0.9990）。

**证 3（等畸变证书）**。上例 WF 解的各帧畸变 = [0.0593]×5，
max/min = 1.000000——活跃帧畸变严格相等，与 KKT 一阶条件一致。

**证 4（B 帧闭式）**。GOP = I+2P+9B，ρ = θ_B/θ_P ∈ {1, ½, ¼, ⅛}：
数值 WF 的 R_B 与闭式 `R_P + ½log₂ρ` 差 ≤ 1.1e-16（f64 累加噪声）。

**证 5（收益）**。12 帧 GOP（首帧场景切换尖峰 θ≈8–16，其余 0.2–0.7）：
等速率分配 vs WF，等总比特下总畸变降 **63.0–73.6%**（3 次试验）。

### ⑤ 工作量杠杆

V1.5-E 的「档位率控/B 帧」从「启发式调参 + 主观验收」变为「闭式算法
+ 可断言证书」：水位二分 ~20 行、凸包查表 ~30 行、证书断言 ~10 行，
且调参空间从「质量档怎么设」塌缩到「θ 怎么估」。等畸变证书同时是
回归门禁（任何破坏最优性的改动立刻红）。

### ⑥ 效果提升

等比特总畸变降 63–74%（等价 PSNR +4~5 dB 于同码率）；B 帧按闭式
权重省比特（ρ=¼ 时每 B 帧 −1 bit/符号）；切换帧不再被平均质量饿死
（实测 WF 把 3.3–3.6 bit/符号 分给尖峰帧，其余帧 0.4–1.3）。

### ⑦ 风险反证

- **模型风险**：真实 RD 曲线不是精确指数形。若 θ 估计偏差大，WF 在
  错误模型上最优——但仍在**凸族**内，且等畸变证书会检测到不一致
  （证书失败 ⇒ 回退路径），不会静默劣化。诚实的结论：收益上界
  63–74% 依赖模型保真，下界由证书回退保证。
- **两遍成本**：头遍编码 + 拟合增加一遍运算。对策：一遍路径用前一
  GOP 先验（GOP 间复杂度相关性高），证书监控漂移。
- 离散质量阶梯的量化把连续解投影到 ladder，损失 ≤ hull 弦 slack
  （凸性保证可界）；非凸 real-RD 时该 slack 无界——已归入模型风险
  的证书回退路径。

## 5. P5 — 缓存键完备性定理 + 依赖闭包哈希（V1.5-P1-4 / V2.0-I）

### ① 问题现状

- `crates/prism-core/src/signature.rs:452-468` `CacheDims` =
  `{width, height, spp_tier, tile, engine_version, frame}`；
  `signature.rs:473-486` `cache_key` 哈希这些维度 + 子图签名。
- 但渲染输出还依赖 `crates/prism-rt/src/integrator.rs:768`
  `RenderParams{spp, max_bounces, clamp_indirect, nee_only}`——四项
  **均不在键内**；且 `spp` 只以「档位」进键，精确值丢失。
- `crates/prism-render/src/incremental.rs` 的三维复用模型把「键相等
  ⇒ 逐字节一致」当公理式断言——**当前键不支撑该断言**。

### ② 数学结构

**缓存健全性定理**。设输出 `O = F(P)`，P 为全部渲染参数（确定性的
F）。缓存键 `k = H(π(P))`。则

```
健全 ⟺ π(P₁) = π(P₂) ⇒ F(P₁) = F(P₂)
```

即 π 必须是 F 的**充分统计量**：等价地，F 的依赖闭包
`Dep(F) = {P 中被 F 读取的分量}` 必须被 π 覆盖。逆否命题给出反例
构造法：任何 `Dep(F) \ π` 中的分量都能造出「同键不同图」——
**陈旧命中**，且返回的是似是而非的字节（最坏的失败模式：不崩溃、
只是错）。

### ③ 算法设计

1. **键结构**：`cache_key = hash(tag, schema_version, engine_version,
   subgraph_sig, dims, RenderParams_bytes, sampler_state,
   scene_sig, frame)`，其中 `RenderParams_bytes` 由
   `RenderParams::to_hash_bytes()` 产生（字段名+值逐个入哈希的显式
   实现，禁 derive 黑盒）。
2. **闭包 lint 测试**（防回归）：对 `RenderParams` 每个字段构造
   「仅该字段不同」的参数对，断言键不同；新增字段忘记入哈希时该
   测试红。同理覆盖 scene/sampler 维。
3. schema 版本随键结构 bump：旧缓存静默失效重建（宪章 C13/D-28 既有
   语义），不误复用。
4. 与 P7 联动：转场链的精确有理权重向量也入键（转场是渲染输入的
   一部分）。

### ④ 数学证明

**证 1（健全性）**。若 π 覆盖 Dep(F)，则 π(P₁)=π(P₂) ⇒ P₁ 与 P₂ 在
Dep(F) 上逐分量相同（哈希碰撞概率按 SHA-256 计，业务上忽略）⇒
F 确定性 ⇒ F(P₁)=F(P₂) ⇒ 缓存命中返回正确字节。✓

**证 2（现行键的反例）**。取同子图、同 dims、同帧，两RenderParams
仅 `max_bounces` 不同（3 vs 6）：`trace_one` 的弹射次数上界读该字段
⇒ 图像不同（间接光样本数不同）；而现行 `CacheDims` 无该字段 ⇒
`cache_key` 相同 ⇒ 第二次渲染命中第一次的字节——**陈旧命中的具体
构造**。同法适用于 `clamp_indirect`、`nee_only`、精确 `spp`
（同档不同值）。

**证 3（fail-safe 方向）**。过度入键（哈希不影响输出的量）只减少
命中、不产生错误字节；入键不足才产生错误字节。故设计规则是
「宁过勿欠」——与宪章「旧缓存静默失效」语义一致。

### ⑤ 工作量杠杆

V1.5-P1-4 与 V2.0-I 都建在这个键上；现在修，成本是几个字段 + 一个
反射式测试；等缓存系统上线后再修，成本是「silent wrongness」整类
调试（无崩溃、无日志，只有错的画面）外加一次 schema 迁移。杠杆
计量单位是**失败模式的代价**，不是代码行数。

### ⑥ 效果提升

incremental「键相等⇒逐字节一致」从假设升级为定理；V2.0-I 的
cache_manifest 生产化获得可信键；顺带消灭「同 spp 档不同 spp 值」
的隐性不命中。

### ⑦ 风险反证

- 键变大（RenderParams_bytes ~32B + scene_sig 32B）⇒ 每 tile 一次
  额外 SHA-256 输入准备；相对 tile 渲染成本可忽略，但要有基准测试
  防呆。
- `to_hash_bytes` 是手工实现，有漂移风险——由闭包 lint 测试兜底
  （证 2 的反例构造即测试体）。
- scene_sig 要求场景可序列化签名（mesh 数据大时哈希成本上升）——
  对静态场景可预算一次、随 asset 版本缓存；记录为工程注意项。

## 6. P6 — 降噪分配律修正（σ 非 σ²）+ Kalman 时域（V2.0-RQ-2 / D-2）

### ① 问题现状

- `crates/prism-postfx/src/denoise.rs:171` `allocate_spp` 按权重
  largest-remainder 分配（实现正确、确定性已测），但**文档语义是
  「variance 自适应」**——若调用方传方差 σ² 作权重，则分配
  `n_i ∝ σ_i²`，**不是** MSE 最优。
- `denoise.rs:130` `TemporalAccumulator::accumulate` 用均匀递推均值
  `acc + (cur − acc)/(n+1)`——只在各帧方差相等时最优。
- RQ-2 验收线：「同等画质采样数下降 ≥50%」。

### ② 数学结构

**分配律（Lagrange）**：`min Σσ_i²/n_i s.t. Σn_i = N`。拉格朗日
`−σ_i²/n_i² + λ = 0` ⇒ `n_i ∝ σ_i`（**标准差**，不是方差）。

**Cauchy–Schwarz 最优性下界**：
`(Σσ_i)² = (Σ√n_i·σ_i/√n_i)² ≤ (Σn_i)(Σσ_i²/n_i) = N·MSE`
⇒ `MSE ≥ (Σσ)²/N`，等号成立 ⟺ `n_i ∝ σ_i`。σ² 分配达到等号仅当
所有 σ 相等。

**削减率定理**：等分配 `MSE_eq = m·E[σ²]/N`，最优
`MSE_opt = m²E[σ]²/N` ⇒

```
MSE_eq/MSE_opt = E[σ²]/E[σ]² = 1 + CV²
采样削减率 = 1 − 1/(1+CV²)
```

CV=1（区域噪声差一倍，典型）时恰为 **50%**——正是 RQ-2 的验收线。

**Gauss–Markov / Kalman**：帧观测 `x_k = θ + ε_k`（ε_k 零均值、方差
σ_k²、互不相关）时，逆方差加权 `x̂ = Σ(x_k/σ_k²)/Σ(1/σ_k²)` 是
MMSE 最优线性估计，`Var = 1/Σ(1/σ_k²)`。递推形式：

```
K_n = V_{n−1}/(V_{n−1}+σ_n²),  x̂_n = x̂_{n−1}+K_n(x_n−x̂_{n−1}),
V_n = (1−K_n)V_{n−1} = 1/Σ_{k≤n}(1/σ_k²)
```

### ③ 算法设计

1. **分配律修正**：`allocate_spp` 权重语义改为「区域噪声**标准差**」；
   调用方传 `sqrt(方差)`（或让 allocate_spp 内部对输入开平方——二选
   一，但必须写进文档与测试，防再次误用）。largest-remainder 分配器
   本身不动（确定性已证）。
2. **Kalman 时域**：`TemporalAccumulator` 状态 `(acc, samples)` →
   `(acc, V, samples)`；σ_k² 由当帧 spp 与像素方差先验闭式给出
   （spp 来自 P6-1 的自适应预算——两个改动天然耦合）。
3. 全程 f32 乘除固定式 ⇒ 逐位确定；seek 重放语义不变（状态仍显式）。

### ④ 数学证明

**证 1（分配最优性）**。目标在各 n_i 上严格凸（`2σ_i²/n_i³ > 0`）、
约束线性 ⇒ KKT 全局最优；C-S 不等式给分布无关的最优值下界，
`n_i ∝ σ_i` 达到它。

**证 2（σ² 严格次优）**。σ² 分配 `n_i = Nσ_i²/Σσ²` 的 MSE =
`Σσ_i²/(Nσ_i²/Σσ²) = (Σσ²)²/N`；与最优 `(Σσ)²/N` 之比 =
`(Σσ²)²/(Σσ)² ≥ 1`（C-S，等号仅当所有 σ 相等）。实测
（exp4，m=8，CV=1/2）：σ² 分配 MSE 比最优高 **+22% ~ +172%**。

**证 3（削减率与 RQ-2 可达性）**。CV=1、m=32、N=2048：σ 律达等分配
画质只需 **423 spp（−79.3%）**；σ² 律需 1646 spp（**−19.6%**）——
**σ² 权重下 RQ-2 的 ≥50% 验收线不可达**。这是本提案最硬的杠杆：
不是「更好」，是「达标与不达标」的差别。

**证 4（Gauss–Markov）**。BLUE 标准定理；递推=批量的等价性由对
`V_n = 1/Σ_{k≤n}(1/σ_k²)` 的归纳给出（实测差 3.3e-16，f64 噪声）。
等方差剖面时 `K_n = 1/n`，与现行递推**逐位同式** ⇒ 无回退。

**证 5（实证）**。300 个随机 σ 剖面 × 400 实现：Kalman 经验 MSE
300/300 严格低于现行均匀均值（持平集恰为恒定 σ 剖面）；变剖面场景
（噪声递减/递增/随机）改善 55.0–80.5%。

### ⑤ 工作量杠杆

两处改动都是小手术：权重开方（1 行）+ 累积器状态加一维 f32（~10 行）。
但没有它们，RQ-2 的 P0 验收线在完整实现之后才会失败——那是路线图
上最贵的失败时序。D-2 阶段一（时域累积）已落地，本提案是其最优性
补全，不是新阶段。

### ⑥ 效果提升

同等画质采样数 −79.3%（CV=1）；时域估计 MSE −55~80%（变噪声剖面）；
恒定噪声零回退；降噪后端（SVGF 阶段二）的 spp 预算语义由此确定。

### ⑦ 风险反证

- **σ_i 估计成本**：需要区域方差先验。低成本方案：低 spp 探针帧
  （预算的 1/8）估计 + 帧间递推；诚实声明估计误差会稀释理论收益
  （削减率从 79% 向估计精度收敛），但 C-S 下界保证不会劣于等分配
  太多。
- Kalman 需要逐像素方差缓冲：累积状态从 2 个 f16 缓冲增至 3 个
  （+50% 时域内存）；可代存 `1/σ²` 于 f16（动态范围够：spp ≤ 2^24
  ⇒ 1/σ² ≤ 2^24，f16  max 65504——不够！须 f32 或对数存储。记录
  为工程约束：V 缓冲用 f32）。
- 若帧间方差实际独立同分布（静态场景），Kalman ≡ 现行（证 4），
  收益为零但无损耗——升级是免费的期权。

## 7. P7 — 转场半群 + 定点权重（V1.5-C / ADR-18）

### ① 问题现状

- `crates/prism-author/src/render.rs:1335` `mix_frame` 用 f32
  `lerp`；`render.rs:1465` `concat_with_transition` 链式拼接；
  Transition 枚举 Fade/Wipe/Dissolve/Slide。
- V1.5-C 将把这些类型下沉 `prism-core`（ADR-18）——**下沉时顺手
  换成有代数结构的实现，成本最低**；否则 f32 lerp 语义被固化成
  core 公约，日后难改。

### ② 数学结构

**半群结构**：淡混合 `F_t(A,B) = (1−t)A + tB`。定义保留分数
`k(t) = 1−t`，复合 `F_s∘F_t` 的保留分数 = `k(s)k(t)` ⇒ 复合参数
闭式 `u = s+t−st`。乘法可结合 ⇒ `{F_t}` 关于复合构成**半群**
（单位元 t=0）；经 logit 变换 `t ↦ ln(t/(1−t))` 同构于 `(ℝ,+)`
——转场参数复合是精确闭式，链式不漂移。

**有界定点表示**：值取 2^-24 网格（f32 尾数 24 位，[0,1]→u32 精确），
权重取 2^-24 网格；混合 `M = (2^24−W)A + W·B ∈ ℤ`，`0 ≤ M ≤ 2^48`
（u64 精确）。**Slide 转场 = 平移群 (ℤ²,+)**：整数像素偏移，零舍入。

### ③ 算法设计

1. `core::sceneseq`（V1.5-C 新建）内置定点混合器：输入量化到
   2^-24 网格 → u64 整数混合 → round-to-nearest 回网格。
2. 转场链状态 = 精确有理权重向量（每源帧一个 u32 权重 + 公共分母
   2^24；链长 ≤ 4 时可用 u128 保持完全精确，更长链每 4 步重归一
   化，误差 2^-25/次，有界）。
3. 权重向量入缓存键（与 P5 联动）⇒ 转场链的中间态可缓存、seek
   重放无损。
4. Wipe/Dissolve 的阈值抖动继续走 `prism-noise` 整数 hash
   （确定性不依赖 FP）。

### ④ 数学证明

**证 1（半群律）**。`k(s+t−st) = (1−s)(1−t)`（展开即得）⇒
`F_s∘F_t = F_{s+t−st}`；乘法结合律给出转场链的任意结合方式同结果。
实测 2000 组随机 (s,t,A,B,C)：链式 f32 混合与「后缀积精确权重混合」
一致（容差 1e-6）；结合律 2000 组成立；`F_0 = id`。

**证 2（定点误差界）**。单次混合误差 = 两输入量化（各 ≤ 2^-25）+
混合（整数精确）+ 输出舍入（≤ 2^-25）⇒ `≤ 3·2^-25 = 8.94e-8`。
实测 20000 组 max 7.2e-8 ≤ 界。累加器恒在网格上 ⇒ 链式不引入新的
输入量化，worst-case 误差与链长无关。

**证 3（跨端一致性）**。WGSL 允许 fma 收缩：`fma(1−t, a, t·b)` 与
分离乘加 `(1−t)·a + t·b` 实测差 ≤ 1 ulp（max 5.96e-8，中位 0）——
即同一 transition 在 CPU 与 GPU 下**逐位不同**。整数混合无收缩语义
⇒ 两端逐位一致。这对「转场也要进 GPU 合成路径」的未来是刚需。

**证 4（诚实的效果边界）**。实测 f32 链式漂移停留在 u 量级（凸组合
的舍入不相干累积，n=48 时 ~8e-9）——**精度不是本提案的主要卖点**；
卖点是 ① worst-case 界 O(1)（可证明、可写门禁）；② GPU fma 下的
跨端 bit-exactness；③ 精确有理权重可哈希、可缓存、可重放。

### ⑤ 工作量杠杆

V1.5-C 是绿地（类型下沉 + 新建 sceneseq），实现即用新语义，无迁移
成本；约 50 行。若等 author 层固化后再改，要动 `mix_frame` 全部
调用方 + 黄金基线。

### ⑥ 效果提升

链式误差 worst-case 界 O(1)；CPU/GPU 转场逐位一致；转场链中间态
可入缓存（P5 键体系直接受益）；作者 DSL 获得转场代数（`fade(fade(x,
a, t₁), b, t₂)` = `fade(x, b, t₁+t₂−t₁t₂)`，渲染器可折叠）。

### ⑦ 风险反证

- 收益是结构性的而非大幅精度提升（证 4 已诚实量化）——若团队只认
  「可测量的画质提升」，本提案应排最后。它排在 P7 正是因为如此。
- 2^-24 网格对 HDR（>1 值域）不够：须按曝光缩放或加指数位——
  记为 HDR 路径的待办，不影响 LDR 转场（当前全部用例）。
- u128 链式精确态增加实现复杂度；可降级为「每步重归一化 + 有界
  误差」方案（仍满足证 2 的界）。

## 9. 负面清单（诚实的「不做」）

1. **QMC mesh 面采样（Sobol/Owen 上车三角形采样）——不提案。**
   现有 `sampler.rs` 的 Joe–Kuo 64 维 Sobol + XOR 打散已是
   (t,m,s)-net 级；对光滑被积函数 ANOVA/Koksma 分解下 QMC 的边际
   增益落在估计噪声内。真正的方差杠杆在 P6 的分配律（−79%），不在
   采样序列升级。**工作量应花在 P6。**
2. **公式排版 max-plus 格化（tropical 代数优化字形布局）——不提案。**
   结构优雅，但当前 SDF/光栅路径已过门禁；无可测画质或确定性增益，
   净杠杆为零。
3. **Morph 接入、PH-1 物理入管线、V1.5-B 字体装载、V1.5-F 预览壳、
   ffmpeg 协作探测链——不提案。** 纯工程整合，本桌（算法）无数学
   杠杆；应由工程波次按路线图推进。
4. **「让 GPU 也逐位确定」——不提案，且反对。** D-3 已正确定案：
   GPU 浮点归约序非确定是物理性质，双门禁（语义级 parity + 输出级
   PSNR/统计）是正确框架。本报告的 P2 是**强化**该框架（给统计判据
   解析预算），不是推翻它。
5. **BVH 质量再调优（HBVH/宽 BVH/更细 SAH）——不提案。** 实测 SAH
   代价相对预排序输入无损（1.0000），构建质量已在位；进一步调优
   是 trace 时间与构建时间的权衡，与确定性目标无关，留给性能波次
   用数据决策。
6. **自研 H.264/AV1 编码器——重申不做**（D-10 已禁）。P4 的率控
   只作用于自研 MJPEG/PRMV 容器路径与「档位」决策，不越界。
